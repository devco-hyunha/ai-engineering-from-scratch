# 구조화된 출력 전략

구조화된 데이터가 필요한 LLM (대규모 언어 모델) 애플리케이션을 구축할 때, 이 의사결정 프레임워크를 적용해 보세요.

## 각 접근 방식의 사용 시점

**프롬프트 기반 ("JSON 반환"):** 프로토타입에만 사용하세요. 간헐적인 파싱 실패가 허용되는 내부 도구에서는 수용 가능합니다. try/except와 재시도를 추가하세요. 프로덕션 파이프라인에서는 절대 사용하지 마세요.

**JSON 모드 (API 플래그):** 유효한 JSON이 보장되어야 하지만 스키마가 단순하거나 유연한 경우입니다. 애플리케이션 측에서 형태를 검증할 때 작동합니다. 사용 가능: OpenAI, Anthropic (도구 사용 경유), Google.

**스키마 모드 (제약 디코딩):** 모든 출력이 특정 스키마와 일치해야 하는 프로덕션 시스템입니다. 파싱 실패가 없고 스키마 위반도 없습니다. 모든 프로덕션 추출 또는 분류 작업에 기본적으로 이 방식을 사용하세요. 사용 가능: OpenAI 구조화된 출력, Outlines, Guidance.

**함수 호출 / 도구 사용:** 모델이 매개변수를 채우는 것뿐만 아니라 호출할 함수를 선택해야 하는 경우입니다. 여러 스키마가 있고 모델이 적절한 것을 선택합니다. 기존 도구/함수 인프라와 통합할 때도 사용하세요.

**Instructor 라이브러리:** 모든 공급자에 걸쳐 Pydantic 검증과 자동 재시도를 원할 때 사용하세요. Python 프로젝트에 가장 좋은 개발 경험(DX)을 제공합니다. OpenAI, Anthropic, Google 및 오픈소스 모델을 래핑합니다.

## 공급자별 가이드

**OpenAI:** `json_schema` 타입과 함께 `response_format`를 사용하세요. 제약 디코딩이 내장되어 있습니다. Pydantic 모델이 직접 작동합니다. 가장 신뢰할 수 있는 구조화된 출력 구현입니다.

**Anthropic:** 구조화된 출력에 도구 사용을 사용하세요. 원하는 스키마를 가진 단일 도구를 정의하세요. 모델은 스키마와 일치하는 도구 호출 인자를 반환합니다. 신뢰할 수 있지만 도구 사용 API 패턴이 필요합니다.

**오픈소스 모델 (vLLM, Ollama):** 제약 디코딩을 위해 Outlines 또는 Guidance를 사용하세요. 이 라이브러리들은 JSON 스키마를 유한 상태 기계로 컴파일하여 생성 중 유효하지 않은 토큰을 마스킹합니다. 로컬에서 추론(Inference)을 실행해야 합니다.

## 스키마 설계 지침

1. 가능한 경우 스키마를 평평하게 유지하세요. 2단계 이상의 중첩된 객체는 추출 오류를 증가시킵니다.
2. 범주형 필드에는 열거형(enums)을 사용하세요. 모델이 올바른 문자열을 생성하도록 의존하지 마세요.
3. 모호한 필드는 선택적(optional)으로 두지 말고, 명시적인 null 지원을 통해 필수(required)로 만드세요. 모델이 결정을 내리도록 강제합니다.
4. 스키마 속성에 설명을 추가하세요. 모델은 이를 지침으로 읽습니다.
5. 필요하지 않은 한 유니온 타입(oneOf/anyOf)을 피하세요. 디코딩 복잡성을 증가시킵니다.
6. 숫자에 최소값/최대값을 설정하세요. 환각된 극단적 값을 잡아냅니다.
7. 배열에 minItems/maxItems를 사용하여 빈 출력이나 무한한 출력을 방지하세요.

## 일반적인 실패 패턴 및 해결 방법

- **모델이 JSON을 마크다운 울타리(fences)로 감싸는 경우**: 프롬프트 기반 방식에서 JSON 모드 또는 스키마 모드로 전환하세요
- **스키마는 유효하지만 사실적으로 잘못된 경우**: 추출 후 LLM-as-judge 검증 단계를 추가하세요
- **일관되지 않은 열거형 값**: 제약 디코딩(제약 디코딩)으로 전환하거나 후처리 정규화를 추가하세요
- **선택적 필드 누락**: 필수로 만들거나 애플리케이션 코드에 기본값을 추가하세요
- **매우 느린 추출**: 제약 디코딩은 5-15%의 지연을 추가합니다. 지연에 민감하다면 스키마 복잡성을 줄이세요
- **다양한 항목을 가진 큰 배열**: 입력을 청킹(chunking)하고 청크별로 추출한 후 결과를 병합하세요
