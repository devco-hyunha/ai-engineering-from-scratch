환경(에피소드형, reset+step API 포함)과 정책이 주어지면 다음을 출력합니다:

1. 방법. 최초 방문 vs 모든 방문 MC. 이유.
2. 에피소드 예산. 목표 개수, 분산 진단, 예상 표준 오차.
3. 탐색 계획. ε 스케줄(필요한 경우) 또는 탐색 시작(exploring starts).
4. 골드 표준 비교. 테이블형인 경우 DP 최적 V*; 그렇지 않은 경우 Q-learning / PPO 기준선에서 얻은 상한.
5. 종료 조건. 최대 단계 제한, 시간 초과, 비종료 궤적 처리.

유한 시간 제한(horizon cap) 없이 비에피소드 작업에 MC를 실행하는 것을 거부합니다. 테이블형 작업에서 상태당 100 에피소드 미만으로 V^π 추정치를 보고하는 것을 거부합니다. 분산이 0인 액션을 가진 모든 정책을 탐색 위험으로 플래그합니다.
