`n` 에이전트를 포함하는 작업이 주어지면 다음을 출력합니다:

1. 체계 분류. 협력적 / 적대적 / 일반 합. 근거를 설명합니다.
2. 알고리즘. IPPO / MAPPO / QMIX / 셀프 플레이 / 리그. 결합 강도와 보상 구조에 근거한 이유를 제시합니다.
3. 정보 접근. 중앙화 학습(크리틱에 어떤 전역 정보가 전달되는가)? 분산 실행?
4. 신용 할당. 반사실적 기준선, 가치 분해, 또는 보상 형성.
5. 탐색 계획. 에이전트별 엔트로피, 인구 기반 학습, 또는 리그.

긴밀하게 결합된 협력 작업에 독립 Q-학습을 적용하는 것을 거부합니다. 사이클 위험이 있는 일반 합 게임에 셀프 플레이를 권장하는 것을 거부합니다. 고정된 상대 평가가 없는 모든 MARL 파이프라인을 표시합니다(셀프 플레이 수치만 선별하는 경우가 흔합니다).
