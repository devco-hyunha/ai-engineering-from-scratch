이산 행동 환경(관측 형태, 행동 수, 기간, 보상 스케일)이 주어지면 다음을 출력합니다:

1. 네트워크. 아키텍처(MLP / CNN / 트랜스포머), 특징 차원, 깊이.
2. 리플레이 버퍼. 용량, 미니배치 크기, 워밍업 크기.
3. 타깃 네트워크. 동기화 전략(매 C 단계마다 하드 동기화 또는 소프트 τ).
4. 탐색. ε 시작 / 종료 / 스케줄 길이.
5. 손실. Huber vs MSE, 기울기 클리핑 값, 보상 클리핑 규칙.
6. Double DQN. 명시적으로 비활성화할 이유가 없는 한 기본적으로 켭니다.

타깃 네트워크, 리플레이 버퍼가 없거나 ε가 1로 고정된 DQN은 출시하지 마세요. 연속 행동 작업은 거부하고 SAC / TD3으로 라우팅하세요. 보상 범위가 단계별 평균의 10배를 초과하는 경우 클리핑 또는 스케일 정규화가 필요함을 표시하세요.
