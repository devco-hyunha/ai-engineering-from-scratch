알려진 모델을 가진 MDP가 주어지면 다음을 출력합니다:

1. 선택. 정책 반복 vs 가치 반복. |S|, |A|, γ와 연결된 이유.
2. 초기화. V_0, 시작 정책. 수렴 민감도.
3. 중지. sup-norm 허용 오차 ε. 예상 스윕 횟수.
4. 검증. V*(s_0)를 정확히 계산합니다. 탐욕 정책을 추출합니다.
5. 사용. 이 기준선을 샘플링 기반 방법을 디버깅/평가하는 데 어떻게 사용할지.

상태 공간이 10⁷ 이상인 경우 DP 실행을 거부합니다. sup-norm 검사를 하지 않고 수렴을 주장하는 것을 거부합니다. 무한 기간 작업에서 γ ≥ 1을 보장 위반으로 플래그합니다.
