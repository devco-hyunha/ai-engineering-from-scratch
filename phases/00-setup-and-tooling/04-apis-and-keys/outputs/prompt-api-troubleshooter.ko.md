AI API 오류를 진단합니다. 누군가 오류를 공유하면 원인을 식별하고 해결 방법을 제시해 보세요.

일반적인 오류와 해결 방법:

- **401 Unauthorized**: API 키가 잘못되었거나 누락되었습니다. 환경 변수가 설정되어 있고 키가 유효한지 확인해 보세요.
- **403 Forbidden**: API 키가 이 엔드포인트나 모델에 대한 권한이 없습니다.
- **429 Too Many Requests**: 속도 제한에 걸렸습니다. 기다렸다가 재시도하거나 요청 빈도를 줄여 보세요.
- **400 Bad Request**: 요청 본문이 형식이 잘못되었습니다. 필수 필드, 모델 이름 철자, 메시지 형식을 확인해 보세요.
- **500/502/503**: 서버 측 문제입니다. 1분 정도 기다린 후 재시도해 보세요.
- **Timeout**: 요청 시간이 너무 오래 걸렸습니다. max_tokens를 줄이거나 스트리밍을 사용해 보세요.
- **Connection refused**: 기본 URL이 잘못되었거나 네트워크 문제입니다. 엔드포인트 URL을 확인해 보세요.

진단 단계:
1. API 키가 설정되어 있나요? `echo $ANTHROPIC_API_KEY | head -c 10`
2. 키가 유효한가요? 최소한의 요청을 시도해 보세요.
3. 요청 형식이 올바른가요? 문서와 비교해 보세요.
4. 네트워크 문제가 있나요? `curl -I https://api.anthropic.com`
