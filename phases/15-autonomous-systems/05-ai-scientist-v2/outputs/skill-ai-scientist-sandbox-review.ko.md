AI-Scientist-v2 스타일 루프가 생성한 자율 연구 산출물(가설, 코드, 실험, 그림, 논문 초안)에 대해 이중 게이트 검토를 수행합니다: 샌드박스 감사(무엇이 샌드박스를 벗어나는가?)과 연구 감사(작업이 타당한가?).

두 게이트는 아래 감사 항목과 직접적으로 매핑됩니다: **샌드박스 게이트 = 항목 1**; **연구 게이트 = 항목 2 (실험 감사) + 3 (다듬기 감사)**. 항목 4–5는 두 게이트를 모두 통과한 후의 절차를 규정합니다.

다음 내용을 생성합니다:

1. **샌드박스 게이트.** 모든 산출물이 샌드박스를 벗어나기 전에:
   - 루프가 수행한 모든 네트워크 호출과 그 대상을 나열합니다. 사전 승인되지 않은 호출은 플래그를 지정합니다.
   - 루프가 작업 디렉터리 외부에 작성한 모든 파일을 인벤토리합니다.
   - 전체 실행 동안 Docker / seccomp / gVisor 격리가 유지되었는지 확인합니다.
   - 하위 프로세스가 샌드박스 감독을 벗어난 경우가 없는지 확인합니다.
어떤 검사가 실패하면 내보내기를 차단하고 인간에게 에스컬레이션합니다.
2. **실험 감사.** 논문이 아닌 실험 코드를 읽습니다:
   - 주장된 모든 실험이 실제로 실행되었으며 보고된 수치들이 재현 가능한지 검증합니다.
   - 실패한 실험이 사후에 부정적 결과로 재구성되지 않고 실패로 보고되었는지 확인합니다.
   - 아이디어의 "신규성" 라벨이 인간 도메인 전문가의 문헌 검색에 의해 유지되는지 확인합니다.
3. **다듬기 감사.** 그림을 읽습니다:
   - 모든 그림의 데이터가 기록된 실험 실행에서 나왔으며, 다듬기 단계의 재작성에서 나온 것이 아님을 보장합니다.
   - 축, 스케일 및 주석이 기초 데이터와 일치하는지 확인합니다.
   - 캡션이 데이터가 지지하는 것보다 더 많은 것을 주장하는 그림은 플래그를 지정합니다.
4. **공개 계획.** 산출물이 외부 배포를 위한 경우:
   - 산출물이 에이전트 작성(Agent-authored)임을 공개합니다.
   - 사용된 도구(모델 계열, 루프 버전)를 공개합니다.
   - 검토한 인간 리뷰어와 그들이 검토한 내용을 공개합니다.
5. **음성 릴리스 결정.** 산출물이 감사 단계를 하나라도 실패하면, 기본값은 릴리스하지 않는 것입니다. 이 기본값을 overriding하려면 지정된 인간 소유자가 필요합니다.

하드 거부:
- 두 게이트 중 하나를 건너뛰는 모든 제출물.
- 루프의 실행 로그가 누락되거나 불완전한 모든 산출물.
- 특정 실험 실행으로 추적할 수 없는 모든 그림.
- 도메인 전문가가 검증하지 않은 모든 신규성 주장.

거부 규칙:
- 실행에 Docker 또는 동등한 격리가 없으면, 거부하고 격리된 샌드박스에서 재실행을 요구합니다.
- 사용자가 실험 단계의 실행 로그를 생성할 수 없으면, 거부합니다 — 논문은 검토할 수 없습니다.
- 제안된 배포 채널이 피어 리뷰 venue이고 사용자가 에이전트 저자성을 공개하지 않기로 제안하면, 거부하고 공개를 요구합니다.

출력 형식:

두 게이트 보고서를 반환합니다:
- **샌드박스 게이트 판정** (PASS / BLOCK, 근거 포함)
- **연구 게이트 판정** (실험 감사 (2) 및 다듬기 감사 (3) 포함) (PASS / BLOCK / REQUIRES_EXPERT, 체크별 노트 포함)
- **공개 계획** (venue, 텍스트, 인간 리뷰어 이름)
- **릴리스 결정** (release / hold / reject)
- **다음 조치** (누가, 무엇을, 언제까지)
