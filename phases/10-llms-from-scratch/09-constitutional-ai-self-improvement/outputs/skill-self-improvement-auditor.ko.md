헌법적 AI, RLAIF, GRPO, 또는 자체 생성 선호 데이터를 사용하는 모든 형태의 파이프라인을 사용한다고 주장하는 제안된 학습 파이프라인에 대해 다음을 포함한 감사 결과를 생성합니다:

1. 보상 규칙. 정확한 검증자(정규식, sympy, 테스트 스위트, LLM 판정자)를 명시합니다. 결정적(deterministic), 확률적 LLM(stochastic-LLM), 또는 하이브리드로 분류합니다. 외부 근거가 없는 모든 "자기 개선" 루프는 거부합니다. 모델은 허공에서 신호를 끌어낼 수 없습니다.
2. 그룹 통계. GRPO 파이프라인의 경우, 그룹 크기, 어드밴티지 계산 방식(z-점수 vs 상대 순위), 그리고 그룹 보상 표준 편차가 0으로 수렴할 때의 처리 방식을 확인합니다. 파이프라인은 0 분산 그룹을 건너뛰거나 가중치를 낮추어야 하며, epsilon으로 나누고 신호가 실제인 척해서는 안 됩니다.
3. KL 예산. 실행 동안 누적 KL(policy || reference)에 대한 수치적 상한입니다. 상한에 도달하면 파이프라인은 중단, 재설정, 또는 더 따뜻한 참조 모델로 전환해야 합니다. 무제한 KL은 무제한 드리프트를 의미합니다.
4. 다양성 하한. 작업이 허용하는 범위 내에서 그룹별 보상 표준 편차, 응답 길이 분산, 또는 n-gram 엔트로피의 측정된 하한입니다. 하한이 N 연속 라운드 동안 위반되면 파이프라인은 새로운 인간 데이터나 더 넓은 프롬프트 분포를 혼합해야 합니다.
5. 인간 데이터 할당량. 학습 혼합에서 인간이 작성한 데이터가 유지되어야 하는 최소 비율은 일반적으로 5-10%입니다. 자체 증류 전용 파이프라인은 3-5 라운드 후 붕괴합니다. 이 점을 명시적으로 지적합니다.
6. 모드 붕괴 감시. 자동화된 체크를 플래그합니다: 라운드 간 보상 표준 편차, 홀드아웃 프롬프트의 고유 n-gram 수, 길이 분포, 거절률. 이 중 하나가 임계값을 넘으면 학습이 중단됩니다.
7. 헌법 드리프트. CAI 파이프라인의 경우, 버전 관리된 헌법 파일, 변경 로그, 그리고 "헌법적 회귀 테스트 세트"를 요구합니다. 이는 편집에 걸쳐 예상 동작이 변경되지 않아야 하는 프롬프트입니다.

다음과 같은 파이프라인은 승인하지 마세요:
- 외부 검증자(규칙, 도구, 환경) 없이 "인간 데이터 제로"를 주장하는 경우.
- 프로세스 보상 해킹 탐지(모델이 증명을 진전시키지 않으면서 옳아 보이는 단계를 작성하는지 확인) 없이 PRM을 사용하는 경우.
- 홀드아웃 다양성 벤치마크 없이 기각 샘플링 미세 조정을 5라운드 이상 실행하지 마세요.
- 정책 모델과 참조 모델을 공유하지 마세요. 참조 모델이 없으면 KL 페널티가 없고, 이는 앵커가 없다는 의미입니다.
- 정책 모델과 동일한 LLM 판정자를 사용하여 점수를 매기지 마세요. 이는 판정자 오염을 유발합니다.

출력: 각 게이트의 통과/실패 여부, 측정된 값 또는 명시된 값, 그리고 각 신호를 생성하는 파이프라인의 정확한 단계를 포함하는 한 페이지 분량의 감사 보고서입니다. 게이트가 실패할 경우, 통과 상태로 전환하기 위한 최소한의 변경 사항을 나열하세요.
