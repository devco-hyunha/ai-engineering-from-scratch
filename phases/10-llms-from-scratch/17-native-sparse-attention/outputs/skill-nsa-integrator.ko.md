긴 컨텍스트 사전 학습 실행 사양(목표 컨텍스트, 기본 아키텍처, 사용 가능한 학습 토큰, GPU 토폴로지, 배포 대상)이 주어지면, NSA 통합 계획을 작성해 보세요.

다음 내용을 산출합니다:

1. 압축 블록 크기 `l`. 32, 64, 또는 128 중 하나를 선택합니다. 목표 컨텍스트에 대한 근거를 제시합니다: `l = 32`는 16k-32k, `l = 64`는 64k-128k, `l = 128`는 256k 이상에 적합합니다. `l`가 크면 압축된 키의 개수는 줄어들지만 라우팅 신호는 거칠어집니다.
2. Top-k 선택 개수. 08강 32 사이에서 선택합니다. 논문 기본값은 16입니다. 목표 작업 조합에 대한 근거를 제시합니다: 추론 중심 작업(수학, 코드)은 선택 정밀도가 더 중요하므로 높은 `k`가 유리합니다. 검색 중심 작업은 낮은 `k`에서도 잘 작동합니다.
3. 슬라이딩 윈도우 `W`. 256, 512, 또는 1024 중 하나를 선택합니다. 기본값은 512입니다. 지역 컨텍스트가 충분한 구조화된 콘텐츠(코드)에는 짧게, 산문에는 길게 설정합니다.
4. 게이트 MLP. 너비와 초기화를 지정합니다. 기본값: `hidden`에서 3으로 가는 선형 레이어이며, `sigmoid` 또는 `softplus` 활성화 함수를 사용합니다. 게이트 가중치가 한 가지 분기를 선호하도록 붕괴되면 경고합니다. 이는 `l`, `k`, 또는 `W`가 잘못 튜닝되었음을 나타냅니다.
5. 커널 선택. 목표 가속기에서 Triton 또는 CUDA 커널 가용성을 확인합니다. 추론 시 밀집 어텐션으로의 폴백을 거부합니다(NSA의 핵심은 디코딩 연산을 절약하는 것입니다). 순방향 커널만 있고 역방향 커널이 없다면 사전 학습을 거부하고, 기존 밀집 체크포인트에서 계속 학습할 것을 권장합니다.

하드 거부 조건:
- 밀집 어텐션으로 사전 학습된 모델에 NSA를 적용하는 경우, 계속 사전 학습이 필요합니다. 추론 시에 붙일 수 없습니다.
- 목표 컨텍스트가 16k 미만인 경우. 세 분기의 오버헤드가 지배적입니다.
- NSA 커널 지원이 없는 스택에서의 추론 전용 배포. 대신 MLA 또는 슬라이딩 윈도우 어텐션을 권장합니다.

거부 규칙:
- 긴 컨텍스트 평가 데이터(RULER, LongBench, needle-in-haystack)가 없다면, 거부하고 먼저 보정 데이터를 요청합니다.
- 학습 데이터의 컨텍스트 분포가 짧은 시퀀스로 지배된다면, NSA를 통합하기 전에 데이터 재가중을 권장하며 이를 거부해 보세요.
- 가속기가 A100보다 오래된 경우, 거부해 보세요. NSA의 커널 이점은 H100/H200/MI300 메모리 계층을 전제로 합니다.

출력: `l`, `k`, `W`, 게이트 구성, 커널 경로, 목표 컨텍스트에서의 예상 연산 절감량을 나열한 한 장의 통합 계획을 작성해 보세요. "성공 기준" 단락으로 마무리하세요. NSA를 유지할 근거가 되는 특정 RULER 또는 LongBench 수치(밀집 어텐션 기준선 대비 백분율 포인트)를 명시하세요. 롤백 트리거도 포함하세요. 이 지표가 임계값 아래로 떨어지면 아키텍처를 MLA 또는 밀집 GQA로 되돌려야 합니다.
