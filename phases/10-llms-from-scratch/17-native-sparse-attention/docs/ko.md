# 네이티브 희소 어텐션 (DeepSeek NSA)

> 64k 토큰에서 어텐션은 디코딩 지연의 70-80%를 차지합니다. 모든 오픈 모델 연구실은 이를 해결하기 위한 계획을 가지고 있습니다. DeepSeek의 NSA (ACL 2025 최우수 논문)는 성공적으로 정착한 방법입니다: 압축된 coarse-grained 토큰, 선택적으로 유지된 fine-grained 토큰, 그리고 지역적 컨텍스트를 위한 슬라이딩 윈도우라는 세 개의 병렬 어텐션 브랜치를 학습된 게이트를 통해 결합합니다. 이는 하드웨어 정렬(kernel-friendly)되어 있으며, 네이티브로 학습 가능하고(추론 시 붙여 넣는 것이 아니라 사전 학습에서 작동), 64k 디코딩에서는 FlashAttention보다 빠르게 실행되면서 전체 어텐션의 품질과 일치하거나 이를 능가합니다. 이 강의는 세 개의 브랜치를 엔드투엔드로 구축하고, 희소성이 엔드투엔드로 미분 가능한 이유를 보여줍니다.

**유형:** Build
**언어:** Python (stdlib)
**선수 요건:** 7단계 · 12강 (KV 캐시, flash-attention), 7단계 · 15강 (어텐션 변형), 10단계 · 16강 (차분 어텐션)
**시간:** 약 60분

## 문제점

시퀀스 길이 N에서의 전체 어텐션은 `O(N^2)` 시간과 `O(N)` KV 캐시를 레이어당 소모합니다. 64k 토큰에서는 연산 및 메모리 대역폭 수치가 치명적입니다. NSA 논문에서 측정된 이론적 추정치에 따르면, 64k에서 어텐션은 총 디코딩 지연의 70-80%를 차지합니다. TTFT, 초당 토큰 수, 백만 토큰당 비용 등 모든 후속 지표는 어텐션 비용에 의해 지배됩니다.

희소 어텐션은 명백한 해답입니다. 이전 시도들은 두 가지 범주로 나뉩니다. 고정 패턴 희소성(슬라이딩 윈도우, 스트라이드, 블록 지역)은 정보를 버리고 장거리 재현 작업에서 실패합니다. 추론 시간 희소성(KV 캐시 가지치기, H2O, StreamingLLM)은 밀집 어텐션으로 사전 학습된 모델에 적용되며, 모델이 희소 패턴을 통해 정보를 라우팅하도록 요청받지 않았기 때문에 잠재적 속도 향상의 일부만 회복합니다.

네이티브 희소 어텐션(Native Sparse Attention, Yuan et al., DeepSeek + PKU + UW, ACL 2025 최우수 논문, arXiv:2502.11089)은 두 가지를 모두 수행합니다. 사전 학습 중에 모델이 학습하는 희소 패턴을 커널 정렬된 알고리즘으로 구현하여 추론 시 실제 연산 절감을 달성합니다. 2년 후, NSA 또는 그 직접적인 후손은 모든 프론티어 장문 컨텍스트 모델의 기본 어텐션이 될 것입니다.

## 개념

### 세 개의 병렬 분기

각 쿼리에 대해, NSA는 KV 캐시의 세 가지 다른 뷰에 대해 어텐션을 세 번 실행합니다:

1. **압축 분기.** 토큰은 크기 `l` (일반적으로 32 또는 64)의 블록으로 그룹화됩니다. 각 블록은 작은 학습된 MLP를 통해 단일 요약 토큰으로 압축됩니다. 쿼리는 이러한 압축된 토큰에 대해 어텐션하여 전체 시퀀스의 거시적(coarse-grained) 뷰를 얻습니다.

2. **선택 분기.** 압축 분기의 어텐션 점수를 사용하여 현재 쿼리와 가장 관련성이 높은 상위 k개 블록을 식별합니다. 해당 블록의 세밀한(fine-grained, 압축되지 않은) 토큰을 읽고 쿼리가 그 모든 토큰에 대해 어텐션합니다. 압축 분기 어텐션을 선택을 위한 라우팅 신호로 생각하세요.

3. **슬라이딩 윈도우 분기.** 쿼리는 지역 컨텍스트를 위해 가장 최근 `W` 토큰(일반적으로 512)에 대해 어텐션합니다. 이 분기는 다른 두 분기가 놓칠 수 있는 구조가 많은 단거리 패턴(구문, 지역 참조)을 포착합니다.

세 분기의 출력은 학습된 위치별 게이트를 통해 결합됩니다:

```
out = g_cmp * out_cmp + g_sel * out_sel + g_win * out_win
```

`g_cmp, g_sel, g_win`는 쿼리에 대한 작은 MLP에서 나온 게이트 가중치입니다. 합이 1이 될 필요는 없으며, 분기를 독립적으로 가중할 수 있습니다.

### 이것이 "네이티브 학습 가능(natively trainable)"인 이유

선택 단계(top-k 블록)는 이산적입니다. 이산 연산은 기울기 흐름을 끊습니다. 이전의 희소 어텐션(sparse-attention) 연구는 선택 단계에 대한 역전파를 생략하여 학습을 제한하거나, 추론 시 실제 희소성을 제공하지 못하는 연속적 완화 기법을 사용했습니다.

NSA는 이 문제를 우회합니다. 압축 브랜치 압축 브랜치(compressed-branch)의 어텐션은 전체 시퀀스에 대한 미분 가능한 coarse-grained 어텐션입니다. top-k 연산은 압축 브랜치에서 얻은 상위 어텐션 점수를 재사용하여 로드할 fine-grained 블록을 선택합니다. 기울기는 압축 브랜치 점수를 통해 흐르며(이 점수는 압축 출력과 선택 로직 모두에 영향을 미침), 선택된 블록이 최종 출력에 기여하는 부분도 미분 가능합니다. 미분 불가능한 `top_k` 연산은 순방향 계산 그래프에서 no-op이며, 메모리에서 어떤 블록을 로드할지 제어하는 역할만 수행합니다.

이 때문에 NSA는 사전 학습(pre-training)에서 end-to-end로 사용될 수 있습니다. 모델은 세 브랜치를 통해 정보를 jointly 라우팅하는 법을 학습하며, 추론 시 약속된 속도 향상을 실제로 달성하는 희소 패턴을 생성합니다.

### 하드웨어 정렬된 커널

NSA의 커널은 현대 GPU 메모리 계층을 위해 설계되었습니다. 커널은 GQA 그룹별로 쿼리를 로드하고(외부 루프), 각 그룹에 해당하는 희소 KV 블록을 가져오며(내부 루프), SRAM에서 어텐션을 실행합니다. 선택이 쿼리 헤드가 아닌 쿼리 그룹 단위로 이루어지므로 각 쿼리 그룹은 동일한 선택된 블록을 보게 되며, KV 로드는 그룹 전체에 걸쳐 상각(amortized)됩니다. 연산 강도(arithmetic intensity)는 높게 유지됩니다.

논문에서는 64k 디코딩 시 FlashAttention보다 9배 빠른 Triton 커널을 보고하며, 시퀀스 길이가 증가함에 따라 속도 향상 비율도 증가한다고 보고합니다. 순방향 및 역방향 커널이 모두 제공됩니다.

### 연산 예산

`N`를 시퀀스 길이, `l`를 압축 블록 크기, `k`를 top-k 선택 개수, `w`를 슬라이딩 윈도우, `b`를 선택된 블록 크기(일반적으로 `l`와 동일)라고 합시다.

- 압축 브랜치: 쿼리당 `O(N/l)`개의 키, 따라서 총 `O(N * N / l)`개입니다.
- 선택 브랜치: 쿼리당 `O(k * b)`개의 키, 따라서 `O(N * k * b)`개입니다.
- 슬라이딩 브랜치: 쿼리당 `O(w)`개의 키, 따라서 `O(N * w)`개입니다.

총합: `O(N * (N/l + k*b + w))`입니다.

`N = 64k, l = 64, k = 16, b = 64, w = 512`을 사용하면 쿼리당 비용은 `1000 + 1024 + 512 = 2536 keys`입니다. 전체 어텐션은 `64000 keys`입니다. 연산량이 25배 감소합니다.

`N = 128k, l = 64, k = 16, b = 64, w = 512`을 사용하면 쿼리당 비용은 `2000 + 1024 + 512 = 3536 keys`입니다. 전체 어텐션은 `128000 keys`입니다. 36배 감소합니다. 시퀀스 길이가 길어질수록 이점이 커지며, 이것이 핵심입니다.

## 구현하기

`code/main.py`은 짧은 합성 시퀀스에서 세 가지 분기를 구현하며 다음을 보여줍니다:

- 압축 MLP (교육적 명확성을 위해 단순한 평균 풀링 기준선을 사용하며, 실제 NSA는 학습된 MLP를 사용합니다).
- 압축 분기 점수에 의해 구동되는 Top-k 블록 선택.
- 마지막 `w` 토큰에 대한 슬라이딩 윈도우 어텐션.
- 게이트 결합.
- 전체 어텐션과 비교하는 연산량 출력.

### 1단계: 토큰을 블록으로 압축

```python
def compress(K, l):
    n = len(K)
    n_blocks = (n + l - 1) // l
    out = []
    for b in range(n_blocks):
        start, end = b * l, min((b + 1) * l, n)
        block = K[start:end]
        summary = [sum(row[d] for row in block) / len(block) for d in range(len(K[0]))]
        out.append(summary)
    return out
```

### 2단계: 압축 분기 어텐션

쿼리를 압축된 키에 대해 Softmax 어텐션을 실행합니다. 압축 분기 점수는 Top-k 선택을 위한 신호로도 사용됩니다.

### 3단계: Top-k 블록 선택

가장 높은 점수를 받은 압축 블록 `k`개의 인덱스를 선택합니다. 해당 블록에서 원본 비압축 토큰을 로드하고 어텐션을 실행합니다.

### 4단계: 슬라이딩 윈도우 어텐션

마지막 `w` 토큰을 가져와 표준 어텐션을 실행합니다.

### 5단계: 게이트 + 결합

쿼리에 작은 MLP를 적용하면 세 개의 게이트 가중치가 생성됩니다. 최종 출력은 세 가지 브랜치 출력의 가중 합입니다.

### 6단계: 계산량 산출

각 브랜치에서 쿼리당 어텐션된 키의 개수와 총합을 출력하세요. `N` (풀 어텐션)과 비교해 보세요. `l = 32, k = 4, w = 128`을 사용하는 1024 토큰 합성 데이터에서 NSA는 쿼리당 `32 + 128 + 128 = 288`개의 키를 봅니다. 이는 풀 어텐션의 1024개보다 3.5배 적습니다.

## 사용하기

NSA는 DeepSeek 자체의 긴 컨텍스트 사전 학습 파이프라인에 출시되었습니다. 2026년 4월 기준 공개 추론 스택에서의 통합 상태는 다음과 같습니다:

- **DeepSeek 내부**: 네이티브 지원. 공개된 가중치는 NSA 또는 그 후속인 DSA (Deepseek Sparse Attention)를 사용합니다.
- **vLLM**: DeepSeek-V3.x 가중치를 위한 실험적 NSA 지원이 개발 중입니다.
- **SGLang**: NSA 벤치마크가 공개되었습니다. 프로덕션 경로는 vLLM을 따릅니다.
- **llama.cpp / CPU**: 지원되지 않습니다. CPU 처리량에서는 커널 분해의 오버헤드가 가치 있는 이점을 제공하지 못합니다.

NSA를 선택해야 하는 경우:

- 64k 이상의 긴 컨텍스트를 목표로 하는 사전 학습 또는 지속 학습 실행으로, 상당한 컴퓨팅 예산이 확보된 경우.
- DeepSeek 자체의 긴 컨텍스트 체크포인트 추론. 가중치가 NSA 네이티브인 경우.

NSA를 선택하지 않아야 하는 경우:

- 기존 밀집 어텐션 사전 학습 모델을 서빙하는 경우. 지속 학습 없이 NSA를 retrofit할 수 없습니다.
- 컨텍스트가 16k 미만인 경우. 세 브랜치의 오버헤드가 절감 효과를 압도합니다.
- 배치 크기 1의 대화형 채팅. 지연 시간에 민감한 디코딩은 이점을 얻지만, 긴 컨텍스트에서만 유효합니다.

## 출시하기

이 강의는 `outputs/skill-nsa-integrator.md`을 생성합니다. 긴 컨텍스트 사전 학습 실행 사양이 주어지면, NSA 통합 계획을 생성합니다. 여기에는 압축 블록 크기, top-k, 슬라이딩 윈도우, 게이트 MLP 너비, 커널 선택, 그리고 아키텍처 변경을 정당화할 특정 긴 컨텍스트 평가가 포함됩니다.

## 연습 문제

1. 1024 토큰 합성 데이터에서 `code/main.py`을 실행하세요. 세 가지 프리셋에 걸쳐 `(l, k, w)`을 스윕(sweep)하고 계산량을 출력하세요. haystack 속의 바늘(needle-in-haystack) 테스트에서 풀 어텐션 대비 95%의 재현율을 유지하면서 쿼리당 키 개수를 최소화하는 프리셋을 식별하세요.

2. 평균 풀링 압축기를 작은 학습된 MLP (2층, 은닉 32)로 교체하세요. 블록의 평균이 신호인 합성 작업으로 학습하세요. 유지된 데이터에서 평균 풀링 기준선 대비 퍼플렉시티 격차를 측정하세요.

3. 게이트 MLP를 구현하세요. 쿼리를 입력으로 받아 세 개의 스칼라를 출력합니다. 게이트가 합리적으로 동작함을 보이세요: 랜덤 쿼리에서는 거의 균일한 가중치를 부여하고, 쿼리가 먼 과거 블록에 도달할 때는 선택된 가지에 큰 가중치를 부여합니다.

4. 128k 컨텍스트에서 NSA가 활성화된 70B 모델의 KV 캐시 메모리 예산을 계산하세요. KV 헤드는 8, 헤드 차원 128, BF16입니다. 전체 어텐션 및 MLA와 비교하세요 (10단계 14강에서 MLA의 수치를 보여 주었습니다). NSA의 세밀한 가지 KV 캐시가 전체 어텐션과 동일해지는 시퀀스 길식을 식별하세요.

5. NSA 논문 (arXiv:2502.11089)의 4장을 읽고, 압축 가지의 어텐션 점수가 별도의 라우팅 점수를 계산하는 대신 top-k 선택에 재사용되는 이유를 세 문장으로 설명하세요. 답을 기울기 흐름과 연결하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| 압축 가지 | "거시적 관점" | 쿼리당 O(N/l) 키로 전역 컨텍스트를 제공하는 블록 평균 키에 대한 어텐션 |
| 선택된 가지 | "Top-k 블록" | 압축 가지 점수가 가장 높은 `k` 블록에 대한 세밀한 어텐션 |
| 슬라이딩 윈도우 | "지역 컨텍스트" | 짧은 범위 패턴을 위해 마지막 `W` 토큰에 대한 어텐션 |
| 네이티브 학습 가능성 | "희소성을 켠 상태로 사전 학습" | 희소성 패턴은 추론 시에 붙여지는 것이 아니라 사전 학습 중에 학습됨 |
| 압축 블록 크기 l | "거시적 관점의 그룹 크기" | 몇 개의 토큰이 하나의 요약으로 병합되는지; 일반적으로 32-64 |
| Top-k | "유지할 블록" | 비압축 토큰이 읽히는 압축 블록의 수; 일반적으로 16 |
| 슬라이딩 윈도우 W | "지역 어텐션 반경" | 일반적으로 512; 짧으면 지역 일관성이 손상되고, 길면 연산이 낭비됨 |
| 가지 게이트 | "세 가지를 혼합하는 방법" | 세 가지 가지의 기여도에 가중치를 부여하는 위치별 MLP 출력 |
| 하드웨어 정렬 | "커널 친화적 희소성" | 실제 GPU 커널이 이론적 가속을 달성하도록 선택된 희소 패턴 |
