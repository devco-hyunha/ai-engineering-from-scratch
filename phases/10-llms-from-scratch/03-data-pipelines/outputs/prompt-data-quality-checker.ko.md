# LLM 사전 학습용 데이터 품질 검사기

LLM 사전 학습용 데이터 파이프라인을 구축하거나 감사할 때, 문제가 모델에 도달하기 전에 이를 포착하기 위해 이 프레임워크를 사용해 보세요.

## 파이프라인 출력의 위험 신호

**중복 제거가 웹 데이터의 20% 미만을 제거했습니다.** Common Crawl은 일반적으로 30-40%의 중복을 포함합니다. 중복 제거 단계가 20% 미만을 제거한다면, MinHash 매개변수가 너무 보수적이거나 임계값이 너무 높습니다. 다음을 확인하세요: shingle 크기 k, 해시 함수 수, LSH 밴드 수, Jaccard 임계값.

**압축률이 토큰당 2.0자 미만입니다.** 이는 토크나이저가 너무 공격적으로 분할하고 있음을 의미합니다. 더 많은 병합으로 재학습하거나, 어휘 크기를 늘리거나, 사전 토큰화가 텍스트를 불필요하게 파편화하지 않는지 확인하세요.

**압축률이 토큰당 6.0자 초과입니다.** 토크나이저가 매우 도메인 특화된 병합을 학습하여 일반화되지 않을 수 있습니다. 도메인 특화 모델에는 문제가 없지만, 범용 모델에는 경고 신호입니다.

**시퀀스 활용률이 90% 미만입니다.** 패딩이 너무 많습니다. 문서가 매우 짧아서(필터링하거나 최소 문서 길이를 늘리세요) 시퀀스 패킹이 비효율적일 수 있습니다(나이브 패딩에서 다중 문서 패킹으로 전환하세요).

**어휘 활용률이 50% 미만입니다.** 어휘의 절반 이상이 이 코퍼스에서 사용되지 않습니다. 어휘가 도메인에 비해 너무 크거나, 토크나이저가 매우 다른 데이터로 학습되었을 수 있습니다.

## 품질 필터 보정

각 파이프라인 단계에서 1,000개 문서의 랜덤 샘플에 대해 다음 검사를 수행하세요:

1. **청소 후 랜덤 문서 20개를 읽어보세요.** 잔여 HTML, JavaScript, 내비게이션 텍스트, 또는 boilerplate가 포함되어 있나요? 그렇다면 HTML 제거가 불완전합니다.

2. **품질 필터를 통과한 랜덤 문서 20개를 읽어보세요.** 스팸, 키워드 목록, 또는 기계 생성 텍스트가 있나요? 그렇다면 필터 임계값을 강화하세요.

3. **품질 필터에 실패한 무작위 문서 20개를 읽어 보세요.** 그중 실제로 좋은 콘텐츠가 있나요? 있다면, 필터가 너무 공격적입니다. 임계값을 완화하거나 특정 패턴에 대한 예외를 추가해 보세요.

4. **중복 제거(dedup)에서 무작위 유사 쌍 20개를 읽어 보세요.** 실제로 유사한가요? 유사하지 않다면, 자카드(Jaccard) 임계값을 낮추거나 해시 함수의 수를 늘려 보세요.

## 데이터 혼합 비율

보편적인 공식은 없습니다. 아래 기준선으로 시작하여 평가 결과에 따라 조정하세요:

| 카테고리 | Llama 3 비율 | 시작점 |
|----------|--------------|----------------|
| 웹 텍스트 | 50% | 50% |
| 코드 | 25% | 15-25% |
| 도서/학술 | 13% | 10-15% |
| 수학 | 8% | 5-10% |
| 다국어 웹 | 4% | 5-10% |

모델이 프로그래밍에 강해야 한다면 코드 비율을 높여 보세요. 추론이 중요하면 수학 비율을 높여 보세요. 노이즈가 적어야 한다면 웹 비율을 낮추세요. 비율을 변경한 후에는 항상 벤치마크로 평가하세요.

## 확장 추정

목표 토큰 수에 대해:

- 웹에서 1T 토큰: 원시 텍스트 약 3-5TB, 정제 및 중복 제거 후 약 1.5-2TB 예상
- 토큰화 속도 (Rust): 코어당 초당 약 100M 토큰
- 토큰화 속도 (Python): 코어당 초당 약 1-10M 토큰
- 128개 해시, 16개 밴드에서의 MinHash 중복 제거: 코어당 초당 약 10K 문서
- 시퀀스 패킹: I/O 바운드, 10GB 이상의 코퍼스에 메모리 매핑 파일 사용

15T 토큰(Llama 3 규모)의 경우, 원시 입력 데이터 약 30-50TB, 64코어 머신에서 1-2주간의 전처리, 그리고 중간 파일을 위한 100TB 이상의 디스크 공간을 계획하세요.

## 학습 전 체크리스트

1. 총 토큰 수가 컴퓨팅 예산과 일치합니다 (Chinchilla 확장 법칙이나 Llama 3의 과학습 비율을 가이드로 사용하세요)
2. 중복 제거가 웹 데이터의 30-40%를 제거했습니다
3. 품질 필터가 남은 데이터의 10-20%를 제거했습니다
4. 영어의 압축 비율이 토큰당 3-5자입니다
5. 시퀀스 활용률이 95% 이상입니다
6. 무작위 표본 검사가 모든 파이프라인 단계에서 깨끗하고 일관된 텍스트를 보여줍니다
7. 데이터 혼합 비율이 소규모 학습 실행에서 검증되었습니다
8. PII 제거가 샘플에서 검증되었습니다
9. 모든 바이너리 형식(압축된 시퀀스, 토큰 ID 배열)이 왕복 인코딩/디코딩 테스트를 통과합니다
10. 파이프라인은 재현 가능합니다: 고정된 랜덤 시드를 사용하면 동일한 입력이 동일한 출력을 생성합니다
