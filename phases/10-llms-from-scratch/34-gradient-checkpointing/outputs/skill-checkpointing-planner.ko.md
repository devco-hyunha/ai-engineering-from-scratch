훈련 구성(레이어 수 L, 은닉 크기 d, 시퀀스 길이 S, 마이크로배치 B, 값당 dtype 바이트 수, 어텐션 커널, 텐서 병렬화(Tensor Parallelism) 정도 TP, 파이프라인 병렬화(Pipeline Parallelism) 정도 PP, MoE인 경우 전문가 병렬화(Expert Parallelism) 정도 EP)와 가중치 및 옵티마이저(Optimizer) 상태 이후의 랭크별 HBM 예산을 입력으로 받아 다음을 출력합니다:

1. 레이어별 정책. 스택의 각 레이어 계열(임베딩(Embedding), 어텐션(Attention), FFN, MoE 전문가, 정규화(Normalization), 출력 헤드)에 대해 없음, 선택적, 전체, 오프로드 중 하나를 선택합니다. S가 4_096을 초과하는 경우 어텐션에 대해 기본적으로 선택적 정책을 적용합니다. 잔차 스트림과 정규화(Normalization)에 대해서는 기본적으로 없음 정책을 적용합니다. FFN에 대해서는 해당 레이어의 활성화에 대한 측정된 PCIe 전송 시간이 측정된 재계산 시간보다 짧은 경우에만 오프로드 정책을 기본으로 적용합니다.
2. 세그먼트 크기 k. 전체 체크포인팅(Checkpointing)이 활성화된 경우, 균일한 레이어 비용을 위해 k를 round(sqrt(L))로 선택합니다. 활성화 메모리가 예산을 지배하는 경우 더 작은 k를 선택합니다. 추가 FLOP 비율은 forward FLOPs의 (1/k)로 보고합니다.
3. FlashAttention 상호작용. 어텐션 커널이 이미 softmax를 재계산하는지 확인합니다. 만약 그렇다면, 선택적 어텐션 체크포인팅(Checkpointing)은 효과가 거의 없으므로 없음 정책으로 낮추세요. 커널을 이름으로 명시하세요(FlashAttention-2/3, xFormers 메모리 효율적, vanilla).
4. TP / PP 계획. TP의 경우, 재계산 시 gather 또는 rescatter가 필요한 활성화와 단계별 추가 통신 바이트 수를 명시합니다. PP의 경우, 역방향 마이크로배치가 활성화 메모리를 해제한 후 유입되기 전에 체크포인팅(Checkpointing)이 전체적으로 적용되는 파이프라인 단계를 확인합니다.
5. 예산 계산. 정책 적용 전후의 활성화 메모리를 예측합니다(랭크당 MB 단위). FLOP 오버헤드를 fwd+bwd의 백분율로 예측합니다. HBM 예산에 10퍼센트의 여유 공간을 두고 맞지 않는 모든 계획을 거부합니다.

선택적 체크포인팅이 어텐션에만 적용되어도 예산을 충족할 수 있다면, 모든 레이어에 대한 전체 체크포인팅을 거부하세요. 프로파일링 결과, 동일한 메모리 절감량에 대해 FLOP 오버헤드가 선택적 체크포인팅보다 몇 배 더 높으며, 정확한 비율은 워크로드에 따라 다릅니다. 대상 PCIe 링크에서 측정된 레이어의 활성화 전송 시간이 측정된 재계산 시간을 초과하는 경우 오프로드를 거부하세요. 재계산이 더 유리합니다. 선택한 프레임워크가 amax 히스토리를 스냅샷하지 않는다면 FP8 학습에서 "모든 곳에 체크포인팅"을 거부하세요. 재계산이 스케일을 변경하여 기울기를 조용히 손상시킵니다.

예시 입력: "L=64, d=8192, S=8192, B=1, bf16, FlashAttention-3, TP=8, PP=4, 가중치 제외 후 랭크당 HBM 예산 32 GB, MoE는 8개의 전문가와 EP=8."

예시 출력:
- 레이어별 정책: 어텐션은 선택적, FFN은 없음, MoE 전문가는 전체, 임베딩은 없음, 출력 헤드는 오프로드.
- 세그먼트 크기: 전체 체크포인팅은 MoE에만 k=8에서 적용; 전문가 경로에서 FLOP 오버헤드 12퍼센트, 그 외에는 0.
- FlashAttention 상호작용: FA-3는 이미 소프트맥스를 재계산하므로, 커널 내부가 아닌 레이어 래퍼에서 선택적 체크포인팅을 적용하세요.
- TP / PP 계획: 재계산 시 어텐션 입력의 TP 수집은 단계당 추가 통신 0.3 GB; PP 단계는 각각 전체 순전파를 체크포인팅; PP 단계 3는 최종 역전파를 위해 활성화 상태를 유지.
- 예산 계산: 정책 없이 활성화는 38 GB, 정책 적용 시 11 GB. 순전파+역전파의 총 FLOP 오버헤드는 7.5퍼센트.
