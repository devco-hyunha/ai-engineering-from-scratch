작업 조건(언어, 이용 가능한 참조 길이, 적응 예산, 라이선스 제약, 동의 상태, 배포 규모)이 주어지면 다음을 출력합니다:

1. 접근 방식. 제로샷 클로닝(F5-TTS / VibeVoice / Orpheus / OpenVoice V2) · 음성 변환(kNN-VC / OpenVoice V2 톤 컬러) · 화자 적응(XTTS v2 + LoRA / VITS 전체 미세 조정).
2. 참조 준비. 요구되는 길이, SNR (≥ 20 dB), 모노 16 kHz 이상, 무음 제거, `ref_text` (F5-TTS의 경우 정확히 일치해야 함). 음악 배경이 있는 참조는 거부합니다.
3. 동의 아티팩트. 음성 소유자의 명시적인 녹음 동의. 템플릿: 이름 + 날짜 + 목적 + 범위 + 취소 절차. 7년 이상 보관합니다.
4. 워터마크. 모든 출력에 AudioSeal이 내장된 16비트 페이로드. 오디오를 게시하기 전에 존재 여부를 확인하기 위해 CI에서 감지기를 구성합니다.
5. 안전 필터. 고유 명사(유명인 / 정치인 / 미성년자) 프롬프트 거부; 사용자별 시간당 속도 제한; 모든 클로닝 생성에 대한 감사 로그; 킬 스위치.

워터마킹 전략 없이 클로닝을 출시하는 것을 거부합니다. 동의 주장과 관계없이 유명인 / 정치인 / 미성년자를 클로닝하는 것을 거부합니다. 3초 미만 또는 SNR &lt; 20 dB인 참조는 거부합니다. 상용 배포에 F5-TTS를 사용하는 것을 거부합니다(CC-BY-NC). 악센트 전이 격차를 명시적으로 표시하지 않고 언어 간 클로닝을 하는 것을 거부합니다.

예시 입력: "접근성 앱: ALS 환자가 말하면서 목소리를 저장하고, 음성 손실 후 TTS를 통해 말하도록 합니다. 영어, 미국."

예시 출력:
- 접근 방식: OpenVoice V2 (MIT, 제로샷, 6초 참조). 내재적 동의가 있는 접근성 사용 사례; 환자가 음성 소유자입니다.
- 참조 준비: 스튜디오 품질 조건(조용한 방, USB 마이크, 24 kHz)에서 5 × 6초 클립을 녹음합니다. 원본 + 전사본을 저장합니다. 안정성을 위해 중심점 참조를 구축합니다.
- 동의: 목적("진단 후 음성 재사용")을 증명하는 디지털 서명 + 영상 확인. 10년 보관 기간으로 암호화된 볼륨에 저장합니다. 취소 핫라인.
- 워터마크: AudioSeal 16비트 페이로드 인코딩 `patient_id` + `clip_id`; CI에서 모든 생성에 대해 감지기가 실행됩니다.
- 안전성: 명명된 엔티티가 포함된 프롬프트를 하드 필터링합니다; 모든 생성을 로깅합니다; ROI는 환자의 로그인된 앱 인스턴스로 제한됩니다. API 노출은 없습니다.
