PDF 코퍼스(10-K 보고서, 과학 논문, 스캔 문서)가 주어졌을 때, ColPali 스타일의 늦은 상호작용(late interaction)을 사용하여 페이지를 이미지로 인덱싱하고 페이지 수준의 증거 영역으로 질문에 답변하는 파이프라인을 구축해 보세요.

구축 계획:

1. PyMuPDF를 사용하여 모든 PDF 페이지를 180 DPI로 1536x2048 PNG로 렌더링합니다.
2. ColQwen2.5-v0.2 또는 ColQwen3-omni를 사용하여 모든 페이지를 임베딩합니다. 다중 벡터 패치 임베딩을 Vespa, Qdrant 다중 벡터 또는 AstraDB에 저장합니다.
3. DocPruner 스타일의 50% 패치 프루닝(pruning)을 적용합니다. ViDoRe v3에서 정확도 감소가 0.5% 미만으로 유지되는지 확인합니다.
4. 쿼리 시점: 쿼리 토큰을 임베딩합니다. 모든 페이지의 패치에 대해 MaxSim을 계산하고 상위 k개를 랭킹합니다.
5. 쿼리 및 상위 5개 페이지 이미지를 전달하여 Qwen3-VL-30B 또는 Gemini 2.5 Pro로 합성합니다. 인용된 `(doc_id, page, region)` 앵커를 요구합니다.
6. 수식이나 표가 많은 페이지의 경우, Nougat 또는 dots.ocr를 선택적 텍스트 채널로 실행하고 이미지와 함께 입력합니다.
7. 원본 페이지에 증거 영역을 바운딩 박스로 오버레이하는 Next.js 15 뷰어를 구축합니다.
8. ViDoRe v3 및 M3DocVQA에서 평가합니다. 순수 텍스트, 표, 차트, 필기체, 수식에 대해 비전 우선(vision-first) 방식과 OCR 후 텍스트 방식을 비교하는 콘텐츠 클래스 × 접근 방식 매트릭스를 생성합니다.

평가 기준:

| 가중치 | 기준 | 측정 |
|:-:|---|---|
| 25 | ViDoRe v3 / M3DocVQA 정확도 | 매칭된 페이지에서 OCR 후 텍스트 기준선 대비 벤치마크 |
| 20 | 증거 영역 그라운딩 | 인용된 영역 중 답변 스팬을 포함하는 영역의 비율 |
| 20 | 저장 및 지연 엔지니어링 | DocPruner 압축, 인덱스 p95, 답변 p95가 2초 미만 |
| 20 | 다중 페이지 추론 | 수동으로 라벨링된 100개 질문의 다중 페이지 세트에서의 정확도 |
| 15 | 출처 검토 UX | 오버레이 충실도, 비교 도구, 페이지별 탐색기 |

하드 리젝트(Hard rejects):

- OCR 우선 파이프라인을 "비전 우선"으로 표방하며, OCR 텍스트를 단일 벡터 임베딩으로 재구성하는 방식.
- 패치 수준 바운딩 박스를 제거하여 증거 오버레이를 렌더링할 수 없는 모든 시스템.
- DocPruner 설정을 문서화하지 않고 보고된 저장소 수치.

거부 규칙:

- 전용 마스킹 정책 없이 스캔된 법적 계약을 인덱싱하는 것을 거부하세요. ColQwen 임베딩은 콘텐츠를 유출합니다.
- 사용자가 공개하지 않은 코퍼스에 대한 쿼리를 제공하는 것을 거부하세요. 규제 대상 영역에서는 감사 추적 기록이 필수입니다.
- 동일한 코퍼스에 두 파이프라인을 모두 실행하지 않고 OCR 후 텍스트 방식과 비교하는 것을 거부하세요.

출력: 데이터 수집 파이프라인, Vespa(또는 Qdrant 다중 벡터) 구성, 100개 질문의 다중 페이지 평가 세트, 뷰어 UI, 콘텐츠 분류 x 접근 방식 매트릭스 및 2026년에도 OCR 후 텍스트 방식이 유리한 콘텐츠 분류에 대한 구체적 권고안을 포함한 문서가 포함된 저장소.
