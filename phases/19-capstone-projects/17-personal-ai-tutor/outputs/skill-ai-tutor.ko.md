과목(K-12 대수 또는 입문 Python)을 지정하여, 텍스트 + 음성 + 사진 수학 입력, 베이지안 지식 추적 학습자 모델, 커리큘럼 그래프 기반 개념 선택, COPPA 인식 메모리, 안전 필터를 갖춘 개인 튜터를 구축하세요. 10명의 학습자를 대상으로 2주간의 효능 연구를 수행하세요.

구축 계획:

1. Neo4j의 커리큘럼 그래프: 선결 조건 엣지와 연결된 OER 콘텐츠(OpenStax, Open Textbook)를 가진 50-150개의 개념 노드.
2. 학습자 모델: 개념별 추측/실수/학습률에 대한 사전 확률을 가진 베이지안 지식 추적; 학습자별 영속화된 상태.
3. 튜터 정책(Claude Sonnet 4.7에 대한 LangGraph, 프롬프트 캐싱 사용): read_signal -> select_concept (그래프 탐색) -> scaffold (소크라테스식) -> update_mastery.
4. 메모리: agentmemory 스타일의 영속적인 에피소드 + 시맨틱 저장소; COPPA 인식 자동 삭제(1년 후); 부모가 접근 가능한 삭제.
5. 음성: Whisper-v3-turbo ASR과 Cartesia Sonic-2 TTS를 사용하는 LiveKit Agents 워커; capstone 03 파이프라인 재사용.
6. 사진 수학: dots.ocr 또는 PaliGemma 2를 사용하여 방정식 인식; 구조화된 입력을 튜터에 전달.
7. 안전: Llama Guard 4 입력/출력; 자기 해침/성인/폭력 차단하는 연령 적절 필터; 학습자 범위 메모리 격리.
8. 학습자별 주간 PDF 진행 상황 보고서.
9. 효능 연구: 10명의 학습자, 사전 테스트(표준화된 30문항 기준선), 2주간의 세션(주 3회), 사후 테스트; 비적응형 선형 코호트와 비교.

평가 기준표:

|:-:|---|---|
| 25 | 학습 향상 델타 | 10명 학습자 2주 연구에서의 사전/사후 테스트 델타 |

| 15 | 커리큘럼 범위 및 그래프 품질 | 개념 커버리지 + 선수 요건 그래프 일관성 |

하드 리젝트:

- 다음 질문을 던지지 않고 답을 쏟아내는 튜터 정책. 소크라테스식 접근은 필수 요건입니다.
- 상호작용마다 업데이트되지 않는 학습자 모델. BKT는 최소 기준입니다.
- COPPA 인식 보존이 없는 메모리. K-12 대상에서는 용인될 수 없습니다.
- 비적응형 기준 집단(cohort) 없이 효능을 주장하는 것.

거부 규칙:

- 입력과 출력 모두에 Llama Guard 4가 적용되지 않은 상태로 배포하는 것을 거부합니다.
- 부모가 접근 가능한 삭제 기능이 없는 상태로 학습자 데이터를 저장하는 것을 거부합니다.
- 비적응형 기준을 병행하여 실행하지 않은 상태로 "적응형"이라고 주장하는 것을 거부합니다.

출력: 커리큘럼 그래프, BKT 학습자 모델, LangGraph 튜터 정책, 멀티모달 입력 핸들러, LiveKit 음성 파이프라인, 안전 파이프라인, 부모 대시보드, 효능 연구 실행기, 사전/사후 테스트 하네스, 그리고 선형 기준 대비 학습 향상 델타를 신뢰 구간과 함께 문서화한 보고서가 포함된 저장소입니다.
