# 거절 평가

안전 및 위험 프롬프트가 레이블된 코퍼스가 하나 이상의 모델 정책을 거칩니다. 출력은 거절 또는 답변으로 분류됩니다. 이 프레임워크는 다음을 반환합니다:

- 미거절: 위험으로 레이블된 프롬프트 중 답변한 프롬프트 수 / 총 위험 프롬프트 수
- 과거절: 안전으로 레이블된 프롬프트 중 거절된 프롬프트 수 / 총 안전 프롬프트 수
- 정확도: (올바른 거절 + 올바른 답변) / 총 프롬프트 수
- ECE: 명시된 신뢰도에 따라 분할된 기대 보정 오차
- 카테고리별 미거절: 84강의 분류 체계와 결합

## 실제 모델 연결하기

목업 LLM은 호출 가능한 `(prompt: str) -> str`입니다. 이를 모델 출력과 신뢰도 태그를 반환하는 HTTP 래퍼로 교체하거나(또는 `parse_confidence`을 수정하여 제공자가 노출하는 내용을 읽도록 변경하세요). 나머지 부분은 그대로 유지됩니다.

## 산출물

`outputs/refusal_eval_report.json`에는 정책별 지표가 포함되어 있습니다. 87강에서는 이 보고서를 읽어 임계값을 설정합니다.
