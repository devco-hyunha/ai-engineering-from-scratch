시드 아이디어, 좁은 도메인, $30 컴퓨팅 예산을 바탕으로 실험 트리 탐색을 수행하고, 검토 가능한 LaTeX 논문을 작성하며, 재현성 번들을 생성하는 에이전트를 구축해 보세요.

구축 계획:

1. 문헌 탐색: Semantic Scholar Graph API + OpenAlex; 초록을 FAISS에 캐싱; 1페이지 도메인 다이제스트 생성.
2. 트리 탐색: `expand(node) -> children` (자식당 하나의 구성 편집) 및 `score(node) = novelty*0.4 + quality*0.5 + budget*0.1`을 사용하여 실험 노드에 대한 최우선(best-first) 확장을 구현합니다.
3. 노드별 샌드박스: 모든 실험은 `docker run --network=none --memory=8g --cpus=2 --pids-limit=256 --read-only` 또는 E2B 동등 환경에서 실행됩니다; 결정론적 시드; 자원 상한이 강제됩니다.
4. 계획-실행-검증: 검증 단계는 손실(loss)이 수렴했는지, 기준선(baselines)이 실행되었는지, 어블레이션(ablations)이 주장을 분리하는지 확인합니다.
5. 저자: LaTeX를 생성하고 PDF로 컴파일한 후, PDF를 Claude Opus 4.7 비전 모드에 입력하여 레이아웃 및 주장-증거 정렬에 대한 비판을 수행하고, 최대 3회까지 반복합니다.
6. 리뷰어 앙상블: 다섯 명의 심사위원(Opus 4.7, GPT-5.4, Gemini 3 Pro, DeepSeek R1, Qwen3-Max)이 NeurIPS 평가 기준(독창성, 엄밀성, 명확성, 재현성, 영향력)에 따라 점수를 매깁니다; 평균 점수가 4.0 미만이면 저자에게 반환됩니다.
7. 레드 팀: 적대적 작업(포크 폭탄, 파일 시스템 탈출, LLM이 작성한 네트워크 호출)을 통합합니다. 모든 작업이 차단되었는지 확인합니다. `red_team.md`을 방출합니다.
8. 재현성 번들: paper.pdf + review.md + 트리 탐색 추적 JSON + 시드 + W&B 실행 링크 + 샌드박스 구성 + 한 줄 재실행 명령.

평가 기준표:

| 가중치 | 기준 | 측정 |
|:-:|---|---|
| 25 | 논문 품질 | 동일한 시드 주제에 대해 공개된 워크숍 논문과 비교하는 블라인드 평가 기준 검토 |
| 20 | 실험적 엄밀성 | 기준선, 시드, 어블레이션; 모든 주장은 결과 표의 셀로 뒷받침됨 |
| 20 | 비용 및 컴퓨팅 규율 | 논문당 $30 상한이 강제되며, Langfuse로 추적됨 |
| 20 | 안전성 | 샌드박스 레드 팀 통과; 네트워크 정책 및 킬 스위치가 기록된 시도와 함께 검증됨 |
| 15 | 재현성 | 한 명령어 재실행으로 동일한 시드로 논문을 재현할 수 있습니다 |

하드 리젝트:

- 샌드박스 밖에서 실행되는 실험. 캡스톤의 전체 논지는 실행이 격리되어 있다는 것입니다.
- 컴파일된 PDF를 다시 읽지 않는 작성 단계 (비전 비평은 핵심입니다).
- 베이스라인, 시드, 또는 Ablation 섹션이 없는 논문.
- 하드 상한이 아닌 사후 경고로만 강제되는 비용 예산.

거부 규칙:

- 명시적인 인간 오버라이드 없이 리뷰어 평균이 4.0/5 미만인 논문은 게시를 거부합니다.
- 샌드박스 내부에서 네트워크 접근이 필요한 시드 아이디어에 대해 실행을 거부합니다. 대신 읽기 전용 데이터셋 볼륨을 추가하세요.
- 레드 팀이 실행되고 기록되지 않은 논문의 재실행을 거부합니다.

출력: 트리 검색 엔진, 샌드박스 정책, 작성자/리뷰어 루프, 재현성 번들이 포함된 세 가지 예제 실행, 레드 팀 보고서, 비용 장부 csv, 그리고 Sakana v2 실패 모드 중 어떤 것을 재현했는지와 완화 조치가 어떻게 작동했는지 명시한 문서가 포함된 저장소입니다.
