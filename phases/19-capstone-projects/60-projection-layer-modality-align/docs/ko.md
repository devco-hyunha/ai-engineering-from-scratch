# 모달리티 정렬(Modality Alignment)를 위한 투영 레이어

> 비전 인코더는 이미지 토큰을 생성합니다. 텍스트 디코더는 텍스트 토큰을 소비합니다. 이 두 가지는 서로 다른 벡터 공간에 존재합니다. 작은 2층 MLP가 이미지 토큰을 텍스트 임베딩 공간으로 투영하며, 짝을 이루는 캡션에 대한 코사인 정렬 손실(cosine alignment loss)이 두 공간을 일치시킵니다. 이 투영은 비전-언어 모델(Vision-Language Model)의 가장 작은 부분이며, 전이 학습(Transfer Learning)에서 가장 중요한 부분입니다.

**유형:** Build
**언어:** Python
**선수 요건:** 19단계 30-37강 (Track B 기초)
**시간:** 약 90분

## 학습 목표

- 이미지 특징을 텍스트 임베딩 공간으로 매핑하는 2층 MLP 투영을 구축해 보세요.
- 모의 텍스트 임베딩 테이블을 구성해 보세요 (사전 학습된 토크나이저 없음, 실제 코퍼스 없음).
- 투영된 이미지 토큰과 짝을 이루는 캡션 임베딩 간의 코사인 정렬 손실을 계산해 보세요.
- 동결된 비전 인코더와 동결된 텍스트 테이블을 사용하여 투영 레이어만 학습해 보세요.

## 문제점

차원 `vision_hidden = 768`의 토큰을 생성하는 비전 인코더(58-59강)가 있습니다. 임베딩 차원이 `text_hidden = 512`인 텍스트 디코더를 그 위에 결합하고 싶다고 가정해 보세요 (다른 숫자도 마찬가지로 타당합니다). 디코더는 텍스트 형태의 토큰을 기대합니다. 이미지 토큰은 텍스트 형태가 아닙니다: 이미지 토큰은 비전 전용 사전 학습 동안 인코더가 학습한 기저(basis)에 존재하며, 디코더의 단어 벡터와의 관계가 없습니다.

2층 MLP 투영 (선형, GELU, 선형)이 이 간극을 연결합니다. 이는 단일 GPU에서 몇 분 안에 학습할 수 있을 만큼 작으며 (약 `768 * 1024 + 1024 * 512 = 1.3M` 매개변수), 정렬 단계 동안 학습해야 하는 유일한 부분입니다. 비전 인코더는 동결된 상태로 유지됩니다. 텍스트 임베딩 테이블도 동결된 상태로 유지됩니다. 투영 레이어만 이동합니다. 이는 LLaVA가 2023년에 출시한 레시피이며, BLIP-2가 Q-Former로 재구성한 방식이고, 이후 모든 오픈 웨이트 VLM이 어떤 형태로든 채택한 방식입니다.


### 투영 전 풀링

비전 인코더는 197개의 토큰을 방출합니다. 텍스트 쪽에는 단일 캡션 수준 임베딩이 있습니다. 이 둘을 정렬하려면 샘플당 하나의 이미지 수준 벡터가 필요합니다. CLS 풀링이 가장 단순합니다: 인코더에서 첫 번째 토큰을 가져와 투영합니다. 모든 197개 토큰에 대한 평균 풀링은 또 다른 옵션이며, SigLIP이 사용하는 방식입니다. 두 방식 모두 197개의 벡터를 하나로 풀링합니다.

### 왜 한 층이 아니라 두 층인가

단일 선형 투영은 회전 및 재스케일링을 할 수 있지만, 두 공간에 곡률 불일치가 있을 경우 기저를 수정할 수 없습니다. 두 선형 층 사이에 GELU를 두면 투영에 하나의 비선형 굴곡이 생깁니다. 이는 CLIP 스타일 특징을 언어 모델 임베딩에 정렬하는 데 경험적으로 충분합니다. 더 깊은 투영(LLaVA-NeXT는 GLU를 사용; Qwen-VL은 어텐션 층 스택을 사용)은 확장이며, 두 층 MLP는 표준적인 기준선이며, BLIP-2의 Q-Former 투영 헤드가 내부적으로 사용하는 방식입니다.

| 층 | 모양 | 매개변수 |
|-------|-------|------------|
| fc1 | `(vision_hidden, projection_hidden)` | `768 * 1024 + 1024` |
| 활성화 | GELU | 0 |
| fc2 | `(projection_hidden, text_hidden)` | `1024 * 512 + 512` |

`768 -> 1024 -> 512` 헤드에 대해 약 1.3M개의 매개변수입니다.

### 코사인 정렬 손실

정렬은 `image_emb == text_emb`을 의미하지 않습니다. 정렬은 `image_emb`이 결합 공간에서 `text_emb`와 같은 방향을 가리키는 것을 의미합니다. 코사인 손실은 `1 - cos_sim(image, text)`이며, 0(완벽하게 정렬됨)에서 2(반대 방향)까지 범위를 가집니다. 학습은 쌍마다 이 값을 0으로 유도합니다. 62강은 대비 학습 배치(InfoNCE)로 일반화하며, 모든 이미지는 배치 내의 다른 모든 캡션보다 자신의 캡션에 더 가까워야 합니다. 이 강의는 역학이 보이도록 쌍별 버전을 사용합니다.

### 동결된 인코더가 핵심입니다

비전 인코더는 86M개의 매개변수를 가집니다. 텍스트 테이블은 몇백만 개를 더 가집니다. 목업 코퍼스로 모두를 학습하는 것은 불가능합니다. 둘을 동결하면 투영의 1.3M개 매개변수만 변하게 되며, 합성 쌍에 대해 몇백 단계의 학습만으로도 손실을 낮추는 데 충분합니다. 이는 모든 어댑터 기반 VLM의 운영 형태와 정확히 일치합니다: 무거운 부분은 동결된 상태로 유지되고, 가벼운 브리지가 학습됩니다.

## 구현하기

`code/main.py`는 다음을 구현합니다:

- `MLPProjector(in_dim, hidden_dim, out_dim)`, GELU 활성화 함수를 사용하는 2층 선형 MLP입니다.
- `MockTextEmbedding(vocab_size, dim)`, 시드(seed)에서 결정적으로 초기화된 고정된 임베딩 테이블입니다.
- `make_pair(seed, vocab_size)`, 하나의 짝을 이루는 (이미지, 캡션) 샘플을 합성합니다. 캡션은 짧은 ID 시퀀스이며, 캡션 임베딩은 토큰 임베딩의 평균 풀링(mean-pooling)을 수행합니다.
- `cosine_alignment_loss(image_emb, text_emb)`, 쌍(pair)별 `1 - cos_sim` 목적 함수입니다.
- 비전 인코더와 텍스트 테이블이 고정된 상태에서, 32개의 합성 쌍(순환 사용)에 대해 투영(projection)을 200 스텝 동안 실행하고, 25 스텝마다 손실(loss)을 출력하는 학습 루프입니다.

실행해 보세요:

```bash
python3 code/main.py
```

출력: 학습 보고서는 초기 손실 약 1.07에서 200 스텝 내에 약 0.80까지 감소하며, 투영(projection)만으로도 이미지 토큰을 텍스트 공간으로 끌어당길 수 있음을 보여줍니다. 각 쌍의 최종 코사인 유사도도 출력됩니다.

## 사용하기

이와 동일한 패턴이 모든 오픈 웨이트 VLM에서 나타납니다:

- **LLaVA 1.5.** CLIP-ViT-L 은닉(hidden) 차원에서 LLaMA 임베딩 차원으로 투영하는 2층 GELU MLP입니다. 비전 인코더와 LLM은 고정되며, 투영(projection)만 학습합니다(이후 2단계에서 LLM의 고정(freeze)을 해제합니다).
- **BLIP-2.** Q-Former는 이미지 토큰에 대해 교차 어텐션(cross-attention)을 수행하는 32개의 학습된 쿼리 토큰을 사용하며, 이후 LLM 임베딩 차원으로 투영합니다. Q-Former의 맨 끝에 있는 투영 헤드(projection head)는 이 강의의 MLP에 해당합니다.
- **MiniGPT-4.** BLIP-2 Q-Former 출력에서 Vicuna 임베딩 차원으로 투영하는 단일 선형 투영입니다.
- **Qwen-VL.** 여러 층을 가진 교차 어텐션 어댑터이지만, 최종 부분은 다시 LM 임베딩 차원으로의 투영입니다.

형태는 다양하지만 역할은 동일합니다: 이미지 토큰을 풀링(pooling)하고, 텍스트 임베딩 차원으로 투영(projection)하며, 단독으로 학습합니다.

## 연습 문제

1. CLS 풀링을 196개 패치 토큰에 대한 평균 풀링으로 교체하고 200 스텝 후 최종 손실을 비교해 보세요. 평균 풀링은 합성 데이터에서 더 빠르게 학습되는 경향이 있으며, CLS는 자연 이미지에서 더 샘플 효율적입니다.

2. 코사인 손실에 학습 가능한 스칼라 온도(`cos / tau`)를 추가하고, `tau`이 너무 작을 때(기울기 잡음) 또는 너무 클 때(손실이 높은 곳에서 평평해짐) 어떤 일이 일어나는지 관찰해 보세요.

3. 2층 MLP를 단일 선형 레이어로 교체하고 손실 격차를 정량화해 보세요. 비선형성은 자연 이미지 특징에서는 더 중요하고, 합성 특징에서는 덜 중요합니다.

4. 프로젝터 가중치에 작은 L2 페널티를 추가하고, 이것이 코사인 정렬(cosine은 스케일 불변이므로 페널티는 주로 사용되지 않는 방향을 축소합니다)과 어떻게 상호작용하는지 지켜보세요.

5. 프로젝터 가중치를 저장한 후, 이를 다시 로드하고 비전 인코더의 역전파 없이 추론을 실행하여 배포 시에는 프로젝트만 필요함을 확인해 보세요.

## 핵심 용어

| 용어 | 의미 |
|------|---------------|
| 모달리티 정렬(Modality Alignment) | 이미지와 텍스트 임베딩을 하나의 공유 공간에서 비교 가능하게 만드는 행위 |
| 투사 헤드(Projection head) | 한 공간을 다른 공간으로 매핑하는 작은 모듈로, 보통 2층 MLP |
| 코사인 유사도(Cosine Similarity) | 내적(dot product)을 L2 노름의 곱으로 나눈 값 |
| 동결 인코더(Frozen encoder) | 비전(또는 텍스트) 모델의 모든 매개변수가 `requires_grad=False` |
| 목(mock) 코퍼스 | 학습이 데이터셋 다운로드 의존성을 갖지 않도록 사용하는 합성 쌍 |
