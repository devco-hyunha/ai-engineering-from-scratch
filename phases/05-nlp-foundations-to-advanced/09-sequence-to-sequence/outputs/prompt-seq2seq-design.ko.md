과제(번역, 요약, 패러프레이즈, 질문 재작성)가 주어지면 다음을 출력하세요.

1. 아키텍처. 사전학습 트랜스포머 인코더-디코더(BART, T5, mBART, NLLB)가 기본입니다. RNN 기반 seq2seq는 특정 제약(스트리밍, 엣지 추론, 교육)이 있을 때만.
2. 시작 체크포인트. 이름을 적으세요(`facebook/bart-base`, `google/flan-t5-base`, `facebook/nllb-200-distilled-600M`). 과제와 언어 커버리지에 맞게 고르세요.
3. 디코딩 전략. 결정적 출력에는 탐욕(greedy), 품질에는 빔 서치(너비 4–5), 다양성에는 temperature 샘플링. 한 문장으로 근거를 적으세요.
4. 배포 전에 확인할 실패 모드 하나. 노출 편향은 긴 출력에서 생성 드리프트로 나타납니다. 90백분위 길이에서 출력 20개를 뽑아 눈으로 확인하세요.

병렬 예제가 ~100만 개 미만이면 처음부터 seq2seq를 학습하라고 추천하지 마세요. 사용자 대면 콘텐츠에 탐욕적 디코딩만 쓰는 파이프라인은 취약하다고 표시하세요(탐욕은 반복과 루프를 만듭니다).
