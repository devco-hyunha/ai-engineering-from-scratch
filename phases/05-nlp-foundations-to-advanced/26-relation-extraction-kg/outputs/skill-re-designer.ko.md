코퍼스(도메인, 언어, 볼륨)와 다운스트림 사용(KG-RAG, 분석, 컴플라이언스)이 주어지면 다음을 출력합니다:

1. 추출기. 패턴 기반 / 지도 학습 / LLM / AEVS 하이브리드. 정밀도 대 재현율 목표와 연결된 이유를 포함합니다.
2. 온톨로지. 폐쇄적 속성 목록(Wikidata / 도메인) 또는 정규화 패스를 포함한 개방형 IE.
3. 출처. 모든 삼중항은 소스 문자 범위 + 문서 ID를 포함합니다. 감사(audit)를 위해 필수입니다.
4. 병합 전략. 정규화된 엔티티 ID + 관계 ID + 시간 한정자; 중복 제거 정책.
5. 평가. 200개 수동 라벨 삼중항에 대한 정밀도 / 재현율 + LLM 추출 샘플에 대한 환각률.

스팬 검증(소스 출처)이 없는 LLM 기반 RE 파이프라인은 거부합니다. 정규화 없이 생산 그래프로 유입되는 개방형 IE 출력은 거부합니다. 시간 한정 관계(고용주, 배우자, 직위)에 시간 한정자가 없는 파이프라인은 플래그를 지정합니다.
