사용 사례(단일 문서 / 다중 문서, 도메인, 언어)가 주어지면 다음을 출력합니다:

1. 접근법. 규칙 기반 / 신경망 스팬 기반 / LLM 프롬프트 기반 / 하이브리드. 한 문장 이유를 포함합니다.
2. 모델. 신경망인 경우 명명된 체크포인트를 지정합니다.
3. 통합. 연산 순서: 토큰화 → NER → 코어퍼런스 → 다운스트림 작업.
4. 평가. 홀드아웃 세트에 대한 CoNLL F1 (MUC + B³ + CEAF-φ4 평균) + 20개 문서에 대한 수동 클러스터 검토.

슬라이딩 윈도우 병합 없이 2,000 토큰 이상의 문서에 대해 LLM 전용 코어퍼런스를 거부합니다. 언급 수준 정밀도-재현율 보고서 없이 코어퍼런스를 실행하는 파이프라인을 거부합니다. 인구통계학적으로 다양한 텍스트에 배포된 성별 휴리스틱 시스템을 플래그합니다.
