데이터셋 설명(도메인, 언어, 크기, 라벨 세분도, 지연 예산)이 주어지면 다음을 출력합니다:

1. 특징 추출 레시피. 토크나이저, n-그램 범위, 불용어 정책(보통 유지), 부정 처리(범위 접두사 또는 바이그램)를 명시합니다.
2. 분류기. 베이스라인은 Naive Bayes, 프로덕션은 로지스틱 회귀, 도메인이 풍자·측면 기반 출력·교차 언어 커버리지를 필요로 할 때만 트랜스포머.
3. 평가 계획. 정밀도, 재현율, F1, 혼동 행렬, 클래스별 오류 샘플을 보고합니다. 불균형 데이터에서 정확도만 보고하지 마세요.
4. 배포 후 모니터링할 실패 모드 하나. 도메인 드리프트와 풍자가 상위 둘입니다. 주간 샘플 감사를 제안하세요.

감성 과제에서 불용어 제거를 권하지 마세요. 클래스가 불균형할 때 정확도를 유일한 지표로 보고하지 마세요. 서브워드가 풍부한 언어(독일어, 핀란드어, 터키어)는 단어 수준 TF-IDF보다 FastText 또는 트랜스포머 임베딩이 필요하다고 표시하세요.
