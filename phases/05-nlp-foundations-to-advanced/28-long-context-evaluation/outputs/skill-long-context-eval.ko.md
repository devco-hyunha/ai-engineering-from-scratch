목표 모델, 목표 컨텍스트 길이, 사용 사례가 주어지면 다음을 출력합니다:

1. 테스트. NIAH 깊이 × 길이 그리드; RULER 다중 홉; 사용자 정의 도메인 작업.
2. 샘플링. 각 길이에서 깊이 0, 0.25, 0.5, 0.75, 1.0.
3. 지표. 검색 통과율; 추론 통과율; 첫 토큰까지의 시간 (TTFT)(Time to First Token (TTFT)); 쿼리당 비용.
4. 컷오프. 유효 검색 길이 (90% 통과) 및 유효 추론 길이 (70% 통과). 두 값을 모두 보고합니다.
5. 회귀. 고정된 하네스, 모든 모델 업그레이드 시 재실행, 차이(deltas)를 표시합니다.

모델 카드만으로 컨텍스트 윈도우를 신뢰하지 마세요. 다중 홉 작업에 대해 NIAH 전용 평가를 신뢰하지 마세요. 공급업체가 자체 보고한 긴 컨텍스트 점수를 독립적인 증거로 신뢰하지 마세요.
