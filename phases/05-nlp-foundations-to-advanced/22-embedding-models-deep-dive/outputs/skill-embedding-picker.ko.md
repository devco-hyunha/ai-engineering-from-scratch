코퍼스(크기, 언어, 도메인, 평균 길이), 배포 대상(클라우드 / 엣지 / 온프레미스), 지연 시간 예산, 저장소 예산이 주어지면 다음을 출력합니다:

1. 모델. 명명된 체크포인트 또는 API. 한 문장 이유.
2. 차원. 전체 / Matryoshka 절단 / int8 양자화. 저장소 예산과 연결된 이유.
3. 모드. 밀집(Dense) / 희소(Sparse) / 다중 벡터(Multi-vector) / 하이브리드(Hybrid). 이유.
4. 모델 카드가 요구하는 경우 쿼리 접두어 / 템플릿.
5. 평가 계획. 도메인과 관련된 MTEB 작업 + nDCG@10을 사용한 보존된 도메인 평가.

도메인 검증 없이 Matryoshka를 64차원 미만으로 절단하는 권장 사항을 거부합니다. 1만 개 미만의 패시지 코퍼스에 대해 ColBERTv2를 거부합니다(오버헤드가 정당화되지 않음). 512 토큰 윈도우를 가진 모델로 라우팅되는 긴 문서 코퍼스(>8k 토큰)를 플래그합니다.
