코퍼스(문서 유형, 평균 길이, 도메인)와 쿼리 분포(사실형 / 분석형 / 다중 홉)가 주어지면 다음을 출력합니다:

1. 전략. 재귀 / 문장 / 시맨틱 / 부모 문서 / 후기 / 컨텍스트 기반. 이유를 설명합니다.
2. 청크 크기. 토큰 수. 쿼리 유형과 연결된 이유를 설명합니다.
3. 겹침. 기본값은 0입니다. 0보다 큰 경우 이유를 정당화합니다.
4. 최소/최대 강제 적용. `min_tokens`, `max_tokens` 가드.
5. 평가 계획. 50개 쿼리 계층화 평가 세트(사실형, 분석형, 다중 홉)에서 Recall@5를 측정합니다.

최소/최대 청크 크기 강제 적용이 없는 청킹 전략은 거부합니다. 도움이 된다는 어블레이션(ablation)이 없는 경우 20% 이상의 겹침은 거부합니다. 최소 토큰 하한(min-token floor)이 없는 시맨틱 청킹 권장 사항은 플래그를 지정합니다.
