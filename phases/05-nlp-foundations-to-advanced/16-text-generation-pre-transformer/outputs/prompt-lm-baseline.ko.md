코퍼pus와 목표 용도(다음 단어 예측, 재채점, 퍼플렉시티 기준선)가 주어지면 다음을 출력합니다:

1. N-gram 차수. 일반적인 영어에는 trigram, 코퍼pus가 크면 4-gram, 음성 재채점에는 5-gram을 사용합니다.
2. 스무딩. Modified Kneser-Ney가 기본값이며, Laplace는 교육용으로만 사용합니다.
3. 라이브러리. 프로덕션에는 `kenlm`, 교육에는 `nltk.lm`을 사용하며, 수학적 원리를 학습하기 위해 직접 구현하는 것은 학습 목적에 한합니다.
4. 평가. 학습 세트와 테스트 세트 간에 토큰화가 일관되게 유지된 상태에서 홀드아웃 퍼플렉시티를 측정합니다.

비교 대상 시스템 간에 토큰화가 다른 경우 퍼플렉시티를 보고하지 마세요. 퍼플렉시티 수치는 동일한 토큰화 조건에서만 비교가 가능합니다. 테스트 세트의 OOV 비율을 표시하세요. 학습 중 `<UNK>` 토큰을 예약하지 않으면 KN은 OOV를 잘 처리하지 못합니다.
