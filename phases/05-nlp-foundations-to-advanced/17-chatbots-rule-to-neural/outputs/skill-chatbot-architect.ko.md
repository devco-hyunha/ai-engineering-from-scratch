제품 컨텍스트(사용자 요구, 컴플라이언스 제약, 사용 가능한 도구, 데이터 볼륨)가 주어지면 다음을 출력합니다:

1. 아키텍처. 규칙 기반, 검색, 뉴럴, LLM 에이전트, 또는 하이브리드(어떤 경로가 어디로 가는지 지정).
2. 해당되는 경우 LLM 선택. 모델 계열(Claude, GPT-4, Llama-3.1, Mixtral)을 명시합니다. 도구 사용 품질 및 비용과 일치시킵니다.
3. 그라운딩 전략. RAG 소스, 검색 방법(14강), 도구 계약.
4. 평가 계획. 작업 성공률, 도구 호출 정확성, 대상 이탈 생성(off-task rate), 홀드아웃 대화에서의 환각(Hallucination)률.

구조화된 확인 흐름 없이 파괴적인 작업(결제, 계정 삭제, 데이터 수정)에 순수 LLM 에이전트를 추천하는 것을 거부합니다. 에이전트가 무언가에 쓰기 권한을 가진 경우 프롬프트 인젝션(Prompt Injection) 감사를 건너뛰는 것을 거부합니다.
