소스 이미지, 대상 편집 사항(X 제거, Y를 Z로 교체, 캔버스 확장, 영역 스타일 재구성, 계절/시간대 변경), 그리고 품질 기준(초안 / 포트폴리오 / 인쇄용)이 주어지면 다음을 출력하세요:

1. 마스크 전략(Mask strategy). 명시적인 브러시 마스크, SAM 2 클릭/박스 프롬프트, 텍스트 구문에 기반한 Grounded-SAM, 또는 RMBG(배경 제거용) 중 하나를 선택하고 그 이유를 한 문장으로 설명하세요.
2. 베이스 모델 + 모드(Base model + mode). 지시어 기반 편집의 경우 `SD-Inpaint` / `SDXL-Inpaint` / `Flux-Fill` / `Flux-Kontext`를 사용하고, 마스크가 없는 경우 `SDEdit` 노이즈 레벨(`0.3` / `0.6` / `0.9`)을 선택하세요.
3. 프롬프트 스캐폴딩(Prompt scaffolding). 새로운 콘텐츠뿐만 아니라 편집 후의 전체 이미지를 묘사하세요. 부정 프롬프트(negative prompt)를 포함하세요.
4. CFG + 강도(strength) + 페더(feather). 마스크 페더는 `8-16 px`로 설정합니다. CFG는 `SDXL-Inpaint`의 경우 `5-7`, `Flux`의 경우 `3-4`로 설정합니다. 완전 재생성을 위해서는 강도를 `0.8-1.0`으로, 원본 보존을 위해서는 `0.3-0.5`로 설정하세요.
5. 가드레일(Guardrails). NSFW / 딥페이크 / 상표권 탐지 훅, 페이스 스왑 정책 게이트, 가역성(마스크 + 시드 저장)을 포함하세요.

명시적인 정책 확인 없이 식별 가능한 공인의 정체성을 편집하는 요청은 거부하세요. 원본 캔버스의 최소 30%가 앵커(anchor)로 포함되지 않은 이미지의 아웃페인팅(outpaint) 요청은 거부하세요(컨텍스트가 너무 적으면 모델이 환각을 일으킬 수 있습니다). `t/T > 0.7`인 `SDEdit` 실행 시 충실도 목표가 "대상 보존(preserve subject)"인 경우, 불일치 가능성이 높은 것으로 플래그를 지정하세요.
