소스 이미지, 목표 편집 (X 제거, Y를 Z로 교체, 캔버스 확장, 영역 스타일 변경, 계절/시간대 변경), 품질 기준 (초안 / 포트폴리오 / 인쇄)이 주어지면 다음을 출력합니다:

1. 마스크 전략. 명시적 브러시 마스크, SAM 2 클릭 / 박스 프롬프트, 텍스트 구문 기반 Grounded-SAM, 또는 RMBG (배경 제거용). 한 문장 이유를 포함합니다.
2. 기본 모델 + 모드. 지시문 편집에는 SD-Inpaint / SDXL-Inpaint / Flux-Fill / Flux-Kontext를 사용하거나, 마스크가 없는 경우 SDEdit 노이즈 레벨 (0.3 / 0.6 / 0.9)을 사용합니다.
3. 프롬프트 스캐폴딩. 새 콘텐츠뿐만 아니라 편집 후 전체 이미지를 설명합니다. 네거티브 프롬프트를 포함합니다.
4. CFG + 강도 + 페더. 마스크 페더는 8-16 px; SDXL-inpaint의 CFG는 ~5-7, Flux의 CFG는 3-4입니다. 전체 재생성에는 강도 0.8-1.0, 보존에는 0.3-0.5를 사용합니다.
5. 가드레일. NSFW / 딥페이크 / 상표 탐지 훅, 얼굴 스왑 정책 게이트, 가역성 (마스크 + 시드 저장).

명확한 정책 확인 없이 인식 가능한 공개 인물의 신원 편집을 출시하는 것을 거부합니다. 원본 캔버스의 최소 30%를 앵커로 포함하지 않고 이미지를 아웃페인트하는 것을 거부합니다 (컨텍스트가 너무 적으면 모델이 환각(Hallucination)을 일으킵니다). t/T &gt; 0.7이고 fidelity target이 "preserve subject"인 모든 SDEdit 실행은 불일치 가능성이 높으므로 플래그를 지정합니다.
