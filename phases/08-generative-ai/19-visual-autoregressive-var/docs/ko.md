# 시각적 자기회귀 모델링(VAR): 다음 스케일 예측

> 확산 모델은 시간(디노이징 단계)에서 반복적으로 샘플링합니다. VAR는 스케일에서 반복적으로 샘플링합니다. 즉, 1x1 토큰을 예측한 후 2x2, 4x4를 예측하여 최종 해상도까지 진행하며, 각 스케일은 이전 스케일에 조건을 둡니다. 2024년 논문은 VAR가 이미지 생성에서 GPT 스타일 스케일링 법칙과 일치하며, 동일한 연산 예산에서 DiT를 능가함을 보여 주었습니다. 이 강의는 핵심 메커니즘을 구축합니다.

**유형:** Build
**언어:** Python (PyTorch 사용)
**선수 요건:** 7단계 03강 (멀티 헤드 어텐션), 8단계 06강 (DDPM)
**시간:** 약 90분

## 문제점

자기회귀 생성은 예측 가능한 스케일링 때문에 언어 모델링을 지배했습니다. 더 많은 연산, 더 많은 매개변수, 더 낮은 퍼플렉시티, 더 나은 출력으로 이어집니다. 2024년 이전 이미지 생성에는 두 가지 주요 AR 시도가 있었습니다. PixelRNN/PixelCNN (픽셀 단위)과 DALL-E 1 / Parti / MuseGAN (VQ-VAE 코드에 대한 토큰 단위)입니다.

두 방법 모두 생성 순서 문제를 겪었습니다. 픽셀과 토큰은 2D 그리드에 배치되어 있지만, AR 모델은 1D 래스터 순서로 방문해야 합니다. 초기 코너 픽셀은 이미지가 최종적으로 어떻게 될지 알 수 없습니다. 생성 품질은 GPT-on-text보다 더 나쁘게 스케일링되었으며, 동일한 연산량에서 확산 모델의 품질에 도달하지 못했습니다.

VAR는 생성되는 대상을 변경하여 생성 순서 문제를 해결합니다. 공간에서 이미지 토큰을 하나씩 예측하는 대신, VAR는 증가하는 해상도로 전체 이미지를 예측합니다. 1단계: 1x1 토큰(이미지 전체 "요약")을 예측합니다. 2단계: 2x2 토큰 그리드(더 거친 특징)를 예측합니다. 3단계: 4x4 그리드를 예측합니다. K단계: 최종 (H/8)x(W/8) 그리드를 예측합니다.

각 스케일은 이전 모든 스케일에 ("스케일 순서"에서 인과적으로) 주의하고, 자신의 스케일 내에서는 병렬로 주의합니다. 순서 문제가 사라집니다. 스케일 k의 전체 이미지는 하나의 트랜스포머 패스에서 생성됩니다.

## 개념

### VQ-VAE 다중 스케일 토크나이저

VAR는 **다중 스케일 이산 토크나이저**가 필요합니다. 이미지 x에 대해, 점진적으로 더 높은 해상도의 토큰 그리드 시퀀스를 생성합니다:

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

각 z_k는 동일한 코드북(일반적으로 크기 4096-16384)을 사용합니다. 각 스케일에서의 토큰화는 독립적이지 않으며, 각 스케일의 잔차를 합산하면 f를 재구성하도록 학습됩니다:

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

이것은 **잔차 VQ** 변형입니다. 스케일 k는 스케일 1..k-1이 놓친 부분을 포착합니다. 디코더는 모든 스케일 임베딩의 합을 받아 이미지를 생성합니다.

멀티스케일 VQ 토크나이저는 한 번 학습(VQGAN처럼)된 후 고정됩니다. 모든 생성 작업은 그 위에 있는 자기회귀 모델이 수행합니다.

### 다음 스케일 예측

생성 모델은 이전 모든 스케일의 토큰을 보고 다음 스케일의 토큰을 예측하는 트랜스포머입니다.

입력 시퀀스 구조:
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

포지션 임베딩은 스케일 인덱스와 스케일 내 공간 위치를 모두 인코딩합니다. 어텐션은 스케일 순서로 인과적입니다. 스케일 k, 위치 (i, j)의 토큰은 스케일 1..k의 모든 토큰과 스케일 k 자체에서 사용된 스케일 내 순서상 더 앞쪽에 있는 토큰에 어텐션할 수 있습니다(VAR는 스케일 내 인과성이 없는 고정 포지션 어텐션을 사용하며, 스케일 내 모든 위치는 병렬로 예측됩니다).

학습 손실: 각 스케일 k에서 이전 스케일의 모든 토큰을 고려하여 z_k의 토큰을 예측합니다. 이산 VQ 코드에 대한 교차 엔트로피 손실입니다. "시퀀스"가 이제 스케일 구조를 갖는 것 외에는 GPT와 동일한 구조입니다.

### 생성

추론 시:
```
generate z_1 = sample from p(z_1)                    # 1개 토큰
generate z_2 = sample from p(z_2 | z_1)              # 4개 토큰 병렬
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16개 토큰 병렬
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

K = 10 스케일인 경우, 생성은 10번의 트랜스포머 순방향 전파로 이루어집니다. 각 전파는 해당 스케일 전체를 병렬로 생성합니다 — 스케일 내 토큰별 자기회귀는 없습니다. 256x256 이미지의 경우 이는 DiT의 28-50번 전파와 비교해 대략 10번 전파입니다.

### 다음 스케일 예측이 다음 토큰 예측보다 이기는 이유

세 가지 구조적 이점:
1. **거친 것에서 섬세한 것으로 가는 과정이 자연 이미지 통계와 일치합니다.** 인간의 시각 지각과 이미지 데이터셋 모두 스케일 의존적 규칙성을 보입니다. 저주파 구조는 안정적이고 예측 가능하며, 고주파 세부 사항은 저주파 콘텐츠에 조건부입니다. 다음 스케일 예측은 이를 활용합니다.
2. **스케일 내 병렬 생성.** GPT 스타일 토큰 AR과 달리, VAR는 한 단계에서 스케일의 모든 토큰을 생성합니다. 효과적인 생성 길이는 선형이 아닌 로그 스케일입니다.
3. **생성 순서 편향 없음.** 스케일 k의 토큰은 스케일 k-1의 모든 토큰을 참조합니다. 늦은 컨텍스트가 가용하기 전에 초기 토큰이 확정되도록 강제하는 "왼쪽" 또는 "위쪽" 편향은 없습니다.

### 스케일링 법칙

Tian 등은 VAR이 ImageNet의 FID에 대해 GPT가 퍼플렉시티에 대해 보이는 것과 동일한幂법(power-law) 스케일링 곡선을 따름을 입증했습니다. 매개변수나 연산량을 두 배로 늘리면 오류가 신뢰할 수 있게 절반으로 줄어듭니다. 이는 언어 모델만큼 깔끔하게 이러한 스케일링 동작을 보인 최초의 이미지 생성 모델이었습니다. 그 결과 VAR 스케일 예측은 경험적인 아키텍처별 추측이 아닌, 연산량으로부터 예측 가능해집니다.

### 확산 모델과의 관계

VAR와 확산 모델은 동일한 데이터 압축 스토리를 공유합니다. 둘 다 생성 문제를 더 쉬운 하위 문제들의 시퀀스로 분해합니다.

- 확산 모델: 점진적으로 잡음을 추가하고, 한 단계를 되돌리는 것을 학습합니다.
- VAR: 점진적으로 해상도를 추가하고, 다음 스케일을 예측하는 것을 학습합니다.

이 둘은 문제를 통과하는 서로 다른 축입니다. 둘 모두 다루기 쉬운 조건부 분포를 생성합니다. 경험적으로 VAR는 추론 시 더 빠르며(더 적은 패스, 스케일 내 모든 병렬 처리), 클래스 조건부 ImageNet에서 DiT와 동등하거나 더 나은 성능을 보입니다. 텍스트 조건부 VAR(VARclip, HART)은 활발한 연구 방향입니다.


## 구현하기

`code/main.py`에서는 다음을 수행합니다:
1. 합성 "이미지" 데이터(2D 가우시안 링)에 **다중 스케일 VQ 토크나이저**를 구축합니다.
2. 토큰을 다음 스케일로 예측하는 **VAR 스타일 트랜스포머**를 학습합니다.
3. 트랜스포머를 4번 호출(4개 스케일)하고 디코딩하여 샘플링합니다.
4. 스케일 순서 학습이 스케일 내 생성을 병렬화함을 검증합니다.

이는 장난감(toy) 구현입니다. 핵심은 스케일 구조화된 어텐션 마스크와 스케일 내 병렬 생성이 실제로 작동하는 것을 보는 것입니다.

## 출시하기

이 강의는 `outputs/skill-var-tokenizer-designer.md`를 생성합니다. 이는 다중 스케일 토크나이저 설계에 대한 스킬입니다: 스케일 수, 스케일 비율, 코드북 크기, 잔차 공유, 디코더 아키텍처.

## 연습 문제

1. **스케일 수 Ablation.** VAR를 4, 6, 8, 10 스케일로 학습합니다. 재구성 품질을 자기회귀 패스 수에 대해 측정합니다. 더 많은 스케일 = 더 미세한 잔차 = 더 좋은 품질, 그러나 더 많은 패스.

2. **코드북 크기.** 코드북 크기를 512, 4096, 16384로 설정하여 토크나이저를 학습해 보세요. 더 큰 코드북은 더 나은 재구성 성능을 제공하지만 예측이 더 어려워집니다. 무릎(knee) 지점을 찾아 보세요.

3. **스케일 내 병렬 처리 확인.** 학습된 VAR에 대해 어텐션 패턴을 명시적으로 측정해 보세요. 스케일 k 내에서 모델이 스케일 간 위치에는 어텐션하지만 스케일 내 위치에는 어텐션하지 않는지 확인해 보세요. 마스크 구현을 검증해 보세요.

4. **VAR vs DiT 스케일링.** 동일한 ImageNet 클래스 조건부 작업에서 VAR과 DiT를 동일한 매개변수 예산(예: 33M, 130M, 458M)으로 학습해 보세요. FID 대 연산량 그래프를 그려 보세요. VAR은 각 크기에서 DiT보다 앞서야 합니다. 작은 규모에서 논문의 결과를 재현해 보세요.

5. **텍스트 조건부 처리.** VAR을 확장하여 CLIP 풀링된 텍스트 임베딩을 adaLN을 통해 추가 조건부 입력으로 받도록 해 보세요. 이것이 HART 레시피입니다. 텍스트 정렬된 샘플링에서 FID가 얼마나 개선되는지 확인해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|----------------------|
| VAR | "Visual AutoRegressive" | VQ 토큰 그리드의 피라미드에 대한 다음 스케일 예측을 통한 이미지 생성 |
| 다음 스케일 예측 | "거친 것을 먼저, 그 다음 더 세밀한 것을 예측" | 모델이 모든 이전 스케일을 조건부로 하여 점진적으로 해상도가 높은 스케일에서 토큰을 예측 |
| 다중 스케일 VQ 토크나이저 | "Residual VQ" | 점진적으로 해상도가 높은 K개의 토큰 그리드를 생성하며, 디코더가 모든 스케일을 합산하는 VQ-VAE |
| 스케일 k | "피라미드 레벨 k" | k=1에서의 1x1부터 k=K에서의 (H/p)x(W/p)까지의 K개 해상도 레벨 중 하나 |
| 스케일 내 병렬 처리 | "스케일당 한 번의 순전파" | 스케일 k의 모든 토큰이 자기회귀적으로가 아닌 한 번의 트랜스포머 패스에서 예측됨 |
| 스케일 간 인과적 처리 | "스케일 순서 어텐션" | 스케일 k의 토큰은 스케일 1..k의 모든 것에 어텐션할 수 있지만 스케일 k+1..K에는 어텐션할 수 없음 |
| 잔차 VQ | "가산적 토큰화" | 각 스케일의 토큰은 더 낮은 스케일들이 남긴 잔차를 인코딩하며, 디코더는 모든 스케일 임베딩을 합산 |
| VAR 스케일링 법칙 | "Image GPT 스케일링" | FID가 언어 모델의 퍼플렉시티처럼 연산량에 대해 예측 가능한幂법칙(power law)을 따름 |
| HART | "Hybrid VAR + text" | MaskGIT 스타일의 반복적 디코딩과 VAR의 스케일 구조를 결합한 텍스트 조건부 VAR 변형 |
| 스케일 위치 임베딩 | "(스케일, 행, 열) 삼중 쌍" | 위치 인코딩은 스케일 인덱스와 스케일 내 공간 좌표를 모두 포함합니다 |
