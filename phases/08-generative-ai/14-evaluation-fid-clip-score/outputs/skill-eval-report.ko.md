새로운 생성 모델 체크포인트, 참조 기준선, 모달리티(이미지 / 비디오 / 오디오 / 3D)가 주어지면, 전체 평가 계획을 출력합니다:

1. 샘플 품질. 10-30k 샘플에 대해 FID / FD-DINO / CMMD를 홀드아웃된 실제 데이터셋과 비교합니다. 해상도를 일치시킵니다. 3개 시드 평균 +/- 표준 편차를 보고합니다.
2. 준수. 프롬프트-이미지 쌍에 대해 CLIP 점수 / CMMD를 사용합니다. 텍스트-이미지의 경우 HPSv2 + ImageReward + PickScore를 포함합니다. 비디오의 경우 비전-언어 지표(V-Eval)를 추가합니다. 오디오의 경우 CLAP + MOS를 사용합니다.
3. 쌍별 선호도. 기준선과 비교하여 200-2000개 프롬프트에 대해 블라인드 A/B 테스트를 수행합니다. 인간 + LLM 심사자 + PartiPrompts 커버리지를 포함합니다.
4. 카테고리별 분류. 프롬프트 카테고리별 성능(사람, 동물, 텍스트 렌더링, 구성, 스타일). 전역 지표가 개선되더라도 카테고리별 회귀를 표시합니다.
5. 안전 / 오용. NSFW 분류기, 딥페이크 탐지, 워터마크 검사, 상위 K 생성물에 대한 저작권 유사성 스캔.
6. 승인. 명시적 게이트: FID가 기준선 대비 +5% 이내 OR 인간 승률 >55% OR 문서화된 정성적 우위. 단일 지표 주장은 허용되지 않습니다.

N < 5000일 때 FID를 보고하지 마세요. 모델이 학습 중에 보았을 수 있는 프롬프트로 계산된 벤치마크를 출시하지 마세요. 인간 교차 검증 없이 LLM 심사자 결과만 보고하지 마세요. 절대 기준값을 보고하지 않고 단일 시드만 보고하면서 지표가 "20% 상승했다"는 주장을 표시하세요.
