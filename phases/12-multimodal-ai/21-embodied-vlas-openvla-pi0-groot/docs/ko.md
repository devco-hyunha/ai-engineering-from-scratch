# 구체화된 VLA: RT-2, OpenVLA, π0, GR00T

> 모델이 웹사이트에서 레시피를 읽고 주방 로봇에서 실행한 최초의 사례는 RT-2 (Google DeepMind, 2023년 7월)입니다. RT-2는 행동을 텍스트 토큰으로 이산화하고, 웹 데이터와 로봇 행동 데이터로 VLM을 공동 미세 조정(co-fine-tuning)하여, 웹 규모의 비전-언어 지식이 로봇 제어에 전이된다는 것을 입증했습니다. OpenVLA (2024년 6월)는 오픈 7B 참조 모델을 출시했습니다. Physical Intelligence의 π0 시리즈 (2024-2025)는 흐름 매칭(flow-matching) 행동 전문가를 추가했습니다. NVIDIA의 GR00T N1 (2025년 3월)은 휴머노이드 로봇을 위한 대규모 이중 시스템(System 1 / System 2) 제어 기능을 제공했습니다. VLA 기본 요소인 비전-언어-행동(vision-language-action), 즉 보고, 읽고, 행동하는 단일 모델은 이 단계의 이해 모델과 15단계의 자율 시스템 사이의 다리 역할을 합니다.

**유형:** Learn
**언어:** Python (stdlib, 행동 토크나이저 + VLA 추론 골격)
**선수 요건:** 12단계 · 05강 (LLaVA), 15단계 (자율 시스템, 참조됨)
**시간:** 약 180분

## 학습 목표

- 행동 토큰화(action tokenization)를 설명해 보세요: 이산 바이트 인코딩(discrete bin encoding, RT-2), FAST 효율적인 행동 토큰, 연속 흐름 매칭 행동(π0).
- 웹 + 로봇 데이터에 대한 공동 미세 조정이 새로운 작업에 대한 일반 지식 전이를 보존하는 이유를 설명해 보세요.
- 동일한 로봇 작업에서 OpenVLA (오픈 7B Llama+VLM), π0 (흐름 매칭), GR00T N1 (이중 시스템)을 비교해 보세요.
- Open X-Embodiment 데이터셋과 RT-X 학습 코퍼스(corpus)로서의 역할을 명명해 보세요.

## 문제점

자연어 지시문으로 집안일을 수행하는 로봇은 1970년대부터 연구 목표였습니다. 2020년대의 답은 비전-언어-행동(VLA) 모델입니다. VQA에 사용된 것과 동일한 VLM 아키텍처를 사용하지만, 출력은 텍스트가 아닌 행동(관절 토크, 엔드 이펙터 자세, 이산 명령)입니다.

VLA에 특화된 도전 과제:

1. 행동 공간은 연속적(관절 각도, 힘)이며 고차원적입니다(7-DOF 팔 + 3-DOF 그리퍼 = 30Hz에서 10차원).
2. 로봇 특화 학습 데이터는 희소합니다. Open X-Embodiment에는 약 100만 개의 궤적(trajectory)이 있으며, 웹 텍스트-이미지는 50억 개 이상입니다.
3. 제어 주파수가 중요합니다. 30Hz 제어 루프는 행동당 33ms의 예산을 의미합니다.
4. 안전성. 잘못된 동작은 하드웨어, 인간, 또는 재산에 손상을 줄 수 있습니다.

## 개념

### 동작 토큰화 (RT-2)

RT-2의 핵심 기법: 각 관절 목표값을 양자화된 텍스트 토큰으로 표현합니다. 정규화된 [-1, 1] 범위를 256개 빈(bin)으로 이산화하고, 각 빈을 어휘 ID에 매핑합니다. 10자유도(DOF) 동작은 각 제어 단계에서 10개 토큰이 됩니다.

PaLM-X VLM을 혼합 데이터셋으로 공동 미세 조정합니다:

- 웹 이미지-텍스트 쌍 (캡셔닝, VQA).
- 로봇 시연 데이터, 동작을 토큰으로 표현.

모델은 "빨간색 큐브를 집어" (언어) → 이미지 (비전) → 10개 토큰의 동작 시퀀스 (이산화된 관절 목표값)를 순서대로 처리합니다. 웹 사전 학습은 일반 지식 전이를 보존하므로, RT-2는 "fast-moving"이 학습 데이터에 없음에도 "빠르게 움직이는 물체 쪽으로 이동해"라는 지시를 따를 수 있습니다.

RT-2 논문에서는 VLM의 자기회귀 디코딩에 의해 제한되어 추론 속도가 3-5 Hz입니다.

### OpenVLA — 오픈 7B 참조 모델

OpenVLA (Kim et al., 2024년 6월)는 RT-2의 오픈 웨이트 버전입니다. 7B Llama 백본, DINOv2 + SigLIP 이중 비전 인코더, 256개 빈(bin)에 대한 동작 토큰화를 사용합니다.

Open X-Embodiment (22개 로봇에 걸친 97만 개 궤적)로 학습되었습니다. 새로운 로봇에 적응하기 위한 LoRA 미세 조정 지원이 포함됩니다.

추론: 양자화를 적용한 A100에서 4-5 Hz. 느린 조작에는 충분히 빠르지만, 고주파 제어에는 적합하지 않습니다.

### FAST 토크나이저 — 더 빠른 동작 디코딩

Pertsch et al. (2024)은 이산 빈(bin) 토큰화가 비효율적임을 입증했습니다. 대부분의 동작이 빈 공간의 작은 영역에 집중되기 때문입니다. FAST (주파수 영역 동작 시퀀스 토크나이저)는 DCT를 통해 동작 시퀀스를 압축하고 계수를 양자화합니다.

30단계 동작 궤적은 300개의 이산 빈(bin) 토큰 대신 약 10개의 FAST 토큰이 됩니다. 품질 손실 없이 추론 속도가 3-5배 빨라집니다.

### π0 및 흐름 매칭(flow-matching) 동작

Physical Intelligence의 π0 (Black et al., 2024년 10월)는 이산 동작 토큰을 흐름 매칭(flow-matching) 동작 전문가(expert)로 대체합니다:

- 작은 동작 트랜스포머가 VLM의 은닉 상태를 읽고, rectified flow를 통해 연속적인 50단계 동작 시퀀스를 출력합니다.
- 동작 헤드는 흐름 매칭 손실로 학습되며, VLM 사전 학습은 변경되지 않습니다.
- 추론(Inference): 전체 행동 시퀀스가 약 5단계의 디노이징(denoising) 스텝으로 생성되며, 효과적으로 50 Hz 제어 속도를 달성합니다.

π0의 주장: 광범위한 조작 작업 suite에서 OpenVLA와 Octo를 능가합니다. 연속 행동 formulation은 이산화(discretization)가 파괴하는 부드러움을 보존합니다.

π0.5와 π0-FAST는 점진적인 업그레이드입니다. π0-FAST는 FAST 토큰화(tokenization)와 flow matching을 결합합니다.

### GR00T N1 — 휴머노이드용 이중 시스템

NVIDIA의 GR00T N1 (2025년 3월)은 휴머노이드 로봇(30개 이상의 DOF, 전신)을 위해 구축되었습니다:

- System 2: 장면과 지시문을 읽는 대규모 VLM(Vision-Language Model)으로, 약 1 Hz의 고수준 하위 목표(subgoals)를 생성합니다.
- System 1: 하위 목표에 조건을 둔 소규모 action-head transformer로, 저수준의 50-100 Hz 관절 명령을 생성합니다.

이 분리는 Kahneman의 빠르고 느린 사고(fast-and-slow thinking)에 대응됩니다: System 2는 계획하고, System 1은 실행합니다. 장점: 느린 VLM 규모의 계획이 빠른 제어의 병목이 되지 않으며, System 1은 지연(latency)을 위해 작게 유지됩니다.

GR00T N1.7 (2025년 말)은 데이터 scaling을 개선합니다. GR00T는 Omniverse의 sim-to-real 데이터로 미세 조정(fine-tuning)합니다.

### Open X-Embodiment

훈련 데이터입니다. RT-X (2023년 10월)는 22개 로봇에 걸친 100만 개 궤적(trajectories)을 포함하는 22개 데이터셋을 수집했습니다. Open X-Embodiment는 모두가 사용하는 코퍼pus입니다:

- ALOHA / Bridge V2 / Droid / RT-2 Kitchen / Language Table.
- 각 샘플: (로봇 상태, 카메라 뷰, 지시문, 행동 시퀀스).
- 훈련 위생(training hygiene): 행동 공간(action space) 통합, 관절 범위 정규화(normalization), 카메라 크기 조정.

OpenVLA와 π0는 Open X-Embodiment로 훈련됩니다. 특정 로봇과의 domain gap은 100-1000개의 작업별 데모(demo)에 대한 LoRA 미세 조정(fine-tuning)으로 해소됩니다.

### Co-fine-tuning vs. 로봇 전용 훈련

Co-fine-tuning은 웹 VQA 데이터를 로봇 궤적과 혼합합니다. 비율이 중요합니다: VQA가 너무 많으면 모델이 행동을 잊고, 로봇 데이터가 너무 많으면 모델이 일반 지식을 잃습니다.

RT-2의 비율: 약 1:1. OpenVLA: 약 0.5:1의 web-to-robot 비율. π0: 유사합니다. 정확한 비율은 데이터셋 크기에 따라 조정해야 하는 하이퍼파라미터(hyperparameter)입니다.

로봇 전용 훈련은 out-of-distribution 지시문에서 실패하는 작업 특화 모델을 생성합니다. Co-fine-tuning은 "(데모에서) 빨간 큐브를 집어"와 "(새로운 표현으로) 왼쪽에서 세 번째로 큰 물건을 집어"의 차이를 만듭니다.

### 안전 및 동작 한계

모든 프로덕션 VLA는 다음을 포함합니다:

- 하드 조인트 한계 (사양을 초과하는 토크를 허용하지 않음).
- 속도 한계 (소프트 클리핑).
- 작업 공간 경계 (엔드 이펙터가 테이블 밖으로 나가지 못함).
- 신규 작업에 대한 인간 개입 루프 (HITL)(Human-in-the-Loop (HITL)) 승인.

이러한 요소들은 VLA 외부의 제어 계층 체크로 위치합니다. VLA의 출력은 제안일 뿐, 명령이 아닙니다.

```figure
mm-action-tokens
```

## 사용하기

`code/main.py`:

- 256-빈 동작 토큰화 및 디토큰화를 구현합니다.
- DCT + 양자화(Quantization)를 기반으로 한 FAST 토크나이저를 스케치합니다.
- (이산 빈, FAST, 연속 흐름) 간에 동작 단계별 토큰 수를 비교합니다.
- RT-2 → OpenVLA → π0 → GR00T의 계보 요약(lineage summary)을 출력합니다.

## 출시하기

이 강은 `outputs/skill-vla-action-format-picker.md`를 생성합니다. 로봇 작업(조작, 내비게이션, 휴머노이드 전신)이 주어지면 이산 빈 + RT-2, FAST + OpenVLA, 흐름 매칭 + π0, 또는 이중 시스템 + GR00T 중 하나를 선택합니다.

## 연습 문제

1. 30 Hz 제어 속도의 10-DOF 팔. 256 빈에서의 이산 빈 토큰화는 초당 몇 개의 토큰을 방출합니까? 7B VLM이 이를 따라갈 수 있습니까?

2. FAST 토큰화는 30단계 궤적을 약 10개 토큰으로 압축합니다. 궤적에 고주파 동작(예: 드럼 연주)이 있는 경우 사용자가 잃는 것은 무엇입니까?

3. π0의 흐름 매칭 헤드는 약 5단계로 디노이징(denoising)합니다. 4-5 Hz의 OpenVLA 자기회귀(Autoregressive) 디코딩과 처리량을 비교해 보세요.

4. GR00T의 시스템 1 / 시스템 2 분리는 Kahneman의 이론에 대응됩니다. 이족 보행에 도움이 될 수 있는 다른 분리 방식(시스템 3?)을 제안해 보세요.

5. Open X-Embodiment의 섹션 4를 읽고 데이터셋 큐레이션에 대해 알아보세요. 도메인 누수(Data Leakage)를 방지하는 세 가지 큐레이션 규칙을 나열해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|------------------------|
| VLA | "비전-언어-동작" | 이미지 + 지시문을 입력으로 받아 동작 명령을 출력하는 모델 |
| 동작 토큰화 | "이산 빈" | 연속 조인트 타겟을 차원당 256 빈으로 양자화(Quantization)하고, 각 빈을 어휘(Vocabulary) ID로 매핑 |
| FAST 토크나이저 | "주파수 동작 토큰" | DCT + 양자화(Quantization)로 30단계 궤적을 약 10개 토큰으로 압축 |
| 공동 미세 조정 | "웹 + 로봇 혼합" | 웹 VQA 데이터와 로봇 시연 데이터를 함께 학습하여 일반 지식을 보존합니다 |
| 흐름 매칭 액션 헤드 | "π0 연속 출력" | 수정된 흐름(rectified flow)를 통해 50단계 액션 시퀀스를 출력하는 소형 트랜스포머입니다 |
| 시스템 1 / 시스템 2 | "듀얼 시스템 제어" | 대형 VLM이 느리게 계획하고, 소형 액션 헤드가 빠르게 실행합니다. GR00T 패턴입니다 |
| Open X-Embodiment | "RT-X 데이터셋" | 100만 개 궤적을 포함하는 크로스 로봇 데이터셋으로, 학습 코퍼스입니다 |
