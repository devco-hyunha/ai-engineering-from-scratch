# 멀티모달 RAG 및 교차 모달 검색

> 비전 기반 문서 RAG는 하나의 단면에 불과합니다. 프로덕션 멀티모달 RAG는 더 넓은 범위를 다루며, 여행 계획("자연광이 있는 조용한 비건 브런치를 찾아줘"), 의료 분류("이 사진과 노트에 해당하는 부상은 무엇인가요?"), 전자 상거래("이 셀피와 유사한 옷을 내 사이즈에 맞춰 찾아줘"), 현장 서비스("이 엔진 소음과 부품 사진을 진단해줘")와 같은 워크플로우를 위해 텍스트, 이미지, 오디오, 비디오를 가로질러 검색합니다. 2025년의 세 가지 조사 연구인 Abootorabi et al., Mei et al., Zhao et al.은 하위 문제를 코디파이했습니다: 교차 모달 검색, 검색 융합, 생성 그라운딩, 멀티모달 평가. 이 강의는 이 조사 연구들을 읽고 프로덕션 파이프라인을 설계합니다.

**유형:** Build
**언어:** Python (표준 라이브러리, 융합 및 그라운딩 생성기가 포함된 교차 모달 검색기)
**선수 요건:** 12단계 · 23강 (ColPali), 11단계 (RAG 기초)
**시간:** 약 180분

## 학습 목표

- 교차 모달 검색을 설계하세요: 텍스트 → 이미지, 이미지 → 텍스트, 오디오 → 비디오 등.
- 세 가지 융합 전략을 비교하세요: 점수 융합, 어텐션 기반 융합, MoE 융합.
- 생성 그라운딩을 설명하세요: 소스가 모달리티의 혼합일 때 "소스를 인용하세요"가 어떤 모습인지.
- 2025년의 세 가지 표준 멀티모달 RAG 조사 연구와 그 하위 문제 분류 체계를 나열하세요.

## 문제점

단일 모달리티 RAG는 해결된 패턴입니다: 쿼리를 임베딩하고, 청크를 임베딩하고, 검색하고, LLM에 채워 넣습니다. 멀티모달 RAG는 다음을 요구합니다:

1. 다중 검색 헤드 (각 모달리티는 호환되는 공간에서 임베딩이 필요합니다).
2. 모달리티 간 검색 결과의 융합.
3. 모달리티 간 소스를 인용하는 생성 그라운딩.
4. 교차 모달 신호를 포괄하는 평가 지표.

2025년의 조사 연구들은 모두 동일한 분류 체계에 도달합니다.

## 개념

### 교차 모달 검색

모달리티 A의 쿼리가 주어졌을 때 모달리티 B의 문서를 검색합니다. 세 가지 패턴이 있습니다:

1. 공유 임베딩 공간. CLIP과 CLAP는 공유 공간에서 텍스트 + 이미지 / 텍스트 + 오디오 임베딩을 생성합니다. 모달리티 간 코사인 유사도가 직접 작동합니다. CLIP으로 학습된 쌍에 제한됩니다.

2. 모달리티별 인코더 + 변환. 텍스트 인코더 + 이미지 인코더 + 공간 간 매핑을 수행하는 작은 변환 모듈. Gupta 등의 Sen2Sen 및 기타 2024년 설계. 유연하지만 복잡성이 추가됩니다.

3. VLM을 인코더로 사용. VLM의 은닉 상태를 검색 표현으로 사용합니다. VLM이 지원하는 모든 모달리티가 작동합니다. 품질은 높지만 비용이 더 많이 듭니다.

선택: 텍스트+이미지는 CLIP / SigLIP 2; 텍스트+오디오는 CLAP; 프론티어 수준의 크로스 모달리티는 VLM 은닉 상태.

### 융합 전략

10개의 결과를 검색했습니다: 이미지 5개, 텍스트 passage 3개, 오디오 클립 2개. 어떻게 병합하나요?

점수 융합 (가장 저렴). 각 모달리티는 자체 검색기를 가지며 점수를 반환합니다. 모달리티 내에서 점수를 정규화한 후 합산합니다. 단순하며, 종종 잘 작동합니다.

어텐션 기반 융합. 검색된 모든 항목을 연결하고, 작은 어텐션 네트워크가 가중치를 부여하도록 합니다. 학습이 필요합니다.

MoE 융합. 게이팅 네트워크가 모달리티별 전문가로 라우팅합니다. 쿼리 유형에 따라 라우팅이 달라집니다 — 시각적 질문은 이미지에 더 높은 가중치를 부여합니다.

프로덕션 기본값: 쿼리의 지배적 모달리티에 약간의 편향을 둔 점수 융합. A/B 테스트가 도메인에서 명확한 승리를 보여줄 경우 MoE로 업그레이드하세요.

### 생성 그라운딩

LLM은 각 주장이 어떤 검색된 항목에 의해 주도되었는지 인용해야 합니다. 멀티모달의 경우:

- 텍스트 출처: 표준 인용 `[1]`.
- 이미지 출처: `[img 3]` 및 짧은 캡션.
- 오디오: `[audio 2 at 0:34]`.

그라운딩 인식 데이터로 생성기를 학습하세요: 학습 대상의 각 주장은 출처 인덱스로 태그됩니다. 추론 시 모델은 자연스럽게 인용을 생성합니다.

### 2025년 설문조사

Abootorabi 등 (arXiv:2502.08826, "Ask in Any Modality"): 멀티모달 RAG 분류 체계. 검색, 융합, 생성을 다룹니다. 가장 넓은 커버리지.

Mei 등 (arXiv:2504.08748, "A Survey of Multimodal RAG"): 하위 작업 벤치마크 및 실패 모드에 초점을 맞춥니다. 평가 설계에 유용합니다.

Zhao 등 (arXiv:2503.18016): 비전 중심 설문조사. ColPali 계열 작업에 강합니다.

세 가지를 모두 읽으면 2025년 봄 기준의 최신 상태를 파악할 수 있습니다. 대부분의 하위 문제는 여전히 열려 있습니다.

### MuRAG — 기초 논문

MuRAG (Chen et al., 2022)는 최초의 멀티모달 RAG였습니다. 멀티모달 KB에서 이미지와 텍스트를 검색하고 답변을 생성했습니다. VLM 물결 이전의 실현 가능성을 보여 주었습니다. 현대 시스템(REACT, VisRAG, M3DocRAG)은 이를 기반으로 구축됩니다.

### 생산 환경 여행 계획 예제

쿼리: "자연광이 있는 조용한 비건 브런치를 찾아 주세요."

파이프라인:

1. 쿼리를 분해합니다. "조용한" → 오디오/리뷰 키워드; "비건 브런치" → 메뉴 항목; "자연광" → 이미지 특징.
2. 모달리티별 검색:
   - 리뷰에 대한 텍스트 검색: "비건 브런치, 조용한 분위기."
   - 레스토랑 사진에 대한 이미지 검색: "자연광, 개방감."
   - 주변 소리 클립에 대한 오디오 검색: "저 데시벨, 음악 없음."
3. 점수를 융합합니다. 각 레스토랑은 복합 점수를 가집니다.
4. 상위 k개 레스토랑 → 모든 증거를 포함하는 VLM 생성기 → 인용이 포함된 답변.

이것은 텍스트 RAG를 훨씬 넘어서는 것입니다. 각 모달리티는 텍스트만으로는 놓치는 신호를 추가합니다.

### 에이전트형 멀티모달 RAG

멀티홉: 첫 번째 검색이 높은 신뢰도의 답변을 반환하지 않으면 LLM이 재공식화하고 다시 검색합니다. 14단계의 에이전트형 RAG 패턴이 여기에 적용됩니다. 예:

- 초기 상위 10개 검색 → LLM이 "너무 시끄럽, 40 dB 미만으로 필터링" 요청 → 재검색.
- 이미지 검색 → LLM이 메뉴가 있는 것을 발견 → 메뉴 텍스트 검색 → 답변.

복잡성이 추가되지만, 단일 샷 검색이 처리할 수 없는 쿼리를 처리합니다.

### 평가

교차 모달리티 평가는 아직 성숙하지 않았습니다. 일반적인 대리 지표:

- 모달리티별 Recall@k.
- 융합된 상위 k개 정확도.
- 인간이 판단한 엔드투엔드 만족도.
- 작업별(예약 완료, 구매 완료).

모든 모달리티를 포괄하는 표준 벤치마크는 없습니다. 대부분의 논문은 도메인별 작업으로 평가합니다.

## 사용하기

`code/main.py`:

- 레스토랑 공유 코퍼스에서 작동하는 세 개의 모의 리트리버(텍스트, 이미지, 오디오).
- 구성 가능한 가중치로 모달리티 점수를 결합하는 점수 융합.
- 인용이 포함된 최종 답변을 생성하는 생성기 스텁입니다.
- 신뢰도가 낮으면 쿼리를 재구성하는 단순한 에이전트 루프입니다.

## 연습 문제

1. 의료 트리아지용 멀티모달 RAG를 제안해 보세요. 쿼리 = 부상 사진 + 텍스트 증상. 어떤 모달리티가 어떤 KB에서 검색하나요?

2. 점수 융합은 단순한 가중 합입니다. MoE 융합이 피하는 실패 모드에는 어떤 것이 있나요?

3. Abootorabi 등의 분류 체계(3장)를 읽어 보세요. 세 가지 표준 하위 문제는 무엇이며, 선택한 제품에 어떻게 매핑되나요?

4. 여행 계획용 멀티모달 RAG에 대한 평가 사양을 설계해 보세요. 이미지 리콜, 오디오 리콜 및 복합 정확도를 다루는 지표는 무엇인가요?

5. 에이전트형 멀티홉 RAG는 왕복마다 지연 비용이 발생합니다. 쿼리 난이도가 어느 수준일 때 정확도 향상분이 지연을 정당화하나요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|------------------------|
| 교차 모달리티 검색 | "한 모달리티로 쿼리하여 다른 모달리티를 검색" | 텍스트 쿼리가 이미지를 검색하고, 이미지 쿼리가 텍스트를 검색합니다. 공유 공간이나 변환기가 필요합니다 |
| 점수 융합 | "점수를 결합" | 모달리티별 검색 점수의 가중 합입니다. 가장 단순한 융합 방식 |
| MoE 융합 | "모달리티 라우팅 전문가" | 게이팅 네트워크가 쿼리별로 신뢰할 모달리티의 점수를 선택합니다 |
| 그라운딩된 생성 | "출처를 인용" | 답변의 모든 주장이 출처 인덱스로 태그됩니다 |
| MuRAG | "첫 번째 멀티모달 RAG" | 멀티모달 RAG 패턴을 확립한 2022년 논문 |
| 에이전트형 멀티홉 | "재구성하고 재시도" | LLM이 첫 번째 신뢰도가 낮을 때 리트리버에 다시 쿼리합니다 |
