LLaVA 계열 VLM (LLaVA-1.5, LLaVA-NeXT, LLaVA-OneVision 또는 커뮤니티 포크)과 테스트 이미지 세트가 주어지면, 캡셔닝, VQA, 추론, 거부, 형식 준수를 포함하는 10개 프롬프트 스모크 테스트를 실행합니다. 프로젝터와 LLM이 올바르게 연결되어 있음을 확인하는 스코어카드를 생성합니다.

생성물:

1. 기대 동작 설명이 포함된 10개 프롬프트:
   - 3개의 캡셔닝 (짧은, 상세한, 창의적인).
   - 3개의 VQA (개수 세기, 색상, 객체 존재 여부).
   - 2개의 추론 (두 영역 비교, 인과 관계).
   - 2개의 거부 (개인 정보, PII 식별).
2. 프롬프트별 점수. 통과 / 부분 통과 / 실패와 한 줄 근거.
3. 전체 패턴 진단. 캡셔닝은 통과하지만 VQA가 실패하면 스테이지 2 데이터 혼합을 의심합니다. 상세 캡셔닝에 환각(Hallucination)이 나타나면 ShareGPT4V 스타일 데이터 부족을 의심합니다. 거부가 실패하면 안전 데이터 공백을 표시합니다.
4. 해상도 확인. OCR이 필요한 프롬프트를 336x336 기본 해상도와 AnyRes에서 각각 실행하고 차이를 기록합니다. 저해상도 실패는 예상됩니다. 고해상도 실패는 AnyRes가 잘못 구성되었음을 의미합니다.
5. 제안된 후속 조치. 특정 범주가 실패할 경우 호출자가 실행할 수 있는 세 가지 구체적인 훈련 데이터 추가 사항.

하드 리젝트(Hard rejects):
- 바이브스 평가(vibes suite)를 실행하지 않고 벤치마크 수치만으로 VLM을 채점하는 것. 벤치마크는 조작될 수 있으며, 바이브스 평가는 실제 배포 준비 상태를 드러냅니다.
- 환각(Hallucination)을 문체적 장황함과 혼동하는 것. 객체가 발명된 것인지, 단순히 상세하게 묘사된 것인지 구체적으로 표시합니다.
- 최종 답변만 확인하고 추론 체인(reasoning chain)을 확인하지 않은 채 추론 프롬프트에 통과를 주장하는 것.

거부 규칙:
- 호출자가 API 접근 권한 없이 독점 VLM (Gemini, Claude, GPT-5V)에 대해 바이브스 평가(vibes-eval)를 요청하면 거부합니다. 테스트에는 실제 추론(Inference)이 필요합니다.
- 대상 사용 사례가 의료 진단이나 법률 조언인 경우 거부합니다. 바이브스 평가(vibes-eval)는 인증이 아니며 고위험 도메인에 사용해서는 안 됩니다.
- 이미지가 제공되지 않으면 거절하세요 — 테스트는 정의상 이미지 기반입니다.

출력: 10개의 행(프롬프트, 이미지, 예상, 실제, 통과/부분 통과/실패)을 포함한 스코어카드, 전체 패턴 진단, 그리고 세 항목의 후속 조치 목록을 생성하세요. 해상도 관련 실패의 경우 12.06강(AnyRes)을, 데이터 혼합 튜닝의 경우 12.07강(ablations)을 가리키는 "다음에 읽을 내용" 단락으로 마무리하세요.
