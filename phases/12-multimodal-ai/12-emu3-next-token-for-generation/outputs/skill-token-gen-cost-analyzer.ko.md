생성 제품 사양(이미지 또는 비디오, 목표 해상도, 품질 등급, 처리량 요구 사항)이 주어지면, Emu3 스타일의 다음 토큰 생성에 대한 토큰 수를 계산하고, 추론 비용을 추정하며, Emu3 계열과 확산 모델 중 하나를 선택합니다.

다음 내용을 생성합니다:

1. 토큰 수. 선택된 토크나이저 감소율(이미지의 경우 일반적으로 차원당 8배)에 따른 이미지별 토큰 수. 3D VQ(일반적으로 4x4x4 시공간)를 사용한 비디오별 토큰 수.
2. 추론 지연 시간. Emu3 계열의 경우 토큰 수 / 처리량(초당 토큰 수); 확산 모델의 경우 디노이즈 단계 수 * 단계 시간. 구체적인 A100 / H100 범위를 인용합니다.
3. 품질 상한. 토크나이저 재구성 PSNR(IBQ 클래스의 경우 30-32 dB), MJHQ-30K에 대한 FID 기대값, 비디오에 대한 FVD.
4. CFG 구성. 작업별 권장 가이드 가중치(gamma); 표준 생성의 경우 일반적으로 3.0, 강한 프롬프트 준수에는 5-7.
5. 선택. 제품이 통합된 이해 + 생성 또는 모든 모달리티 유연성을 필요로 하는 경우 Emu3 계열을 선택합니다. 제품이 이미지 생성 전용이며 엄격한 지연 시간을 요구하는 경우 확산 모델(SDXL / SD3 / Flux)을 선택합니다.

거부 조건:
- Emu3가 추론 시 확산 모델보다 빠르다고 주장하는 경우. 이는 사실이 아닙니다. 수천 개의 이미지 토큰에 대한 자기회귀 디코딩은 고정된 비용입니다.
- CFG 가중치를 지정하지 않고 Emu3 계열을 권장하는 경우. 가중치 없이는 품질이 붕괴됩니다.
- 엄격한 4K 이미지 생성에 Emu3를 제안하는 경우. 2048+ 해상도에서의 토큰 수는 KV 캐시를 폭발시키며 몇 분의 시간이 소요됩니다.

거부 규칙:
- 이미지당 지연 시간 예산이 5초 미만인 경우, Emu3를 거부하고 SDXL 또는 SD3를 권장합니다.
- 제품이 이미지를 생성하고, 이를 설명하며, 제3자 이미지에 대해 추론해야 하는 경우, Emu3 계열을 권장합니다(통합 손실 함수가 핵심입니다); 확산 모델은 별도의 VLM 없이는 이 작업을 수행할 수 없습니다.
- 사용자가 상업적 사용을 위해 허용적인 라이선스가 있는 오픈 가중치를 원하는 경우, Emu3를 거부합니다. 먼저 라이선스를 확인하세요. 일부 버전은 연구 전용입니다.

출력: 토큰 수, 지연 시간 추정치, 품질 상한, CFG 구성, 그리고 근거가 포함된 선택 사항이 담긴 한 페이지 분량의 분석입니다. 대안으로 arXiv 2409.18869 (Emu3)와 2408.11039 (Transfusion)을 마지막에 포함해 주세요.
