# CLIP에서 BLIP-2로 — 모달리티 브리지로서의 Q-Former

> CLIP은 이미지와 텍스트를 정렬(Alignment)할 수 있지만, 캡션을 생성하거나 질문에 답하거나 대화를 유지할 수 없습니다. BLIP-2 (Salesforce, 2023)는 이 문제를 작은 학습 가능한 브리지로 해결했습니다: 32개의 학습 가능한 쿼리 벡터가 고정된 ViT의 특징에 교차 어텐션(Cross-Attention)으로 접근한 후, 고정된 LLM (대규모 언어 모델)(LLM (Large Language Model))의 입력 스트림에 직접 슬롯을 넣습니다. 1억 8800만 파라미터의 브리지가 110억 파라미터의 LLM을 ViT-g/14에 연결했습니다. 2026년까지의 모든 어댑터 기반 VLM (비전-언어 모델)(VLM (Vision-Language Model)) — MiniGPT-4, InstructBLIP, LLaVA의 친척들 —는 이의 후손입니다. 이 강의는 Q-Former의 아키텍처를 읽고, 2단계 학습을 설명하며, 시각 토큰을 고정된 텍스트 디코더에 공급하는 토이 버전을 구축합니다.

**유형:** Build
**언어:** Python (stdlib, 교차 어텐션 + 학습 가능한 쿼리 데모)
**선수 요건:** 12단계 · 02강 (CLIP), 7단계 (트랜스포머(Transformer))
**시간:** 약 180분

## 학습 목표

- 고정된 비전 인코더와 고정된 LLM (대규모 언어 모델)(LLM (Large Language Model)) 사이의 학습 가능한 병목 현상이 비용과 안정성 측면에서 엔드투엔드 미세 조정(Fine-tuning)을 능가하는 이유를 설명해 보세요.
- 고정된 학습 가능한 쿼리 세트가 외부 이미지 특징에 어텐션하는 교차 어텐션(Cross-Attention) 블록을 구현해 보세요.
- BLIP-2의 2단계 사전 학습을 따라가 보세요: 표현 (ITC + ITM + ITG) 다음 생성 (고정된 디코더를 사용한 LM 손실 함수(Loss Function)).
- Q-Former를 LLaVA에서 사용된 더 단순한 MLP 프로젝터와 비교하고, 각 선택이 승리하는 시점을 논증해 보세요.

## 문제점

이미지당 차원 1408의 256개 패치 토큰을 생성하는 고정된 ViT가 있습니다. 차원 4096의 토큰 임베딩을 기대하는 고정된 70억 파라미터 LLM (대규모 언어 모델)(LLM (Large Language Model))이 있습니다. obvious한 브리지인 1408에서 4096으로의 선형 레이어는 작동하지만, 모든 256개 패치 토큰을 LLM의 컨텍스트 윈도우(Context Window)에 공급하면 이미지당 256개의 추가 토큰이 소모됩니다. 32개 이미지 배치를 고려하면 시각 모달리티(Modalities)만으로 8192개의 토큰이 소모됩니다.

BLIP-2의 질문: LLM이 캡션을 생성하고, 질문에 답하고, 이미지에 대해 추론할 만큼 충분한 정보를 보존하면서 256개 토큰의 이미지 표현을 훨씬 적은 토큰 (예를 들어 32개)으로 압축할 수 있을까요? 그리고 고정된 백본을 건드리지 않고, 학습 비용을 브리지의 파라미터에만 유지하면서 이 브리지를 학습할 수 있을까요?

정답은 Q-Former입니다. ViT의 패치 토큰에 교차 어텐션(cross-attend)하는 32개의 학습 가능한 "쿼리" 벡터가 32개 토큰의 시각적 요약(sumaary)를 생성하며, LLM이 이를 소비합니다. 총 매개변수는 188M입니다. LLM을 건드리기 전에 대조 학습(Contrastive Learning), 매칭, 생성 목적 함수로 학습됩니다.

## 개념

### 학습 가능한 쿼리

Q-Former의 핵심 트릭은 LLM의 텍스트 토큰이 이미지 패치에 어텐션하도록 하는 대신, 새로운 32개의 학습 가능한 쿼리 벡터 `Q`를 도입하고 *그들이* 이미지 패치에 어텐션하도록 하는 것입니다. 쿼리는 모델의 매개변수이며, 학습 중에 학습되고 모든 이미지에서 동일한 32개의 쿼리가 사용됩니다.

교차 어텐션(Cross-Attention) 후, 각 쿼리는 이미지의 압축된 요약("주요 객체 설명", "배경 설명", "객체 수 세기" 등)을 포함합니다. 쿼리는 문자 그대로 의미론적 레이블에 특화되지 않으며, 하위 손실(losses)을 낮추는 인코딩을 학습합니다.

### 아키텍처

Q-Former는 두 경로가 있는 작은 트랜스포머(12층, 약 100M 매개변수)입니다:

1. 쿼리 경로: 32개의 쿼리 벡터가 셀프 어텐션(Self-Attention)(서로 간)을 거친 후, 동결된 ViT의 패치 토큰에 대한 교차 어텐션(Cross-Attention)을 거치고, FFN을 통과합니다.
2. 텍스트 경로: BERT 유사 텍스트 인코더가 쿼리 경로와 셀프 어텐션 및 FFN 가중치를 공유합니다. 텍스트 경로에서는 교차 어텐션(Cross-Attention)이 비활성화됩니다.

학습 시간에는 두 경로가 모두 실행됩니다. 쿼리와 텍스트는 공유된 셀프 어텐션(Self-Attention)을 통해 상호작용하므로, 쿼리는 텍스트가 필요한 작업(ITM, ITG)에 텍스트를 조건으로 삼을 수 있습니다. VLM 핸드오프(Handoff)를 위한 추론 시간에는 쿼리만 흐르며, 32개의 시각적 토큰을 생성합니다.

### 2단계 학습

BLIP-2는 두 단계로 사전 학습합니다:

1단계: 표현 학습(LLM 없음). 세 가지 손실:
- ITC (이미지-텍스트 대조 학습): 풀링된 쿼리 토큰과 텍스트 CLS 토큰 간의 CLIP 스타일 대조 학습(Contrastive Learning).
- ITM (이미지-텍스트 매칭): 이진 분류기 — 이 이미지-텍스트 쌍이 매칭입니까? 하드 네거티브(hard-negative)로 채굴됨.
- ITG (이미지 기반 텍스트 생성): 쿼리에 조건을 둔 텍스트의 인과적 LM 헤드. 쿼리가 텍스트 생성 가능한 내용을 인코딩하도록 강제합니다.

Q-Former만 학습합니다. ViT는 동결됩니다. LLM은 관여하지 않습니다.

2단계: 생성형 학습. 동결된 LLM (OPT-2.7B 또는 Flan-T5-XL 등)을 연결합니다. 작은 선형 레이어를 통해 32개의 쿼리 출력값을 LLM의 임베딩 차원으로 투영합니다. 이를 텍스트 프롬프트 앞에 붙입니다. 연결된 프롬프트 + 이미지 + 캡션 시퀀스에 대한 LM 손실(loss)에 대해 선형 투영 레이어와 Q-Former만 학습합니다.

2단계 이후, Q-Former + 투영 레이어가 전체 시각 어댑터가 됩니다. 추론 시: 이미지 → ViT → Q-Former → 선형 투영 → 텍스트 앞에 붙임 → 동결된 LLM이 출력 생성.

### 매개변수 경제성

BLIP-2는 ViT-g/14 (1.1B, 동결) + OPT-6.7B (6.7B, 동결) + Q-Former (188M, 학습) = 총 8B, 학습 매개변수 188M입니다. Q-Former는 전체 스택 매개변수의 약 2.4%에 불과합니다. 학습 비용도 이를 반영합니다: 몇 개의 A100으로 며칠이 걸리는 반면, 엔드투엔드(end-to-end) 학습은 몇 주가 걸립니다.

품질: BLIP-2는 제로샷 VQA에서 Flamingo-80B와 동등하거나 더 나은 성능을 보이면서도 크기는 50배 작습니다. 브리지(bridge) 방식이 효과적입니다.

### InstructBLIP과 지시문 인식 Q-Former

InstructBLIP (2023)은 Q-Former에 추가 입력으로 지시문 텍스트 자체를 포함합니다. 교차 어텐션(cross-attention) 시 쿼리들은 이제 이미지 패치와 지시문 모두에 접근할 수 있습니다. 쿼리들은 단일 고정 요약이 아니라 지시문별로 특화될 수 있습니다 ("자동차 수 세기", "분위기 묘사"). 홀드아웃(held-out) 작업에서 벤치마크 성능이 향상됩니다.

### MiniGPT-4와 투영 레이어 전용 접근법

MiniGPT-4는 Q-Former를 유지하되, 나머지 모든 부분을 동결하고 출력 선형 투영 레이어만 학습했습니다. 비용은 저렴하지만, 품질이 희생됩니다 — 쿼리는 BLIP-2의 것이지 사용자의 것이 아닙니다. 빠른 반복에는 적합하지만, 최적의 아키텍처는 아닙니다.

### LLaVA가 더 단순해진 이유

LLaVA (2023, 12.05강)는 Q-Former를 단순한 2층 MLP로 대체하여 모든 ViT 패치 토큰을 LLM 공간으로 투영합니다 — 24x24 그리드당 이미지당 576개 토큰을 모두 LLM에 입력합니다. 압축률은 낮지만, LLM이 원시 패치에 어텐션할 수 있게 합니다. 당시에는 논쟁이 있었지만, 2023년 후반에는 시각 지시문 데이터 (LLaVA-Instruct-150k)가 MLP가 충분한 신호를 보존하도록 학습될 수 있음을 증명하면서 지배적이 되었습니다. 트레이드오프: LLaVA의 컨텍스트는 더 빨리 채워지지만, 다중 이미지 및 비디오로 자연스럽게 확장됩니다.

2026년경 이 분야는 분화되었습니다: 토큰 예산이 중요한 경우(긴 영상, 다수의 이미지)에는 Q-Former가 살아남고, 토큰당 원시 품질이 우선인 경우 MLP 프로젝터가 지배합니다.

### 게이트된 교차 어텐션: Flamingo, 조상 격

Flamingo(12.04강)는 BLIP-2보다 먼저 등장했으며, 동일한 교차 어텐션 아이디어를 사용했지만 모든 동결된 LLM 레이어에서 적용했고, 단일 브리지로만 사용하진 않았습니다. BLIP-2는 입력 레이어에만 압축해도 잘 작동한다는 것을 보여 주었습니다. Gemini와 Idefics는 두 방식을 결합합니다: 인터리브드 입력 토큰과 선택적 게이트된 교차 어텐션을 인컨텍스트 소수 예시(few-shot)에 사용합니다.

### 2026년 후손들

- Q-Former: BLIP-2, InstructBLIP, MiniGPT-4, 그리고 토큰 예산 문제로 대부분의 영상-언어 모델.
- Perceiver 리샘플러: Flamingo의 변형(12.04강); Idefics 계열, Eagle, OmniMAE.
- MLP 프로젝터: LLaVA, LLaVA-NeXT, LLaVA-OneVision, Cambrian-1.
- 어텐션 풀: VILA, PaliGemma.

네 가지 모두 유효합니다. 결정적인 질문은 토큰 예산에 제약이 있는지, 토큰당 품질에 제약이 있는지입니다.

## 사용하기

`code/main.py`는 표준 라이브러리 기반 Q-Former 스타일 교차 어텐션을 구축합니다:

1. 256개의 이미지 패치 토큰(차원 128)을 시뮬레이션합니다.
2. 32개의 학습 가능한 쿼리(차원 128)를 인스턴스화합니다.
3. 스케일된 점 곱 교차 어텐션을 실행합니다(Q는 쿼리에서, K/V는 패치에서).
4. 선형 레이어를 통해 LLM 차원(512)으로 프로젝션합니다.
5. 32개의 LLM 준비된 시각 토큰을 출력합니다.

모든 연산은 순수 Python으로 수행합니다(벡터에 대한 중첩 루프). 장난감 수준이지만 형태는 정확합니다. 어텐션 가중치 행렬이 출력되어 각 쿼리가 어떤 패치에서 정보를 가져왔는지 확인할 수 있습니다.

## 연습 문제

1. PyTorch로 교차 어텐션 블록을 구현합니다. 32개의 쿼리와 256개의 키/값을 사용할 때 어텐션 가중치 행렬이 32 x 256이며, 소프트맥스 후 각 행의 합이 1임을 검증합니다.

2. BLIP-2 1단계에서 Q-Former는 ITC, ITM, ITG 세 가지 손실 함수를 동시에 실행합니다. 각 손실 함수의 forward 시그니처를 의사 코드(pseudo-code)로 작성해 보세요. 어느 손실 함수가 텍스트 인코더 경로가 활성화되어야 합니까?

3. 매개변수 수를 비교해 보세요: Q-Former (12층, hidden size 768) vs 2층 MLP 프로젝터 (1408 → 4096, 두 층). LLM 규모가 어느 정도일 때 188M 크기의 Q-Former 비용이 학습 효율성 측면에서 회수됩니까?

4. BLIP-2 논문(arXiv:2301.12597)의 3.2절을 읽고 Q-Former가 어떻게 초기화되는지 설명하세요. BERT-base로 초기화하는 것(무작위 초기화 아님)이 수렴을 가속화하는 이유를 설명해 보세요.

5. 10분 길이의 영상을 1 FPS로 샘플링하여 60 프레임을 얻는 경우, 프레임당 토큰 비용을 계산해 보세요: (Q-Former → 프레임당 32 토큰) vs (MLP 프로젝터 → 프레임당 576 토큰). 어느 방식이 128k 토큰 LLM 컨텍스트 윈도우에 적합합니까?

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| Q-Former | "Querying transformer" | 32개의 학습 가능한 쿼리 벡터를 가지며, 동결된 ViT 특징과 교차 어텐션(Cross-Attention)하는 작은 트랜스포머 |
| 학습 가능한 쿼리 | "비전용 소프트 프롬프트" | 교차 어텐션의 쿼리 역할을 하는 고정된 매개변수 집합; 모델별로 학습되며 모든 입력에 공유됨 |
| 교차 어텐션 | "Q는 여기서, K/V는 저기서" | 쿼리, 키, 값이 서로 다른 출처에서 오는 어텐션; 쿼리가 ViT 패치에서 정보를 끌어오는 방식 |
| ITC | "이미지-텍스트 대비 학습" | Q-Former의 풀링된 쿼리와 텍스트 CLS에 적용된 CLIP 스타일 손실 |
| ITM | "이미지-텍스트 매칭" | 하드 네거티브(hard-negative)로 채굴된 쌍에 대한 이진 분류기; 쿼리가 세밀한 불일치를 구별하도록 강제 |
| ITG | "이미지 기반 텍스트 생성" | 쿼리 조건으로 텍스트가 생성되는 인과적 언어 모델(Causal LM) 손실; 쿼리가 텍스트로 디코딩 가능한 내용을 인코딩하도록 강제 |
| 2단계 사전 학습 | "표현 학습 후 생성 학습" | 1단계는 Q-Former만 학습(ITC/ITM/ITG); 2단계는 동결된 LLM을 연결하고 프로젝션 + Q-Former만 학습 |
| 동결된 백본 | "미세 조정하지 마세요" | 비전 인코더와 LLM 가중치는 고정되어 있으며, 브리지(bridge)만 학습 |
| 프로젝션 헤드 | "LLM 차원으로 선형 변환" | Q-Former 출력을 LLM의 임베딩 차원으로 매핑하는 최종 선형 레이어 |
| Perceiver 리샘플러 | "Flamingo의 버전" | 학습 가능한 쿼리 교차 어텐션이 유사하며, Flamingo는 단일 브리지로 사용하는 대신 모든 레이어에서 사용 |
