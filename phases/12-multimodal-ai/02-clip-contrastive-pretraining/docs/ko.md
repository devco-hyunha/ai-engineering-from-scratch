# CLIP 및 대조적 비전-언어 사전 학습

> OpenAI의 CLIP (2021)은 향후 5년을 뒷받침할 만큼 큰 하나의 아이디어를 증명했습니다: 노이즈가 있는 웹 이미지-캡션 쌍과 대조 손실만 사용하여 이미지 인코더와 텍스트 인코더를 동일한 벡터 공간에 정렬하는 것입니다. 지도 학습 레이블은 0개, 쌍은 4억 개입니다. resulting embedding space는 제로샷 분류, 이미지-텍스트 검색을 수행하며, 2026년 모든 VLM의 비전 타워로 연결됩니다. SigLIP 2 (2025)는 softmax를 sigmoid로 대체하고 더 낮은 비용으로 CLIP을 넘어 확장했습니다. 이 강의는 InfoNCE에서 sigmoid 쌍별 손실까지의 수학적 과정을 거치고, stdlib Python으로 학습 단계를 구축합니다.

**유형:** Build
**언어:** Python (stdlib, InfoNCE + sigmoid 손실 구현)
**선수 요건:** 12단계 · 01강 (ViT 패치), 7단계 (트랜스포머)
**시간:** 약 180분

## 학습 목표

- 상호 정보(mutual information)로부터 InfoNCE 손실을 유도하고, 수치적으로 안정적인 벡터화 버전을 구현합니다.
- sigmoid 쌍별 손실(SigLIP)이 softmax가 요구하는 all-gather 오버헤드 없이 배치 크기 32768+로 확장되는 이유를 설명합니다.
- 텍스트 템플릿(`a photo of a {class}`)을 구성하고 코사인 유사도에 대해 argmax를 취하여 제로샷 ImageNet 분류를 실행합니다.
- CLIP / SigLIP 사전 학습이 제공하는 네 가지 레버를 나열합니다: 배치 크기, 온도, 프롬프트 템플릿, 데이터 품질.

## 문제점

CLIP 이전의 비전 분야는 지도 학습이었습니다. 레이블이 지정된 데이터셋(ImageNet: 이미지 120만 개, 클래스 1000개)을 수집하고, CNN을 학습하고, 출시했습니다. 레이블은 비싸고, 레이블러가 합의할 수 있는 것에 편향되며, 미세 조정 없이는 새로운 작업으로 전이되지 않습니다.

이미지-캡션 웹은 10억 개 이상의 느슨하게 레이블이 지정된 쌍을 무료로 제공합니다. 골든 리트리버 사진에 "my dog Max in the park"라는 alt 텍스트가 있으면, 텍스트가 이미지를 설명하므로 지도 신호가 존재합니다. 질문은 이것을 유용한 학습으로 전환할 수 있느냐입니다.

CLIP의 답은 이미지-캡션 쌍을 매칭 작업으로 취급하는 것입니다. N개의 이미지와 N개의 캡션으로 구성된 배치를 주어, N-1개의 방해물(distractor)에 대해 각 이미지를 자신의 캡션과 매칭하도록 학습합니다. 지도 신호는 "이 두 가지는 함께 속한다; 이 N-1개는 속하지 않는다"입니다. 클래스 레이블은 없고, 인간 주석도 없습니다. 오직 대조 손실만 있습니다.

결과적으로 생성된 임베딩 공간은 CLIP이 학습된 목적 그 이상을 수행합니다. ImageNet 제로샷이 작동하는 이유는 "a photo of a cat"이 명시적으로 고양이로 라벨링되지 않은 고양이 사진들 근처에 임베딩되기 때문입니다. 이것이 2026년 모든 VLM을 탄생시킨 베팅입니다.

## 개념

### 듀얼 인코더

CLIP은 두 개의 타워를 가지고 있습니다:

- 이미지 인코더 `f`: ViT 또는 ResNet, 이미지당 D차원 벡터를 출력합니다.
- 텍스트 인코더 `g`: 작은 트랜스포머, 캡션당 D차원 벡터를 출력합니다.

두 타워 모두 출력값을 단위 길이로 정규화합니다. 둘 다 단위 노름(unit-norm)이므로 유사도는 `cos(f(x), g(y)) = f(x)^T g(y)`입니다.

N개의 (이미지, 캡션) 쌍으로 이루어진 배치에 대해, `(N, N)` 형태의 유사도 행렬 `S`을 구축합니다:

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

여기서 `tau`는 학습된 온도 파라미터입니다 (CLIP은 0.07으로 초기화하며, 로그 공간에서 학습됩니다).

### InfoNCE 손실

CLIP은 행과 열에 대한 대칭 교차 엔트로피를 사용합니다:

```
loss_i2t = CE(S, labels=identity)     # 각 이미지의 양의 예(positive)는 자신의 캡션입니다
loss_t2i = CE(S^T, labels=identity)   # 각 캡션의 양의 예는 자신의 이미지입니다
loss = (loss_i2t + loss_t2i) / 2
```

이것이 InfoNCE입니다. CE의 소프트맥스는 각 이미지가 배치 내의 다른 모든 캡션보다 자신의 캡션과 더 잘 매칭되도록 강제합니다. "음의 예(negatives)"는 배치 내의 다른 모든 항목입니다. 더 큰 배치 = 더 많은 음의 예 = 더 강한 신호. CLIP은 배치 크기 32k로 학습되었습니다; 스케일이 중요합니다.

### 온도

`tau`는 소프트맥스의 날카로움을 제어합니다. 낮은 tau → 날카로운 분포, 하드 음의 예 마이닝 효과. 높은 tau → 부드러운 분포, 모든 샘플이 기여합니다. CLIP은 log(1/tau)를 학습하며, 붕괴를 방지하기 위해 클리핑합니다. SigLIP 2는 초기 tau를 고정하고 대신 학습된 편향을 사용합니다.

### 시그모이드가 더 잘 확장되는 이유 (SigLIP)

소프트맥스는 전체 유사도 행렬을 동기화해야 합니다. 분산 학습에서는 모든 임베딩을 모든 레플리카에 all-gather해야 하며, 그 후 소프트맥스를 수행해야 합니다. 이는 통신 측면에서 월드 크기에 대해 이차적입니다.

SigLIP은 소프트맥스를 요소별 시그모이드로 대체합니다: 각 쌍 `(i, j)`에 대해, 손실은 "이 쌍이 매칭 쌍인가?"에 대한 이진 분류입니다. 양의 클래스 레이블은 대각선이며, 나머지는 모두 음의 예입니다. 손실은 다음과 같습니다:

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`y_ij = 1`가 `i == j`이면, 그렇지 않으면 0입니다. 각 쌍의 손실은 독립적입니다. 올-개더(all-gather)가 필요하지 않습니다. 각 GPU는 로컬 블록을 계산하고 합산합니다. SigLIP 2는 CLIP이 비례적으로 더 많은 통신을 필요로 하는 상황에서 배치 크기 32k-512k까지 저렴하게 확장됩니다.

### 제로샷 분류

N개의 클래스 이름이 주어지면, 각 클래스에 대해 텍스트 템플릿을 생성합니다:

```
"a photo of a {class}"
```

텍스트 인코더로 각 템플릿을 임베딩하고, 이미지 인코더로 이미지를 임베딩합니다. 코사인 유사도의 argmax가 예측된 클래스입니다. 대상 클래스에 대한 학습이 필요하지 않습니다.

프롬프트 템플릿이 중요합니다. CLIP의 원 논문은 각 클래스에 대해 80개의 템플릿(plain, artistic, photo, painting 등)을 사용하고 임베딩을 평균화했습니다. ImageNet 점수가 +3 상승했습니다. 현대적인 사용에서는 일반적으로 하나 또는 두 개의 템플릿을 선택합니다.

### 선형 프로브와 미세 조정

제로샷은 기준선입니다. 선형 프로브(동결된 CLIP 기능 위에 대상 클래스에 대한 선형 레이어 하나를 학습)는 인-도메인 작업에서 제로샷보다 성능이 좋습니다. 전체 미세 조정은 인-도메인에서 선형 프로브보다 성능이 좋지만 제로샷 전이를 해칠 수 있습니다. 세 가지 영역과 세 가지 트레이드오프가 있습니다.

### SigLIP 2: NaFlex 및 밀집 기능

SigLIP 2 (2025)는 다음을 추가합니다:
- NaFlex: 단일 모델이 가변적인 종횡비와 해상도를 처리합니다.
- 분할 및 깊이 추정용 더 나은 밀집 기능으로, VLM에서 동결된 백본으로 사용하도록 목표로 합니다.
- 다국어: CLIP이 영어 전용이었던 것과 달리 100개 이상의 언어로 학습되었습니다.
- CLIP이 400M에서 최고점에 도달한 것과 달리 1B 매개변수 규모입니다.

2026년 오픈 VLM에서는 SigLIP 2 SO400m/14가 기본 비전 타워입니다. CLIP은 LAION-2B 학습 분포가 쿼리 패턴과 일치하는 순수 이미지-텍스트 검색의 기본으로 남아 있습니다.

### ALIGN, BASIC, OpenCLIP, EVA-CLIP

ALIGN (Google, 2021): CLIP과 동일한 아이디어로, 1.8B 쌍 규모이며 90%가 잡음입니다. 잡음 데이터가 확장된다는 것을 증명했습니다. OpenCLIP (LAION): LAION-400M / 2B에서 CLIP의 오픈 재현으로, 여러 규모를 가지며 표준 오픈 체크포인트입니다. EVA-CLIP: 마스크된 이미지 모델링에서 초기화되며, VLM용 강력한 백본입니다. BASIC: Google의 CLIP+ALIGN 하이브리드입니다. 모두 같은 계열이며, 데이터와 튜닝이 다릅니다.

### 제로샷 상한선

CLIP 계열 모델은 ImageNet 제로샷 성능이 약 76% (CLIP-G, OpenCLIP-G)에서 상한을 찍습니다. 그 이상을 달성하려면 훨씬 더 큰 데이터(SigLIP 2는 80%+)나 아키텍처 변경(지도 학습 헤드, 더 많은 매개변수)이 필요합니다. 벤치마크는 포화 상태에 접어들고 있으며, 진정한 가치는 다운스트림 VLM이 소비하는 임베딩 공간입니다.

## 사용하기

`code/main.py`는 다음을 구현합니다:

1. numpy 없이 InfoNCE의 형태를 확인할 수 있도록, 해시 기반 이미지 특징과 텍스트 문자 특징을 사용하는 장난감 이중 인코더(dual encoder)를 제공합니다.
2. 순수 Python으로 InfoNCE 손실 함수를 구현합니다(log-sum-exp를 통해 수치적 안정성을 확보합니다).
3. 비교를 위해 시그모이드 쌍별(pairwise) 손실 함수를 제공합니다.
4. 제로샷 분류 루틴: 텍스트 프롬프트 집합에 대해 코사인 유사도를 계산하고, argmax를 통해 예측값을 도출합니다.

실행하여 손실 곡선을 관찰해 보세요. 절대적인 수치는 장난감 수준이지만, 곡선의 형태는 실제 CLIP 트레이너가 생성하는 결과와 일치합니다.

## 출시하기

이 강의는 `outputs/skill-clip-zero-shot.md`를 생성합니다. 경로로 지정된 이미지 집합과 대상 클래스 목록이 주어지면, CLIP 템플릿으로 텍스트 프롬프트를 구성하고, 지정된 체크포인트(예: `openai/clip-vit-large-patch14`)로 양쪽을 임베딩하여 유사도 점수와 함께 top-1 / top-5 예측값을 반환합니다. 이 스킬은 프롬프트 목록에 없는 클래스에 대한 주장을 하지 않습니다.

## 연습 문제

1. 4개 쌍으로 구성된 배치에 대해 InfoNCE를 손으로 구현해 보세요. 4x4 유사도 행렬을 구성하고, softmax를 실행한 후 대각선을 추출하여 교차 엔트로피를 계산합니다. Python 구현 결과가 이 손 계산과 일치하는지 검증해 보세요.

2. SigLIP는 온도 외에도 편향(bias) 매개변수 `b`를 사용합니다: `S'[i,j] = S[i,j]/tau + b`. 배치에 큰 클래스 불균형이 있을 때(각 행에서 양의 예보다 음의 예가 훨씬 많을 때) `b`는 어떤 역할을 수행합니까? SigLIP 논문 3장(arXiv:2303.15343)을 읽어 보세요.

3. 고양이와 개를 구분하는 제로샷 분류기를 구축해 보세요. 두 가지 프롬프트 템플릿 `a photo of a {class}`과 `a picture of a {class}`을 시도해 보세요. 100개의 테스트 이미지에서 정확도를 측정해 보세요. 템플릿 앙상블이 단일 템플릿보다 성능이 좋은가요?

4. 배치 크기 32k로 512 GPU를 사용하는 실행에서 softmax InfoNCE와 시그모이드 쌍별(pairwise) 손실의 통신 비용을 계산해 보세요. 어떤 방식이 O(N)으로 확장되고, 어떤 방식이 O(N^2)으로 확장됩니까? SigLIP 논문 4장을 인용하세요.

5. OpenCLIP 스케일링 법칙 논문(arXiv:2212.07143, Cherti et al.)을 읽어 보세요. 그림에서 데이터 스케일링에 대한 결론을 재현해 보세요: 모델 크기가 고정된 상태에서, ImageNet 제로샷 정확도와 학습 데이터 크기 사이의 로그 선형 관계는 무엇인가요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| InfoNCE | "대조 손실" | 배치의 유사성 행렬에 대한 교차 엔트로피; 각 항목의 양의 예는 짝을 이루는 항목이며, 음의 예는 나머지 모든 항목입니다 |
| 시그모이드 손실 | "SigLIP 손실" | 쌍별 이진 교차 엔트로피; 소프트맥스 없음, 올-개더 없음, 분산 학습에서 저렴하게 확장됩니다 |
| 온도 | "tau" | 소프트맥스/시그모이드 전에 로짓을 스케일링하는 스칼라; 분포의 날카로움을 제어합니다 |
| 제로샷 | "미세 조정 없는 분류" | 텍스트 프롬프트를 사용하여 클래스 임베딩을 구성하고 코사인 유사도로 분류합니다; 대상 클래스에 대한 학습이 없습니다 |
| 프롬프트 템플릿 | "a photo of a ..." | 클래스 이름周围的 텍스트 스캐폴드; 제로샷 정확도에 1-5 포인트 영향을 미칩니다 |
| 이중 인코더 | "Two-tower" | 하나의 이미지 인코더 + 하나의 텍스트 인코더, 공유된 D차원 공간에 출력 |
| 하드 네거티브 | "Tough distractor" | 양의 예와 충분히 유사하여 모델이 분리하기 위해 노력해야 하는 음의 예 |
| 선형 프로브 | "Frozen + one layer" | 동결된 특징 위에 선형 분류기만 학습합니다; 특징 품질을 측정합니다 |
| NaFlex | "Native flexible resolution" | SigLIP 2의 기능으로, 리사이징 없이 어떤 종횡비와 해상도의 이미지도 입력할 수 있습니다 |
| 온도 스케일링 | "log-parametrized tau" | CLIP은 `log(1/tau)`을 매개변수화하여 기울기가 잘 작동하도록 합니다; 거의 0에 가까운 tau로 붕괴하는 것을 방지하기 위해 클리핑합니다 |
