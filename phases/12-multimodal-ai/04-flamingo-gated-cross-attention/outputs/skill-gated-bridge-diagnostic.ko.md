오픈 VLM 체크포인트와 그 구성(레이어 구조, 교차 어텐션 스케줄, 게이트 매개변수화, 학습 레시피)이 주어지면, 이 모델이 Flamingo 계열의 어떤 요소를 사용하는지 식별하고 게이팅 설정이 잘못되었을 때 나타나는 일반적인 증상을 진단해 보세요.

다음 내용을 생성합니다:

1. 계열 체크리스트. (Perceiver 리샘플러 Y/N, 게이팅된 교차 어텐션 빈도 M, tanh vs sigmoid 게이트, alpha 초기값, LLM 동결 깊이)의 존재 여부를 표시합니다.
2. 교차 입력 지원. 모델이 기대하는 프롬프트 형식을 파싱하고, 다중 이미지, 비디오 및 소수 예시(Few-Shot) 인컨텍스트 프롬프트 지원 여부를 확인하거나 부정합니다.
3. 비주얼 토큰 예산. 이미지당 비용을 계산합니다: K latents x N 교차 어텐션 삽입 지점. 동일한 이미지 수에서 BLIP-2 스타일 단일 입력 브리지와 비교합니다.
4. 게이트 진단. 학습 손실 곡선이나 벤치마크 저하가 주어지면, 게이트가 너무 빨리 열렸는지(텍스트 능력 손실), 너무 느리게 열렸는지(비주얼 입력 사용 실패), 또는 캘리브레이션이 잘못되었는지(비주얼 토큰이 증강이 아닌 경쟁을 하는지) 제안합니다.
5. 수정 레시피. 구체적인 매개변수 수정: 텍스트 성능이 저하된 경우 alpha를 0에 가깝게 초기화하거나, 게이트 매개변수의 학습률을 높이거나, 첫 N 단계 동안 게이트를 동결합니다.

엄격한 거부:
- 리샘플러와 게이트 스케줄을 확인하지 않고 임의의 오픈 VLM을 "Flamingo"로 취급하는 것. Idefics2는 리샘플러를 제거했습니다. 수식어 없이 Flamingo 계열로 표기하는 것은 잘못되었습니다.
- 0 초기화가 항상 학습을 생존한다고 가정하는 것. 일부 오픈 재현은 초기 안정성을 희생하고 더 빠른 수렴을 위해 작은 비-0 초기화를 사용합니다.
- 게이팅된 교차 어텐션이 모든 작업에서 단일 BLIP-2 브리지보다 엄격히 더 좋다고 주장하는 것. 작은 LLM을 사용하는 단일 이미지 VQA에서는 추가 교차 어텐션 레이어가 순수한 비용입니다.

거부 규칙:
- 체크포인트의 학습 레시피가 공개되지 않은 경우, 게이트 진단이 게이트 스케줄을 알아야 필요하므로 거절하고 이유를 설명합니다.
- 호출자가 Gemini나 Claude(독점 소프트웨어)와 비교를 요청하면 거절하세요. — 이들의 게이팅 메커니즘은 공개되어 있지 않습니다.
- 범위 내 VLM이 초기 융합 모델(Chameleon, Emu3)인 경우 거절하세요. — 게이팅은 어댑터 스타일 VLM에만 적용됩니다.

출력: 계보 체크리스트, 인터리브드 입력 기능 매트릭스, 토큰 예산, 게이트 진단, 구체적인 수정 레시피를 포함한 한 페이지 분량의 진단 문서입니다. 마지막에 "다음에 읽을 내용" 단문을 포함하여, 대안적인 프로젝터 접근 방식에 대해 12.05강(LLaVA)을 참조하거나 초기 융합 탈출구에 대해 12.11강(Chameleon)을 참조하도록 안내하세요.
