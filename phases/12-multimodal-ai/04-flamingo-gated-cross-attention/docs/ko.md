# Few-Shot VLM을 위한 Flamingo와 게이트된 교차 어텐션

> DeepMind의 Flamingo (2022)는 다른 누구보다 먼저 두 가지를 해냈습니다. 하나의 모델이 이미지, 비디오, 텍스트가 임의로 교대로 섞인 시퀀스를 처리할 수 있음을 보여 주었습니다. 그리고 VLM이 인컨텍스트(in-context)로 학습할 수 있음을 보여 주었습니다. 세 개의 (이미지, 캡션) 쌍을 포함한 few-shot 프롬프트를 주면, 모델은 기울기 단계 없이 새로운 이미지에 캡션을 생성합니다. 메커니즘은 다음과 같습니다: 동결된 LLM의 기존 레이어 사이에 게이트된 교차 어텐션 레이어를 삽입하고, tanh 게이트를 학습합니다. 이 게이트는 초기화 시 0으로 시작하므로 LLM의 텍스트 능력이 보존됩니다. 이 강의는 Flamingo의 Perceiver 리샘플러와 게이트된 교차 어텐션 아키텍처를 다룹니다. 이는 Gemini의 교대로 입력되는 이미지와 Idefics2의 시각적 토큰의 조상입니다.

**유형:** Learn
**언어:** Python (stdlib, 게이트된 교차 어텐션 + Perceiver 리샘플러 데모)
**선수 요건:** 12단계 · 03강 (BLIP-2 Q-Former)
**시간:** 약 120분

## 학습 목표

- tanh(gate) = 0을 통해 초기화 시 동결된 LLM의 텍스트 능력이 게이트된 교차 어텐션에 의해 어떻게 보존되는지 설명해 보세요.
- Perceiver 리샘플러를 따라가 보세요: N개의 이미지 패치 → 교차 어텐션을 통해 K개의 고정된 '잠재(latent)' 쿼리로 변환됩니다.
- Flamingo가 이미지 배치 위치를 고려하는 인과적 마스킹(causal masking)을 사용하여 교대로 입력되는 이미지-텍스트 시퀀스를 어떻게 처리하는지 설명해 보세요.
- few-shot 멀티모달 프롬프트 구조(3개의 이미지-캡션 예시, 그 다음 쿼리 이미지)를 재현해 보세요.

## 문제점

BLIP-2는 32개의 시각적 토큰을 동결된 LLM의 입력 레이어에 공급합니다. 프롬프트당 하나의 이미지에는 잘 작동합니다. 하지만 "여기 이미지 A가 있고, 캡션을 생성하세요; 여기 이미지 B가 있고, 캡션을 생성하세요; 이제 이미지 C가 있고, 캡션을 생성하세요"처럼 텍스트와 교대로 *많은* 이미지를 공급하려면 어떻게 해야 할까요? LLM의 셀프 어텐션은 단일 스트림에서 이미지 토큰과 텍스트 토큰을 처리해야 하며, 어떤 위치가 어떤 이미지에 어텐션할 수 있는지에 대한 문제가 복잡해집니다.

Flamingo의 답변: LLM의 입력 스트림을 전혀 변경하지 않습니다. 기존 LLM 블록 사이에 추가적인 교차 어텐션(Cross-Attention) 레이어를 삽입합니다. 텍스트 토큰은 항상 LLM의 인과적 셀프 어텐션(Causal Self-Attention)을 통해 그대로 흐릅니다. 몇몇 LLM 블록 사이마다, 텍스트 토큰은 새로운 게이트된 레이어를 통해 이미지 특징에도 교차 어텐션합니다. 게이트(0으로 초기화됨)는 스텝 0에서 새로운 레이어가 노오프(no-op)임을 의미합니다. 즉, 모델은 사전 학습된 LLM과 정확히 동일하게 동작합니다. 학습이 진행됨에 따라 게이트가 열리고 시각 정보가 흐르기 시작합니다.

Flamingo가 답변한 두 번째 질문: 프롬프트당 가변적인 수의 이미지(0, 1, 또는 다수)를 어떻게 처리합니까? Perceiver 리샘플러는 패치 수에 관계없이 고정된 수의 시각적 잠재(latent) 토큰을 생성하는 작은 교차 어텐션 모듈입니다. LLM의 교차 어텐션 레이어는 프롬프트에 몇 개의 이미지가 있든 동일한 형태를 봅니다.

## 개념

### 동결된 LLM

Flamingo는 동결된 Chinchilla 70B LLM으로 시작합니다. 모든 70B 가중치는 변경되지 않습니다. 기존 텍스트 셀프 어텐션 및 FFN은 정상적으로 동작합니다.

### Perceiver 리샘플러

프롬프트의 각 이미지에 대해, ViT는 N개의 패치 토큰을 생성합니다. Perceiver 리샘플러는 K개의 고정된 학습 가능한 잠재(latent)를 가지고 있습니다(Flamingo는 K=64를 사용). 각 리샘플러 블록은 두 단계로 구성됩니다:

1. 교차 어텐션: K개의 잠재가 N개의 패치 토큰에 어텐션합니다(Q는 잠재에서, K/V는 패치에서).
2. 잠재 내부의 셀프 어텐션 + FFN.

6개의 리샘플러 블록 후, 출력은 ViT가 생성한 패치 수에 관계없이 차원 1024의 K=64 시각적 토큰입니다. 224x224 이미지(196 패치)와 480x480 이미지(900 패치) 모두 64개의 리샘플러 토큰으로 나옵니다.

비디오의 경우, 리샘플러는 시간적으로 적용됩니다: 각 프레임의 패치는 64개의 잠재를 생성하며, 시간적 위치 인코딩은 모델이 t=00강 t=N을 구별할 수 있게 합니다. 전체 비디오는 T * 64개의 시각적 토큰이 됩니다.

### 게이트된 교차 어텐션

동결된 LLM의 모든 M 레이어 사이(Flamingo는 M=4 사용)에 새로운 게이트된 교차 어텐션 블록을 삽입합니다:

```
x_after_llm_block = llm_block(x_before)
cross = cross_attn(x_after, resampler_output)
gated = tanh(alpha) * cross + x_after
x_before_next_block = gated
```

- `alpha`는 0으로 초기화된 학습 가능한 스칼라입니다.
- `tanh(0) = 0`이므로, 초기화 시 게이트된 분기는 0을 기여합니다.
- `alpha`가 0에서 멀어질수록, 교차 어텐션(Cross-Attention) 기여도가 매끄럽게 증가합니다.
- 잔여 연결(Residual Connection) 덕분에 완전히 열린 게이트(Gate)도 LLM의 텍스트 표현을 덮어쓰지 않으며, 그 위에 시각적 정보를 추가할 뿐입니다.

이것은 Flamingo에서 가장 중요한 설계 선택입니다. 시각적 조건화(Visual Conditioning)는 가산적이며, 게이트가 적용되고, 초기화 시 0입니다. 0단계의 Flamingo는 텍스트 전용 입력에 대한 완벽한 Chinchilla 70B입니다.

### 교차 입력을 위한 마스킹된 교차 어텐션(Masked Cross-Attention)

"<image A> caption A <image B> caption B <image C> ?"와 같은 프롬프트에서, 각 텍스트 토큰은 시퀀스에서 그 앞에 나온 이미지만 봐야 합니다. 교차 어텐션 마스크는 다음을 강제합니다: 위치 `t`의 텍스트 토큰은 이미지 인덱스 `i < i_t`가 위치 `t` 이전의 가장 최근 이미지인 `i_t`인 이미지 리샘플러(Image Resampler) 토큰에만 어텐션합니다. "마지막 선행 이미지만 본다" 또는 "모든 선행 이미지를 본다"는 모두 유효한 선택이며, Flamingo는 전자를 선택했습니다.

### 인컨텍스트 소수 예시 학습(In-Context Few-Shot Learning)

Flamingo 프롬프트는 다음과 같습니다:

```
<image1> A photo of a cat. <image2> A photo of a dog. <image3> A photo of a
```

모델은 완성 패턴을 보고 "bird" (또는 image3가 보여주는 내용)를 출력합니다. 기울기 단계는 없습니다. 동결된 LLM의 인컨텍스트 학습(In-Context Learning) 능력은 게이트가 적용된 교차 어텐션을 통해 유지됩니다. 이것이 논문의 핵심 요점이며 중요한 이유입니다.

### 학습 데이터

Flamingo는 세 가지 데이터셋으로 학습되었습니다:

1. MultiModal MassiveWeb (M3W): 읽기 순서를 재구성한, 이미지와 텍스트가 교차된 43M개의 웹 페이지.
2. 이미지-텍스트 쌍(Image-Text Pairs) (ALIGN + LTIP): 4.4B개의 쌍.
3. 비디오-텍스트 쌍(Video-Text Pairs) (VTP): 27M개의 짧은 비디오 클립.

OBELICS (2023)는 교차된 웹 코퍼스의 오픈 재현본이며, Idefics, Idefics2 및 대부분의 오픈 "Flamingo 스타일" 모델이 학습하는 데이터입니다.

### OpenFlamingo와 Otter

OpenFlamingo (2023)는 오픈 재현본입니다. 아키텍처는 동일합니다 (동결된 LLaMA 또는 MPT에 Perceiver 리샘플러 + 게이트가 적용된 교차 어텐션). 3B, 4B, 9B 체크포인트(Checkpoint)가 있습니다. 더 작은 기반 LLM과 더 적은 데이터 때문에 품질이 Flamingo보다 떨어집니다.

Otter (2023)는 OpenFlamingo를 기반으로 MIMIC-IT (멀티모달 지침 데이터셋)에 대한 지침 미세 조정(Instruction Tuning)을 수행하며, 게이트가 적용된 교차 어텐션이 지침 따르기(Instruction Following)에도 작동함을 보여줍니다.

### 후손들

- Idefics / Idefics2 / Idefics3: Hugging Face의 게이트드 교차 어텐션 계보로, 점진적으로 단순해졌습니다 (Idefics2는 resampler를 제거하고 적응형 풀링을 적용한 직접 패치 토큰을 사용했습니다).
- Flamingo에서 Chameleon으로의 전환: 2024년까지 많은 팀이 초기 융합(12.11강)으로 이동했습니다. Flamingo 스타일의 게이트드 교차 어텐션은 백본 동결이 필요한 프로덕션 환경에서 여전히 사용되고 있습니다.
- Gemini의 인터리브드 입력: 개념적으로 Flamingo의 인터리브드 형식 유연성을 상속받았지만, 정확한 메커니즘은 비공개입니다.

### BLIP-2와의 비교

| | BLIP-2 | Flamingo |
|---|---|---|
| 시각적 브리지 | 입력 시 한 번의 Q-Former | 모든 M 레이어에서 게이트드 교차 어텐션 |
| 시각적 토큰 | 이미지당 32개 | 교차 어텐션 레이어당 이미지당 64개 |
| 동결된 LLM | 예 | 예 |

## 사용하기

`code/main.py`는 다음을 시연합니다:

1. 36개의 가짜 패치 토큰에 대해 8개의 학습 가능한 라텐트를 사용하는 Perceiver resampler (순수 Python 교차 어텐션).
2. `alpha = 0` → 출력은 입력과 동일합니다 (LLM 변경 없음), 그 다음 `alpha = 2.0` → 시각적 기여가 혼합됩니다.
3. "(이미지 1) (텍스트 1) (이미지 2) (텍스트 2)" 시퀀스에 대한 2D 어텐션 마스크를 생성하는 인터리브드 마스크 빌더.

## 출시하기

이 강의는 `outputs/skill-gated-bridge-diagnostic.md`를 생성합니다. 오픈 VLM의 구성(resampler Y/N, 교차 어텐션 빈도, 게이트 스킴)이 주어지면 Flamingo 계보 요소를 식별하고 동결 전략을 설명합니다. 미세 조정이 텍스트 성능을 저하시킨 이유를 디버깅하는 데 유용합니다 (답변: 게이트가 너무 빨리 너무 넓어짐).

## 연습 문제

1. Flamingo-9B의 시각 매개변수 수를 계산해 보세요: 9B LLM + 1.4B 게이트된 교차 어텐션 레이어 + 64M 리샘플러. 총 매개변수 중 학습되는 비율은 얼마인가요?

2. PyTorch에서 게이트된 잔차 `y = tanh(alpha) * cross + x`을 구현해 보세요. `alpha=0`일 때 초기화 시 `y==x`이 정확히 성립함을 실험적으로 보여 주세요.

3. OpenFlamingo의 섹션 3.2 (arXiv:2308.01390)를 읽고, 각 프롬프트의 이미지 개수가 다를 때 배치 내 여러 이미지를 처리하는 방식을 확인해 보세요. 패딩 전략을 설명해 보세요.

4. Flamingo의 교차 어텐션 마스크는 텍스트 토큰이 모든 선행 이미지를 참조하는 것이 아니라 *가장 최근의* 선행 이미지만 참조하도록 허용합니다. Flamingo 논문 섹션 2.4를 읽고 이 트레이드오프를 설명해 보세요.

5. 인컨텍스트 소수 예시(Few-Shot): 새로운 Flamingo 변형에 대해 "이미지 → 주요 객체의 색상" 예시 4개를 포함하는 프롬프트를 구성해 보세요. 예시 수를 0에서 8까지 변화시킬 때 예상되는 정확도 패턴을 설명해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| Perceiver 리샘플러 | "고정 잠재 교차 어텐션" | 가변 수의 입력 패치에서 K개의 고정 토큰을 생성하는 모듈 |
| 게이트된 교차 어텐션 | "Tanh 게이트 브리지" | 잔차 레이어 `y = tanh(alpha)*cross + x`, 학습 가능한 알파, 초기값 0 |
| 인터리브드 입력 | "혼합 시퀀스" | 읽기 순서대로 이미지와 텍스트가 자유롭게 섞인 프롬프트 형식 |
| 동결된 LLM | "LLM 기울기 없음" | 텍스트 LLM의 가중치는 업데이트되지 않으며, 리샘플러 + 교차 어텐션 레이어만 학습됨 |
| 소수 예시(Few-Shot) | "인컨텍스트 예시" | 프롬프트에 몇 개의 (이미지, 답변) 쌍을 제공하며, 모델은 미세 조정 없이 일반화됨 |
| OBELICS | "인터리브드 웹 코퍼스" | 읽기 순서대로 이미지와 텍스트가 포함된 1억 4,100만 개의 웹 페이지로 구성된 오픈 데이터셋 |
| Chinchilla | "70B 동결 베이스" | DeepMind의 Chinchilla 논문에서 나온 Flamingo의 동결된 텍스트 LLM |
