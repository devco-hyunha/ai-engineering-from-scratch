# Chameleon 및 초기 융합 토큰 전용 멀티모달 모델

> 지금까지 살펴본 모든 VLM은 이미지와 텍스트를 분리하여 처리합니다. 시각 토큰은 비전 인코더에서 생성되어 프로젝터를 거친 후 LLM 내부에서 텍스트와 만나게 됩니다. 비전 어휘와 텍스트 어휘는 절대 겹치지 않습니다. Chameleon (Meta, 2024년 5월)은 이렇게 질문했습니다: 만약 겹친다면 어떻게 될까요? VQ-VAE를 학습하여 이미지를 공유 어휘의 이산 토큰 시퀀스로 변환합니다. 이제 모든 멀티모달 문서는 하나의 시퀀스가 됩니다. 텍스트 토큰과 이미지 토큰이 교대로 배치되며, 단일 자기회귀 손실로 학습됩니다. 부수 효과: 모델이 혼합 모달리티 출력, 즉 단일 추론 호출에서 텍스트와 이미지 토큰이 교대로 생성되는 결과를 만들어낼 수 있습니다. 이 강의에서는 초기 융합 논지를 읽고 장난감 버전을 처음부터 끝까지 구축합니다.

**유형:** Build
**언어:** Python (stdlib, VQ-VAE 토크나이저 + 교대 디코더)
**선수 요건:** 12단계 · 05강 및 08강단계 (생성형 AI)
**시간:** 약 180분

## 학습 목표

- 공유 어휘와 단일 손실이 모델의 수행 능력을 어떻게 변화시키는지 설명해 보세요.
- VQ-VAE가 이미지를 트랜스포머의 다음 토큰 예측 목표와 호환되는 이산 시퀀스로 토큰화하는 방식을 설명해 보세요.
- Chameleon의 학습 안정성 기법, 즉 QK-Norm, 드롭아웃 배치, LayerNorm 순서를 나열해 보세요.
- Chameleon과 BLIP-2의 Q-Former 접근법을 비교하고, 각각이 적합한 시점을 설명해 보세요.

## 문제점

어댑터 기반 VLM (LLaVA, BLIP-2, Qwen-VL)은 텍스트와 이미지를 서로 다른 것으로 취급합니다. 텍스트 토큰은 `embed(text_token)`을 거치고, 이미지는 `visual_encoder(image) → projector → ... pseudo_tokens`을 거칩니다. 모델은 중간 지점에서 합쳐지는 두 개의 입력 경로를 가집니다.

세 가지 결과:

1. LLM은 이미지를 소비만 할 수 있고 생성할 수는 없습니다. 출력은 텍스트로만 제한됩니다.
2. 혼합 모달리티 문서 (기사처럼 단락과 이미지가 교대로 배치된 경우)는 다루기 어렵습니다. 모델 외부에서 멀티모달 입력을 파싱하거나 생성을 체이닝해야 합니다.
3. 분포 불일치. 시각 토큰과 텍스트 토큰은 은닉 공간의 서로 다른 영역에 존재하며, 미묘한 정렬 문제를 일으킵니다.

Chameleon은 전제를 거부합니다: 이미지는 공유 어휘에서 나온 이산 토큰의 시퀀스일 뿐입니다. 교차된 문서로 모델을 학습하고, 하나의 손실 함수와 하나의 자기회귀(Autoregressive) 디코더를 사용하면, 혼합 모달리티 생성을 무료로 활용할 수 있습니다.

## 개념

### 이미지 토크나이저로서의 VQ-VAE

토크나이저는 벡터 양자화 변분 오토인코더(VAE)입니다. 아키텍처는 다음과 같습니다:

- 인코더(Encoder): 이미지를 공간적 특징 맵으로 매핑하는 CNN + 비전 트랜스포머(ViT)로, 예를 들어 차원 256의 32x32 특징을 생성합니다.
- 코드북(Codebook): 차원 256의 K개 벡터로 구성된 학습된 어휘입니다 (Chameleon은 8192개를 사용).
- 양자화(Quantization): 각 공간적 특징에 대해 L2 거리를 통해 가장 가까운 코드북 항목을 조회합니다. 연속적인 특징을 정수 인덱스로 대체합니다.
- 디코더(Decoder): 양자화된 특징을 픽셀로 복원하는 CNN입니다.

학습: VAE 재구성 손실 + 커밋 손실 + 코드북 손실. 코드북 인덱스는 이미지를 위한 이산 알파벳을 형성합니다.

Chameleon의 경우: 하나의 이미지는 8192개 어휘에서 뽑힌 32*32 = 1024개의 토큰이 됩니다. 이를 텍스트 토큰 (LLM의 바이트 쌍 인코딩(BPE) 어휘, 예를 들어 32000개)과 연결합니다. 최종 어휘는 40192개입니다. 트랜스포머는 하나의 시퀀스와 하나의 손실만 봅니다.

### 공유 어휘

Chameleon의 어휘는 텍스트 토큰, 이미지 토큰, 모달리티 구분자를 결합합니다. 각 토큰은 단일 ID를 가집니다. 입력 임베딩 레이어는 모든 ID를 D차원 은닉 벡터로 매핑합니다. 출력 투영은 은닉 벡터를 어휘 로짓(Logits)으로 매핑합니다. 소프트맥스(Softmax)는 모달리티에 관계없이 다음 토큰을 선택합니다.

구분자가 중요합니다: `<image>` 및 `</image>` 태그가 이미지 토큰 시퀀스를 둘러쌉니다. 생성 시 모델이 `<image>`를 방출하면, 다운스트림 소프트웨어는 다음 1024개 토큰이 픽셀 렌더링을 위해 디코더로 보내야 할 VQ 인덱스임을 인식합니다.

### 혼합 모달리티 생성

추론은 공유 어휘에서의 다음 토큰 예측입니다. 예시 프롬프트: "고양이를 그리고 설명하세요." Chameleon은 다음을 방출합니다:

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

모델은 순서를 자율적으로 선택합니다 — 이미지 후 텍스트, 텍스트 후 이미지, 또는 교차 생성을 수행할 수 있습니다. 동일한 디코더, 동일한 손실 함수를 사용합니다.

생성이 텍스트 전용인 어댑터 기반 비전-언어 모델(VLM)과 비교해 보세요. Chameleon은 모델 출력 모달리티의 문제를 다시 열었습니다.

### 학습 안정성 — QK-Norm, 드롭아웃, LayerNorm 순서

초기 융합 학습은 대규모에서 불안정합니다. Chameleon 논문은 세 가지 트릭을 문서화했습니다:

- QK-Norm. 어텐션 내부의 쿼리 및 키 투영에 LayerNorm을 적용하여 내적(dot product) 전에 수행합니다. 깊이가 깊어질 때 로짓 크기 폭발을 방지합니다. 2024년 이후의 여러 대규모 모델에서 사용되었습니다.
- 드롭아웃 배치. 어텐션과 MLP 후뿐만 아니라 모든 잔차 더하기(residual-add) 후에도 드롭아웃을 적용합니다. 이미지 토큰에서 유래한 기울기가 지배적일 수 있으므로 더 많은 정규화가 필요합니다.
- LayerNorm 순서. 잔차 브랜치에 Pre-LN을 적용(표준)하고, 마지막 블록의 스킵 연결에 추가 LN을 적용합니다. 최종 레이어의 기울기 흐름을 안정화합니다.

이러한 트릭이 없으면 340억 파라미터 Chameleon 학습은 여러 체크포인트에서 발산했습니다. 트릭을 적용하면 수렴합니다. 학습 레시피는 아키텍처만큼 중요한 기여입니다.

### 토크나이저의 재구성 한계

VQ-VAE는 손실(lossy)이 있습니다. 8192개의 코드북 항목과 512x512 이미지당 1024개 토큰에서, 재구성 PSNR은 약 26-28 dB로 상한이 정해집니다. 이는 인식 가능한 이미지 생성에는 충분하지만, 연속 공간 확산 모델(Stable Diffusion 3는 32+ dB 달성)보다 눈에 띄게 더 나쁩니다.

토크나이저가 병목입니다. 더 나은 토크나이저(MAGVIT-v2, IBQ, SBER-MoVQGAN)는 한계를 높입니다. Emu3 (12.12강)는 더 나은 토크나이저만으로 SDXL 품질의 생성을 달성합니다.

### Chameleon vs BLIP-2 / LLaVA

Chameleon (초기 융합, 공유 어휘):
- 하나의 손실, 하나의 디코더.
- 혼합 모달리티 출력을 생성합니다.
- 토크나이저가 품질 한계입니다.
- 비쌉니다: 추론 경로에서 생성된 이미지마다 VQ-VAE 디코더가 필요합니다.

BLIP-2 / LLaVA (후기 융합, 분리된 타워):
- 비전 입력, 텍스트 출력만.
- 사전 학습된 LLM을 재사용합니다.
- 이해에 대한 토크나이저 병목이 없습니다.
- 저렴합니다: 단일 순방향 패스.

작업에 따라 선택하세요. 이미지 생성이 필요하면 Chameleon 계열을 선택하세요. 이해만 필요하면, 어댑터-VLM이 더 단순하고 더 많은 사전 학습된 연산을 재사용합니다.

### Fuyu와 AnyGPT

Fuyu (Adept, 2023)는 관련 접근법입니다: 별도의 비전 인코더를 완전히 생략하고, 원본 이미지 패치를 토큰인 것처럼 LLM의 입력 투영에 공급하며, 토크나이저가 없습니다. Chameleon보다 단순하지만, 공유 어휘 출력 생성을 잃습니다.

AnyGPT (Zhan et al., 2024)는 Chameleon을 네 가지 모달리티(텍스트, 이미지, 음성, 음악)로 확장합니다. 각 모달리티에 동일한 VQ-VAE 기법을 사용하며, 공유 트랜스포머를 사용합니다. Any-to-any 생성을 수행합니다. 12.16강에서 더 자세히 다루고 있습니다.

## 사용하기

`code/main.py`는 장난감 수준의 엔드투엔드 초기 융합 모델을 구축합니다:

- 8x8 패치를 코드북 인덱스(K=16)로 매핑하는 작은 VQ-VAE 스타일 양자화기.
- (텍스트 ID 0..31) + (이미지 ID 32..47) + (구분자 48, 49)로 구성된 공유 어휘.
- 합성 캡션 + 이미지 토큰 시퀀스로 학습된 장난감 자기회귀 디코더(바이그램 테이블).
- 프롬프트가 주어지면 텍스트 + 이미지 토큰을 교대로 방출하는 샘플링 루프.

코드는 신호 흐름을 엔드투엔드로 추적할 수 있도록 트랜스포머를 의도적으로 작게(바이그램) 유지합니다.

## 연습 문제

1. Chameleon은 K=8192 코드북 항목과 512x512 이미지당 1024 토큰을 사용합니다. 24비트 RGB 이미지 대비 압축 비율을 추정해 보세요. 손실 압축인가요? 얼마나 손실되나요?

2. 동일한 VQ-VAE 밀도로 4K 이미지(3840x2160)가 생성하는 이미지 토큰은 몇 개인가요? Chameleon 스타일 모델이 한 번의 추론 호출로 4K 이미지를 생성할 수 있나요? 먼저 무너지는 것은 컨텍스트, 토크나이저 품질, KV 캐시 중 무엇인가요?

3. 순수 Python으로 QK-Norm을 구현해 보세요. 64차원 쿼리와 키가 주어졌을 때, LayerNorm 전후의 내적을 보여 주세요. 깊이가 깊어질 때 크기(magnitude) 제어가 중요한 이유는 무엇인가요?

4. Chameleon 논문 2.3절의 학습 안정성을 읽어 보세요. 논문이 34B 모델에서 QK-Norm 없이 관찰한 정확한 실패 모드에 대해 설명해 보세요. "노름 폭발(norm explosion)"의 징후는 무엇이었나요?

5. 장난감 디코더를 확장하여 텍스트 전용 프롬프트에 대해 혼합 모달리티 응답을 생성하도록 해 보세요. 학습 데이터 분포가 60% 텍스트 우선 / 40% 이미지 우선일 때, 모델이 이미지 우선과 텍스트 우선 중 어느 것을 선택하는 빈도를 측정해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|------------------------|
| 초기 융합(Early Fusion) | "통합 토큰" | 첫 단계부터 트랜스포머의 어휘를 공유하는 이산 토큰으로 변환된 이미지 |
| VQ-VAE | "이미지 토크나이저" | 이미지를 트랜스포머가 예측할 수 있는 정수 인덱스로 매핑하는 CNN + ViT + 코드북 |
| 공유 어휘 | "하나의 사전" | 텍스트 + 이미지 + 모달리티 구분자를 포함하는 단일 토큰 ID 공간 |
| QK-Norm | "어텐션 안정화 장치" | 내적(dot product) 전에 쿼리와 키에 적용되는 LayerNorm, 노름 폭발을 방지 |
| 혼합 모달리티 생성 | "텍스트 + 이미지 출력" | 한 번의 패스에서 텍스트와 이미지 토큰을 교대로 자율적으로 생성하는 추론 |
| 코드북 크기 | "K 항목" | VQ-VAE가 양자화할 수 있는 이산 벡터의 수; 압축률과 충실도 간 트레이드오프 |
| 토크나이저 상한 | "재구성 한계" | VQ 토큰 디코딩으로 달성할 수 있는 최고 PSNR; 모델의 이미지 품질을 제한 |
