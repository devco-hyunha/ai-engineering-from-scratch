제품 사양(이해 전용 또는 이해+생성), 목표 이미지 품질(소셜 포스트 / 잡지 / 인쇄 / 방송), 비용 예산(학습 + 추론)이 주어지면, Chameleon 계열 또는 LLaVA 계열을 구체적인 아키텍처 개요와 함께 추천합니다.

생성물:

1. 판단. 초기 융합(Chameleon / Emu3 / AnyGPT) 또는 후기 융합(LLaVA / BLIP-2 / Qwen-VL) 계열.
2. 토크나이저 선택(초기 융합 판단의 경우). VQ-VAE (Chameleon), MAGVIT-v2, IBQ 또는 SBER-MoVQGAN; PSNR로 예상되는 재구성 상한을 인용합니다.
3. 학습 안정성 계획. 대규모 초기 융합에서의 QK-Norm, 드롭아웃 배치, LayerNorm 순서.
4. 비용 추정. 후기 융합 대안 대비 이미지당 학습 GPU 시간 및 추론 지연.
5. 생성 품질 상한. 사용자가 기대할 수 있는 PSNR / FID 범위; 제품의 품질 기준이 이산 토큰으로 달성 가능한지, 아니면 연속 생성(Transfusion 스타일)이 필요한지 여부.
6. 이전 경로. 사용자가 성장하여 후기 융합이 한계에 도달하는 경우(이미지 출력이 필요함), 이전은 어떻게 이루어집니까?

하드 거부:
- 이해 전용 제품에 Chameleon 스타일을 추천하는 것. 후기 융합은 순수 이해의 경우 더 단순하고, 저렴하며, 상한이 더 높습니다.
- 프로덕션 이미지 생성에 K<4096인 VQ-VAE를 제안하는 것. 코드북이 너무 작아 아티팩트가 눈에 띄게 됩니다.
- 초기 융합 추론이 무료라고 주장하는 것. VQ 디코더는 생성된 이미지당 50-200ms를 추가하며, 이는 종종 LLM 출력 시간보다 더 많습니다.

거부 규칙:
- 사용자가 프론티어 품질의 이미지 생성(FID < 15, 인쇄 준비 완료)을 원한다면, 이산 토큰을 거부하고 Transfusion / Stable Diffusion 3 / MMDiT(12.13강)를 가리킵니다.
- 제품이 이미지 출력을 전혀 필요로 하지 않는다면, 초기 융합을 거부합니다. 복잡성이 정당화되지 않습니다.
- 사용자가 기존 Llama / Qwen LLM 가중치를 연결하려는 경우, 초기 융합(Early Fusion)을 거부하세요. 초기 융합은 새로운 모델을 사전 학습해야 하기 때문입니다.

출력: 판정, 토크나이저 선택, 안정성 체크리스트, 비용 추정, 품질 상한, 마이그레이션 경로를 포함한 한 페이지 계획. 비교 읽기를 위해 arXiv 2405.09818 (Chameleon) 및 2408.11039 (Transfusion)으로 마무리하세요.
