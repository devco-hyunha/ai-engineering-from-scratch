# Show-o 및 이산 확산 통합 모델

> Transfusion은 연속 및 이산 표현을 혼합합니다. Show-o (Xie et al., 2024년 8월)는 그 반대 방향으로 접근합니다: 텍스트 토큰은 인과적 다음 토큰 예측(causal next-token prediction)을 사용하고, 이미지 토큰은 MaskGIT의 정신에 따라 마스킹된 이산 확산(masked discrete diffusion)을 사용합니다. 두 가지 모두 하나의 트랜스포머 내부에 하이브리드 어텐션 마스크를 포함하고 있습니다. 그 결과, 하나의 백본, 모달리티당 하나의 토크나이저, 하나의 손실 공식화(다음 토큰 예측을 마스킹된 예측으로 확장)로 VQA, 텍스트-이미지 생성, 인페인팅 및 혼합 모달리티 생성을 통합합니다. 이 강의는 Show-o 설계를 살펴보고, 왜 마스킹된 이산 확산이 병렬적이고 몇 단계의 이미지 생성기인지 설명하며, Transfusion 및 Emu3와 대조합니다.

**유형:** Learn
**언어:** Python (stdlib, 마스킹된 이산 확산 샘플러)
**선수 요건:** 12단계 · 13단계 (Transfusion)
**시간:** 약 120분

## 학습 목표

- 마스킹된 이산 확산을 설명해 보세요: 토큰을 균일하게 마스킹한 후 트랜스포머가 이를 복원하도록 요청하는 스케줄입니다.
- 병렬 이미지 디코딩(Show-o, MaskGIT)을 자기회귀 이미지 디코딩(Chameleon, Emu3)과 속도 및 품질 측면에서 비교해 보세요.
- Show-o가 하나의 체크포인트에서 처리하는 세 가지 작업(T2I, VQA, 이미지 인페인팅)을 나열해 보세요.
- 마스킹 스케줄(코사인, 선형, 절단)을 선택하고 샘플 품질에 미치는 영향을 추론해 보세요.

## 문제점

Transfusion의 두 손실 학습은 작동하지만 더 복잡한 동역학을 가집니다. 연속 확산 손실은 이산 NTP 손실과 다른 수치적 스케일에 있습니다. 손실 가중치를 균형 잡는 것은 하이퍼파라미터 탐색입니다. 아키텍처는 효과적이지만 복잡합니다.

Show-o의 답변: 두 모달리티 모두 이산 상태로 유지(Chameleon처럼)하되, 순차적으로 생성하는 대신 마스킹된 이산 확산을 통해 이미지를 병렬로 생성합니다. 학습 목표는 다음 토큰 예측을 자연스럽게 일반화하는 단일 마스킹된 토큰 예측이 됩니다.

## 개념

### 마스킹된 이산 확산 (MaskGIT)

Chang et al. (2022)의 MaskGIT 기법은 우아합니다. 완전히 마스킹된 이미지(모든 토큰이 특수 `<MASK>` id)에서 시작합니다. 각 단계에서 마스킹된 모든 토큰을 병렬로 예측한 후, 가장 확신도가 높은 상위 K개 예측을 유지하고 나머지는 다시 마스킹합니다. 약 8-16번의 반복 후 모든 토큰이 채워집니다. 각 단계에서 마스킹을 해제할 토큰 수의 스케줄은 조정됩니다 — 코사인 스케줄이 잘 작동합니다.

학습은 간단합니다: [0, 1]에서 균일하게 마스킹 비율을 샘플링하여 이미지의 VQ 토큰에 적용하고, 마스킹된 토큰을 복원하도록 트랜스포머를 학습합니다. 텍스트에 대해 BERT가 수행한 것을 이미지 생성으로 확장한 것과 정확히 동일합니다.

### Show-o: 단일 트랜스포머, 하이브리드 마스킹

Show-o는 MaskGIT를 인과적 언어 모델(causal-language-model) 트랜스포머 내부에 배치합니다. 어텐션 마스크는 다음과 같습니다:

- 텍스트 토큰: 인과적(standard LLM).
- 이미지 토큰: 이미지 블록 내에서 완전한 양방향(full bidirectional) (따라서 마스킹된 토큰은 예측 중에 다른 모든 이미지 토큰을 참조할 수 있습니다).
- 텍스트-이미지: 텍스트는 이전 이미지를 참조하고, 이미지는 이전 텍스트를 참조합니다.

학습은 다음 사이에서 교대로 진행됩니다:
1. 텍스트 시퀀스에 대한 표준 NTP.
2. T2I 샘플: 마스킹된 이미지 토큰을 가진 텍스트 → 이미지, 마스킹된 토큰 예측 손실.
3. VQA 샘플: 마스킹된 텍스트 토큰을 가진 이미지 → 텍스트 (사실은 NTP일 뿐).

통합 손실은 `<MASK>` 토큰에 대한 교차 엔트로피(Cross-Entropy)로, 텍스트 NTP (마지막 토큰만 "마스킹"됨)과 이미지 마스킹 확산(masked-diffusion) (무작위 하위 집합이 마스킹됨) 모두를 포함합니다.

### 병렬 샘플링

Show-o는 약 16단계로 이미지를 생성합니다. 이는 약 1000단계(토큰별 자기회귀) 또는 약 20단계(확산 모델)와 비교됩니다. 각 단계에서 마스킹된 모든 토큰을 병렬로 예측하고, 확신도가 높은 상위 K개를 확정(commit)하며, 이를 반복합니다.

비교:
- Chameleon / Emu3 (토큰에 대한 자기회귀): N_tokens개의 순방향 전파(forward passes), 이미지당 일반적으로 1024-4096개.
- Transfusion (연속 확산): 약 20단계, 각 단계는 전체 트랜스포머 순방향 전파입니다.
- Show-o (마스킹된 이산 확산): 약 16단계, 각 단계는 전체 트랜스포머 순방향 전파입니다.

Show-o는 유사한 규모의 모델에서 Chameleon보다 빠르며, Transfusion의 단계 수와 대략 일치하지만 단계별 비용은 더 낮습니다 (이산 어휘 로짓(Logits) vs 연속 MSE 손실).

### 하나의 체크포인트(Checkpoint)에서의 작업

Show-o는 추론 시 프롬프트 형식에 따라 선택되는 네 가지 작업을 지원합니다:

- 텍스트 생성: 표준 자기회귀(Autoregressive) 텍스트 출력.
- VQA: 이미지 입력, 텍스트 출력.
- T2I: 텍스트 입력, 마스킹된 이산 확산(masked discrete diffusion)을 통한 이미지 출력.
- 인페인팅(Inpainting): 일부 토큰이 마스킹된 이미지에서 빈 공간을 채움.

인페인팅 기능은 마스킹 예측(masked-prediction) 학습에서 자연스럽게 얻어집니다. VQ 토큰 그리드의 특정 영역을 마스킹하고, 나머지 토큰과 텍스트 프롬프트를 입력하여 마스킹된 토큰을 예측합니다.

### 마스킹 스케줄

각 단계에서 마스킹을 해제할 토큰의 수를 결정하는 스케줄은 품질에 영향을 미칩니다. Show-o는 코사인을 권장합니다:

```
mask_ratio(t) = cos(pi * t / (2 * T))   # t = 0..T
```

단계 0에서는 모든 토큰이 마스킹됩니다(비율 1.0). 단계 T에서는 마스킹이 없습니다. 코사인은 예측이 가장 정보량이 높은 중간 비율에 집중합니다. 선형 스케줄도 작동하지만 더 빨리 평탄화됩니다.

### Show-o2

Show-o2 (2025년 후속 연구, arXiv 2506.15564)는 Show-o를 확장한 모델입니다: 더 큰 LLM 기반 모델, 더 나은 토크나이저, 개선된 마스킹 스케줄을 사용합니다. 동일한 아키텍처 패턴을 따릅니다.

### Show-o의 위치

2026년 분류 체계에서는:

- 이산 토큰 + NTP: Chameleon, Emu3. 단순하지만 추론이 느립니다.
- 이산 토큰 + 마스킹 확산: Show-o, MaskGIT, LlamaGen, Muse. 병렬 샘플링을 수행하며, 토크나이저로 인해 손실이 발생합니다.
- 연속 + 확산: Transfusion, MMDiT, DiT. 최고 품질을 제공하며, 학습이 더 복잡합니다.
- 연속 + VLM에서의 흐름 매칭(flow matching): JanusFlow, InternVL-U. 최신 모델입니다.

작업에 따라 선택하세요: 합리적인 속도로 T2I + 인페인팅 + VQA를 하나의 오픈 모델에서 원한다면 Show-o를 선택하세요. 품질이 최우선이고 두 가지 손실(loss) 처리를 감당할 수 있다면 Transfusion을 선택하세요.

## 사용하기

`code/main.py`는 Show-o 샘플링을 시뮬레이션합니다:

- 16개의 VQ 토큰으로 구성된 장난감 그리드.
- 프롬프트와 현재 마스킹이 해제된 토큰을 기반으로 로짓(Logits)을 예측하는 가짜 "트랜스포머".
- 코사인 스케줄을 사용하여 8단계에 걸친 병렬 마스킹 샘플링.
- 중간 상태(마스킹 패턴 변화)와 최종 토큰을 출력합니다.

실행하여 마스킹이 단계별로 사라지는 것을 관찰해 보세요.

## 연습 문제

1. 마스크된 이산 확산은 약 16단계로 샘플링합니다. 왜 1단계가 아닌가요? 0단계에서 모든 마스크를 제거하면 무엇이 깨지나요?

2. 마스크된 확산에서는 인페인팅이 무료입니다. Show-o의 인페인팅이 전문가 모델보다 우월한 제품 사용 사례(실제 또는 가상의)를 제안해 보세요.

3. 코사인 스케줄 vs 선형 스케줄: T=8일 때 단계별 마스크 제거된 토큰 수를 추적해 보세요. 어느 쪽이 더 균형 잡혀 있나요?

4. 512x512 Show-o 이미지는 1024개 토큰입니다. 어휘 K=16384일 때 모델은 1024 * log2(16384) = 14,336비트(~1.75 KiB)의 데이터를 방출합니다. Stable Diffusion은 512*512*24비트 = 6,291,456비트(~768 KiB)의 원시 픽셀을 출력합니다. 압축 비율은 얼마이며, 어떤 품질을 얻나요?

5. LlamaGen(arXiv:2406.06525)을 읽어 보세요. LlamaGen의 클래스 조건부 자기회귀 이미지 모델은 Show-o의 마스크된 접근 방식과 어떻게 다른가요?

|------|-----------------|------------------------|
| 마스크된 이산 확산 | "MaskGIT 스타일" | 마스크된 토큰을 예측하도록 학습; 추론 시 가장 확신도가 높은 예측을 반복적으로 마스크 제거 |

| 하이브리드 어텐션 | "인과 + 양방향" | 텍스트 토큰에 대해 인과적이고 이미지 블록 내에서 양방향인 마스크 |

| 확정률 | "단계별 Top-K" | 반복마다 "완료"로 선언되는 토큰 수; 추론 vs 품질 트레이드오프를 제어 |
