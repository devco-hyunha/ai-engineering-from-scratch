# 비전 트랜스포머(Vision Transformers)와 패치 토큰 프리미티브(Patch-Token Primitive)

> 멀티모달 처리를 하기 전에, 이미지는 트랜스포머가 처리할 수 있는 토큰 시퀀스로 변환되어야 합니다. 2020년 ViT 논문은 이를 16x16 픽셀 패치, 선형 투사(linear projection), 위치 임베딩(position embedding)으로 해결했습니다. 5년 후인 2026년, 모든 최첨단 모델(Claude Opus 4.7는 네이티브 2576px, Gemini 3.1 Pro, Qwen3.5-Omni)은 여전히 이 방식으로 시작합니다. 인코더는 ViT에서 DINOv2, SigLIP 2로 변경되었고, 레지스터 토큰(register tokens)이 추가되었으며, 위치 인코딩 방식은 2D-RoPE가 되었지만, 프리미티브는 유지되었습니다. 이 강의는 패치 토큰 파이프라인을 처음부터 끝까지 살펴보고, stdlib Python으로 이를 구현하여 12단계의 나머지 부분에서 "시각적 토큰"에 대한 구체적인 개념 모델을 구축합니다.

**유형:** Learn
**언어:** Python (stdlib, 패치 토크나이저 + 기하 계산기)
**선수 요건:** 7단계 (트랜스포머), 4단계 (컴퓨터 비전)
**시간:** 약 120분

## 학습 목표

- HxWx3 이미지를 올바른 위치 인코딩을 가진 패치 토큰 시퀀스로 변환해 보세요.
- 주어진 (패치 크기, 해상도, 은닉 차원, 깊이)에 대해 ViT의 시퀀스 길이, 매개변수 수, FLOPs를 계산해 보세요.
- ViT를 2020년 연구에서 2026년 생산 환경으로 끌어올린 세 가지 업그레이드, 즉 자기 지도 사전 학습(DINO / MAE), 레지스터 토큰, 네이티브 해상도 패킹을 나열해 보세요.
- 다운스트림 작업에 CLS 풀링, 평균 풀링, 레지스터 토큰 중 하나를 선택해 보세요.

## 문제점

트랜스포머는 벡터 시퀀스를 다룹니다. 텍스트는 이미 시퀀스(바이트 또는 토큰)입니다. 이미지는 세 가지 색상 채널을 가진 2D 픽셀 그리드이며, 시퀀스가 아닙니다. 모든 픽셀을 평탄화(flatten)하면 224x224 RGB 이미지는 150,528개의 토큰이 되며, 이 길이에서의 셀프 어텐션은 불가능합니다(시퀀스 길이에 대해 2차 함수적).

2020년 이전 접근 방식은 CNN 특징 추출기를 앞에 붙였습니다. ResNet은 2048차원 벡터의 7x7 특징 맵을 생성하고, 이 49개 토큰을 트랜스포머에 전달합니다. 이는 작동하지만 CNN의 편향(병진 등변성, 국소 수용 영역)을 상속받으며, 트랜스포머가 가진 확장성에 대한 선호를 잃게 됩니다.

Dosovitskiy 등(2020)은 직설적인 질문을 던졌습니다: CNN을 건너뛰면 어떻게 될까? 이미지를 고정 크기 패치(예: 16x16 픽셀)로 분할하고, 각 패치를 선형 투영하여 벡터로 만든 후 위치 인코딩을 추가하고, 이 시퀀스를 순수 트랜스포머에 입력하는 방식입니다. 당시 이는 이단으로 여겨졌습니다 — 합성곱 없는 비전. 충분한 데이터(JFT-300M, 이후 LAION)가 있으면 ImageNet에서 ResNet을 능가했고, 성능은 계속 향상되었습니다.

2026년 현재 ViT 원시 요소는 의심할 여지 없는 기반입니다. 모든 오픈 웨이트 VLM의 비전 타워는 DINOv2, SigLIP 2, CLIP, EVA, InternViT 등 어떤 후손이든입니다. 질문은 더 이상 "패치를 사용해야 하는가?"가 아니라 "패치 크기는 얼마인가, 해상도 스케줄은 어떻게 되며, 사전 학습 목표는 무엇이고, 위치 인코딩은 어떤 방식인가?"입니다.

## 개념

### 토큰으로서의 패치

`x` 크기의 이미지와 `(H, W, 3)` 모양, `P` 크기의 패치 크기가 주어지면, 이미지를 `(H/P) x (W/P)`개의 겹치지 않는 패치로 구성된 격자로 분할합니다. 각 패치는 `P x P x 3` 픽셀 값으로 이루어진 큐브입니다. 각 큐브를 `3 P^2` 벡터로 평탄화(flatten)합니다. `(3 P^2, D)` 모양의 공유 선형 투영 `W_E`을 적용하여 각 패치를 모델의 숨겨진 차원 `D`로 매핑합니다.

ViT-B/16 표준 구성의 경우:
- 해상도 224, 패치 크기 16 → 격자 14x14 → 196개의 패치 토큰.
- 각 패치는 `16 x 16 x 3 = 768` 픽셀 값이며, `D = 768`로 투영됩니다.
- 학습 가능한 `[CLS]` 토큰을 추가합니다 → 시퀀스 길이 197.

패치 투영은 수학적으로 `P` 크기의 커널, `P` 스트라이드, `D` 출력 채널을 가진 2D 합성곱과 동일합니다. 프로덕션 코드는 실제로 이를 구현하는 방식이 `nn.Conv2d(3, D, kernel_size=P, stride=P)`입니다. "선형 투영"이라는 표현은 개념적인 것이며, 커널 표현은 효율적입니다.

### 위치 인코딩

패치에는 고유한 순서가 없습니다 — 트랜스포머는 이를 가방(bag)으로 봅니다. 초기 ViT는 학습 가능한 1D 위치 인코딩(각 위치에 768차원 벡터 하나, 총 197개)을 추가했습니다. 작동하지만, 모델이 학습 해상도에 묶이게 됩니다: 추론 시 격자를 변경하면 위치 테이블을 보간해야 합니다.

현대적인 비전 백본은 2D-RoPE (Qwen2-VL의 M-RoPE, SigLIP 2의 기본 설정) 또는 분해된 2D 위치 인코딩을 사용합니다. 2D-RoPE는 패치의 (행, 열) 인덱스에 따라 쿼리 및 키 벡터를 회전시키므로, 모델은 회전 각도로부터 상대적인 2D 위치를 추론합니다. 위치 테이블이 필요 없습니다. 모델은 추론 시 임의의 그리드 크기를 처리할 수 있습니다.

### CLS 토큰, 풀링된 출력 및 레지스터 토큰

이미지 수준 표현은 무엇일까요? 세 가지 선택지가 공존합니다:

1. `[CLS]` 토큰. 패치 시퀀스 앞에 학습 가능한 벡터를 추가합니다. 모든 트랜스포머 블록을 거친 후, CLS 토큰의 은닉 상태가 이미지 표현이 됩니다. BERT에서 상속된 방식이며, 원본 ViT와 CLIP에서 사용됩니다.
2. 평균 풀링(Mean pool). 패치 토큰들의 출력 은닉 상태를 평균냅니다. SigLIP, DINOv2 및 대부분의 현대적인 VLM에서 사용됩니다.
3. 레지스터 토큰(Register tokens). Darcet 등(2023)은 명시적인 싱크(sink) 토큰 없이 학습된 ViT가 셀프 어텐션을 장악하는 높은 노름(norm)의 "아티팩트" 패치를 개발한다는 것을 관찰했습니다. 4~16개의 학습 가능한 레지스터 토큰을 추가하면 이 부하를 흡수하여 밀집 예측 품질(분할, 깊이)을 개선합니다. DINOv2와 SigLIP 2 모두 레지스터를 포함하고 있습니다.

이 선택은 다운스트림 작업에 중요합니다. 분류에는 CLS가 적합합니다. 패치 토큰을 LLM에 입력하는 VLM의 경우, 풀링을 완전히 생략합니다. 모든 패치가 LLM 입력 토큰이 됩니다. 레지스터는 핸드오프 전에 폐기됩니다(레지스터는 발판일 뿐, 내용이 아닙니다).

### 사전 학습: 지도 학습, 대조 학습, 마스킹, 자기 증류

2020년 ViT는 JFT-300M에 대한 지도 분류로 사전 학습되었습니다. 이는 곧 다음 방식들에 의해 대체되었습니다:

- CLIP (2021): 4억 쌍의 이미지-텍스트에 대한 대조 학습. 12.02강 참조.
- MAE (2021, He 등): 패치의 75%를 마스킹하고 픽셀을 재구성합니다. 자기 지도 학습 방식이며, 순수 이미지에만 작동합니다.
- DINO (2021) / DINOv2 (2023): 학생-교사 자기 증류(self-distillation) 방식이며, 레이블이나 캡션이 필요 없습니다. 2023년 DINOv2 ViT-g/14는 가장 강력한 순수 시각 백본이며, "밀집 특징(dense features)" 사용 사례의 기본 설정입니다.
- SigLIP / SigLIP 2 (2023, 2025): 시그모이드 손실과 NaFlex를 사용하여 네이티브 종횡비를 지원하는 CLIP 변형입니다. 2026년 오픈 VLM(Qwen, Idefics2, LLaVA-OneVision)에서 지배적인 비전 타워입니다.

사전 학습 선택은 백본(backbone)이 어떤 용도에 적합한지 결정합니다. 텍스트와 시맨틱 매칭에는 CLIP/SigLIP, 밀집 시각적 특징(dense visual features)에는 DINOv2, downstream 미세 조정(fine-tuning)의 출발점으로는 MAE가 적합합니다.

### 스케일링 법칙

ViT 스케일링(Zhai et al. 2022)은 ViT의 품질이 모델 크기, 데이터 크기, 연산량에 대해 예측 가능한 법칙을 따른다는 것을 확립했습니다. 고정된 연산량에서는:
- 더 큰 모델 + 더 많은 데이터 → 더 좋은 품질.
- 패치 크기는 시퀀스 길이와 충실도(fidelity) 사이의 균형점입니다. Patch 14 (DINOv2/SigLIP SO400m의 전형적인 값)는 patch 16보다 이미지당 더 많은 토큰을 생성합니다. OCR 및 밀집 작업에는 더 좋지만, 속도에는 불리합니다.
- 해상도는 다른 주요 균형점입니다. 224에서 384, 512로 높이는 것이 거의 항상 도움이 되며, FLOPs는 제곱 비용으로 증가합니다.

ViT-g/14 (1B 파라미터, patch 14, 해상도 224 → 256 토큰)와 SigLIP SO400m/14 (400M 파라미터, patch 14)는 2026년 오픈 VLM의 두 가지 주력 인코더입니다.

### ViT의 파라미터 수

전체 계산은 `code/main.py`에 있습니다. ViT-B/16, 해상도 224의 경우:

```
patch_embed = 3 * 16 * 16 * 768 + 768  =  591k
cls + pos    = 768 + 197 * 768          =  152k
block        = 4 * 768^2 (QKVO) + 2 * 4 * 768^2 (MLP) + 2 * 2*768 (LN)
             = 12 * 768^2 + 3k          =  7.1M
12 blocks    = 85M
final LN    = 1.5k
total       ≈ 86M
```

체크포인트를 로드하기 전에 모든 ViT를 이 방식으로 대략적으로 계산해 보세요. 백본 크기는 모든 downstream VLM의 VRAM 하한을 설정합니다.

### 2026년 프로덕션 구성

2026년 오픈 VLM들이 가장 많이 탑재하는 인코더는 네이티브 해상도(NaFlex)의 SigLIP 2 SO400m/14입니다. 이 구성은:
- 400M 파라미터를 가집니다.
- 패치 크기 14, 기본 해상도 384 → 이미지당 729개의 패치 토큰.
- 이미지 수준 작업에는 평균 풀(mean pool)을 사용하며, VQA에서는 모든 729개 패치가 LLM으로 전달됩니다.
- 4개의 register 토큰은 LLM 핸드오프(handoff) 전에 폐기됩니다.
- 네이티브 종횡비를 위해 이미지 수준 스케일링을 적용한 2D-RoPE를 사용합니다.

이 구성의 모든 결정은 읽을 수 있는 논문으로 거슬러 올라갑니다.

## 사용하기

`code/main.py`는 패치 토크나이저 및 지오메트리 계산기입니다. (이미지 H, W, 패치 P, hidden D, depth L)를 입력으로 받아 다음을 보고합니다:

- 패칭 후의 그리드 형태와 시퀀스 길이.
- 합성 8x8 픽셀 토이 이미지의 토큰 시퀀스 (flatten + project 경로를 따라가 보세요).
- 패치 임베딩, 위치 임베딩, 트랜스포머 블록, 헤드별로 분해된 파라미터 수.
- 목표 해상도에서의 순방향 전파당 FLOPs입니다.
- ViT-B/16 @ 224, ViT-L/14 @ 336, DINOv2 ViT-g/14 @ 224, SigLIP SO400m/14 @ 384에 대한 비교 표입니다.

실행해 보세요. 매개변수 수를 공개된 수치와 일치시켜 보세요. 패치 크기와 해상도를 조절하여 토큰 수 비용의 변화를 느껴 보세요.

## 연습 문제

1. 패치 크기 14로 네이티브 1280x720 입력을 사용하는 Qwen2.5-VL의 패치 토큰 시퀀스 길이를 계산해 보세요. CLS 전용 표현과 비교하면 어떻게 되나요?

2. 패치 14로 1080p 프레임(1920x1080)은 몇 개의 토큰을 생성하나요? 5분 영상에서 30 FPS로 총 시각 토큰은 몇 개가 되나요? 풀링, 프레임 샘플링, 토큰 병합 중 어떤 비용 절감이 가장 큰가요?

3. 순수 Python으로 패치 토큰에 대한 평균 풀링을 구현해 보세요. DINOv2 출력의 196개 토큰에 대한 평균 풀링이 풀링된 임베딩을 요청할 때 모델의 `forward`가 반환하는 값과 일치하는지 검증해 보세요.

4. "Vision Transformers Need Registers" (arXiv:2309.16588)의 섹션 3을 읽어 보세요. 레지스터가 흡수하는 아티팩트와 이것이 다운스트림 밀집 예측에 중요한 이유를 두 문장으로 설명해 보세요.

5. `code/main.py`를 수정하여 patch-n'-pack을 지원하세요. 서로 다른 해상도의 이미지 목록이 주어지면 단일 팩 시퀀스와 블록 대각 어텐션 마스크를 생성합니다. 12.06강에 도달했을 때 검증해 보세요.

| CLS 토큰 | "클래스 토큰" | 최종 은닉 상태가 전체 이미지를 표현하도록 앞에 추가된 학습 가능한 벡터; 2026년에는 선택 사항 |
| 등록 토큰 | "싱크 토큰" | ViT가 사전 학습 중에 생성하는 높은 노름의 어텐션 아티팩트를 흡수하는 추가 학습 가능한 토큰 |
| 위치 임베딩 | "위치 정보" | 시퀀스 순서를 인식하게 하는 위치별 벡터 또는 회전; 2D-RoPE가 현대적 기본값 |
| 그리드 | "패치 그리드" | 주어진 해상도와 패치 크기에 대한 (H/P) x (W/P) 2D 패치 배열 |
| NaFlex | "네이티브 유연 해상도" | SigLIP 2 기능: 단일 모델이 재학습 없이 여러 종횡비와 해상도를 지원 |
| 백본 | "비전 타워" | VLM에서 LLM에 패치 토큰 출력을 공급하는 사전 학습된 이미지 인코더 |
| 풀링 | "이미지 수준 요약" | 패치 토큰을 하나의 벡터로 변환하는 전략: CLS, 평균, 어텐션 풀, 또는 등록 기반 |
| 패치 14 vs 16 | "더 세밀한 vs 더 거친 그리드" | 패치 14는 이미지당 더 많은 토큰을 생성하며, OCR에 대한 충실도가 더 높지만 속도가 느림; 패치 16은 고전적 기본값 |
