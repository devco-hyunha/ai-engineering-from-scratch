# Transfusion: 하나의 트랜스포머에서 자기회귀 텍스트 + 확산 이미지 생성

> Chameleon과 Emu3는 이산 토큰에 모든 것을 걸었습니다. 이 방식은 작동하지만, 양자화 병목 현상이 명확히 드러납니다. 이미지 품질이 연속 공간 확산 모델보다 낮은 수준에서 정체됩니다. Transfusion (Meta, Zhou et al., 2024년 8월)은 정반대의 선택을 합니다. 이미지를 연속 상태로 유지하고 VQ-VAE를 완전히 제거하며, 두 가지 손실 함수로 하나의 트랜스포머를 학습합니다. 텍스트 토큰은 다음 토큰 예측(NTP)을 수행하고, 이미지 패치는 흐름 매칭(flow-matching) / 확산 손실을 적용합니다. 두 목적 함수가 동일한 가중치를 최적화합니다. Stable Diffusion 3 (MMDiT)의 기본 아키텍처는 밀접한 관련이 있습니다. 이 강의에서는 Transfusion 논문을 읽고, 두 손실 함수를 사용하는 장난감(trivial) 트레이너를 구축하며, 하나의 트랜스포머가 두 작업을 수행할 수 있도록 하는 어텐션 마스크를 추적합니다.

**유형:** Build
**언어:** Python (표준 라이브러리, MNIST 규모 장난감에서의 두 손실 트레이너)
**선수 요건:** 12단계 · 11강 (Chameleon), 8단계 (생성형 AI)
**시간:** 약 180분

## 학습 목표

- 하나의 백본(backbone)에서 두 손실 함수(텍스트 토큰에 대한 NTP, 이미지 패치에 대한 확산 MSE)를 실행하는 트랜스포머를 연결해 보세요.
- 이미지 패치에 대한 양방향 어텐션과 텍스트 토큰에 대한 인과적(causal) 어텐션이 올바른 마스크 선택인 이유를 설명해 보세요.
- Transfusion 방식(연속 이미지, 확산 손실)과 Chameleon 방식(이산 이미지, NTP)을 연산량, 품질, 코드 복잡성 측면에서 비교해 보세요.
- MMDiT의 기여도를 명시해 보세요. 각 블록에서 모달리티별 가중치를 사용하고, 잔차 스트림(residual stream)에서 결합 어텐션을 적용하는 방식입니다.

## 문제점

이산 이미지 토큰과 연속 이미지 토큰의 논쟁은 LLM보다 오래되었습니다. 연속 표현(원시 픽셀, VAE 잠재 변수)은 세부 정보를 보존합니다. 이산 토큰(VQ 인덱스)은 트랜스포머의 기본 어휘에 맞지만, 양자화 단계에서 세부 정보를 잃습니다.

Chameleon / Emu3는 이산 방식을 선택했습니다. 하나의 손실 함수, 하나의 아키텍처를 사용하지만, 이미지 충실도는 토크나이저 품질에 의해 상한이 정해집니다.

확산 모델은 연속 방식을 선택했습니다. 뛰어난 이미지 품질을 제공하지만, LLM과 분리된 모델이며, 복잡한 노이즈 스케줄 엔지니어링이 필요하고, 텍스트 생성과의 깔끔한 통합이 없습니다.

Transfusion은 이렇게 묻습니다. 둘 다 가질 수 있을까요? 이미지를 연속 상태로 유지하면서 하나의 모델을 학습하고, 하나의 기울기 단계에 두 손실 함수를 결합하는 방식입니다.

## 개념

### 두 손실 아키텍처

단일 디코더 전용 트랜스포머는 다음을 포함하는 시퀀스를 처리합니다:

- 텍스트 토큰 (이산적, BPE 어휘에서).
- 이미지 패치 (연속적, 16x16 픽셀 블록이 선형 임베딩을 통해 은닉 차원으로 투영됨 — ViT 인코더의 입력과 동일).
- 연속 패치가 위치하는 곳을 표시하는 `<image>` 및 `</image>` 태그.

순전파는 한 번 실행됩니다. 손실은 토큰마다 두 헤드 중 하나를 선택합니다:

- 텍스트 토큰의 경우: 어휘 로짓 헤드에 대한 표준 교차 엔트로피.
- 이미지 패치의 경우: 연속 패치에 대한 확산 손실 — 각 패치에 추가된 잡음을 예측합니다.

기울기는 공유 트랜스포머 본체를 통해 흐릅니다. 두 손실 모두 공유 가중치를 동시에 개선합니다.

### 어텐션 마스크: 인과적 텍스트 + 양방향 이미지

텍스트 토큰은 인과적이어야 합니다 — 텍스트 토큰이 미래 텍스트를 어텐션하도록 허용할 수 없으며, 그렇게 하면 티처 포싱이 깨집니다. 이미지 패치는 하나의 스냅샷을 나타내므로, 같은 이미지 블록 내에서 서로 양방향으로 어텐션해야 합니다.

마스크는 다음과 같습니다:

```
M[i, j] = 1 if:
  (i is text and j is text and j <= i)   # 텍스트에 대해 인과적
  OR (i is image and j is image and same_image_block(i, j))   # 이미지 내에서 양방향
  OR (i is text and j is image and j < i_image_end)   # 텍스트가 이전 이미지를 어텐션
  OR (i is image and j is text and j < i_image_start)   # 이미지가 선행하는 텍스트를 어텐션
```

학습 및 추론 시 블록 삼각형 마스크로 구현됩니다.

### 트랜스포머 내부의 확산 손실

확산 손실은 표준적입니다: 이미지 패치에 잡음을 추가하고, 모델이 잡음을 (또는 동등하게 깨끗한 패치를) 예측하도록 요청합니다. Transfusion의 버전은 흐름 매칭을 사용하며, 잡음에서 깨끗한 상태까지의 속도 필드를 예측합니다.

학습 중에는:
1. 각 이미지 패치 x0에 대해 랜덤 타임스텝 t를 샘플링합니다.
2. 잡음 ε를 샘플링하고, xt = (1-t) * x0 + t * ε (흐름 매칭을 위한 선형 보간)를 계산합니다.
3. 트랜스포머는 v_theta(xt, t)를 예측하며, 손실 = MSE(v_theta(xt, t), ε - x0)입니다.
4. 같은 시퀀스의 텍스트 NTP 손실과 함께 역전파합니다.

추론 시 생성은 다음과 같습니다:
- 텍스트 토큰: 표준 자기회귀 샘플링.
- 이미지 패치: 이전 텍스트 토큰을 조건으로 하는 확산 샘플링 루프(일반적으로 10-30단계).

### MMDiT: Stable Diffusion 3의 변형

Stable Diffusion 3(Esser et al., 2024년 3월)는 Transfusion과 거의 동시에 MMDiT(Multimodal Diffusion Transformer)를 출시했습니다. 두 아키텍처는 형제 관계입니다.

MMDiT의 주요 차이점:

- 블록별 모달리티 특화 가중치. 각 트랜스포머 블록은 텍스트 토큰과 이미지 패치에 대해 각각 별도의 Q, K, V 및 MLP 가중치를 가집니다. 어텐션은 결합형(교차 모달리티)이며, 나머지 요소는 모달리티 특화입니다.
- Rectified flow 학습. DDPM보다 알려진 샘플링과 더 단순한 수학을 가진 특정 flow-matching 변형입니다.
- 규모. MMDiT는 SD3(2B 및 8B 파라미터 변형)의 백본입니다. Transfusion 논문은 7B까지 확장합니다.

두 모델 모두 동일한 핵심 아이디어로 수렴합니다: 하나의 트랜스포머가 텍스트에 대해 NTP를 수행하고, 연속적인 이미지 표현에 대해 확산을 수행합니다.

### Chameleon 스타일을 능가하는 이유

이미지 생성에서 연속 확산과 이산 NTP 간의 품질 격차는 측정 가능합니다. Transfusion 논문은 다음을 보고합니다:

- 7B 파라미터에서 동일한 크기의 Chameleon 스타일 모델보다 FID가 3-5점 더 좋습니다.
- 토크나이저 학습이 필요 없습니다. 이미지 인코더는 더 단순합니다(은닉층으로의 선형 투사, ViT의 입력층과 동일).
- 자기회귀 이미지 토큰과 달리, 추론 시 이미지 패치 디노이징을 병렬화할 수 있습니다.

단점: Transfusion은 이중 손실 모델이므로 학습 동역학이 더 복잡합니다. 손실 가중치를 조정해야 합니다. NTP와 확산 간의 스케줄 불일치로 인해 한 헤드가 지배할 수 있습니다.

### 하위 흐름

Janus-Pro(12.15강)는 이해와 생성을 위해 비전 인코더를 분리(SigLIP는 이해용, VQ는 생성용)하고 트랜스포머 본체를 공유함으로써 Transfusion의 아이디어를 정제합니다. Show-o(12.14강)는 확산을 이산 확산(마스크 예측)으로 교체합니다. Transfusion 이후 통합 생성 계열이 빠르게 분기됩니다.

이미지를 생성하는 2026년 생산 VLM(Gemini 3 Pro, GPT-5, Claude Opus 4.7의 이미지 생성 경로)은 거의 확실히 이 계열의 후손을 사용합니다. 세부 사항은 비공개입니다.

## 사용하기

`code/main.py`는 MNIST 유사한 작은 문제에서 장난감 Transfusion을 구축합니다:

- 텍스트 캡션은 숫자(0-9)를 설명하는 짧은 정수 시퀀스입니다.
- 이미지는 바이트로 구성된 4x4 그리드입니다.
- 공유 가중치를 가진 선형 투영 쌍이 트랜스포머의 대체 역할을 수행합니다. 텍스트에는 NTP 손실, 잡음이 있는 패치에는 MSE 손실을 적용합니다.
- 학습 루프는 두 손실을 번갈아 사용하며, 어텐션 마스크는 명시적으로 구성됩니다.
- 생성 과정은 한 번의 순전파로 텍스트 캡션과 4x4 이미지를 생성합니다.

트랜스포머는 장난감입니다. 두 손실 처리 구조, 어텐션 마스크 구성, 추론 루프가 실제 산출물입니다.

## 출시하기

이 강의는 `outputs/skill-two-loss-trainer-designer.md`를 생성합니다. 새로운 멀티모달 학습 작업(텍스트 + 이미지, 텍스트 + 오디오, 텍스트 + 비디오)이 주어지면, 두 손실 스케줄(손실 가중치, 마스크 모양, 공유 블록 vs 모달리티 전용 블록)을 설계하고 구현 위험 요소를 식별합니다.

## 연습 문제

1. Transfusion 스타일 모델은 70%의 텍스트 토큰과 30%의 이미지 패치를 학습합니다. 이미지 확산 손실은 텍스트 NTP 손실의 크기가 약 10배입니다. 이 둘을 균형 잡기 위한 손실 가중치는 무엇인가요?

2. 시퀀스에 대한 블록 삼각형 마스크를 구현하세요: `[T, T, <image>, P, P, P, P, </image>, T]`. 각 항목을 0 또는 1로 표시합니다.

3. MMDiT는 모달리티 전용 QKV 가중치를 사용합니다. Transfusion의 완전히 공유된 트랜스포머와 비교할 때 이 방식은 매개변수 수에 어떤 오버헤드를 추가하나요? 7B 매개변수 규모에서 가치가 있나요?

4. 생성: 텍스트 프롬프트가 주어지면, 모델은 50개 토큰에 대해 NTP를 실행한 후 `<image>`에 도달하고, 20개의 디노이즈 단계에 걸쳐 256개 패치에 대해 확산을 실행합니다. 총 순전파 횟수는 몇 번인가요?

5. SD3 논문 섹션 3을 읽어보세요. 정류된 흐름(rectified flow)을 설명하고, DDPM보다 추론 단계가 적게 소요되어 수렴하는 이유를 서술하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|------------------------|
| 두 손실 학습 | "NTP + 확산" | 단일 트랜스포머가 텍스트 토큰에 대한 교차 엔트로피와 연속 이미지 패치에 대한 MSE를 동일한 기울기 단계에서 함께 최적화함 |
| 흐름 매칭 | "정류된 흐름(rectified flow)" | 잡음에서 깨끗한 데이터까지의 속도 필드를 예측하는 확산 변형; DDPM보다 수학이 단순함 |
| MMDiT | "멀티모달 DiT" | Stable Diffusion 3의 아키텍처: 결합 어텐션, 모달리티 전용 MLP 및 정규화 |
| 블록 삼각형 마스크 | "인과적 텍스트 + 양방향 이미지" | 텍스트에 대해서는 인과적이며 이미지 영역 내에서는 양방향인 어텐션 마스크 |
| 연속 이미지 표현 | "VQ 없음" | 이미지 패치를 정수 코드북 인덱스가 아닌 실수 값 벡터로 표현 |
| 속도 예측 | "v-파라미터화" | 네트워크 출력은 잡음과 데이터 사이의 속도 필드이며, 잡음 자체는 아님 |
