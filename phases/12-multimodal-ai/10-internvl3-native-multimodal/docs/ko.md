# InternVL3: 네이티브 멀티모달 사전 학습

> InternVL3 이전의 모든 오픈 VLM은 동일한 3단계 레시피를 따랐습니다. 수조 개의 텍스트 토큰으로 학습된 텍스트 LLM을 가져와 비전 인코더를 붙인 후, 이음새(seam)를 미세 조정하는 방식입니다. 이 방법은 작동하지만 정렬 부채(alignment debt)가 발생합니다. 텍스트 LLM은 순수 텍스트에 전체 사전 학습 예산을 사용했기 때문에 시각적 토큰을 본질적으로 이해하지 못합니다. 사후(post-hoc)에 비전을 추가하면, LLM은 텍스트를 잊지 않으면서 시각적 입력을 텍스트 추론과 연결하는 방법을 다시 학습해야 합니다. InternVL3 (Zhu et al., 2025년 4월)는 사후 방식을 거부합니다. 첫 단계부터 텍스트와 멀티모달이 인터리브(interleaved)된 단일 사전 학습 실행을 수행합니다. 그 결과, 78B 파라미터의 오픈 모델로 MMMU-Pro에서 Gemini 2.5 Pro와 동등한 성능을 달성했습니다. 이 강의는 네이티브 사전 학습의 근거와 이를 적용했을 때 달라지는 점을 다룹니다.

**유형:** Learn
**언어:** Python (stdlib, training-corpus mixer)
**선수 요건:** 12단계 · 05, 12단계 · 07 (레시피)
**시간:** 약 120분

## 학습 목표

- 사후(post-hoc) VLM 학습이 정렬 부채(alignment debt)를 누적하는 이유를, 세 가지 측정 가능한 증상(파국적遗忘, 답변 드리프트, 시각-텍스트 불일치)을 인용하여 설명하세요.
- InternVL3의 네이티브 사전 학습 코퍼스(corpus) 혼합 구성과 텍스트 : 인터리브드 : 캡션 비율이 중요한 이유를 설명하세요.
- V2PE (가변 시각적 위치 인코딩)를 Qwen2-VL의 M-RoPE와 비교하세요.
- 시각 해상도 라우터(ViR)와 분리된 비전-언어(DvD) 배포 최적화를 나열하세요.

## 문제점

사후(post-hoc) VLM 학습이 기본값입니다. LLaVA, BLIP-2, Qwen-VL, Idefics는 모두 이미 사전 학습된 LLM (Llama, Vicuna, Qwen, Mistral)을 가져와 비전을 추가합니다. 학습 단계는 일반적으로 다음과 같습니다:

1. 동결된 LLM + 동결된 비전 인코더 + 학습 가능한 프로젝터를 캡션 쌍으로 학습하여 임베딩을 정렬합니다.
2. LLM의 동결을 해제하고, 지시 데이터(LLaVA-Instruct, ShareGPT4V)로 학습합니다.
3. 선택적으로 작업별 미세 조정을 수행합니다.

정렬 부채의 세 가지 증상이 나타납니다:

- 파국적遗忘(Catastrophic forgetting). 사후 VLM은 텍스트 전용 스킬을 잊습니다. GSM8K 점수가 5-10점 떨어집니다. Hellaswag 점수가 떨어집니다. 순수 텍스트 에이전트가 후퇴합니다.
- 답변 편차. 동일한 시각적 질문에 대해 표현이 조금만 달라져도 다른 답변이 나옵니다. 비전 인코더는 LLM의 자체 토큰보다 더 약한 연결로 LLM에 연결됩니다.
- 시각-텍스트 불일치. VLM은 이미지를 올바르게 설명한 후, 그 설명과 모순되는 질문에 답변할 수 있습니다. 시각적 토큰은 텍스트처럼 LLM의 내부 일관성 검사에 동일하게 참여하지 않습니다.

이러한 증상들은 잘 문서화되어 있습니다. MM1.5의 4절은 이를 정량화합니다. LLaVA-OneVision의 Ablation은 이를 암시합니다. 네이티브 사전 학습이 해답입니다.

## 개념

### 네이티브 멀티모달 사전 학습

InternVL3는 첫 단계부터 네이티브 멀티모달인 코퍼스로 처음부터 학습합니다. 구성은 다음과 같습니다:

- 40% 텍스트 전용 데이터 (FineWeb, Proof-Pile-2 등)
- 35% 인터리브드 이미지-텍스트 데이터 (OBELICS, MMC4 스타일)
- 20% 이미지-캡션 쌍 데이터
- 5% 비디오-텍스트 데이터

시각적 토큰, 텍스트 토큰 및 교차 모달리티 상호작용은 첫 번째 기울기 단계부터 동일한 손실 함수에 참여합니다. 정렬 사전 학습이 없고, 프로젝터 동결 단계가 없으며, 복구해야 할 파괴적遗忘(forgetting)이 없습니다.

기본 모델의 학습은 단일 단계입니다. 지시문 미세 조정이 뒤따르지만, 기본 모델은 이미 시각적 토큰을 일급 시민(first-class citizens)으로 이해합니다.

### V2PE (가변 시각적 위치 인코딩)

Qwen2-VL은 고정된 축 할당을 사용하는 M-RoPE를 사용합니다. InternVL3는 V2PE를 도입합니다: 위치 인코딩은 모달리티 유형(텍스트, 이미지, 비디오)에 따라 변하며, 학습 가능한 스케일링을 적용합니다. 실제로는:

- 텍스트 토큰은 1D 위치(텍스트 인덱스)를 받습니다.
- 이미지 패치는 2D 위치(행, 열)를 받습니다.
- 비디오 프레임은 3D 위치(시간, 행, 열)를 받습니다.

세 가지는 동일한 RoPE 주파수 기저를 공유하지만, 밴드별 은닉 차원 할당은 고정된 분할이 아닌 학습된 매개변수입니다. 사전 학습 중에 시간적 대 공간적 주파수 해상도를 자유롭게 트레이드오프할 수 있습니다.

V2PE의 Ablation 주장: 동일한 연산량에서 M-RoPE 대비 비디오 벤치마크에서 1-2점 향상. 혁명적인 변화는 아니지만, 더 깔끔합니다.

### 시각적 해상도 라우터 (ViR)

배포 최적화. 모든 이미지가 전체 해상도로 인코딩될 필요는 없습니다. 한 개의 물체가 저해상도로 포함된 사진은 네이티브 1280px로 인코딩할 때 토큰을 낭비합니다. ViR은 인코딩 전에 질문에 답하기 위해 필요한 최소 해상도를 예측하는 소형 분류기입니다.

라우팅은 세 단계로 구성됩니다: 저해상도 (256 토큰), 중해상도 (576), 고해상도 (2048+). 프로덕션 트래픽의 60% 쿼리에는 저해상도 또는 중해상도가 충분합니다. 순 효과: 동일한 품질에서 2-3배의 처리량.

### 분리된 비전-언어 모델 배포 (DvD)

대형 비전-언어 모델 (VLM)을 서빙할 때, 비전 인코더는 이미지당 한 번 실행되지만 LLM은 모든 출력 토큰에 대해 자기회귀적으로 실행됩니다. 두 구성 요소는 서로 다른 병목 현상을 가집니다 (비전 = 합성곱 및 어텐션을 위한 GPU 메모리 대역폭; LLM = KV 캐시). DvD는 이들을 스트리밍이 연결된 별도의 GPU로 분리합니다.

8B 모델 + 400M 인코더 모델의 경우, DvD는 공동 배치(co-located) 대비 노드당 처리량을 대략 두 배로 증가시킵니다.

### 단일 단계 vs 다단계 품질

InternVL3의 주요 벤치마크 주장: 78B 파라미터에서 Gemini 2.5 Pro의 MMMU-Pro 점수와 동등합니다. 38B에서 GPT-4o와 동등합니다. 8B에서 오픈 8B 리더보드에서 선두를 차지합니다. 모두 단일 단계 사전 학습 + 지시문 미세 조정 레시피로 달성했습니다.

정렬 부채(alignment-debt) 가설은 측정 가능합니다: InternVL3-8B는 비전 벤치마크 향상 단위당 Qwen2.5-VL-7B보다 텍스트 벤치마크 점수(MMLU, GSM8K) 손실이 적습니다. 학습이 한 부분으로 이루어졌기 때문에, 두 부분으로 이루어진 모델보다 더 범용적인 모델입니다.

### InternVL3.5 및 InternVL-U

InternVL3.5 (2025년 8월)는 레시피를 확장합니다. 동일한 네이티브 사전 학습 접근 방식, 더 많은 데이터, 더 많은 파라미터. MMMU 개선은 점진적입니다.

InternVL-U (2026)는 통합 생성을 추가합니다 — 동일한 백본 위에 MMDiT 헤드를 통해 이미지 출력. "U"는 "이해 + 생성"을 의미하며, Transfusion 스타일의 통합 모델 (12.13강)을 추격합니다. 동일한 네이티브 사전 학습 백본이 이해 및 생성 헤드를 모두 지원합니다.

### 네이티브 사전 학습의 트레이드오프

네이티브 사전 학습은 무료가 아닙니다:

- 컴퓨팅. 새로운 VLM을 처음부터 학습하는 비용은 텍스트 LLM을 학습하는 비용과 동일합니다 — 수백만 GPU-시간. 사후 적응(post-hoc adaptation)은 기존 LLM 가중치를 재사용하여 대부분의 비용을 절약합니다.
- 데이터. 대규모의 교차(interleaved) 이미지-텍스트 코퍼스는 희소합니다. OBELICS는 141M 문서이고, MMC4는 571M입니다. 텍스트만으로는 15T 토큰이 제공됩니다. 멀티모달 사전 학습 데이터의 희소성은 어려운 제약 조건입니다.
- 기본 LLM 재사용. 네이티브 사전 학습은 나중에 새로운 LLM을 도입할 수 있는 옵션을 포기합니다. 사후(post-hoc) 방식은 어댑터만 재학습하여 Llama-3.1을 Llama-4로 교체할 수 있습니다.

InternVL3가 거는 베팅: 정렬 부채(alignment debt)가 재사용 손실보다 더 나쁩니다. 벤치마크가 이 주장을 뒷받침합니다. 생산 비용이 미래의 연구실이 저렴하게 복제하는 것을 막습니다. 사후 VLM은 대부분의 프로젝트에서 더 저렴하기 때문에 계속 존재할 것입니다.

## 사용하기

`code/main.py`는 학습 코퍼스 믹서 및 ViR 라우터 시뮬레이터입니다. 이 도구는:

- 목표 코퍼스 믹스(%text, %interleaved, %caption, %video)를 받아 모달리티별 예상 스텝 수를 계산합니다.
- 쿼리 배치(분포: 50% 저세부, 30% 중세부, 20% 고세부)에 대해 ViR 라우팅을 시뮬레이션하고 평균 토큰 수를 보고합니다.
- 인코더 대 LLM FLOPs를 고려한 DvD 처리량 추정치를 보고합니다.
- 사후(post-hoc) 대 네이티브 사전 학습을 매개변수, 컴퓨팅, 데이터 및 예상 정렬 부채(alignment-debt) 증상 측면에서 나란히 비교하여 출력합니다.

## 출시하기

이 강의는 `outputs/skill-native-vs-posthoc-auditor.md`를 생성합니다. 제안된 VLM 학습 계획을 받아 네이티브 방식과 사후(post-hoc) 방식 중 어느 것을 선택할지 감사하고, 정렬 부채(alignment-debt) 위험을 플래그하며, 코퍼스 믹스를 권장합니다. 새로운 오픈 VLM 프로젝트의 규모를 결정하고 학습 전략을 선택해야 할 때 사용해 보세요.

## 연습 문제

1. InternVL3-8B (네이티브 사전 학습)와 LLaVA-OneVision-7B (사후(post-hoc)) 간의 컴퓨팅 차이를 추정해 보세요. GPU-hours의 비율은 대략 얼마인가요? 격차를 설명하는 것은 무엇인가요?

2. InternVL3는 40% 텍스트 / 35% 교차(interleaved) / 20% 캡션 / 5% 비디오를 보고합니다. 목표 작업이 비디오 중심이라면 새로운 비율을 제안하고, 기본 모델이 여전히 상당한 양의 텍스트 및 캡션 데이터를 필요로 하는 이유를 논증해 보세요.

3. MM1.5의 섹션 4를 읽고 '망각(forgetting)'에 대해 살펴보세요. 사후(post-hoc) 학습에서 가장 큰 후퇴(regression)가 나타난 정확한 벤치마크를 지정해 보세요. 후퇴의 비용은 얼마나 되었나요?

4. ViR은 트래픽의 60%를 저해상도 인코딩으로 라우팅합니다. 어떤 종류의 쿼리를 잘못 라우팅하나요 (고해상도가 필요할 때 저해상도로 보내는 경우)? 세 가지 라우터 실패 모드를 제안해 보세요.

5. DvD는 비전과 LLM을 separate GPU에 분할합니다. 어떤 트래픽 패턴에서 DvD가 처리량을 높이는 것이 아니라 오히려 낮추는가요?

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|-----------------|------------------------|
| 네이티브 멀티모달 사전 학습 | "처음부터 함께" | 텍스트 + 이미지 + 비디오 토큰이 1단계부터 손실 계산에 참여하며, 나중에 붙여 넣는 방식이 아님 |
| 정렬 부채 | "사후 페널티" | 동결된 LLM에 비전을 붙여 넣는 것에서 비롯된 텍스트 기술 및 답변 일관성의 측정 가능한 퇴보 |
| V2PE | "가변 시각적 위치 인코딩" | 모달리티별 학습 가능한 위치 인코딩 할당; InternVL3의 M-RoPE 후속 |
| ViR | "해상도 라우터" | 인코딩 전에 쿼리별로 필요한 최소 해상도를 선택하는 소형 분류기로, 추론 토큰을 절약 |
| DvD | "분리된 배포" | 비전 인코더는 한 GPU에, LLM은 다른 GPU에 배치하고 스트림 핸드오프를 수행; 대규모 VLM의 처리량을 두 배로 높임 |
| InternVL-U | "통합 이해 + 생성" | 네이티브 사전 학습 백본에 이미지 생성 헤드를 추가한 2026년 후속 |
| 인터리브드 코퍼스 | "OBELICS / MMC4" | 자연스러운 읽기 순서로 텍스트와 이미지가 포함된 문서; 네이티브 사전 학습의 원재료 |
