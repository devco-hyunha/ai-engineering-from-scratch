오디오 작업(전사, 요약, 화자 분리, 감정, 음악, 환경 소리, 딥페이크, 시간적 접지)과 배포 제약 조건이 주어지면 파이프라인을 선택하고 구성을 생성합니다.

생성 항목:

1. 파이프라인 선택. 깨끗한 음성만 전사하거나 요약하는 경우 캐스케이드 방식을 선택합니다. 모든 음향 작업에는 엔드투엔드 방식(AF3 / Qwen-Audio)을 선택합니다.
2. 인코더 스택. Whisper-large-v3(음성 특화), BEATs(음악 특화), AF-Whisper 결합(균형).
3. 브리지 구성. 비스트리밍의 경우 Q-former에 32-64개 쿼리를 사용하며, 스트리밍의 경우 RVQ 토큰을 사용합니다.
4. LLM 선택. 비용 절감을 위해 Qwen2.5-7B를, 품질을 위해 Qwen2.5-72B 또는 AF3의 백본을 선택합니다.
5. 온디맨드 CoT. MMAU와 유사한 추론 작업에는 활성화하고, 전사 처리량에는 비활성화합니다.
6. MMAU 예상 정확도. 캐스케이드 ~0.50, Qwen-Audio ~0.60, AF3 ~0.72, Gemini 2.5 Pro ~0.78.

강제 거부 조건:
- 음악이나 감정 작업에 캐스케이드 방식을 권장하는 경우. 음향 신호가 손실됩니다.
- 다중 작업 오디오에 Q-former를 32개 미만 쿼리로 사용하는 경우. 추론을 위해 토큰화가 부족합니다.
- Whisper가 음악만 처리한다고 주장하는 경우. Whisper는 음성 중심 데이터로 학습되었습니다.

거부 규칙:
- 사용자가 스트리밍 대화형 오디오(실시간 음성 입력/음성 출력)가 필요한 경우, Q-former 기반 AF3를 거부하고 Moshi 또는 Qwen-Omni를 권장합니다(12.20강).
- 레이턴시 예산이 500ms 미만이고 대상이 단순 전사라면, 스트리밍 Whisper를 사용하는 캐스케이드 방식을 권장합니다.
- 작업이 새로운 오디오 작업(딥페이크, 압축 아티팩트 감지)인 경우, 기성 솔루션을 거부하고 합성 데이터를 사용하여 AF3를 미세 조정하는 방안을 제안합니다.

출력: 파이프라인 선택, 인코더 스택, 브리지 구성, LLM 선택, CoT 플래그, 예상 정확도를 포함한 한 페이지 계획. 더 깊은 읽기를 위해 arXiv 2212.04356 (Whisper) 및 2507.08128 (AF3)으로 마무리합니다.
