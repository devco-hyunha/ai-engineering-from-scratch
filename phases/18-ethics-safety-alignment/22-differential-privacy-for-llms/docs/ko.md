# LLM을 위한 차등 프라이버시

> DP-SGD는 여전히 표준입니다. 노이즈가 주입된 기울기 업데이트는 형식적인 (epsilon, delta) 보증을 제공합니다. 연산, 메모리 및 유틸리티 측면의 오버헤드가 상당합니다. 매개변수 효율적인 DP 미세 조정(LoRA + DP-SGD)은 2025년 일반적인 구성입니다(ACM 2025). 두 가지 증거가 긴장 관계에 있습니다. 카나리 기반 멤버십 추론(Duan et al., 2024)은 언어 모델에 대한 성공이 제한적이라고 보고합니다. 반면, 훈련 데이터 추출(Carlini et al., 2021; Nasr et al., 2025)은 상당한 양의 원문 기억을 복원합니다. 해결책(arXiv:2503.06808, 2025년 3월)은 측정 대상의 차이입니다. 삽입된 카나리 vs "가장 추출 가능한" 데이터. 새로운 카나리 설계는 섀도 모델 없이 손실 기반 MIA를 가능하게 하며, 현실적인 DP 보증을 가진 실제 데이터로 훈련된 LLM의 첫 비자명한 DP 감사를 제공합니다. 대안으로는 PMixED(arXiv:2403.15638)가 있습니다. 이는 다음 토큰 분포에 대한 혼합 전문가를 통해 추론 시점에 프라이빗 예측을 수행합니다. 또한 DP 합성 데이터 생성(Google Research 2024)도 있습니다. 새로운 공격으로는 LLM 피드백을 통한 차등 프라이버시 역전(Differential Privacy Reversal via LLM Feedback)이 있습니다. 이는 신뢰 점수 유출을 이용합니다.

**유형:** Build
**언어:** Python (표준 라이브러리, DP-SGD 노이즈 주입 및 ε-δ 회계원 시연)
**선수 요건:** 01단계 · 09강 (정보 이론), 10단계 · 01강 (대규모 모델 훈련)
**시간:** 약 60분

## 학습 목표

- (epsilon, delta)-차등 프라이버시를 정의하고 DP-SGD 레시피를 서술해 보세요.
- 2024-2025년의 긴장 관계를 설명해 보세요. 카나리 MIA와 훈련 데이터 추출이 서로 다른 그림을 제시합니다.
- PMixED를 설명하고, 추론 시점의 프라이빗 예측이 DP 훈련의 대안인 이유를 서술해 보세요.
- LLM 피드백을 통한 차등 프라이버시 역전(Differential Privacy Reversal via LLM Feedback) 공격을 설명해 보세요.

## 문제점

LLM은 기억합니다. Carlini et al. 2021은 생산용 언어 모델이 요청 시 훈련 텍스트를 원문 그대로 재생한다는 것을 보여 주었습니다. DP는 형식적인 방어책입니다. 훈련 시 출력물이 단일 훈련 예시에 대해provably insensitive(증명 가능한 민감도 없음)이 되도록 합니다. 2024-2025년 증거는 DP-SGD가 필수적이지만, 배포된 ε 값이 위협 모델과 일치하지 않을 수 있음을 보여 줍니다.

## 개념

### (ε, δ)-차등 프라이버시

무작위 알고리즘 M이 (ε, δ)-DP를 만족한다는 것은, 한 예제만 다른 두 데이터셋과 임의의 이벤트 S에 대해 다음이 성립함을 의미합니다:
P(M(D) in S) <= e^ε * P(M(D') in S) + δ.

해석: 출력 분포가 충분히 가깝습니다(ε로 매개변수화됨). 따라서 확률 δ를 제외하고는, 단일 개인의 기여도를 신뢰할 수 있게 추론할 수 없습니다.

### DP-SGD

Abadi et al. 2016. 표준 레시피:
1. 미니배치를 샘플링합니다.
2. 예제별 기울기를 계산합니다.
3. 각 예제별 기울기를 임계값 C로 클리핑합니다.
4. 클리핑된 기울기를 합산하고 표준 편차 σ * C인 가우시안 노이즈를 추가합니다.
5. 노이즈가 포함된 합산 값을 사용하여 매개변수를 업데이트합니다.

개인정보 보호 비용은 어카운터(Moments Accountant, Rényi DP accountant)로 추적됩니다. LLM 문헌에서 보고된 ε 값은 위협 모델, 데이터 민감도, 유틸리티 목표에 따라 크게 varies합니다. universally "safe"한 기본 ε는 없습니다. 공개된 예시들은 일부 LLM 학습 설정에서 ε ≈ 1–10 범위까지 넓게 분포하지만, 이는 예시적일 뿐 권장되는 기본값이 아닙니다. 일반적으로 ε가 낮을수록 더 많은 노이즈가 필요하며, 유틸리티 손실이 증가할 수 있습니다.

### LoRA + DP-SGD

프론티어 모델에 대한 전체 DP-SGD는 prohibitive합니다. LoRA(Hu et al. 2022)는 기울기 업데이트를 작은 어댑터로 제한하여 예제별 기울기 저장 공간을 줄입니다. LoRA + DP-SGD는 2025년 일반적인 구성입니다. DP 보장은 어댑터에 적용되며, 기본 모델은 고정되어 있습니다.

### 2024-2025년의 긴장

두 가지 증거 라인:

- **카나리 MIA (Duan et al. 2024).** 훈련 데이터에 고유한 카나리를 삽입하고, 멤버십 추론 공격자가 이를 식별할 수 있는지 측정합니다. 언어 모델에서는 제한적인 성공만 보고했습니다. MIA가 어렵다는 것을 시사합니다.
- **훈련 데이터 추출(Carlini 2021, Nasr et al. 2025).** 모델에 접두어로 프롬프트를 입력하고, 훈련 데이터에서 원문 텍스트를 복원하는지 측정합니다. 상당한 기억(memorization)을 보고했습니다. 관련 있는 의미에서 MIA가 쉽다는 것을 시사합니다.

2025년 3월 해결책(arXiv:2503.06808): 두 방법은 서로 다른 것을 측정합니다. MIA는 삽입된 카나리에 대해 "예제 e가 D에 있는가?"를 묻습니다. 추출은 "D에서 무엇을 복원할 수 있는가?"를 묻습니다. "가장 추출하기 쉬운" 예제가 개인정보 보호에 중요합니다. 카나리는 추출하기 쉽도록 최적화되지 않았으므로, 이를 과소 보고합니다.

새로운 카나리 설계. 섀도 모델 없는 손실 기반 MIA. 실제 데이터에 대해 현실적인 DP 보증을 적용한 LLM의 첫 비자명 DP 감사.

### DP 학습의 대안

- **PMixED (arXiv:2403.15638).** 추론 시점의 프라이빗 예측. 다음 토큰 분포에 대한 혼합 전문가(MoE)를 사용하며, 각 전문가는 학습 데이터의 청크를 봅니다. 집계 과정에서 DP를 위해 노이즈를 추가합니다. DP 학습을 완전히 피합니다.
- **DP 합성 데이터 생성 (Google Research 2024).** DP-SGD로 LoRA 미세 조정 후 합성 데이터를 샘플링하고, 합성 데이터로 다운스트림 분류기를 학습합니다.

두 방법 모두 다른 위협 모델을 감수하는 대신, 완전 DP 학습의 유틸리티 비용을 피합니다.

### LLM 피드백을 통한 차분 프라이버시 역전

2025년 등장한 공격. DP로 학습된 모델의 신뢰도 점수를 오라클로 사용하여 개인을 재식별합니다. 출력은 유출되지 않더라도 신뢰도 분포는 유출될 수 있습니다.

방어책: 신뢰도를 노출하지 않거나, 노출하기 전에 절단/양자화합니다. 이는 (ε, δ)-DP 학습을 넘어서는 추가 요구 사항입니다.

## 사용하기

`code/main.py`는 장난감 이진 분류 데이터셋에서 DP-SGD를 시뮬레이션합니다. 노이즈 곱셈 σ와 클리핑 노름 C를 스윕하며 (ε, δ) 예산과 정확도 비용을 추적할 수 있습니다. "카나리 공격"은 고유한 학습 예제를 삽입하고, DP 적용 전후에 로그 손실 테스트가 이를 감지할 수 있는지 측정합니다.

5. LLM 피드백을 통한 DP 반전(DP Reversal) 공격을 스케치해 보세요. 신뢰 점수 유출을 제한하는 대응책을 설계하고 그 배포 비용을 추정해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|------------------------|
| DP | "(ε, δ)-차분 프라이버시" | 형식적 프라이버시: 인접한 데이터셋 변경 시 출력 분포가 유사함 |
| DP-SGD | "노이즈가 주입된 SGD" | 기울기 클리핑 + 가우시안 노이즈 추가; 표준 DP 학습 |
| LoRA + DP-SGD | "효율적인 프라이빗 미세 조정" | 저랭크 어댑터에 대한 DP-SGD; 2025년 표준 구성 |
| MIA | "멤버십 추론" | 예제가 학습 데이터에 포함되었는지 결정하는 공격 |
| 카나리 | "삽입된 워터마크 예제" | DP 유출을 측정하기 위해 사용되는 고유한 학습 예제 |
| PMixED | "프라이빗 추론 혼합" | 다음 토큰 분포에 대한 혼합 전문가(mixture-of-experts)를 통한 추론 시간 DP |
| DP 반전 | "신뢰 점수 유출 공격" | 모델의 신뢰 점수를 재식별 오라클로 사용하는 공격 |
