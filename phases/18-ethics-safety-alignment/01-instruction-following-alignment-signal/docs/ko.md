# 정렬 신호로서의 지시문 따르기

> RLHF에 대한 모든 후속 비판은 이 파이프라인을 반대합니다. 최적화 압력이 대용량 지표(proxy)를 왜곡하는 방식을 공부하기 전에, 그 대용량 지표를 먼저 봐야 합니다. InstructGPT (Ouyang et al., 2022)는 참조 아키텍처를 정의했습니다: 지시문-응답 쌍에 대한 지도 미세 조정 (SFT)(Supervised Fine-Tuning), 쌍별 선호 순위로 학습된 보상 모델, 그리고 SFT 정책에 대한 KL 페널티를 포함하여 보상 모델에 대해 수행하는 PPO. 1.3B InstructGPT는 175B GPT-3보다 선호되었습니다. 이 단일 결과가 2026년 모든 프론티어 랩이 여전히 RLHF 형태의 후처리 파이프라인을 출시하는 이유입니다.

**유형:** Learn
**언어:** Python (표준 라이브러리, 장난감 3단계 파이프라인)
**선수 요건:** 10단계 · 06강 (SFT), 10단계 · 07강 (RLHF), 10단계 · 08강 (DPO)
**시간:** 약 45분

## 학습 목표

- InstructGPT 파이프라인의 세 단계와 각 단계에서 사용되는 손실(loss)을 나열해 보세요.
- 1.3B 지시문 미세 조정 모델이 인간 선호 평가에서 원본 175B GPT-3를 이긴 이유를 설명해 보세요.
- 3단계의 KL 페널티가 무엇을 보호하는지, 그리고 이를 제거하면 왜 모드 탐색(mode-seeking) 행동으로 붕괴되는지 설명해 보세요.
- 정렬 세(alignment tax)와 Ouyang et al.이 이를 완화하기 위해 사용한 PPO-ptx 완화 전략을 설명해 보세요.

## 문제점

사전 학습된 언어 모델은 텍스트를 완성합니다. 질문을 답변하지는 않습니다. GPT-3에게 "리스트를 역순으로 만드는 Python 함수를 작성해"라고 요청하면, 종종 다른 프롬프트가 반환됩니다. 대부분의 학습 분포는 웹 텍스트가 더 많은 웹 텍스트로 이어지는 형태이기 때문입니다. 모델은 제 역할을 하고 있습니다 — 그 역할이 잘못된 것입니다.

모든 주요 랩이 이 문제를 해결하기 위해 사용한 대용량 지표는 인간 선호입니다. 두 개의 완성(completions)이 평가자에게 전달되고, 평가자가 더 나은 것을 선택합니다. 보상 모델은 평가자를 학습합니다. 그런 다음 RL 루프가 보상 모델이 높은 점수를 부여하는 출력으로 정책을 이동시킵니다. 이것이 세 문장으로 요약된 InstructGPT의 논지입니다. 나머지 부분은 엔지니어링입니다.

## 개념

### 1단계: 지도 미세 조정 (SFT)(Supervised Fine-Tuning)

선량한 사람이 작성할 만한 응답을 가진 프롬프트-응답 쌍을 수집하세요. Ouyang et al.은 라벨러와 OpenAI API에서 13k개의 프롬프트를 사용했습니다. 이 데이터로 표준 교차 엔트로피 손실(Cross-Entropy Loss)을 사용하여 기본 모델을 미세 조정(Fine-tuning)하세요.

SFT가 제공하는 것: 모델이 이제 질문을 계속하는 대신 질문에 답합니다. SFT가 제공하지 않는 것: 여러 답변이 타당할 때 라이터가 어떤 답변을 선호하는지에 대한 신호입니다.

### 2단계: 보상 모델(RM)

각 프롬프트에 대해 SFT 모델에서 K개의 완성(K completions)을 샘플링하세요. 라벨러가 이들을 순위를 매깁니다. `y_w`가 `y_l`보다 선호된 쌍에 대해 보상 모델이 모든 프롬프트-응답 쌍을 점수화하도록 학습하세요:

```
L_RM = -log sigmoid(r(x, y_w) - r(x, y_l))
```

이것은 Bradley-Terry 쌍별 선호 손실입니다. RM은 보통 LM 헤드를 스칼라 헤드로 대체한 SFT 모델에서 초기화됩니다.

보상 모델은 작습니다: 175B InstructGPT에는 6B가 충분했습니다. 또한 보상 모델은 취약합니다 — 논문 섹션 5는 주로 소규모에서 나타난 보상 해킹(reward-hacking) 행동에 대한 내용입니다.

### 3단계: KL 페널티가 있는 PPO

목표 함수를 정의하세요:

```
J(pi) = E_{x~D, y~pi(.|x)} [ r(x, y) ] - beta * KL(pi(.|x) || pi_SFT(.|x))
```

PPO로 최대화하세요. KL 항은 `pi`가 SFT 정책에서 너무 멀리 벗어나지 않도록 합니다. 이것이 없으면 옵티마이저는 적대적 예제 — RM이 본 적 없어서 RM 점수가 높은 문자열, 인간이 실제로 선호해서가 아닌 경우 —를 찾습니다.

KL 계수 `beta`는 RLHF에서 가장 중요한 하이퍼파라미터입니다. 너무 낮으면: 보상 해킹. 너무 높으면: SFT보다 개선되지 않음.

### 정렬 세(alignment tax)

RLHF 후, 모델은 인간에게 선호되지만 표준 벤치마크(SQuAD, HellaSwag, DROP)에서 성능이 후퇴합니다. Ouyang et al.은 이것을 정렬 세(alignment tax)라고 부르며 PPO-ptx로 해결합니다: RL 목표에 사전 학습 기울기를 혼합하여 모델이 보상받지 못한 다운스트림 작업을 잊지 않도록 합니다.

```
J_ptx(pi) = J(pi) + gamma * E_{x~D_pretrain} [ log pi(x) ]
```

PPO-ptx는 표준이 되었습니다. Anthropic, DeepMind, Meta 모두 변형된 버전을 사용합니다.

### 결과

1.3B InstructGPT (SFT + RM + PPO-ptx)는 라벨러가 175B 기본 GPT-3보다 약 70%의 경우 선호합니다. 생산 트래픽의 숨겨진 테스트 프롬프트에서는 격차가 더 커집니다. 이 수치에서 읽을 수 있는 두 가지가 있습니다:

1. 정렬(Alignment)은 능력(capability)과 다른 축입니다. 175B 모델은 더 높은 능력을 가졌고, 1.3B 모델은 더 높은 정렬도를 가졌으며, 라벨러는 정렬된 모델을 선호했습니다.
2. 능력 하한은 기본 모델에 의해 결정됩니다. RLHF로 기본 모델이 본 적 없는 사실을 알게 할 수는 없습니다.

### 이것이 18단계의 기준점인 이유

이후 강의에서의 모든 비판 — 보상 해킹(2강), DPO(3강), 아첨(sycophancy)(4강), CAI(5강), 슬리퍼 에이전트(sleeper agents)(7강), 정렬 위조(alignment faking)(9강) —는 이 파이프라인의 일부에 반대합니다. 보상 해킹은 2단계를 공격합니다. DPO는 2단계와 3단계를 통합합니다. CAI는 인간 라벨러를 대체합니다. 아첨은 라벨러가 편향된 신호임을 보여줍니다. 정렬 위조는 정책이 3단계를 완전히 우회할 수 있음을 보여줍니다. 머릿속에 파이프라인이 없으면 이러한 비판 중 어느 것도 따를 수 없습니다.

## 사용하기

`code/main.py`는 장난감 선호 데이터에 세 단계를 시뮬레이션합니다. 기본 "정책"은 행동 {A, B, C}에 대한 편향된 코인입니다. 1단계 SFT는 200개 프롬프트에서 라벨러의 행동을 모방합니다. 2단계는 500개 쌍별 순위로부터 Bradley-Terry 보상 모델을 적합합니다. 3단계는 SFT 정책에 대한 KL 페널티가 포함된 단순화된 PPO 업데이트를 실행합니다. 보상 상승, KL 발산 증가, 정책 드리프트를 관찰할 수 있으며, KL 항을 끄면 50개 업데이트 단계 내에서 보상 해킹이 나타나는 것을 볼 수 있습니다.

살펴볼 사항:

- `beta = 0.1`와 `beta = 0.0`의 보상 궤적.
- 학습 단계에 따른 KL(pi || pi_SFT).
- 라벨러 선호와 비교한 최종 행동 분포.

## 출시하기

이 강의는 `outputs/skill-instructgpt-explainer.md`를 생성합니다. RLHF 파이프라인 설명이나 논문 초록이 주어지면, 세 단계 중 어느 단계가 수정되는지, 각 단계에서 어떤 손실 함수가 사용되는지, KL 페널티나 동등한 정규화기가 존재하는지 식별합니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|------------------------|
| SFT | "지시문 튜닝" | 1단계: 프롬프트-응답 쌍에 대한 교차 엔트로피 미세 조정 |
| 보상 모델 | "the RM" | 쌍별 라벨에 대해 Bradley-Terry로 학습된 (프롬프트, 응답)에 대한 스칼라 회귀 모델 |
| Bradley-Terry | "쌍별 선호 손실" | -log sigmoid(r_w - r_l); 쌍별 순위를 이진 분류로 줄임 |
| KL 페널티 | "정규화 인자" | `beta * KL(pi \|\| pi_SFT)` — RL 정책을 SFT 앵커 근처에 유지 |
| PPO-ptx | "프리트레이닝 혼합이 있는 PPO" | 정렬 세(alignment tax)를 상쇄하기 위해 PPO 목적 함수에 프리트레이닝 로그 우도의 일부를 추가 |
| 정렬 세 | "RLHF 회귀" | RLHF가 타겟하지 않은 표준 벤치마크에서의 RLHF 후 성능 저하 |
| 라벨러 선호도 | "정답" | 인간 순위의 샘플; RM은 "인간 가치"가 아닌 이에 대한 통계적 대리 지표 |
