# 에이전트 경제, 토큰 인센티브, 평판

> 장기 자율 에이전트(METR의 1시간~8시간 작업 곡선)는 경제적 주체성이 필요합니다. 부상하는 **5층 스택**은 다음과 같습니다: **DePIN**(물리적 컴퓨팅) → **신원**(W3C DID + 평판 자본) → **인지**(RAG + MCP) → **정산**(계정 추상화) → **거버넌스**(에이전트형 DAO). 생산적인 에이전트 인센티브 네트워크에는 **Bittensor**(TAO 서브넷이 작업 특화 모델에 보상), **Fetch.ai / ASI Alliance**(ASI-1 Mini LLM + FET 토큰), **Gonka**(생산적인 AI 작업으로 컴퓨팅을 재배분하는 트랜스포머 기반 PoW)가 포함됩니다. 학술 연구: AAMAS 2025의 분산 LaMAS는 **Shapley 값 신용 귀속**을 사용하여 기여한 에이전트에 공정하게 보상합니다. Google Research의 "Mechanism design for large language models"는 단조 집계 하에 차익 지불을 하는 **토큰 경매**를 제안합니다. 이 강의는 최소한의 에이전트 마켓플레이스를 구축하고, 다중 에이전트 파이프라인에 Shapley 값 신용 귀속을 적용하며, 차익 토큰 경매를 실행하여 게임 이론적 메커니즘을 구체적으로 구현합니다.

**유형:** Learn
**언어:** Python (stdlib)
**선수 요건:** 16단계 · 16강 (협상과 교섭), 16단계 · 09강 (병렬 스웜 네트워크)
**시간:** 약 75분

## 문제점

에이전트가 가치를 공동으로 생산하지만 개별적으로 보상해야 할 때 다중 에이전트 시스템은 복잡해집니다. 고전적인 메커니즘인 균등 분배나 마지막 기여자 전량 획득은 불공정하거나 조작이 가능합니다. Shapley 값을 통한 연합 기반 보상은 구조적으로 공정하지만 계산 비용이 높습니다. 2025-2026년 문헌은 Shapley 샘플링, 단조 집계 경매, 확인된 기여에서 누적되는 온체인 평판 등 유용한 근사화를 제시합니다.

신용 귀속을 넘어, 이 분야는 실제 경제적 에이전트로 전환되었습니다. Bittensor TAO는 서브넷 특화 모델을 미세 조정하기 위해 마이닝 컴퓨팅에 보상을 지급하고, Fetch.ai/ASI는 FET 토큰으로 ASI-1 Mini LLM 사용을 보상하며, Gonka는 트랜스포머 작업 증명(PoW)을 생산적인 AI 작업으로 재배분합니다. 자율적으로 거래하는 에이전트는 현재 존재하며, 핵심 과제는 인센티브를 정렬하는 것입니다.

이 강의는 에이전트 경제를 신용 귀속, 메커니즘 설계, 평판이라는 특정 문제 가족으로 다루며, 아이디어가 잘 정착하도록 각 요소를 최소한의 수학으로 구축합니다.

## 개념

### 5계층 에이전트 경제 스택

1. **DePIN (물리적 컴퓨팅).** GPU, 스토리지, 대역폭을 임대하는 탈중앙화 인프라입니다. Bittensor 서브넷, Render Network, Akash가 이에 해당합니다. 에이전트 전용은 아니지만, 에이전트가 이를 사용합니다.
2. **신원.** W3C 탈중앙화 식별자(DID)는 각 에이전트에게 플랫폼에 의존하지 않는 영구적인 ID를 부여합니다. 평판은 DID에 축적됩니다. 에이전트 네트워크 프로토콜(ANP)은 DID를 검색 계층으로 사용합니다.
3. **인지.** 에이전트의 추론 루프: LLM + RAG + MCP. 다른 단계들이 구축하는 것이 바로 이것입니다.
4. **정산.** 계정 추상화(ERC-4337)는 에이전트가 ETH를 보유하지 않고도 자체 잔액에서 가스를 지불할 수 있게 합니다. 에이전트는 서비스, 서로, 또는 컴퓨팅 비용을 지불할 수 있습니다.
5. **거버넌스.** 에이전트형 DAO: 인간 *및* 에이전트가 프로토콜 변경에 투표하는 거버넌스 구조로, 투표권은 평판에 연결됩니다.

모든 프로덕션 시스템이 다섯 계층을 모두 사용하진 않습니다. Bittensor는 1, 2, 부분적으로 3, 부분적으로 4를 사용하며 5는 사용하지 않습니다. OpenAI 에이전트는 3을 제외하고는 아무것도 사용하지 않습니다. 이 스택은 참고 지도일 뿐, 필수 요건이 아닙니다.

### Bittensor, Fetch.ai, Gonka — 실행되는 것

**Bittensor (TAO).** 서브넷은 특화된 작업(언어 모델링, 이미지 생성, 예측)입니다. 마이너는 모델 출력물을 제출합니다. 검증자가 이를 순위를 매기며, 스테이크 가중 점수 방식으로 TAO 보상을 분배합니다. 각 서브넷은 자체적인 평가를 가집니다. 경제적 교훈은 다음과 같습니다: 사용된 컴퓨팅이 아닌, 작업별 출력 품질에 대해 지불하는 것입니다.

**Fetch.ai / ASI Alliance.** ASI-1 Mini LLM은 Fetch.ai 네트워크에서 실행되며, 사용자는 추론을 위해 FET 토큰을 지불합니다. 에이전트를 동등한 관계로 보는 서사가 여기서 더 강합니다: Fetch의 에이전트가 작업을 위해 다른 에이전트를 호출하고 FET로 지불할 수 있습니다.

**Gonka.** 트랜스포머 작업 증명: "작업"은 트랜스포머의 순방향 전파입니다. 마이너는 알려진 정답 출력(학습 데이터에서)이 있는 추론 작업을 실행하여 보상을 얻습니다. 해시 기반 PoW 대신 자원 생산적인 PoW입니다.

세 가지 모두 2026년 4월 기준으로 프로덕션급입니다. 보상 분배 방식이 다릅니다. Bittensor는 서브넷 검증자 대비 품질에 대해 보상합니다. Fetch는 지불하는 사용자가 측정하는 유용성에 대해 보상합니다. Gonka는 검증 가능한 추론 작업에 대해 보상합니다.

### 夏普리 값 신용 귀속

세 에이전트가 한 작업에 협력합니다. 출력 점수는 0.8입니다. 누가 무엇을 기여했을까요?

夏普리 값: 네 가지 공리(효율성, 대칭성, 선형성, null)를 만족하는 유일한 크레딧 배분입니다. 에이전트 `i`에 대해:

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

여기서 `S_i_O`는 순서 `O`에서 `i` 앞에 있는 에이전트들의 집합입니다. 실제로는 모든 순열을 나열하고, 각 순열에서 각 에이전트의 한계 기여도를 기록한 후 평균을 내 보세요.

에이전트가 N=3개인 경우 순열은 6개입니다. N=10인 경우 360만 개가 되므로, 실제로는 모든 순열을 나열하는 대신 순서를 샘플링하는 방식을 사용하세요.

### 집계를 위한 제2가격 경매

Google Research는 "Mechanism design for large language models" 논문에서 LLM 출력 집계를 위한 제2가격 토큰 경매를 제안했습니다. 설정: N개의 에이전트가 각각 완성을 제안하며, 선택될 때의 비공개 가치를 가집니다. 경매자는 가장 높은 가치의 제안을 선택하고 *두 번째로 높은* 가치를 지불합니다. 단조 집계(monotone aggregation, 가치 선택은 제안 선택에 의존하며 입찰 수에 의존하지 않음) 하에서는 이것이 진실성(truthful)을 보장합니다. 즉, 에이전트는 자신의 진정한 가치를 입찰합니다.

LLM 시스템에서 중요한 이유: 다양한 가격 책정을 가진 여러 에이전트에게 완성 작업을 아웃소싱할 수 있습니다. 경매는 최상의 제안을 선택하고 공정하게 지불하며, 에이전트에게는 허위 보고에 대한 유인이 없습니다.

### 평판 자본

DID에 바인딩된 평판 점수는 확인된 기여로부터 누적됩니다. 간단한 업데이트 규칙은 다음과 같습니다:

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

감쇠 계수 `alpha`가 1에 가깝습니다. 평판은:

- 라우팅 결정("어려운 작업을 고평판 에이전트에게 보내기")에 읽기 비용이 저렴합니다.
- 위조 비용이 높습니다(시간에 따라 누적되며 DID에 바인딩됨).
- 슬래싱(slashing)이 가능합니다: 검증에 실패한 기여는 차감됩니다.

### AAMAS 2025 분산 LaMAS

LaMAS 제안(AAMAS 2025)은 DID 신원, Shapley 값 크레딧 귀속, 그리고 단순한 경매 메커니즘을 결합합니다. 핵심 주장: 크레딧 귀속 단계를 분산화하면 시스템이 감사 가능해지고 단일 지점 조작에 면역됩니다.

### 경제학이 무너지는 지점

- **가격 오라클 조작.** 크레딧 함수가 조작될 수 있다면 에이전트는 이를 조작할 것입니다. 모든 메커니즘에는 적대적 테스트가 필요합니다.
- **Sybil 공격.** 한 운영자가 N개의 가짜 에이전트를 만들어 자신의 기여도를 부풀립니다. DID는 이를 늦추지만 막지는 못합니다. 평판 위조 비용이 완화책입니다.
- **검증 비용.** 크레딧 귀속은 검증자의 공정성에 비례합니다. 검증이 저렴하면(소형 LLM) 조작이 가능하고, 비싸면(인간 패널) 시스템이 확장되지 않습니다.
- **규제 불확실성.** 에이전트 경제는 금융 규제와 교차합니다. Bittensor, Fetch, Gonka는 2026년 기준 일부 관할권에서 법적 회색 지대에 운영되고 있습니다.

### 에이전트 경제가 합리적인 경우

- **이질적인 운영자가 있는 개방형 네트워크.** 단일 팀이 모든 에이전트를 통제하지 않습니다.
- **검증 가능한 출력.** 검증이 없으면 크레딧 귀속은 추측에 불과합니다.
- **장기 워크플로.** 일회성 작업은 평판 축적의 이점을 얻지 못합니다.
- **토큰화 결제가 관할권 내에서 합법적으로 실행 가능**합니다.

폐쇄적인 기업 시스템에서는 경제학이 더 단순한 할당 방식(관리자가 작업을 배정하고 지표는 내부적)으로 대체됩니다. 경제학 문헌은 주로 개방형 네트워크에 적용됩니다.

## 구현하기

`code/main.py`는 다음을 구현합니다:

- `shapley(value_fn, agents)` — 작은 N에 대해 열거를 통한 정확한 Shapley 계산.
- `second_price_auction(bids)` — 진실한 메커니즘; 승자는 두 번째로 높은 입찰액을 지불합니다.
- `Reputation` — 지수 감쇠와 슬래싱을 적용한 DID 기반 평판.
- 데모 1: 세 에이전트가 협력하며, 정확한 Shapley가 크레딧을 귀속합니다.
- 데모 2: 다섯 에이전트가 작업 슬롯을 입찰하며, 두 번째 가격 경매가 승자와 결제액을 선택합니다.
- 데모 3: 이질적인 평판을 가진 에이전트에게 100라운드 동안 작업을 배정하며, 평판 가중 라우팅이 랜덤보다 우수합니다.

실행:

```
python3 code/main.py
```

예상 출력: 각 에이전트의 Shapley 값; 진실한 입찰 균형이 표시되는 경매 결과; 워밍업 후 랜덤 대비 10-20% 품질 향상으로 평판 가중 라우팅이 표시됨.

## 출시하기

2026년 에이전트 경제 운영:

- **토큰이 아닌 평판부터 시작하세요.** 평판은 구현이 저렴하고 그 자체로 가치가 있으며, 토큰은 법적 및 경제적 복잡성을 추가합니다.
- **보상하기 전에 검증하세요.** 독립적인 검증 단계 없이 크레딧을 분배하지 마세요. 자가 보고된 품질은 시빌 게임(sybil games)을 유발합니다.
- **Shapley-exact가 아닌 Shapley-sample을 사용하세요.** 100-1000개의 순서를 샘플링하세요. 정확한 열거는 확장되지 않습니다.
- **감쇠 계수(cap decay factor)와 평판 하한(floor reputation)을 설정하세요.** 무제한 감쇠는 정당한 기여자를 소멸시킵니다. 너무 느린 감쇠는 오래된 고평판 에이전트(Agent)를 보상합니다.
- **메커니즘을 적대적으로 감사(adversarially audit)하세요.** 네트워크를 열기 전에 레드 티밍(Red Teaming) 시나리오를 실행하세요. 모든 메커니즘에는 게임 이론이 있습니다. 공격자가 아닌 허점을 찾아야 합니다.

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| DePIN | "분산 물리 인프라" | 토큰 인센티브가 있는 컴퓨팅/저장/대역폭. Bittensor, Akash, Render. |
| DID | "분산 식별자" | 휴대 가능한 ID에 대한 W3C 사양. 에이전트(Agent) 평판은 플랫폼이 아닌 DID에 바인딩됩니다. |
| ERC-4337 | "계정 추상화" | 가스를 스폰서할 수 있는 계약 계정으로, 에이전트(Agent) 결제를 가능하게 합니다. |
| Shapley value | "공정한 크레딧 귀속" | 효율성, 대칭성, 선형성, null을 만족하는 유일한 배분. |
| Second-price auction | "Vickrey 경매" | 진실한 메커니즘: 승자는 두 번째로 높은 입찰액을 지불합니다. 단조 집계(monotone aggregation)와 호환됩니다. |
| 평판 자본 | "누적된 품질 점수" | 확인된 기여에서 비롯된 DID 연동 점수; 시간이 지나면 감소합니다. |
| 에이전틱 DAO | "에이전트 + 인간이 거버넌스 수행" | 에이전트 투표자를 일급 구성원으로 포함하고, 투표권이 평판에 연동된 DAO입니다. |
| TAO / FET / GPU 크레딧 | "토큰 단위" | Bittensor TAO, Fetch.ai FET, 다양한 DePIN 토큰입니다. |
