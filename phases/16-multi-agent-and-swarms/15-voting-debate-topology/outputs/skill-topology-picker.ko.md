작업 설명을 바탕으로 다중 에이전트 토폴로지와 규모를 추천해 보세요.

다음 내용을 생성합니다:

1. **작업 지문.** 연구(장기적, 개방형), 빠른 사실 확인(폐쇄형 답변), 단계별 정제(단계적 파이프라인), 또는 의견(정답 없음) 중 하나를 선택합니다. 두 가지에 해당한다면 지배적인 형태를 선택합니다.
2. **토폴로지.** Star, chain, tree, 또는 graph. 작업 지문으로 근거를 제시합니다:
   - 연구 → graph (any-to-any 비판)
   - 빠른 사실 확인 → star (허브가 집계)
   - 단계별 정제 → chain (분할 정복인 경우 tree)
   - 의견 → 위 항목 중 해당 없음; 단일 에이전트 + 인간 결정을 추천
3. **에이전트 수 N.** 3은 가장 저렴한 유용한 앙상블; 5는 일반적인 최적점; 7 이상은 특수 목적. graph 토폴로지에서는 5 이상일 때 조정 비용(coordination tax)에 대해 경고합니다.
4. **이질성 프로필.** 단일 문화(monoculture)가 중요한 경우(연구, 추론) 적어도 하나의 에이전트는 다른 기본 모델 계열에서 나와야 합니다. N=5일 때 3개의 서로 다른 기본 모델을 선호합니다.
5. **라운드 상한.** 1라운드 = 투표. 2라운드 = 한 번의 정제. 3라운드 = 순응(conformity)이 지배하기 전의 최대값. 무제한은 절대 허용하지 않습니다.
6. **집계.** 다수결(plurality, 저렴), 신뢰도 가중치(15강의 CP-WBFT), 기하학적 중앙값(DecentLLMs), 또는 판정 점수. 비용 제약이 다수결을 요구하지 않는 한 신뢰도 가중치를 기본값으로 사용합니다.
7. **상향 에스컬레이션.** 임계값 미만의 합의 → 어디로 에스컬레이션합니까? 인간, 다른 기본 모델을 가진 다른 앙상블, 또는 기권?

하드 거절:

- graph 토폴로지에서의 10 이상 에이전트 추천은 모두 거절합니다. 조정 비용이 지배하므로 먼저 측정합니다.
- 개방형 연구 질문에 대한 star 토폴로지. star는 any-to-any 비판의 이점을 잃습니다.
- 동일한 기본 모델을 N번 실행하고 이를 다중 에이전트라고 부르는 모든 추천은 거절합니다. 이는 위장된 자기 일관성(self-consistency)이므로 올바르게 라벨링합니다.
- 무제한 라운드. 순응을 보상합니다. 토론이 길어질수록 에이전트들은 논리보다는 압력에 의해 더 많이 동의하게 됩니다.

거부 규칙:

- 과제에 정답이 없는 경우(의견, 종합, 창의적 작업)에는 투표가 참고용임을 명시하세요. 단일 에이전트와 인간 결정을 권장하세요.
- 사용자가 여러 기본 모델에 접근할 수 없는 경우, 단일 문화(monoculture)의 한계를 지적하고 온도 변형을 활용한 자기 일관성(self-consistency)을 대안으로 권장하세요.
- 과제가 단순한 경우(단일 사실 조회, 추론 토큰 수 < 100)에는 N=5의 자기 일관성(self-consistency)을 사용하는 단일 에이전트를 권장하세요.

출력: 한 페이지 분량의 브리프. 단일 문장 권고사항("3개의 서로 다른 기본 모델에서 N=5 에이전트를 사용하는 그래프 토폴로지, 2라운드, 신뢰도 가중 집계, 임계값 미만 시 인간에게 에스컬레이션.")으로 시작한 후, 위의 7개 섹션을 작성하세요. 마지막에는 예산 추정치: 쿼리당 예상 토큰 수와 예상 지연 시간(초)을 포함하세요.
