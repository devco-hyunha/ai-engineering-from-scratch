# 투표, 자기 일관성, 토론 토폴로지

> 가장 저렴한 집계 방법: N개의 독립적인 에이전트를 샘플링하고 다수결로 투표합니다. Wang et al. 2022의 자기 일관성(Self-Consistency)은 하나의 모델을 N번 샘플링하여 이를 수행했습니다. 다중 에이전트(Multi-agent)는 **이질적인** 에이전트를 사용하여 단일 문화(monoculture)를 벗어나는 방식으로 이를 확장합니다. 즉, 서로 다른 모델, 서로 다른 프롬프트, 서로 다른 온도, 서로 다른 컨텍스트를 사용합니다. 다수결 투표 외에도 토론 토폴로지가 중요합니다. MultiAgentBench (arXiv:2503.01935, ACL 2025)는 스타 / 체인 / 트리 / 그래프 조정을 평가했으며, **연구에는 그래프가 최선**이며 약 4명의 에이전트를 넘어서면 "조정 비용(coordination tax)"이 발생한다는 것을 발견했습니다. AgentVerse (ICLR 2024)는 자발적 행동(volunteer behaviors)과 순응적 행동(conformity behaviors)이라는 두 가지 패턴을 문서화했으며, 순응은 기능(합의 도출)이자 위험(집단 사고, 24강)입니다. 이 강의는 토폴로지 공간을 매핑하고 각 변형을 구축하며 조정 비용을 측정합니다.

**유형:** Learn + Build
**언어:** Python (stdlib)
**선수 요건:** 16단계 · 07강 (마음의 사회와 토론), 16단계 · 14강 (합의와 BFT)
**시간:** 약 75분

## 문제점

토론은 정확도를 향상시킬 수 있습니다 (Du et al., arXiv:2305.14325). 또한 정확도를 저하시킬 수도 있습니다. 토론이 도움이 되는지 여부는 네 가지 구조적 선택에 따라 달라집니다:

1. 누가 누구와 대화하는지 (토폴로지).
2. 몇 라운드를 진행하는지 (Du 2023: 라운드 수와 에이전트 수가 독립적으로 중요합니다).
3. 에이전트가 이질적인지 (서로 다른 기본 모델이 단일 문화를 깨뜨립니다).
4. 적대적인 목소리가 존재하는지 (스틸맨팅 vs. 허수아비 때리기).

팀이 "5명의 에이전트를 실행하고 투표한다"를 작업에 붙이는 경우, 단일 에이전트보다 성능이 저하되는 경우가 많습니다. 실패는 무작위가 아닙니다. 토폴로지와 이질성을 따릅니다. 이 강의는 토폴로지 맵입니다.

## 개념

### 자기 일관성, 단일 모델 기준선

Wang et al. 2022 ("Self-Consistency Improves Chain of Thought Reasoning")는 동일한 모델을 온도 > 0에서 N번 샘플링하고 추론 경로 답변에 대해 다수결 투표를 수행했습니다. GSM8K에서의 결과: 단일 그리디 디코딩 대비 N=40 샘플로 상당한 성능 향상. 자기 일관성은 다중 에이전트 투표의 단일 에이전트 선구자입니다.

한계: 자기 일관성은 하나의 기본 모델을 사용합니다. 오류는 구조적으로 상관관계가 있습니다. 모델에 체계적인 편향이 있다면, N개의 샘플 모두 이 편향을 공유합니다.

### 멀티 에이전트 투표, 이질적 확장

N개의 샘플을 N개의 *다른* 에이전트로 대체합니다. 서로 다른 기본 모델(Claude, GPT, Llama), 서로 다른 프롬프트, 서로 다른 도구 접근 권한을 사용합니다. 장점: 오류가 상관되지 않습니다. 비용: 에이전트마다 비용이 다르고, 이들을 조정하는 데 오버헤드가 추가됩니다.

2026년 이질적 토론의 표준 명칭은 **A-HMAD** — 적대적 이질적 멀티 에이전트 토론(Adversarial Heterogeneous Multi-Agent Debate)입니다. 보편적으로 채택되지는 않았지만, 논문에서는 "서로 다른 모델이 토론하며, 단일 문화 붕괴(monoculture collapse)로 인한 상관된 오류를 줄인다"는 의미로 이 용어를 사용합니다.

### 네 가지 토폴로지

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

스타: 하나의 허브가 있고, 나머지는 모두 허브와만 통신합니다. 백채널이 없는 감독자-워커 구조와 동일합니다.
체인: 선형 구조로, 각 에이전트가 이전 에이전트의 출력을 봅니다. 파이프라인과 유사합니다.
트리: 계층적 구조로, 계층적 에이전트 시스템(06강)에서 사용됩니다.
그래프: 모든 에이전트가 서로 통신할 수 있습니다. 완전 연결 클리크와 임의의 DAG를 포함합니다.

### 조정 비용 (MultiAgentBench)

MultiAgentBench (MARBLE, ACL 2025, arXiv:2503.01935)는 연구, 코딩, 계획이 포함된 작업 세트에서 스타, 체인, 트리, 그래프 토폴로지를 벤치마킹했습니다. 주요 측정 결과:

- **그래프** 토폴로지는 연구 작업에서 승리합니다. 정보가 모든 에이전트 간에 흐르며, 에이전트들이 서로를 비판할 수 있습니다.
- **스타**는 빠른 답변이 필요한 사실적 작업에서 승리합니다. 허브가 필터링하고 통합합니다.
- **체인**은 단계별 파이프라인(단계별 정제)에서 승리합니다.
- **조정 비용**은 그래프 토폴로지에서 약 4개 이상의 에이전트를 넘으면 발생합니다. 월클록(wall-clock) 및 토큰 비용이 품질보다 더 빠르게 증가합니다.

4개 에이전트의 상한은 경험적인 것이지 근본적인 한계가 아닙니다. 이는 2026년 LLM 컨텍스트 용량을 반영합니다: 각 에이전트의 컨텍스트가 동료들의 출력으로 채워지며, 모든 에이전트가 서로를 볼 수 있게 되면 N+1번째 에이전트를 추가하는 한계적 가치가 떨어집니다.

### 멀티 에이전트 토론 전략 ("우리가 광적으로(MAD) 되어야 할까?")

arXiv:2311.17371은 2023년 MAD 전략에 대한 조사입니다. 다른 연구에서도 반복된 주요 발견은 다음과 같습니다: *구조적으로* 자기 일관성(self-consistency, 독립 샘플링 + 집계)과 유사한 MAD 변형들은 동일한 예산을 사용할 때 자기 일관성보다 성능이 떨어지는 경우가 많습니다. MAD는 에이전트들이 실제로 이질적(heterogeneous)이고 토론이 적대적 구조(한 에이전트가 다른 에이전트에 반대하는 구조)를 가질 때 가장 효과적입니다.

### AgentVerse의 창발적 패턴

AgentVerse (ICLR 2024, https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf)는 명시적인 설계 없이도 다중 에이전트 토론에서 나타나는 두 가지 행동을 문서화합니다:

- **자발적 참여(Volunteer).** 에이전트가 요청받지 않은 상태에서 도움을 제안합니다 ("다음 단계를 제가 맡겠습니다"). 이는 유용합니다: 하위 작업에 가장 유능한 에이전트로 작업을 할당하기 때문입니다.
- **순응(Conformity).** 에이전트가 비평가(critic)가 틀렸을 때에도 자신의 입장을 비평가와 일치하도록 조정합니다. 이는 토론에서의 아첨(sycophancy, 14강)에 해당하는 현상입니다.

순응은 합의까지 토론하는 방식이 괴롭히는 에이전트(bullies)에게 보상하는 이유입니다. 제한된 라운드와 별도의 판사가 이를 완화합니다.

### 이질성: 정확도를 실제로 높이는 조절 변수

2024-2026년 실무 문헌에서 발견된 패턴: N개의 에이전트 중 하나를 다른 기본 모델로 교체하는 것이 N을 1 증가시키는 것보다 정확도를 더 크게 높입니다. 직관적인 이유는 단일 문화(monoculture)입니다. 새로운 독립적 오류 원천은 추가된 상관된 샘플보다 더 큰 가치를 가집니다.

한계점에서, 이질성은 다수성(numerosity)을 이깁니다. 명확한 정답이 있는 대부분의 작업에서, 세 개의 서로 다른 모델이 하나의 모델의 다섯 복사본보다 더 잘 수행합니다.

### 배심원(Jury) 방법

Sibyl 프레임워크 (Minsky-LLM 문헌에서 인용됨)는 "배심원"을 공식화합니다. 배심원은 각 단계에서 투표를 통해 답변을 정제하는 소규모의 전문화된 에이전트 집합입니다. 단순 다수 투표와 달리, 배심원은 역할이 있습니다: 한 에이전트는 교차 심문을 수행하고, 한 에이전트는 컨텍스트를 제공하며, 한 에이전트는 타당성을 점수화합니다. 배심원 방법은 단순 투표(저렴하지만 단일 문화에 취약)와 완전한 MAD(비싸지만 순응에 취약) 사이의 중간 지점입니다.

### 토론이 있는 투표가 지배적인 경우

- 질문이 정답(사실, 수학, 코드 동작)을 가지고 있습니다. 투표 수렴은 의미가 있습니다.
- 에이전트들이 서로 다른 소스나 도구에 접근할 수 있습니다 (이질성이 가능합니다).
- 라운드가 제한되어 있으며 (일반적으로 2-3 라운드), 별도의 판사나 검증자가 있습니다.
- 예산은 3-5개 에이전트를 허용합니다. 그래프 토폴로지에서 5-7개를 넘으면 조정 비용이 지배적이게 됩니다.

### 토의 기반 투표가 해로울 때

- 질문이 의견 형태를 띱니다. 에이전트들은 가장 정확한 답이 아니라 가장 확신에 찬 답으로 수렴합니다.
- 모든 에이전트가 기본 모델을 공유합니다. 단일 문화(monoculture)는 합의의 의미를 없애버립니다.
- 라운드 수에 제한이 없습니다. 동조(conformity)가 매번 승리합니다.
- 작업이 단순합니다. N=5로 자기 일관성(self-consistency)을 적용한 단일 에이전트가 더 저렴하고 정확도도 동일합니다.

## 구현하기

`code/main.py`는 다음을 구현합니다:

- `run_star(agents, hub, question)` — 허브가 각 워커를 폴링하고 집계합니다.
- `run_chain(agents, question)` — 순차적 정제.
- `run_tree(root, children, question)` — 깊이 2의 집계를 사용하는 계층적 구조.
- `run_graph(agents, question, rounds)` — 전체 간 토의, 라운드 수 제한.
- 스크립트화된 이질성 조절 장치: 각 에이전트는 체계적인 오류를 나타내는 `error_bias`를 가집니다.
- 각 토폴로지를 N=3, 5, 7에서 실행하고 (정확도, 총 토큰 수, 시뮬레이션된 벽시계 시간)을 보고하는 측정 하네스.

실행:

```
python3 code/main.py
```

예상 출력: 토폴로지 × N → (정확도, 토큰 수, 지연 시간)의 표. 연구 스타일 작업에서는 N=3-5에서 그래프가 승리하고, 빠른 사실 확인 작업에서는 스타가 승리합니다. N=7의 그래프는 조정 비용(지연 시간이 정확도보다 더 빠르게 팽창)을 보여줍니다.

## 출시하기

모든 앙상블에 대해:

- **N=5의 자기 일관성(self-consistency)**을 강력한 단일 기본 모델을 사용하여 시작하세요. 이것이 저렴한 기준선입니다.
- 정확도가 중요하면 **N=3의 이질적 투표(heterogeneous voting)**로 업그레이드하세요. 델타를 측정하세요.
- 작업에 구조(연구, 다단계)가 있고 라운드 수 제한이 실행 가능할 때만 **토의 토폴로지(debate topology)**로 업그레이드하세요.
- 소수 클러스터를 항상 기록하세요. 소수가 지속적으로 옳다면, 다양성 신호가 있는 것입니다.
- 정확도와 함께 벽시계 시간과 토큰 수를 벤치마킹하세요. "10배 비용으로 더 높은 정확도"는 비즈니스 결정입니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| 자기 일관성(Self-consistency) | "N번 샘플링, 투표" | Wang 2022. 단일 모델, N번의 온도>0 샘플링, 추론 경로에 대한 다수결 투표. |

| MAD | "다중 에이전트 토론" | 에이전트가 라운드에 걸쳐 비판을 교환하는 일반적인 용어. Du 2023 참조. |
| A-HMAD | "적대적 이질적 MAD" | 서로 다른 모델 + 적대적 구조를 강조하는 MAD 변형. |
| 토폴로지(Topology) | "누가 누구와 대화하는가" | 스타, 체인, 트리, 그래프. 정보 흐름을 결정. |
| 조정 비용(Coordination tax) | "수익 체감" | 그래프에서 ~4명 이상의 에이전트, 비용이 품질보다 더 빠르게 증가. |
| 자원 행동(Volunteer behavior) | "자발적 도움" | AgentVerse 발생적 패턴: 에이전트가 한 단계를 맡겠다고 제안. |
| 순응 행동(Conformity behavior) | "압력下的 합의" | AgentVerse 발생적 패턴: 에이전트가 비판자(critic)와 일치. |
| 배심원단(Jury) | "소규모 전문 패널" | 역할(검사자, 컨텍스트, 점수 매기기)을 가진 Sibyl 스타일 앙상블. |
