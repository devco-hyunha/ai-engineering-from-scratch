에이전트 집단의 자발적 행동(emergent behavior)이 필요한 시나리오(사회 시뮬레이션, 게임 NPC, 정책 리허설, 시장 역학)가 주어지면 시뮬레이션을 설계해 보세요.

다음 내용을 생성합니다:

1. **인구 규모 및 이질성.** N개의 에이전트; 기본 모델을 공유하는지 여부; 프롬프트 계열; 역할 분포. Smallville은 개인화된 페르소나를 가진 25개의 동질적인 에이전트를 사용했습니다. 더 큰 집단은 이질성이 도움이 됩니다.
2. **메모리 스키마.** 항목별 필드: `(ts, kind, content, importance, embedding_ref, source_ids)`. 최근성 감쇠 상수; 중요도 점수 산정 절차; 관련성 지표(임베딩 모델 X와의 코사인 유사도(Cosine Similarity)). 압축을 위한 보존 정책.
3. **리플렉션 주기.** 트리거: 처리되지 않은 중요도의 합이 임계값을 초과하거나, N번의 관찰마다, 또는 주기적 틱(tick)마다. 트리거당 리플렉션 횟수. 리플렉션 프롬프트 템플릿.
4. **계획 기간.** 일 / 시간 / 행동 수준. 필수적인 것과 선택적인 것. 수정 트리거: 중요도가 임계값을 초과하여 활성 계획을 모순하는 새로운 관찰.
5. **세계 모델.** 공간 그리드, 사회적 그래프, 자원 제약. 관찰을 구성하는 요소(시야, 대화, 알림). 아키텍처가 학습하지 않으며 명시적으로 인코딩해야 하는 규범적 제약 조건(용량 한도, 영업 시간, 개인 공간).
6. **시드 목표.** 어떤 에이전트에 어떤 우선순위를 시딩(seeding)하는지. 경쟁할 수 있는 겹치는 목표; 공존해야 하는 비경쟁 목표.
7. **예산.** 에이전트별 틱당 LLM 호출 수(관찰 + 검색 + 리플렉션 + 계획 + 행동). 에이전트별 틱당 예상 토큰 수. T 틱에 대한 총 시뮬레이션 비용.
8. **평가 지표.** 신뢰성(인간 평가자), 목표 달성률, 계산된 조정 이벤트, 실패 신호로서의 공간 규범 위반.

하드 리젝트(Hard rejects):

- 명시적인 공간/사회적 규범 인코딩이 없는 설계. 아키텍처가 이를 위반하게 됩니다 (Park 2023의 폐쇄형 상점, 단일 화장실 실패 사례).
- 변경 가능한 메모리를 사용하는 설계. 메모리는 추가 전용(append-only)이어야 하며, 수정은 새로운 항목으로 추가해야 합니다.
- 매 틱마다 리플렉션(reflection)을 실행하는 설계. 이는 예산 비효율적입니다. 리플렉션은 비용이 많이 들며, 트리거는 임계값 기반이어야 합니다.
- 메모리 압축 전략 없이 대규모 N (> 50) 시뮬레이션. 스트림 길이에 따라 검색 비용이 증가합니다.

거부 규칙:

- 시나리오가 emergent *social behavior*가 아닌 emergent *task execution*을 요구하는 경우, supervisor / roles / primitives 패턴을 권장하세요 (16단계 · 05-08). Smallville은 사회적 시뮬레이션용입니다.
- 예산이 틱당 총 LLM 호출이 100회 미만으로 허용되는 경우, 더 큰 인구를 사용하는 것보다 N = 3-5로 밀집 상호작용을 권장하세요.
- 시나리오가 emergent의 이점을 얻지 못하는 경우 (엄격하게 스크립트된 작업), single-agent + tools를 권장하세요.

출력: 한 페이지 설계 브리프. 한 문장 요약으로 시작하세요 ("Smallville 스타일 시뮬레이션: 15개의 이질적 에이전트, 중요도 합계 > 120일 때 리플렉션, 3단계 계획 호라이즌, 용량 제약이 있는 공간 그리드, believability + coordination 이벤트로 측정."), 그 후 위의 8개 섹션을 작성하세요. 예상되는 emergent 행동과 주의해야 할 첫 세 가지 실패 모드로 마무리하세요.
