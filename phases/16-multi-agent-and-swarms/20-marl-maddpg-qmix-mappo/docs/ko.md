# MARL — MADDPG, QMIX, MAPPO

> 멀티 에이전트 조정의 강화 학습 유산은 2026년 LLM 에이전트 시스템에도 여전히 영향을 미치고 있습니다. **MADDPG** (Lowe et al., NeurIPS 2017, arXiv:1706.02275)는 중앙화 학습, 분산 실행 (CTDE)을 도입했습니다. 학습 중에는 모든 크리틱이 모든 에이전트의 상태와 행동을 보며, 테스트 시에는 로컬 액터만 실행됩니다. 협력, 경쟁, 혼합 환경 모두에서 작동합니다. **QMIX** (Rashid et al., ICML 2018, arXiv:1803.11485)는 단조 혼합 네트워크를 사용하는 가치 분해 기법으로, 에이전트별 Q값이 결합 Q값으로 합쳐져 `argmax`가 명확하게 분배됩니다. StarCraft Multi-Agent Challenge (SMAC)에서 지배적입니다. **MAPPO** (Yu et al., NeurIPS 2022, arXiv:2103.01955)는 중앙화 가치 함수를 사용하는 PPO로, 최소한의 튜닝으로 particle-world, SMAC, Google Research Football, Hanabi에서 "놀라울 정도로 효과적"입니다. 이러한 기법들은 분산 실행이 필수인 에이전트 팀의 학습 정책을 뒷받침합니다. MAPPO는 **2026년 협력 MARL의 기본 기준선**입니다. 이 강의에서는 작은 그리드 월드 토이를 통해 각 기법을 구축하고, LLM 에이전트 학습을 다루기 전에 세 가지 개념을 체화합니다.

**유형:** Learn
**언어:** Python (표준 라이브러리, NumPy를 사용하지 않는 작은 구현)
**선수 요건:** 09단계 (강화 학습), 16단계 · 09단계 (병렬 스웜 네트워크)
**시간:** 약 90분

## 문제점

LLM 에이전트 시스템은 에이전트 간 조정을 위한 정책을 점점 더 많이 학습하고 있습니다. 언제 양보할지, 언제 행동할지, 어떤 동료 에이전트를 호출할지 결정하는 정책입니다. 이러한 정책을 학습하는 방법을 알려주는 문헌은 멀티 에이전트 강화 학습(MARL)이며, 이는 LLM 붐보다 먼저 등장했고 소수의 지배적인 알고리즘을 가지고 있습니다.

패턴 어휘 없이 MARL 논문을 읽는 것은 고통스럽습니다. 중앙화 학습과 분산 실행(CTDE), 가치 분해, 중앙화 크리틱은 유행어가 아닙니다. 이들은 특정 문제에 대한 구체적인 해답입니다:

- 독립 RL (각 에이전트가 단독으로 학습)은 각 에이전트의 관점에서 비정상적입니다. 좋지 않습니다.
- 중앙화 RL (하나의 에이전트가 전체를 제어)은 확장성이 없으며 실행 제약 조건을 위반합니다.
- CTDE는 두 가지의 장점을 모두 취합니다. 전역 정보로 학습하고, 로컬 정책으로 배포합니다.

## 개념

### 논문들이 사용하는 세 가지 환경

- **Particle World (다중 에이전트 파티클 환경).** 단순한 2D 물리 시뮬레이션으로 협력 및 경쟁 과제를 포함합니다. MADDPG의 원래 테스트베드입니다.
- **StarCraft Multi-Agent Challenge (SMAC).** 협력형 마이크로 관리, 부분 관측. QMIX의 테스트베드입니다. 이산 동작, 연속 상태.
- **Google Research Football, Hanabi, MPE.** MAPPO의 기준선(baseline)입니다.

각 환경은 서로 다른 동작/관측 유형을 가지며, 알고리즘은 이에 따라 선택됩니다.

### MADDPG (2017) — CTDE 패턴

각 에이전트 `i`는 자신의 관측을 동작으로 매핑하는 액터 `mu_i(o_i)`를 가집니다. 각 에이전트는 또한 학습 중 모든 관측과 모든 동작을 보는 크리틱 `Q_i(x, a_1, ..., a_n)`를 가집니다. 액터는 크리틱의 평가에 대한 정책 기울기(policy gradient)로 업데이트됩니다.

```
actor update:    grad_theta_i J = E[grad_theta mu_i(o_i) * grad_a_i Q_i(x, a_1..n) at a_i=mu_i(o_i)]
critic update:   TD on Q_i(x, a_1..n) given next-state joint estimate
```

CTDE를 사용하는 이유: 학습 시에는 모든 에이전트의 동작을 알 수 있으며, 이를 각 크리틱의 분산을 줄이는 데 사용합니다. 배포 시에는 각 에이전트가 `o_i`만 보고 `mu_i(o_i)`를 호출합니다.

실패 모드: 크리틱은 N개의 에이전트와 함께 커집니다 (입력에 모든 동작이 포함됨). 근사화 없이는 약 10개 이상의 에이전트로 확장되지 않습니다.

### QMIX (2018) — 가치 분해

협력형에만 적용됩니다. 전역 보상은 에이전트별 Q-값의 단조 함수의 합입니다:

```
Q_tot(tau, a) = f(Q_1(tau_1, a_1), ..., Q_n(tau_n, a_n)),   df/dQ_i >= 0
```

단조성은 각 에이전트가 `argmax_{a_i} Q_i`를 독립적으로 선택하여 `argmax_a Q_tot`를 계산할 수 있음을 보장합니다. 이는 바로 필요한 **분산 실행 특성**입니다. 학습 시에는 혼합 네트워크가 에이전트별 Q-값으로부터 `Q_tot`를 생성합니다.

SMAC에서 QMIX가 승리하는 이유: 협력형 StarCraft 마이크로 관리에는 동질적인 에이전트, 지역 관측, 전역 보상이 존재하며, 이는 가치 분해에 완벽하게 부합합니다.

실패 모드: 단조성 제약은 제한적입니다. 일부 과제는 단조 분해가 불가능한 보상 구조를 가집니다 (한 에이전트가 팀을 위해 희생하는 경우). 확장 모델(QTRAN, QPLEX)은 이 제약을 완화합니다.

### MAPPO (2022) — 간과된 기본값

Multi-Agent PPO: 중앙 집중식 가치 함수를 사용하는 PPO입니다. 각 에이전트는 자체 정책을 가지며, 모든 에이전트는 전체 상태를 보는 가치 함수를 공유하거나 에이전트별 가치 함수를 가집니다. Yu et al. 2022는 5개 벤치마크에서 MAPPO를 MADDPG, QMIX 및 그 확장 모델과 비교 벤치마킹하여 다음을 발견했습니다:

- MAPPO는 particle-world, SMAC, Google Research Football, Hanabi, MPE에서 off-policy MARL 방법과 동등하거나 더 나은 성능을 보입니다.
- 하이퍼파라미터 튜닝이 최소화됩니다.
- 안정적인 학습이 가능하며, 시드(seed)에 따라 재현 가능합니다.

이 논문 이전까지 커뮤니티는 on-policy MARL을 과소평가했습니다. 2026년 현재, MAPPO는 협력 MARL의 기본 기준선(baseline)이며, 새로운 방법은 이를 능가해야 합니다.

### LLM 에이전트 엔지니어가 주목해야 하는 이유

세 가지 직접적인 사용 사례:

1. **라우터 훈련.** 메타 에이전트가 작업을 처리할 하위 에이전트를 선택합니다. 이는 N개의 분산 하위 에이전트와 하나의 중앙 집중식 라우터가 있는 MARL 문제입니다. MAPPO가 적합합니다.
2. **역할 형성.** 생성형 에이전트 시뮬레이션에서 에이전트가 시간에 따라 상호 보완적인 역할을 채택하도록 훈련하는 것은 숨겨진 MARL 문제입니다. QMIX 스타일의 가치 분해는 구조적으로 상호 보완성을 강제합니다.
3. **다중 에이전트 도구 사용.** 에이전트가 도구를 공유하고 예산을 놓고 경쟁할 때, CTDE를 통해 훈련하면 자원 제약 조건을 준수하는 배포 가능한 로컬 정책을 생성할 수 있습니다.

실용적인 주의 사항: 2026년 현재, 대부분의 프로덕션 LLM 에이전트 시스템은 정책을 훈련하기보다 프롬프트합니다. MARL은 (a) 많은 상호작용 데이터, (b) 명확한 보상 신호, (c) 훈련 인프라에 투자할 의지가 있을 때 도입됩니다.

### RL을 넘어 설계 패턴으로서의 CTDE

훈련 없이도 CTDE는 유용한 아키텍처 패턴입니다:

- *설계* 단계에서는 팀 전체의 가시성을 가정합니다.
- *실행* 단계에서는 분산 실행을 강제합니다. 각 에이전트는 `o_i`만 볼 수 있습니다.

이 패턴은 에이전트별 상태를 명시적으로 유지하고 부분 관측 가능성을 사전에 고려하도록 강제합니다. 많은 프로덕션 다중 에이전트 시스템은 모든 곳에서 공유 상태를 조용히 가정합니다. CTDE 규율은 이를 방지합니다.

### 비정상성(non-stationarity) 문제

여러 에이전트가 동시에 학습할 때, 각 에이전트의 환경(다른 에이전트의 정책을 포함)은 비정상적입니다. 고전적인 단일 에이전트 RL 증명은 깨집니다. 이 강의의 MARL 알고리즘은 모두 이를 해결합니다:

- MADDPG: 전역 크리틱이 모든 행동을 보므로, 가치 추정값이 정상적입니다.
- QMIX: 가치 분해는 최적성이 잘 정의된 결합-Q 공간으로 학습을 이동시킵니다.
- MAPPO: 중앙화 가치 함수는 다른 에이전트의 정책 변경으로 인한 분산을 줄여줍니다.

LLM 에이전트 시스템에서는 비정상성이 "지난달에는 내 에이전트가 잘 작동했는데, 상류의 다른 에이전트가 변경된 후 내 에이전트가 오작동한다"와 같이 나타납니다. CTDE로 MARL을 학습하는 것이 원리적으로 올바른 해결책입니다. 프롬프트 수준의 수정은 더 빠르지만 지속성이 떨어집니다.

### 이 강의에서 다루지 않는 내용

실제 네트워크 학습은 9단계 주제입니다. 이 강의에서는 기울기 업데이트 없이 CTDE, 가치 분해, 중앙화 가치 패턴을 시연하는 스크립트 정책 버전을 구축합니다. 목표는 완전한 MARL 라이브러리(PyMARL, MARLlib, RLlib multi-agent)를 도입하기 전에 패턴을 내재화하는 것입니다.

```figure
sw-ctde
```

## 구현하기

`code/main.py`는 작은 2 에이전트 협력 그리드 월드에서 세 가지 패턴 시연 구현을 수행합니다:

- 환경: 4x4 그리드 위의 2 에이전트, 하나의 보상 펠릿. 보상 = 1, 펠릿에 도달한 에이전트가 있으면 작업이 완료됩니다.
- `IndependentAgents` — 각 에이전트가 다른 에이전트를 환경으로 취급합니다. 기준선입니다.
- `MADDPGStyle` — 중앙화 크리틱이 결합 가치를 계산합니다. 액터 정책은 이를 기반으로 업데이트됩니다. 스크립트 정책 개선입니다.
- `QMIXStyle` — 단조 믹서를 사용한 가치 분해입니다.
- `MAPPOStyle` — 중앙화 가치 함수; 정책은 공유 기준선을 기준으로 업데이트됩니다.

네 가지 모두 동일한 에피소드를 실행하며 목표까지의 평균 스텝 수를 보고합니다. CTDE 변형은 독립 기준선보다 짧은 경로로 수렴합니다.

실행:

```
python3 code/main.py
```

예상 출력: 독립 에이전트는 평균 약 6 스텝을 취합니다. CTDE 변형은 약 3.5 스텝으로 수렴합니다(4x4 그리드의 최적값은 3입니다). 스크립트 정책임에도 패턴 차이가 나타납니다.

## 출시하기

프로덕션에서의 MARL은 드뭅니다. 사용할 경우:

- **MAPPO로 시작하세요.** 2022년 논문이 이를 기준선으로 확립했습니다. 이를 먼저 재현하면 더 복잡한 방법을 쫓느라 몇 주를 낭비하는 것을 피할 수 있습니다.
- **모든 에이전트의 관측 및 행동 스트림을 로깅하세요.** 에이전트별 추적 없이 MARL을 디버깅하는 것은 불가능합니다.
- **학습 코드와 실행 코드를 분리하세요.** CTDE는 하나의 규율입니다. 실행 경로가 `o_i`만 실제로 볼 수 있도록 하세요.
- **보상 설계 경고.** MARL은 보상 설계에 매우 민감합니다. 보상 설계에 조정 버그가 하나 있으면 에이전트가 이를 악용하게 학습합니다. 적대적 테스트를 실행하세요.
- **LLM 에이전트의 경우**, 먼저 프롬프트 수준 정책을 고려하세요. 상호작용 데이터 + 보상 신호 + 인프라가 모두 갖춰진 경우에만 MARL 학습에 투자하세요.

## 연습 문제

1. `code/main.py`을 실행하세요. 독립 에이전트와 MAPPO 스타일 에이전트 간의 목표까지의 단계 차이를 측정하세요. 6x6 격자에서 차이가 커지나요, 아니면 작아지나요?
2. 경쟁 변형을 구현하세요: 두 에이전트, 하나의 펠릿, 먼저 도달한 에이전트만 보상을 받습니다. 어떤 패턴이 경쟁을 깔끔하게 처리하나요? 역사적으로 MADDPG가 그렇습니다.
3. MADDPG (arXiv:1706.02275)의 3장을 읽으세요. 크리틱 업데이트 규칙을 자신의 언어로 의사 코드에 기호적으로 구현하세요.
4. MAPPO (arXiv:2103.01955)를 읽으세요. 저자들은 왜 중앙화 가치 + PPO가 벤치마크에서 off-policy MARL보다 우월하다고 주장하나요? 가장 강력한 주장 세 가지를 나열하세요.
5. CTDE를 가상의 LLM 에이전트 시스템(예: 연구 에이전트 + 요약 에이전트 + 코더)에 설계 패턴으로 적용하세요. 설계 시점에는 있지만 런타임에는 없는 결합 정보는 무엇인가요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| MARL | "Multi-Agent RL" | 다중 에이전트 시스템을 위한 강화 학습입니다. |
| CTDE | "Centralized Training, Decentralized Execution" | 전역 정보로 학습하고, 지역 정책으로 배포합니다. |
| MADDPG | "Multi-Agent DDPG" | 모든 관측치와 행동을 보는 에이전트별 크리틱을 사용하는 CTDE입니다. |
| QMIX | "Value decomposition" | 에이전트별 Q의 단조 혼합입니다. 협력적입니다. |
| MAPPO | "Multi-Agent PPO" | 중앙화 가치 함수를 사용하는 PPO입니다. 2026년 기본 기준선입니다. |
| 가치 분해 | "개별 Q의 합" | 결합 Q를 에이전트별 Q의 단조 함수로 표현합니다. |
| 비정상성 | "움직이는 목표" | 다른 에이전트가 학습함에 따라 각 에이전트의 환경이 변합니다. MARL의 핵심 문제입니다. |
| 온-폴리시 / 오프-폴리시 | "현재 정책에서 학습 / 리플레이에서 학습" | PPO는 온-폴리시(MAPPO)이며, DDPG와 Q-러닝은 오프-폴리시입니다. |
| SMAC | "StarCraft Multi-Agent Challenge" | 협력적 마이크로매니지먼트 벤치마크; QMIX가 자체적으로 개발한 기반입니다. |
