# 에이전트를 위한 합의와 비잔틴 장애 허용

> 고전적인 분산 시스템의 비잔틴 장애 허용(BFT)이 확률적 LLM과 만납니다. 2025-2026년 동안 세 가지 연구 방향이 등장했습니다: **CP-WBFT** (arXiv:2511.10400)는 신뢰도 탐지(probe)로 각 투표에 가중치를 부여합니다; **DecentLLMs** (arXiv:2507.14928)는 리더 없이 병렬 워커 제안과 기하학적 중앙값 집계로 진행합니다; **WBFT** (arXiv:2505.05103)는 가중치 투표와 계층적 구조 클러스터링을 결합하여 Core 및 Edge 노드를 분리합니다. "Can AI Agents Agree?" (arXiv:2603.01213)의 정직한 경험적 결과는 스칼라 합의조차 오늘날 취약하다는 것입니다. 단일 기만적 에이전트가 Mixture-of-Agents를 손상시킬 수 있습니다. BFT는 필요하지만 충분하지 않습니다. 이 강의는 최소한의 BFT 프로토콜을 구축하고, 세 가지 에이전트 특유의 공격(비잔틴 거짓말, 아첨하는 순응, 상관된 오류의 단일 문화)을 주입하며, 각 합의 변형이 이에 어떻게 대처하는지 측정합니다.

**유형:** Learn + Build
**언어:** Python (stdlib)
**선수 요건:** 16단계 · 07강 (Society of Mind and Debate), 16단계 · 13강 (Shared Memory)
**시간:** 약 75분

## 문제점

N개의 LLM 에이전트가 각각 답변을 생성합니다. 이들은 의견이 불일치합니다. 다수결 투표가 잘못된 답변을 선택하는 이유는 두 에이전트가 상관관계가 있기 때문입니다(동일한 기본 모델, 동일한 학습 데이터, 동일한 실패 모드). 세 번째 에이전트는 새로운 방식으로 우연히 잘못된 답변을 생성합니다. 따라서 다수결은 가짜 다수결이 됩니다.

이제 기만적인 에이전트를 추가해 보세요. 의도적으로 거짓말을 합니다. 또는 아첨하는 에이전트를 추가해 보세요. 마지막에 발언한 사람과 동의합니다. 고전적인 BFT에서는 비잔틴 노드가 `f < n/3`의 비율을 차지하며 임의적으로 행동한다고 가정합니다. 2026년의 현실은 LLM 노드가 정직할 때조차 확률적이며, 모델 간에 상관관계가 있고, 서로의 출력에 영향을 받는다는 것입니다. 이들을 독립적인 베르누이 투표자로 취급할 수 없습니다.

고전적인 BFT(PBFT, 1999)는 틀리지 않았습니다. 불완전할 뿐입니다. 임의적인 비트 뒤집기를 처리합니다. "세 정직한 에이전트가 학습 데이터를 공유하기 때문에 환각을 공유하는" 상황은 처리하지 못합니다. 이 강의는 PBFT의 기초를 바탕으로 2025-2026년의 세 가지 적응을 계층화하여 구축합니다.

## 개념

### 고전적인 BFT가 제공하는 것

실용 비잔틴 장애 허용 (Castro & Liskov, OSDI 1999)은 `f < n/3` 비잔틴 노드를 허용합니다. 이 프로토콜은 세 단계(pre-prepare, prepare, commit)와 두 가지 기본 요소(서명된 메시지, 정족수 인증서)를 포함합니다. `n >= 3f + 1` 정직하거나 악의적인 노드들 사이에서 단일 값에 대한 합의를 이루는 것입니다.

보장 사항은 강력하지만 다음을 가정합니다:

1. **독립적인 장애.** 비잔틴 노드들은 서로 협력하지 않습니다.
2. **정직한 노드는 진정으로 정직합니다.** 정직한 출력의 정확성은 문제가 되지 않으며, 프로토콜은 의견 불일치만 조정합니다.
3. **질문에는 정답이 존재합니다.** 잘못된 사실에 대한 합의도 여전히 합의입니다.

LLM 에이전트(Agent)는 이 세 가지를 모두 위반합니다. 동일한 기본 모델을 실행하는 두 에이전트(Agent)는 장애를 공유합니다. "정직한" LLM은 여전히 환각(Hallucination)을 일으킵니다. 그리고 모호한 질문에 대해서는 "진실"은 에이전트(Agent)들이 결정하는 것이며, 외부 오라클은 존재하지 않습니다.

### LLM 특유의 세 가지 공격

**비잔틴 거짓말.** 한 에이전트(Agent)가 의도적으로 잘못된 답변을 출력합니다. `f < n/3`인 경우 고전적인 BFT는 이를 처리합니다.

**아첨하는 순응.** 한 에이전트(Agent)가 투표 전에 다른 에이전트(Agent)의 답변을 읽고 가장 늦게 말한 사람과 일치합니다. 악의적이지는 않지만 가장 큰 목소리와 상관관계가 있습니다. 에이전트(Agent)가 모든 서명 검사를 통과하기 때문에 고전적인 BFT는 이를 방지하지 못합니다.

**상관된 오류의 단일 문화.** 세 에이전트(Agent)가 기본 모델을 공유합니다. 이들은 동일한 잘못된 답변을 환각(Hallucination)합니다. 다수가 잘못되었습니다. 세 에이전트(Agent)가 모두 "정직하게" 동의하기 때문에 고전적인 BFT는 도움이 되지 않습니다.

### 2025-2026년 대응 방안

**CP-WBFT** (arXiv:2511.10400) — 신뢰도 탐지 가중 BFT. 각 투표자는 답변에 신뢰도 탐지(self-reported probability 또는 별도 보정(Calibration) 모델의 예측)를 첨부합니다. 투표 가중치는 신뢰도에 따라 조정됩니다. 완전 그래프에서 BFT 개선 +85.71%가 보고되었습니다. 완화 대상: 아첨하는 순응 (순응하는 에이전트(Agent)는 자발적으로 제시한 입장에 대해 낮은 신뢰도를 보이는 경향이 있습니다).

**DecentLLMs** (arXiv:2507.14928) — 리더리스. 워커 에이전트(Agent)가 병렬로 제안하고, 평가자 에이전트(Agent)가 제안을 점수화하며, 최종 답변은 점수화된 위치의 기하학적 중위수입니다. `f < n/2`인 경우 강건합니다. 완화 대상: 비잔틴 거짓말 및 상관된 오류 (기하학적 중위수는 이상치에 강건하며, 모델 편향 평균이 아닌 밀집 클러스터로 끌어당깁니다).

**WBFT** (arXiv:2505.05103) — 계층적 구조 클러스터링을 적용한 가중치 BFT. 투표 가중치는 응답 품질과 이력에서 학습된 신뢰 점수를 기반으로 할당됩니다. 에이전트를 Core와 Edge로 클러스터링합니다. Core 에이전트는 먼저 합의에 도달해야 하며, Edge 에이전트는 이를 따릅니다. 완화 대상: 확장성 (Core 합의는 작고 빠름) 및 부분적으로 단일 문화(monoculture) (Core는 다양성을 위해 선택될 수 있음).

### 실증 연구: "Can AI Agents Agree?" (arXiv:2603.01213)

이 논문은 여러 최전선(frontier) 모델에 걸쳐 LLM 에이전트가 단일 수치 값에 합의하는 스칼라 합의(scalar agreement)를 측정합니다. 발견된 결과는 불쾌합니다:

- 적대 세력이 없더라도, LLM 에이전트는 많은 벤치마크에서 스칼라 질문에 대해 30% 이상의 비율로 불일치합니다.
- 기만적인 페르소나를 채택한 단일 에이전트가 Mixture-of-Agents 합의를 정직한 기준선에서 40% 포인트 이상 벗어날 수 있습니다.
- 불일치율은 모델 다양성과 상관관계가 있습니다. 이질적인 앙상블은 동질적인 앙상블보다 더 많이 불일치합니다 (장점: 상관되지 않은 오류) 하지만 더 느리게 드리프트합니다 (단점: 합의까지 걸리는 시간이 길어짐).

요점: BFT는 출력 정렬을 위한 메커니즘을 제공하지만, 정렬된 출력이 옳은지 알려주지는 않습니다. 검증 (16단계 · 08 역할 전문화), 다양성 (16단계 · 15 토론 변형), 평가자 에이전트 (16단계 · 24 벤치마크)와 결합해 보세요.

### 핵심 프로토콜, 간소화 버전

LLM 에이전트를 위한 최소한의 BFT 라운드:

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

의미적 클러스터링 단계는 LLM 특유의 변형입니다. "the study reports 4.2%"와 "4.2% improvement"라는 두 답변은 같은 클러스터입니다. 단순한 문자열 일치 검사로는 이를 놓칠 수 있습니다. 프로덕션에서는 저렴한 임베딩 모델이나 명시적인 정규화(canonicalization)를 사용하세요.

### 임계값 튜닝

`threshold` 매개변수는 언제 수락하고 언제 재시도할지 결정합니다. 너무 낮으면: 약한 다수를 수락합니다. 너무 높으면: 아무것도 수락하지 않습니다. 실증적 범위: `n=5-7` 에이전트의 경우 0.5-0.67, 더 작은 `n`의 경우 더 높습니다. 임계값 아래에서는 인간이나 다른 에이전트 앙상블로 에스컬레이션하세요.

### 합의가 도움이 되지 않는 경우

- **모호한 질문.** 질문이 정답(ground truth)을 가지지 않는다면, 합의는 의견입니다. 그렇게 부르세요.
- **복합 질문.** "코드를 작성하고 설명하세요" — 두 개의 답변입니다. 각각에 대해 독립적으로 투표하세요.
- **적대적 다중 라운드.** 에이전트가 이전 라운드를 관찰하고 모방할 수 있다면(Du 2023 토론), 진위에 관계없이 서로 동의하기 시작합니다. 라운드 수를 제한하세요(통상 2-3회).

## 구현하기

`code/main.py`는 다음을 구현합니다:

- `AgentVoter` — (답변, 신뢰도)를 가진 스크립트 정책입니다.
- `MajorityVote` — 고전적 다수결입니다.
- `CPWBFT` — 시맨틱 클러스터링을 사용하는 신뢰도 가중 투표입니다.
- `DecentLLMs` — 점수화된 제안에 대한 기하학적 중앙값 집계입니다.
- `Scenario` — 세 가지 공격 패턴 하에서 각 집계기를 실행합니다.

구현된 공격 패턴:

1. `byzantine`: 한 에이전트가 높은 신뢰도로 거짓말을 합니다.
2. `sycophancy`: 한 에이전트가 처음 본 답변을 신뢰도를 일치시켜 복사합니다.
3. `monoculture`: 세 에이전트가 중간 신뢰도로 잘못된 답변(상관된 오류)을 공유합니다.

실행:

```
python3 code/main.py
```

예상 출력: (공격, 집계기) -> 최종 답변의 표이며, 정답이 강조됩니다. 다수결은 단일 문화(monoculture) 케이스에서 실패합니다. CPWBFT의 신뢰도 가중은 아첨(sycophancy)을 완화합니다. DecentLLMs의 기하학적 중앙값은 단일 문화가 인구의 절반 미만일 때 정직한 클러스터로 끌어당깁니다.

## 사용하기

`outputs/skill-consensus-designer.md`는 다중 에이전트 앙상블을 위한 합의 프로토콜을 설계합니다: 클러스터링 방법, 가중치, 임계값, 그리고 임계값 미만 라운드에 대한 에스컬레이션 정책입니다.

## 출시하기

합의 메커니즘을 출시하기 전에:

- **위 세 가지 패턴으로 공격 테스트를 수행하세요.** 프로토콜은 조용히 실패하는 것이 아니라 예측 가능하게 실패해야 합니다.
- **출처(provenance)와 함께 모든 소수 클러스터를 기록하세요.** 소수 클러스터는 상관된 오류에 대한 조기 경보 시스템입니다.
- **라운드 수를 제한하세요.** "동의할 때까지 계속 토론"은 아첨을 보상합니다.
- **동의와 정확성을 분리하세요.** 합의 출력은 검증기로 전달되며, 검증기는 앙상블과 독립적입니다.
- **동의율을 모니터링하세요.** 급격한 상승은 순응 편향(conformity bias)을, 급격한 하락은 모델 드리프트(model drift)를 의미합니다.

## 연습 문제

1. `code/main.py`을 실행하세요. 다수결이 단일 문화(monoculture) 공격을 실패시키지만, 단일 문화 신뢰도가 0.7 미만일 때 CPWBFT가 이를 부분적으로 완화하는지 확인하세요.
2. 네 번째 공격 패턴을 추가하세요: **침묵적 기권(silent abstention)** — 한 에이전트가 답변을 거부합니다("모르겠어요"). 각 집계기가 기권을 어떻게 처리해야 할까요? 선택한 방식을 구현해 보세요.
3. 의미론적 클러스터링을 문자열 정규화(string canonicalization)에서 임베딩 유사성(embedding-similarity)으로 교체하세요 (오픈소스 임베딩 모델을 사용하세요). 아첨(sycophancy) 공격에는 어떤 변화가 일어나나요?
4. CP-WBFT (arXiv:2511.10400)를 읽어보세요. 신뢰도 프로브 보정 단계(별도의 보정 모델이 각 에이전트의 자기 보고된 신뢰도를 확인하는 단계)를 구현하세요. 단일 문화 시나리오에서 정확도 향상도를 측정하세요.
5. "Can AI Agents Agree?" (arXiv:2603.01213)를 읽어보세요. 단순화된 스칼라 합의 실험을 재현하세요: 세 개의 에이전트, 하나의 스칼라 질문, 기만적 페르소나 프롬프트. CPWBFT나 DecentLLMs가 이를 포착하나요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| BFT | "비잔틴 결함 허용(Byzantine fault tolerance)" | 임의의 결함 `f < n/3`에 대해 합의하는 Castro-Liskov 1999 프로토콜. |
| 비잔틴(Byzantine) | "모든 나쁜 행동" | 거짓말을 하거나, 메시지를 드롭하거나, 조용히 실패할 수 있는 노드 — 안전하게 크래시하는 것 외의 모든 것. |
| 신뢰도 프로브(Confidence probe) | "얼마나 확신하나요?" | 투표에 첨부된 자기 보고된 또는 보정자 예측 확률. |
| 의미론적 클러스터링(Semantic clustering) | "같은 답변, 다른 단어" | 투표를 계산하기 전에 동등한 답변을 그룹화하는 것. |
| 기하학적 중앙값(Geometric median) | "강건한 중심점" | 샘플 포인트까지의 거리 합을 최소화하는 점. 평균과 달리 이상치(outlier)에 강건합니다. |
| 단일 문화(Monoculture) | "같은 모델, 같은 실패" | 에이전트가 학습 데이터나 기본 모델을 공유할 때 발생하는 상관된 오류. |
| 아첨적 순응(Sycophantic conformity) | "큰 목소리에 동의하기" | 에이전트의 투표가 먼저/더 크게 말한 쪽으로 편향되는 현상. |
| 코어/엣지(Core/Edge) | "계층적 BFT(Hierarchical BFT)" | WBFT 분할: 작은 코어 합의가 먼저 이루어지고, 엣지 노드가 따릅니다. 지연 시간을 제한합니다. |
