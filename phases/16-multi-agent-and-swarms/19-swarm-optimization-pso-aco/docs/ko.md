# LLM을 위한 스웜 최적화 (PSO, ACO)

> 생물학적 영감을 받은 최적화가 LLM의 부활을 이끌고 있습니다. **LMPSO** (arXiv:2504.09247)는 PSO를 사용하며, 각 입자의 속도가 프롬프트이고 LLM이 다음 후보를 생성합니다. 구조화된 시퀀스 출력(수학 표현식, 프로그램)에 잘 작동합니다. **Model Swarms** (arXiv:2410.11163)는 각 LLM 전문가를 모델 가중치 매니폴드 위의 PSO 입자로 취급하며, 9개 데이터셋의 12개 기준선 대비 **평균 13.3% 향상**을 보고합니다(단 200개 인스턴스 사용). **SwarmPrompt** (ICAART 2025)는 PSO + Grey Wolf를 혼합하여 프롬프트를 최적화합니다. **AMRO-S** (arXiv:2603.12933)는 다중 에이전트 LLM 라우팅을 위한 ACO 영감 페로몬 전문가로, **4.7배 속도 향상**, 해석 가능한 라우팅 증거, 추론과 학습을 분리하는 품질 게이트 비동기 업데이트를 제공합니다. 이 강의는 프롬프트 매개변수 공간에 PSO를 구현하고 에이전트 라우팅에 ACO를 적용하며, 이러한 고전 알고리즘이 LLM 시대에 왜 적합한지, 그리고 언제 적합하지 않은지 측정합니다.

**유형:** Learn + Build
**언어:** Python (stdlib)
**선수 요건:** 16단계 · 09강 (병렬 스웜 네트워크), 16단계 · 14강 (합의 및 BFT)
**시간:** 약 75분

## 문제점

태스크 평가에서 62% 점수를 받는 프롬프트가 있습니다. 이를 개선하고 싶다면, 가장 단순한 방법은 기울기 없는 수동 튜닝이지만 이는 확장성이 떨어집니다. 강화 학습은 보상 신호와 학습을 위한 충분한 롤아웃이 필요합니다. 프롬프트에 대한 역전파는 실제로 불가능합니다. 프롬프트는 미분 가능한 매개변수가 아닌 이산 문자열이기 때문입니다.

고전적인 생물학적 영감을 받은 최적화 — 연속 검색 공간을 위한 PSO, 경로 선택을 위한 ACO —는 정확히 이 영역을 위해 설계되었습니다. 기울기 없는, 개체군 기반, 평가당 비용이 낮은 방식입니다. 이들을 LLM과 결합하여 기울기 없는 검색 단계에 사용하면 놀라울 정도로 실용적인 최적화 도구를 얻을 수 있습니다.

동일한 패턴은 다중 에이전트 시스템의 에이전트 *라우팅*에도 적용됩니다. ACO 스타일의 페로몬 트레일은 어떤 에이전트가 어떤 작업 유형에서 가장 잘 작동했는지 기록하고, 라우터가 이 트레일을 활용하며, 페로몬이 감쇠되어 경로를 재발견할 수 있게 합니다.

## 개념

### PSO 복습 (Kennedy & Eberhart 1995)

입자 군집 최적화(Particle Swarm Optimization): 연속적인 탐색 공간 내의 입자 군집. 각 입자는 위치 `x_i` 및 속도 `v_i`를 가집니다. 각 반복마다:

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

여기서 `p_best`는 입자 자신의 최선(best)이고, `g_best`는 군집의 최선(best)이며, `w, c1, c2`는 관성 + 인지 + 사회적 가중치이고, `r1, r2`는 랜덤 요소입니다.

### LLM 출력에 대한 PSO — LMPSO

arXiv:2504.09247는 LLM이 생성한 구조화된 출력(수학 표현식, 프로그램)에 PSO를 적용합니다. 각 입자는 후보 출력입니다. 속도는 현재 출력을 개인적/전역적 최선(best) 방향으로 수정하는 방법을 설명하는 *프롬프트*입니다. LLM은 속도 프롬프트로부터 새로운 출력을 생성합니다. 속도의 "관성(inertia)"은 "작은 증분 변경을 하라"와 같은 프롬프트입니다.

다음과 같은 경우 잘 작동합니다:
- 출력이 구조화되어 있습니다(파싱 및 평가 가능).
- 피트니스(fitness)가 자동화되어 있습니다(테스트 실행, 산술 평가).
- 군집이 작습니다(~10-30 입자)하여 총 LLM 호출 수가 관리 가능한 수준으로 유지됩니다.

피트니스(fitness)에 인간 검토가 필요한 경우 잘 작동하지 않습니다 — 반복당 비용이 감당하기 어려울 정도로 높아집니다.

### 모델 스웜(Model Swarms)

arXiv:2410.11163은 PSO를 출력 레이어에서 *모델* 레이어로 이동시킵니다. 각 "입자"는 전문가 LLM(매개변수)입니다. 스웜은 기울기 없는 업데이트를 통해 매개변수를 집단적 최선(best) 방향으로 이동시킵니다. 보고된 결과: 9개 데이터셋의 12개 기준선(baseline) 대비 평균 13.3% 향상, 반복당 단 200개 인스턴스 사용.

핵심 통찰은 LLM 전문가 모델들이 이미 공유 매개변수 매니폴드(어댑터 가중치, LoRA 델타)에서 서로 가깝다는 점입니다. 이 저차원 부분 공간에서의 PSO는 저렴하고 효과적입니다.

### ACO 복습(Dorigo 1992)

개미 군집 최적화(Ant Colony Optimization): 개미들이 그래프를 순회하며, 각 경로에는 페로몬 트레일(pheromone trail)이 있습니다. 개미의 이동 확률은 페로몬 강도에 따라 가중치가 부여됩니다. 작업을 완료한 개미는 솔루션 품질에 비례하는 페로몬을 방출합니다. 페로몬은 시간이 지남에 따라 감소합니다.

### AMRO-S — 에이전트 라우팅을 위한 ACO

arXiv:2603.12933은 다중 에이전트 라우팅에 ACO를 사용합니다. 각 작업 유형은 "목적지"이고, 각 에이전트는 가능한 경로입니다. 좋은 출력을 생성하는 경로에 페로몬이 강화됩니다. 주요 기여:

- **해석 가능한 라우팅 근거.** 페로몬 강도는 사람이 읽을 수 있는 신호입니다.
- **품질 게이트가 적용된 비동기 업데이트.** 페로몬은 품질 검사를 통과한 후에만 업데이트되며, 추론과 학습을 분리합니다.
- 멀티 에이전트 라우팅 벤치마크에서 **4.7배 속도 향상**을 달성했습니다.

품질 게이트가 중요합니다. 게이트가 없으면 빠르지만 잘못된 에이전트가 페로몬을 축적하고, 시스템이 나쁜 경로에 고착됩니다.

### LLM에 PSO / ACO를 사용할 때

**PSO를 사용할 때:**
- 검색 공간이 연속적이거나 연속 매개변수에 매핑되는 경우 (프롬프트 임베딩, LoRA 가중치, 수치 생성 매개변수).
- 피트니스가 저렴하고 자동화되어 있는 경우.
- 인구 규모가 작을 수 있는 경우 (10-30).

**ACO를 사용할 때:**
- 라우팅 또는 경로 선택 문제가 있는 경우.
- 결정이 시간에 따라 강화되는 경우 (동일한 작업 유형이 반복됨).
- 라우팅 결정에 대해 해석 가능한 근거가 필요한 경우.

**둘 다 사용하지 말아야 할 때:**
- 피트니스에 인간 검토가 필요한 경우 (반복당 비용이 너무 높음).
- 검색 공간이 PSO가 다루지 않는 방식으로 이산적이고 조합적인 경우 (유전 알고리즘을 대신 사용하세요).
- 실시간 결정에 엄격한 지연 시간이 필요한 경우 (PSO/ACO는 단일 패스 휴리스틱에 비해 수렴이 느림).

### 생물학적 영감을 받은 방법이 여전히 승리하는 이유

기반 방법들은 미분 가능한 신호가 필요합니다. LLM 출력과 라우팅 결정은 자명하게 미분 가능하지 않습니다. 유사 기울기 방법 (강화 학습된 라우터, DPO 스타일 프롬프트 튜너)은 작동하지만 비싼 학습이 필요합니다.

PSO와 ACO는 *평가자* 함수만 필요합니다. 후보 출력이나 라우팅 결정을 점수화할 수 있다면, 공간에 대해 최적화할 수 있습니다. 이는 적용 가능성의 기준을 훨씬 낮게 만듭니다.

### 실용적인 한계

- **인구 예산.** N 입자 × T 반복 × 평가당 비용. LLM 평가는 ~$0.02 / call, a 20-particle PSO running 50 iterations costs ~$20입니다. 이에 따라 계획하세요.
- **탐색 vs 활용.** 페로몬 감쇠율과 PSO 관성 사이의 균형이 중요합니다. 너무 빠른 감쇠 → 해를 잊음; 너무 느린 감쇠 → 초기 지역 최적점에 고착됨.
- **치명적 드리프트.** 두 알고리즘 모두 수렴한 후 피트니스 지형이 변하면(새로운 데이터 분포) 발산할 수 있습니다. 최적 피트니스 안정성을 모니터링하세요.

```figure
swarm-stigmergy
```

## 구현하기

`code/main.py`는 다음을 구현합니다:

- `LMPSO` — 수치형 프롬프트 매개변수(온도, top_k 가중치)에 대한 PSO. 각 입자의 "LLM 생성"은 스크립트된 피트니스 함수로 시뮬레이션됩니다. 30번 반복하여 g_best 수렴을 보여줍니다.
- `AMRO_S` — ACO 스타일 라우팅. 3개 에이전트, 4개 작업 유형, 페로몬 매트릭스, 100개 라우팅된 작업. 시간 경과에 따른 (작업 유형 → 에이전트 선택) 분포를 출력하여 경로 형성을 보여줍니다.
- 비교: 동일한 작업 스트림에서 랜덤 라우팅 vs ACO 라우팅. 품질과 지연 시간을 측정합니다.

실행:

```
python3 code/main.py
```

예상 출력:
- LMPSO: g_best 피트니스가 30번 반복 동안 랜덤에서 준최적 상태로 개선됩니다.
- AMRO-S: 페로몬 테이블이 작업 유형별 올바른 에이전트로 안정화됩니다. ACO 라우팅은 품질에서 랜덤 대비 약 30-40% 개선되며 지연 시간도 감소합니다(재시도 감소).

## 사용하기

`outputs/skill-swarm-optimizer.md`는 LLM / 에이전트 최적화 문제를 위해 PSO, ACO, 유전 알고리즘, 기울기 기반 옵티마이저 중 선택하는 데 도움을 줍니다.

## 출시하기

- **작게 시작하세요.** 입자 10-20개, 반복 20-50회. 수렴 곡선이 명확한 이득을 보일 때만 확장하세요.
- **반복마다 페로몬이나 g_best를 로깅하세요.** 경로(trail) 없이 스웜 옵티마이저를 디버깅하는 것은 고통스럽습니다.
- **품질 게이트 업데이트.** 특히 ACO 라우팅의 경우: 빠르고 잘못된 에이전트는 페로몬을 축적해서는 안 됩니다.
- **분포 이동 시 감쇠를 리셋하세요.** 평가 분포가 변하면 오래된 페로몬은 낡은 상태가 됩니다. 일시적으로 리셋하거나 감쇠율을 두 배로 높이세요.
- **반복당 비용을 상한하세요.** 반복당 비용 메트릭을 방출하세요. 반복당 $500 비용이 들고 0.5% 이득을 얻는 PSO는 출시할 수 없습니다.

## 연습 문제

1. `code/main.py`를 실행하세요. LMPSO 수렴을 관찰하세요. 개체군 크기를 5, 10, 20, 50으로 변경하세요. 수렴까지의 시간이 포화되는 크기는 어디인가요?
2. "치명적 드리프트" 실험을 구현하세요: 30번째 반복 후 피트니스 함수를 변경하세요. PSO가 얼마나 빠르게 적응하나요? `p_best`를 리셋하는 것이 도움이 되나요?
3. AMRO-S에 품질 게이트를 추가하세요: 평가 점수가 0.7 이상인 실행에서만 페로몬을 퇴적합니다. 이 변경이 게이트가 없는 버전과 비교하여 수렴에 어떤 영향을 미칩니까?
4. LMPSO (arXiv:2504.09247)를 읽어 보세요. 논문의 "속도를 프롬프트로 사용"하는 개념을 수치적 속도로 매핑해 보세요. 시뮬레이션에서 손실되는 것과 보존되는 것은 무엇입니까?
5. AMRO-S (arXiv:2603.12933)를 읽어 보세요. 비동기 페로몬 업데이트를 사용하는 분리된 "추론 고속 경로"를 구현해 보세요. 지속되는 부하 하에서 시스템 지연이 어떻게 변합니까?

| ACO | "개미 군집 최적화(Ant Colony Optimization)" | Dorigo 1992. 페로몬 경로를 통한 경로/라우팅 최적화. |
| LMPSO | "LLM 생성을 사용하는 PSO" | arXiv:2504.09247. 속도는 프롬프트이며, LLM이 후보를 생성합니다. |
| Model Swarms | "전문가 가중치에 대한 PSO" | arXiv:2410.11163. 모델 매개변수 부분 공간에 대한 기울기 없는 업데이트. |
| AMRO-S | "에이전트 라우팅을 위한 ACO" | arXiv:2603.12933. 작업 유형 × 에이전트 간의 페로몬 매트릭스. |
| p_best / g_best | "개인 / 전역 최적값" | 각 입자와 군집 전체에서 지금까지 발견된 최적 솔루션. |

| Catastrophic drift | "분포 이동(Distribution Shift)" | 적합도 지형이 변함; 이전 p_best와 페로몬이 낡아짐. |
