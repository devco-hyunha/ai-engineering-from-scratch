# Society of Mind와 다중 에이전트 디베이트

> Minsky의 1986년 전제 — 지능은 전문가들의 사회다 —는 매 10년마다 재발견됩니다. 2023년 Du et al.은 이를 구체적인 알고리즘으로 전환했습니다: 여러 LLM 인스턴스가 답을 제안하고, 서로의 답을 읽고, 비판하며, 업데이트합니다. N 라운드에 걸쳐 그들은 6가지 추론 및 사실성 작업에서 zero-shot CoT와 reflection을 능가하는 합의에 수렴합니다. 두 가지 발견이 중요합니다: **다중 에이전트**와 **다중 라운드**가 독립적으로 기여합니다. 사회는 단일 에이전트 독백을 능가하며, 다중 라운드 교환은 one-shot 투표를 능가합니다.

**유형:** Learn + Build
**언어:** Python (stdlib)
**선수 요건:** 16단계 · 04강 (Primitive Model)
**시간:** 약 60분

## 문제점

Self-consistency — 하나의 모델에서 여러 번 샘플링하고 다수 답을 취하는 것 —는 붙일 수 있는 가장 저렴한 추론 개선입니다. 작동하지만, 빠르게 포화됩니다. 샘플 수를 두 배로 늘려도 의미 있는 도약을 볼 수 없습니다.

디베이트는 포화를 깨뜨립니다. 하나의 모델에서 N개의 독립적인 샘플을 얻는 대신, N개의 에이전트가 서로의 추론을 읽고 수정합니다. 샘플 간 상관관계가 낮아지고(더 이상 i.i.d.가 아니게 되며), 수렴점은 i.i.d. 투표가 확신 있게 틀렸던 곳에서 종종 정확합니다.

## 개념

### Du et al. 2023 알고리즘

arXiv:2305.14325 (ICML 2024)에서:

1. N개의 에이전트 각각이 질문에 대한 초기 답을 생성합니다.
2. 라운드 r = 2..R에 대해: 각 에이전트는 다른 에이전트들의 r-1 라운드 답을 보여주고 "이것들을 고려하여 업데이트된 답을 제시하라"는 요청을 받습니다.
3. R 라운드 후, 최종 답에 대해 다수 투표를 수행합니다.

이 논문은 MMLU, GSM8K, 전기(biographies), MATH 및 사실성 벤치마크에서 테스트했습니다. 디베이트는 CoT와 Self-Reflection을 일관되게 능가합니다.

### 두 개의 독립적인 조절 변수

같은 논문에서의 Ablation:

- **에이전트 수만**(1 라운드, N의 다수 투표)은 대부분의 작업에서 단일 에이전트를 능가하지만, 포화됩니다.
- **라운드 수만**(1 에이전트가 자신의 이전 추론을 보는 것)은 거의 도움이 되지 않습니다 — reflection의 알려진 약점입니다.
- **둘을 함께** 적용하면 큰 도약이 만들어집니다. 여러 에이전트(Agent) 간의 다중 라운드 교환이 성능 향상을 주도합니다.

### 작동 원리

두 가지 메커니즘:

1. **불일치에 대한 노출.** 한 에이전트(Agent)가 다른 에이전트(Agent)의 추론 체인(Chain)을 다른 결론과 함께 보게 되면, 이를 정당화하거나 업데이트해야 합니다. 어느 쪽이든, 라운드 r+1의 컨텍스트는 라운드 r보다 더 풍부해집니다.
2. **상관된 오류 감소.** 자기 일관성(Self-Consistency)에서는 모든 샘플이 동일한 모델에서 나오므로 오류가 상관됩니다. 즉, 확신에 찬 오답으로 평균화됩니다. 서로 다른 모델이나 서로 다른 시드(Seed)는 상관을 제거합니다. 서로 다른 *토론된 관점*은 상관을 더욱 제거합니다.

### 이질적 토론

A-HMAD 및 관련 후속 연구는 서로 다른 에이전트(Agent)에 *서로 다른 기본 모델*을 사용합니다. Llama + Claude + GPT가 토론하면 단일 문화 붕괴(Monoculture Collapse, 26강)가 감소합니다. 한 모델 계열의 상관된 오류가 다른 모델들에 의해 공유되지 않기 때문입니다.

단점: 토론에 참여하는 약한 모델이 합의(Consensus)를 자신의 오답 쪽으로 끌고 갈 수 있습니다("Should we be going MAD?", arXiv:2311.17371 참조).

### NLSOM — 129 에이전트 확장

Zhuge 등("Mindstorms in Natural Language-Based Societies of Mind," arXiv:2305.17066)은 이 아이디어를 129명 구성원의 사회로 확장했습니다. 결과: 규모가 커짐에 따라 전문화와 자기 조직화가 나타나며, 시각적 질문 답변(VQA) 같은 작업에서 단일 에이전트(Agent)보다 성능이 뛰어납니다.

### 실패 모드

- **아첨(Sycophancy) 연쇄.** 모든 에이전트(Agent)가 가장 확신에 찬 것처럼 들리는 에이전트(Agent)를 따릅니다. 토론이 가장 큰 목소리로 붕괴됩니다. 적대적 역할("한 에이전트(Agent)는 반드시 반대 입장을 주장해야 함")을 프롬프트하는 것이 도움이 됩니다.
- **주제 이탈.** 많은 라운드에 걸친 토론이 원래 질문에서 벗어납니다. 완화책: 매 라운드마다 질문을 다시 주입하세요.
- **연산량 폭증.** N 에이전트(Agent) × R 라운드 = N·R LLM 호출이며, 각 호출의 컨텍스트는 커집니다. 5 에이전트(Agent), 5 라운드 토론은 컨텍스트가 커지는 25회 호출입니다. 질문당 비용이 단일 CoT 호출의 10배를 초과할 수 있습니다.

## 구현하기

`code/main.py`는 수학 질문에 대해 3개 에이전트(Agent)가 3라운드(Round) 동안 토론을 진행합니다. 각 에이전트는 서로 다른 (잘못된) 답변으로 시작합니다. 에이전트는 스크립트(scripted)로 제어되며, 각 "업데이트"는 스크립트된 신뢰도(confidence)로 가중치를 부여한 이웃 에이전트들의 답변 평균으로 수행됩니다. 라운드별 로그에서 수렴(convergence) 과정을 확인할 수 있습니다.

이 데모는 두 가지 주요 효과를 보여줍니다:

- 단 한 라운드의 교환만으로도 에이전트들이 정답에 더 가까워집니다.
- 2라운드를 초과하는 추가 라운드는 수익 체감(diminishing returns)을 보입니다 (Du 등의 연구에서 관찰된 평탄화 현상과 일치합니다).

실행:

```
python3 code/main.py
```

## 사용하기

`outputs/skill-debate-configurator.md`는 새로운 작업을 위한 토론을 구성합니다: 에이전트 수, 라운드 수, 이질성(heterogeneity) (동일 모델 vs 혼합 모델), 역할 할당 (대칭 vs 단일 적대적). 실행 전에 토큰 비용도 추정합니다.

## 출시하기

토론 시스템을 출시한다면:

- **라운드 수를 3으로 제한하세요.** Du 등의 연구에 따르면 3라운드가 대부분의 성능 향상을 포착합니다. 그 이상은 품질이 아닌 비용입니다.
- **에이전트 수를 5로 제한하세요.** 5개를 초과하면 컨텍스트 팽창과 비용이 지배적입니다.
- **기본적으로 이질적으로 구성하세요.** 풀(pool)에 최소 두 개의 서로 다른 기본(base) 모델을 포함하세요.
- **적대적 슬롯.** 무조건 반대하도록 프롬프트된 에이전트 하나를 포함하세요. 아첨(sycophancy)을 깨뜨립니다.
- **모든 라운드를 기록하세요.** 중간 라운드를 숨기는 토론 시스템은 디버깅이나 감사(audit)가 불가능합니다.

## 연습 문제

1. `code/main.py`를 실행한 후, 라운드 수를 5로 설정하고 수익 체감을 관찰하세요. 추가적인 수렴이 멈추는 라운드는 몇 번째 라운드인가요?
2. 적대적 역할을 가진 네 번째 에이전트를 추가하세요: 항상 현재 다수(majority) 의견에 반대합니다. 이것이 수렴을 깨뜨리나요, 아니면 개선하나요?
3. 라운드별 합의 점수(agreement score) (다수 답변에 동의한 에이전트의 비율)를 플롯(출력)하세요. 언제 1.0에 도달하며, 이것이 "정답"과 동등한가요?
4. Du 등의 논문 섹션 4의 Ablation을 읽어보세요. 이 코드를 사용하여 "에이전트만", "라운드만", "둘 다"의 결과를 복제하세요.
5. "Should we be going MAD?" (arXiv:2311.17371)를 읽고, 라운드 로빈(round-robin)을 제외한 두 가지 토론 변형을 나열하세요. 예: 판사 주도(judge-led), 토론 체인(chain-of-debate), 적대적(adversarial).
