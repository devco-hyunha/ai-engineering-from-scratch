비전 작업(분류 / 분할 / 탐지 / 검색), 이미지 해상도, 데이터셋 크기(라벨링된 데이터 + 라벨링되지 않은 데이터), 배포 대상을 고려하여 다음을 출력합니다:

1. 백본. 다음 중 하나: DINOv2 ViT-L/14 (검색/분류의 기본값), SAM 3 인코더 (분할), SigLIP (비전-언어), ConvNeXt (레이턴시 민감). 한 문장 이유를 제시합니다.
2. 패치 크기. 224 해상도의 표준 분류는 16, DINOv2는 14, 고해상도 밀집 예측은 8. 시퀀스 길이 `(H/P)^2 + 1` 및 어텐션 비용 `O(N^2)`을 표시합니다.
3. 사전 학습 소스. 체크포인트 이름. 작은 라벨링된 세트(<10k)의 경우: DINOv2 특징을 동결하고 선형 프로브를 사용합니다. 100k 이상인 경우: 마지막 블록을 미세 조정합니다. 이유를 명시합니다.
4. 학습 레시피. 옵티마이저 (AdamW), 학습률, 증강 기법 (RandAug, MixUp, Random Erasing), 라벨 스무딩 (일반적으로 0.1), EMA.
5. 리스크 노트. 데이터 레짐 리스크 (전체 미세 조정에 너무 적은 데이터), 해상도 불일치 (사전 학습 224 → 배포 1024, 위치 보간 없이), register-token 부재 (DINOv2 특징 성능 저하 가능성).

100만 이미지 미만에서 ViT를 처음부터 학습하는 것을 추천하지 마세요 — CNN 기준선이 더 잘 작동합니다. 시퀀스 길이가 4096을 초과하는 패치 크기를 추천하지 마세요. Flash Attention 및 계층적 변형(Swin)에 대한 명시적 논의가 없는 경우입니다. 위치 임베딩을 보간하지 않고 입력 해상도를 변경하는 배포는 플래그를 지정합니다.
