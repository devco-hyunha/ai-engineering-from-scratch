# 트랜스포머가 필요한 이유 — RNN의 문제점

> RNN은 토큰을 하나씩 처리합니다. 트랜스포머는 모든 토큰을 한 번에 처리합니다. 이 하나의 아키텍처적 선택은 2017년 이후 딥러닝의 모든 스케일링 곡선을 바꾸었습니다.

**유형:** Learn
**언어:** Python
**선수 요건:** 3단계 (딥러닝 코어), 5단계 · 09강 (시퀀스 투 시퀀스), 5단계 · 10강 (어텐션 메커니즘)
**시간:** 약 45분

## 문제점

2017년 이전에는 전 세계의 모든 최신 시퀀스 모델 — 언어, 번역, 음성 — 은 순환 신경망(RNN)이었습니다. LSTM과 GRU는 5년 동안 ImageNet급 번역 벤치마크를 석권했습니다. 당시에는 이것만이 유일한 도구였습니다.

이들은 세 가지 치명적인 약점을 가지고 있었습니다. 순차적 계산은 시간 축을 따라 병렬화할 수 없음을 의미했습니다: 토큰 `t+1`은 토큰 `t`의 은닉 상태를 필요로 합니다. 1,024개 토큰의 시퀀스는 사이클당 1,000,000개의 부동 소수점 연산을 수행할 수 있는 GPU에서 1,024개의 순차적 단계를 의미했습니다. 병렬 처리를 위해 설계된 하드웨어에서 훈련의 실제 시간(wall-clock time)은 시퀀스 길이에 따라 선형적으로 증가했습니다.

소실되는 기울기(vanishing gradients)는 50개 토큰 앞의 정보가 이미 50개의 비선형성을 통해 압축되어 있음을 의미했습니다. 게이트형 순환 유닛(LSTM, GRU)은 압축을 완화했지만 완전히 없애지는 못했습니다. 장거리 의존성 — "작년 여름 교토로 가는 비행기에서 읽은 책은…" — 은 정기적으로 실패했습니다.

고정된 너비의 은닉 상태는 인코더가 디코더가 무언가를 보기 전에 전체 소스 시퀀스를 단일 벡터로 압축해야 함을 의미했습니다. 소스가 5개 토큰이든 500개 토큰이든 상관없습니다; 병목 현상은 동일한 형태입니다.

2017년 논문 "Attention Is All You Need"는 급진적인 것을 제안했습니다: 순환(recurrence)을 완전히 제거하는 것. 모든 위치가 다른 모든 위치를 병렬로 어텐션하도록 하세요. 1,024개의 순차적 연산 대신 하나의 큰 행렬 곱으로 훈련하세요.

그 결과는 2026년까지 모든 모달리티를 지배합니다. 언어(GPT-5, Claude 4, Llama 4), 비전(ViT, DINOv2, SAM 3), 음성(Whisper), 생물학(AlphaFold 3), 로봇공학(RT-2). 동일한 블록, 다른 입력.

## 개념

![RNN sequential compute vs Transformer parallel attention](../assets/rnn-vs-transformer.svg)

**재귀가 병목입니다.** RNN은 `h_t = f(h_{t-1}, x_t)`를 계산합니다. 각 단계가 이전 단계에 의존합니다. `h_5`는 `h_4`보다 먼저 계산할 수 없습니다. 10,000개 이상의 병렬 코어를 가진 최신 GPU에서는 긴 시퀀스에서 실리콘의 99%를 낭비하게 됩니다.

**어텐션은 브로드캐스트입니다.** 셀프 어텐션은 모든 쌍 `(i, j)`에 대해 `output_i = sum_j(a_ij * v_j)`를 동시에 계산합니다. 전체 N×N 어텐션 행렬이 하나의 배치된 행렬 곱으로 채워집니다. 단계 간 의존성이 없습니다. GPU가 선호하는 방식입니다.

**속도 향상은 상수가 아닙니다.** `O(N)`의 직렬 깊이와 `O(1)`의 직렬 깊이의 차이입니다. 실제로 트랜스포머는 N=512에서 동일한 하드웨어 기준으로 에포크당 5~10배 더 빠르게 학습하며, 시퀀스 길이가 증가함에 따라 격차가 벌어집니다. 어텐션의 `O(N²)` 메모리 한계에 도달하기 전까지 이 격차는 계속 커집니다 (Flash Attention이 이후 이 문제를 해결했습니다 — 12강을 참고하세요).

**트랜스포머의 비용.** 어텐션 메모리는 `O(N²)`로 스케일링됩니다. 2K 컨텍스트는 괜찮습니다. 128K 컨텍스트에서는 슬라이딩 윈도우, RoPE 외삽, Flash Attention 티링, 또는 선형 어텐션 변형이 필요합니다. 재귀는 시간과 메모리 모두에서 `O(N)`이었으며, 트랜스포머는 시간을 메모리와 교환한 후 병렬화를 통해 시간을 되찾습니다.

**귀납적 편향의 변화.** RNN은 지역성과 최신성을 가정합니다. 트랜스포머는 아무것도 가정하지 않습니다 — 모든 쌍이 어텐션의 후보입니다. 그래서 트랜스포머는 잘 학습하려면 더 많은 데이터가 필요하지만, 데이터를 확보하면 더 크게 확장됩니다. Chinchilla (2022)는 이를 공식화했습니다: 충분한 토큰이 주어지면, 트랜스포머는 동일한 매개변수 수의 RNN을 항상 이깁니다.

## 구현하기

여기서는 신경망이 없습니다 — 핵심 병목을 수치적으로 시뮬레이션하여 노트북에서 격차를 체감해 보세요.

### 1단계: 직렬 깊이 측정

`code/main.py`를 참고하세요. 두 함수를 만듭니다. 하나는 시퀀스를 덧셈의 체인으로 인코딩합니다 (직렬, RNN처럼). 다른 하나는 병렬 감소로 인코딩합니다 (브로드캐스트, 어텐션처럼). 같은 수학, 다른 의존성 그래프입니다.

```python
def rnn_style(xs):
    h = 0.0
    for x in xs:
        h = 0.9 * h + x   # 병렬화 불가: h가 이전 h에 의존
    return h

def attention_style(xs):
    return sum(xs) / len(xs)  # 모든 x는 독립적
```

100,000개 요소까지의 시퀀스에서 두 버전을 시간 측정합니다. RNN 버전은 O(N)이며 단일 CPU 파이프라인입니다. 순수 Python에서도 어텐션 스타일의 감소는 길이 ≥ 1,000에서 이깁니다. Python의 `sum()`는 C로 구현되어 있으며 단계별 인터프리터 오버헤드 없이 반복하기 때문입니다.

### 2단계: 이론적 연산 횟수 계산

두 알고리즘 모두 N번의 덧셈을 수행합니다. 차이는 *의존성 깊이*입니다. 즉, 다음 연산이 시작하기 위해 순차적으로 수행해야 하는 연산의 개수입니다. RNN의 깊이는 N입니다. 어텐션의 깊이는 트리 감소(tree reduction)를 사용하면 log(N)이고, 병렬 스캔(parallel scan)을 사용하면 1입니다. 연산 횟수가 아닌 깊이가 GPU 시간을 결정합니다.

### 3단계: 긴 시퀀스에 대한 경험적 스케일링

O(N) 차이를 명확히 보여주는 타이밍 테이블을 출력합니다. 2026년 Mac 노트북에서는 1,000개 요소 미만의 시퀀스가 너무 빨라 측정할 수 없습니다. 100,000개 시퀀스는 선형 스캔이 명확하게 나타납니다. 이를 12층 LSTM에 해당하는 16,384 토큰 트랜스포머로 확장해 보면, 2016년 훈련의 벽시계(wall-clock) 시간이 왜 병목 현상이었는지 이해할 수 있습니다.

## 사용하기

2026년에도 RNN을 선택해야 하는 경우:

| 상황 | 선택 |
|-----------|------|
| 스트리밍 추론, 한 번에 한 토큰, 고정 메모리 | RNN 또는 상태 공간 모델 (Mamba, RWKV) |
| 어텐션 메모리가 폭발하는 매우 긴 시퀀스 (>1M 토큰) | 선형 어텐션, Mamba 2, Hyena |
| 행렬 곱(matmul) 가속기가 없는 엣지 디바이스 | Depthwise-separable RNN이 FLOPs/watt에서 여전히 우세 |
| 기타 모든 경우 (훈련, 배치 추론, 최대 128K 컨텍스트) | 트랜스포머 |

Mamba와 같은 상태 공간 모델(SSM)은 본질적으로 구조화된 매개변수화(structured parameterization)를 가진 RNN으로, 두 가지의 장점을 모두 제공합니다: `O(N)` 스캔 메모리, 선택적 스캔(selective scan)을 통한 병렬 훈련. 트랜스포머 품질의 90%를 회복하면서 더 긴 컨텍스트 스케일링을 제공합니다. 2026년 대부분의 프런티어 랩은 하이브리드 SSM+트랜스포머 모델 (예: Jamba, Samba)을 훈련합니다. 재귀(recurrence)는 사라지지 않았으며, 하나의 구성 요소가 되었습니다.

## 연습 문제

1. **쉬움.** `code/main.py`에서 `rnn_style`를 가져와 스칼라 은닉 상태를 길이 64의 은닉 상태 벡터로 교체합니다. 다시 측정해 보세요. 은닉 상태 차원에 따라 직렬 오버헤드가 얼마나 증가하나요?
2. **중간 난이도.** 순수 Python으로 병렬 접두사 합(Hillis-Steele 스캔)을 구현하세요. 길이 1024에서 순차 스캔과 동일한 수치 출력을 생성하는지 검증하세요. 깊이를 세어 보세요.
3. **어려운 난이도.** 어텐션 스타일 감소 연산을 GPU에서 PyTorch로 이식하세요. 시퀀스 길이를 64에서 65,536까지 변화시키며 두 연산의 시간을 측정하세요. 곡선 형태를 플롯하고 설명하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 재귀식 | "RNN은 순차적이다" | 단계 `t`이 단계 `t-1`에 의존하여 시간 축을 따라 순차 실행을 강제하는 연산. |
| 순차 깊이 | "그래프가 얼마나 깊은가" | 의존하는 연산들의 가장 긴 체인; 무한한 하드웨어에서도 벽시계 시간을 제한한다. |
| 어텐션 | "토큰들이 서로를 바라보게 한다" | 가중 합 `sum_j a_ij v_j`이며, `a_ij`은 위치 i와 j 사이의 유사성 점수에서 나온다. |
| 컨텍스트 윈도우 | "모델이 얼마나 많은 것을 보는가" | 어텐션 레이어가 입력으로 받을 수 있는 위치의 수; 2차 메모리 비용이 여기서 스케일된다. |
| 귀납적 편향 | "아키텍처에 내장된 가정" | 데이터가 어떻게 생겼는지에 대한 사전 지식; CNN은 병진 불변성을, RNN은 최근성을 가정한다. |
| 상태 공간 모델 | "대수적 기반이 있는 RNN" | 구조화된 상태 공간 매트릭스를 통해 병렬 학습을 위해 매개변수화된 재귀식. |
| 2차 병목 | "왜 컨텍스트 비용이 그렇게 큰가" | 어텐션 메모리 = 시퀀스 길이에 대한 `O(N²)`; Flash Attention은 상수를 숨기지만, 스케일링은 숨기지 못한다. |
