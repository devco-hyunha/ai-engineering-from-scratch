# 스케일링 법칙

> 2020년 Kaplan 논문은 "모델이 커지면 손실이 줄어든다"라고 말했습니다. 2022년 Hoffmann 논문은 "모델이 과소 학습되었다"라고 지적했습니다. 연산량은 두 가지 버킷, 즉 매개변수와 토큰으로 나뉘며, 그 분배는 명확하지 않습니다.

**유형:** Learn
**언어:** Python
**선수 요건:** 7단계 · 05강 (전체 트랜스포머), 7단계 · 07강 (GPT)
**시간:** 약 45분

## 문제점

C FLOPs의 학습 연산량이 있고 최적의 모델을 원할 때, 두 가지 조절 변수가 있습니다:

1. **매개변수 수(N)는 얼마로 할까요?** 모델이 커지면 용량이 증가합니다.
2. **학습 토큰 수(D)는 얼마로 할까요?** 데이터가 많아지면 용량을 더 잘 활용합니다.

FLOPs는 `6 × N × D`에 따라 대략적으로 스케일링됩니다. N을 높이고 D를 낮추거나, D를 높이고 N을 낮출 수 있습니다. 어느 쪽이 더 좋을까요?

2022년 이전에는 "N을 크게 늘려야 한다"가 정답이었습니다. GPT-3 (2020)는 약 3000억 토큰으로 학습된 1750억 매개변수 모델이었습니다. 매개변수당 약 1.7개의 토큰 비율이었던 것입니다. Kaplan 스케일링 법칙이 이를 뒷받침했습니다.

Hoffmann et al. (2022)은 Chinchilla라고 불리는 작은 모델 계열을 학습하며 다른 사실을 발견했습니다. 최적의 비율은 매개변수당 **20개 토큰**에 가깝습니다. GPT-3는 10배 과소 학습된 상태였습니다. Chinchilla (700억 매개변수, 1.4조 토큰)는 추론 비용을 2.5배 적게 사용하면서도 모든 벤치마크에서 GPT-3 (1750억 매개변수, 3000억 토큰)를 능가했습니다.

2026년은 Chinchilla의 세계입니다. 중요한 변화가 하나 있습니다. Llama 3 8B는 15조 토큰으로 학습되었으며, 매개변수당 1,875개 토큰 비율을 기록했습니다. Chinchilla 최적 비율의 94배를 넘은 것입니다. 대규모로 사용될 모델의 경우 추론 비용이 학습 비용보다 중요하므로, 배포 가능한 발자취를 줄이기 위해 Chinchilla 비율을 넘겨 과잉 학습하는 것이 2026년의 기본 원칙입니다.

## 개념

![Chinchilla curves: loss vs compute at various N/D ratios](../assets/scaling-laws.svg)

### Hoffmann 법칙

Chinchilla 논문에서 손실은 다음을 따릅니다:

```
L(N, D) = A / N^α + B / D^β + E
```

- `N` = 매개변수 (임베딩 제외).
- `D` = 학습 토큰.
- `α ≈ 0.34`, `β ≈ 0.28` (대략적으로 대칭).
- `E ≈ 1.69`, 감소할 수 없는 손실 상한.
- `A ≈ 406`, `B ≈ 411`.

스케일링함에 따라 두 항이 서로 상충합니다. 고정된 연산량(C = 6ND)에서 `N`에 대해 미분하고 풀어보세요:

```
N_opt ≈ 0.6 × (C/6)^0.5
D_opt ≈ 0.6 × (C/6)^0.5
D_opt / N_opt ≈ 20
```

연산 최적: 매개변수당 20 토큰입니다.

### 왜 과잉 학습을 하는가

Chinchilla 최적은 학습 FLOP당 학습 손실을 최소화합니다. 하지만 학습 비용은 한 번만 지불하고, 추론 비용은 영원히 지불합니다.

월간 1조 토큰을 처리하는 챗봇의 경우, 추론이 총 비용을 지배합니다. Llama의 접근 방식: 더 작게, 더 길게 학습합니다. 8B 모델을 15T 토큰으로 학습하는 것은 추론 최적화가 깊이 적용된 것입니다:

- 소비자용 GPU에서 실행 가능합니다.
- Chinchilla 최적의 70B 모델 대비 지연 시간이 일부에 불과합니다.
- 대부분의 작업에 충분한 품질을 제공합니다.

DeepMind의 2024년 논문("Over-training is the new optimal")은 이를 공식화했습니다. 추론이 지배하는 워크로드의 경우, 서빙 볼륨에 따라 매개변수당 100~500 토큰 비율이 더 적절합니다.

### 출현 대 매끄러움

주장: 특정 능력(산술, 다단계 추론, Chain of Thought (CoT)(Chain of Thought (CoT)) 따르기)은 특정 규모에서 갑자기 "출현"합니다.

Schaeffer et al. (2023)은 이것이 측정 아티팩트라고 주장했습니다. 출현 지표는 불연속적인 점수화(정확 일치(Exact Match (EM))(Exact Match (EM)), 임계값에서의 정확도)를 사용하며, 이는 underlying 로짓(Logits)(Logits)의 매끄러운 개선은 숨깁니다. 연속적인 지표(교차 엔트로피(Cross-Entropy)(Cross-Entropy))는 매끄러운 곡선을 보여줍니다.

2026년 현재 합의는 다음과 같습니다: 연속적인 손실을 통한 예측은 신뢰할 수 있습니다. 벤치마크 급증은 종종 점수화 아티팩트입니다. 연속적인 지표를 기준으로 예산을 계획하세요.

### 2026년 상황

스케일링 법칙은 여전히 작동하지만, 다음과 같은 변화가 있습니다:

| 요인 | 변화 방식 |
|--------|-------------|
| 데이터 품질 | "좋은" 토큰(Token)(Token) 큐레이션(Phi 스타일)은 곡선을 >2× 유효 연산만큼 이동시킵니다 |
| MoE (혼합 전문가)(MoE (Mixture of Experts)) | 총 매개변수가 활성 FLOP와 분리됩니다; 활성 FLOP별 스케일링 법칙 |
| 후 학습 | 일부 능력(지시문 따르기(Instruction Following)(Instruction Following), 코드)은 사전 학습보다 SFT (지도 미세 조정)(SFT (Supervised Fine-Tuning)) + RLHF (인간 피드백 기반 강화 학습)(RLHF (Reinforcement Learning from Human Feedback))에 더 크게 이동합니다 |
| 멀티모달리티 | 이미지 + 텍스트 토큰이 함께 스케일링됩니다; 모달리티별 별도 곡선 |
| 합성 데이터 | 모델이 학습 데이터를 생성합니다; 유효 연산이 복리 효과를 가질 수 있습니다 |

Muon 옵티마이저(Optimizer)(Optimizer) (Kimi Moonlight, 2024)는 동일한 데이터에서 AdamW 대비 ~2× 유효 연산 이득을 보여주었습니다. 일부 2026년 학습 실행은 기본적으로 Muon을 사용합니다. 스케일링 법칙의 절대 상수를 변경하며, 그 형태는 변경하지 않습니다.

### 1단계: Chinchilla 손실

```python
def chinchilla_loss(N, D, A=406.4, B=410.7, alpha=0.34, beta=0.28, E=1.69):
    return A / N ** alpha + B / D ** beta + E
```

고정된 `C = 6ND`에서 `(N, D)`에 대한 `L`의 등고선 플롯을 그려 보세요. 최솟값을 찾아 보세요.

### 2단계: 컴퓨팅 최적 프론티어

`1e17`부터 `1e25` FLOPs까지의 컴퓨팅 예산에 대해 `6ND = C`을 만족하면서 손실을 최소화하는 `(N, D)`을 찾아 보세요. 비율 `D/N ≈ 20`을 검증해 보세요.

### 3단계: 과잉 학습 비용

10배 더 작은 모델(최적 N의 1/10, 최적 D의 10배)을 학습하는 데 추가적으로 발생하는 손실을 계산해 보세요. 그 대가로 추론 FLOP 절감 효과(N에 비례)를 보고합니다.

### 4단계: 실제 모델과 비교

## 사용하기

프론티어 모델을 직접 학습할 가능성은 낮습니다. 하지만 스케일링 법칙은 다음을 알려줍니다:

1. **미세 조정에 충분한 데이터가 있는지.** 작업 특화 데이터가 기본 모델의 매개변수당 20 토큰 미만이라면, 특정 손실 하한에서 포화가 발생할 것으로 예상하세요.
2. **더 큰 기본 모델을 선택할지.** 예산의 전부를 추론에 사용한다면, 더 작고 더 오래 학습된 모델을 선호하세요.
3. **수익이 감소하는 지점.** Chinchilla 최적의 1000배를 넘어서면, 로그 손실 변화는 잡음이 됩니다.

**2026년 연구 방향:**

- **데이터 제약 상태.** 웹에는 고품질 토큰의 유한한 수(~5–10조 영어 토큰, 필터링 후)가 있습니다. 프론티어 사전 학습은 이 상한에 근접하고 있습니다. 합성 데이터, 다국어, 멀티모달, RLHF 확장 미세 조정이 다음 레버입니다.
- **컴퓨팅 배수 트릭.** Muon 옵티마이저, MoE, 더 나은 데이터 큐레이션 — 각각은 점근선(渐近线)이 아닌 절대 상수를 이동시킵니다.
- **RL에 대한 스케일링 법칙.** 열린 질문입니다. 초기 증거는 RL 샘플에서幂律(power-law)을 시사하지만, 사전 학습과 매우 다른 지수를 가집니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 파라미터 (N) | "모델 크기" | 임베딩을 제외한 가중치 수; 용량을 결정합니다. |
| 토큰 (D) | "학습 데이터" | 학습 중 본 토큰의 수; 파라미터가 얼마나 잘 사용될지 결정합니다. |
| 연산량 (C) | "소모된 FLOPs" | 표준 트랜스포머의 경우 대략 `6 × N × D`입니다. |
| Chinchilla 최적 | "D/N ≈ 20" | 사전 학습 FLOP당 손실을 최소화하는 비율입니다. |
| 과잉 학습 | "Chinchilla 초과" | 추론 FLOPs를 절약하기 위해 추가 학습 FLOPs를 사용; D/N >> 20. |
| 감소 불가능한 손실 | "바닥값" | 스케일링 법칙의 `E` 항; 데이터 자체의 엔트로피입니다. |
| 돌출적 능력 | "규모에서의 갑작스러운 도약" | 종종 스코어러의 인위적 산출물입니다; 연속적인 손실은 매끄럽습니다. |
| 유효 연산량 | "학습 효율 곱셈 인자" | 더 나은 데이터 / 옵티마이저 / 아키텍처는 FLOP의 효율을 곱합니다. |
