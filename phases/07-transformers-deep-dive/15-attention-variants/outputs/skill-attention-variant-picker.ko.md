# 어텐션 변형 선택기

개발자가 새 트랜스포머의 어텐션 토폴로지를 선택하고 정당화하거나, 기존 모델을 더 긴 컨텍스트로 확장할 때 선택하고 정당화하도록 돕습니다.

## 수집할 입력

1. **타겟 컨텍스트 길이**는 학습 시와 추론 시에 다릅니다 (많은 모델이 16K에서 학습하고 추론 시에 확장합니다).
2. **검색 요구 사항**은 1–5 척도입니다: 1 = 순수 채팅, 5 = 바늘 찾기 / RAG (검색 증강 생성)(RAG (Retrieval-Augmented Generation)) / 긴 저장소 컨텍스트가 있는 코드.
3. **추론 메모리 예산**은 요청별 KV 캐시 허용량입니다 (레이어당 토큰당 바이트가 올바른 단위입니다).
4. **학습 비용 허용 범위** — SWA를 처음부터 학습하는 것은 저렴합니다. 사전 학습된 모델에 차등 어텐션을 retrofit하는 것은 비쌉니다.
5. **하드웨어 타겟** — Hopper+는 FlashAttention-3을 완전히 지원하며, Ada는 FA2를 지원하고, 구형 GPU는 마스크에 제한됩니다.

## 결정 규칙

- **컨텍스트 ≤ 16K이고 검색 ≤ 3**: FlashAttention을 사용하여 전체 어텐션을 사용합니다. 조기에 최적화하지 마세요.
- **컨텍스트 16–128K이고 검색 ≤ 3**: 윈도우 1024로 전역 레이어와 SWA를 5:1 비율로 혼합합니다 (Gemma 3 형태). KV를 압축하면서 검색 작업을 유지합니다.
- **컨텍스트 > 128K**: 4–6 레이어마다 전역 레이어가 있는 전체 SWA를 사용하며, 위치 보간 / YaRN 스케일링을 추가합니다 (04강).
- **검색 = 5이고 학습 예산이 허용**: 상위 4개 레이어에서만 차등 어텐션을 고려하세요 (KV 증가의 절반, 싱크 취소 이득의 대부분).
- **공개 API를 출시**: 안정적인 패턴 (전체, SWA, Gemma-3 혼합)을 선호하세요. 커널 엔지니어가 없다면 네이티브 희소 / DIFF를 건너뛰세요.
- **기본 모델을 변경할 수 없음**: SWA는 추론 시 마스크를 통해 retrofit할 수 있습니다. 차등 및 희소 어텐션은 retrofit할 수 없습니다.

## 항상 표시

- 7B 미만 순수 SWA 모델은 추론 벤치마크에서 측정 가능한 성능 저하가 자주 발생합니다. 권장하지 마세요.
- 윈도우 크기 < 512는 거의 항상 옳지 않습니다. 더 크게 하거나 다른 토폴로지를 사용하세요.
- 논문에서 차등 어텐션(Differential Attention) 보고는 소형 모델(3–7B)에 대한 것입니다. 2026년 초 기준으로 확장된 증거는 부족합니다.
- 모든 변형은 RoPE / YaRN 스케일링(04강)과 상호작용합니다. 위치 인코딩 방식을 명시적으로 기술해 보세요.

## 출력 형식

반환값:

1. **권장 사항** — 단일 명명된 토폴로지(예: "Gemma-3 mix, W=1024, 5:1 SWA:global").
2. **근거** — 각 입력을 위의 결정 규칙에 매핑합니다.
3. **KV 캐시 추정치** — 목표 컨텍스트에서 레이어당 토큰당 바이트 수 및 배치 1에서의 GB.
4. **마이그레이션 경로** — 기본 모델이 이미 학습된 경우, 어떻게 개조하는지.
5. **알려진 위험** — 어떤 벤치마크 / 워크로드가 회귀할 수 있는지.
