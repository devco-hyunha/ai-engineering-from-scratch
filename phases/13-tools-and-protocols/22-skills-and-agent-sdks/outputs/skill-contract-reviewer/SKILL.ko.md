# 스킬 계약 리뷰어

워크플로우가 재사용 가능한 에이전트 산출물이 될 때 이 스킬을 사용해 보세요.

1. 이 설치된 `SKILL_ROOT`을 포함하는 절대 디렉토리로 을 설정하세요.
`SKILL.md`. 프로세스의 작업 디렉토리가 번들이라고 가정하지 마세요.
2. 원래 작업 공간의 작업 디렉토리를 절대 경로로 `TARGET_ROOT`에 설정하고
그 루트 아래에 제안된 스킬 디렉토리를 해석하세요.
3. `$SKILL_ROOT/references/contract.md`을 읽고 휴대 가능한
`SKILL.md` 식별 필드를 검증하세요.
4. `$SKILL_ROOT/references/decision-model.md`을 읽고 저장소
   컨텍스트, 재사용 가능한 방법, 외부 기능, 생명주기 타이밍,
   결정적 로직, 그리고 격리된 위임을 분리하세요.
5. 실행 전에, 해석된 정확한 인자 벡터를 표시하세요. 실행
 `python3 "$SKILL_ROOT/scripts/check_skill.py" "$TARGET_SKILL"` `TARGET_SKILL` 은 `TARGET_ROOT` 아래에 있는 절대 제안 스킬 디렉토리입니다.
6. JSON 보고서를 검사하세요. 호스트별
확장 기능을 논의하기 전에 모든 오류를 수정하세요.
7. 제안된 산출물을 비교하고
 가장 작은 조합 가능한 원시 집합을 반환하세요.
`$SKILL_ROOT/assets/task-shapes.json` 

런타임 확장 기능이 휴대 가능한 계약의 일부라고 주장하지 마세요. 유효한 스킬을 스크립트 실행이나 도구 접근의 권한으로 취급하지 마세요.

검증 보고서, 선택된 원시, 그리고 각 선택에 대한 한 문장 설명을 반환하세요. 해석된 스크립트 경로, 해석된 대상 경로, cwd, 정확한 argv, 종료 코드를 포함한 실행 증거를 포함하세요. 호스트가 이러한 관찰 중 하나를 노출할 수 없는 경우, 발명하지 말고 '검증되지 않음'으로 표시하세요.
