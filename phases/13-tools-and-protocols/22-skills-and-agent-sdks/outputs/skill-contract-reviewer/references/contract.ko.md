# 이식 가능한 계약 체크리스트

- 번들은 일반적인 `SKILL.md` 파일을 포함하는 디렉토리입니다.
- 프론트매터는 첫 줄에서 시작하며 닫는 구분자가 있습니다.
- `name`이 존재하며, 64자 이하이고, 소문자, 숫자, 단일 하이픈만 사용합니다.
- `name`이 번들 디렉토리와 일치합니다.
- `description`이 존재하며, 1024자 이하이고, 스킬이 유용한 시점을 명시합니다.
- 선택적 `compatibility`이 존재할 경우 1~500자입니다.
- 선택적 `metadata`은 문자열 키를 문자열 값에 매핑합니다.
- 선택적 실험적 `allowed-tools`은 공백으로 구분된 비어 있지 않은 문자열이며, 그 동작은 대상 호스트에서 검증됩니다.
- 알 수 없는 런타임 필드는 이식 가능한 패키지 계약과 분리되어 명시적인 어댑터에 의해 처리됩니다.
- Markdown 본문에는 절차가 포함되어 있습니다.
- 선택적 이식 가능한 메타데이터와 호스트별 확장 기능은 구별 가능한 상태로 유지됩니다.

이 체크리스트를 통과하면 패키지가 구조적으로 로드 가능해집니다. 파일 시스템, 네트워크, 시크릿, 하위 프로세스, 도구 권한을 부여하지는 않습니다.
