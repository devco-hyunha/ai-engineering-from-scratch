# 원시 의사결정 모델

책임에 따라 선택하세요. 여러 원시가 정답일 수 있습니다.

| 필요 | 원시 | 경계 |
|---|---|---|
| 일회성 지시 | 프롬프트 | 현재 상호작용 동안 존재 |
| 저장소 전체 기본값 | AGENTS.md | 해당 저장소 범위에서 작업하는 동안 적용 |
| 재사용 가능한 작업 방법 | 에이전트 스킬 | 작업을 위한 절차적 지식을 로드 |
| 외부 작업 또는 데이터 | MCP 도구 | 입력 계약이 있는 호출 가능한 기능을 노출 |
| 런타임 이벤트에 대한 반응 | 훅 | 호스트가 정의한 라이프사이클 지점에서 실행 |
| 결정적 변환 | 일반 코드 | 모델 판단 없이 반복 가능한 출력 생성 |
| 격리된 또는 병렬 컨텍스트 | 서브 에이전트 | 제한된 작업을 별도의 컨텍스트 윈도우로 위임 |

원격 서비스를 쿼리하는 릴리스 리뷰 방법은 에이전트 스킬과 MCP 도구를 모두 사용할 수 있습니다. 저장소 테스트 관례는 AGENTS.md를 추가할 수 있습니다. 도구 후 감사(audit)는 훅을 추가할 수 있습니다. 안정적인 파싱은 일반 코드에 속합니다. 컨텍스트 격리의 이점을 얻는 독립적인 연구는 서브 에이전트를 사용할 수 있습니다.
