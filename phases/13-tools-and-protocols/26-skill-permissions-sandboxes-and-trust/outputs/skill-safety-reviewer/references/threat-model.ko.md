# 위협 모델(Threat Model)

이 경계들을 독립적으로 검토해 보세요:

- 권한: 지시문은 호스트 권한을 재작성할 수 없습니다.
- 파일 시스템: 대상을 해석하고 워크스페이스 루트 내부에 유지하며, 심볼릭 링크 탈출을 거부합니다.
- 명령: argv 배열을 허용하고, 셸 메타문자 및 파괴적인 실행 파일을 거부하며, 실행 파일 허용 목록을 요구합니다.
- 네트워크: HTTPS와 정확한 오리진 허용 목록을 요구합니다. 유효 포트 번호를 정규화하여 `https://api.example.test`과 `https://api.example.test:443`이 일치하도록 하고, 포트 `8443`는 자체 항목이 필요합니다. URL 사용자 정보에 자격 증명을 허용하지 마세요.
- 외부 콘텐츠: 검색된 텍스트는 데이터로 취급하며, 정책이나 승인으로는 절대 취급하지 마세요.
- 비밀: 값은 기록하지 않으면서 비밀이 포함될 가능성이 있는 페이로드를 감지합니다.
- 파괴적 작업: 호스트 정책에 따라 거부하거나 기록된 인간 승인을 요구합니다.

`allow` 판정은 시뮬레이션된 요청이 제공된 정책을 충족한다는 의미일 뿐입니다. 이 번들(bundled)은 어떤 작업도 실행하지 않습니다.
