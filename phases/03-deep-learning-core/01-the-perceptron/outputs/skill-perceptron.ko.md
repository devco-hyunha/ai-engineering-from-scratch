# 퍼셉트론 패턴 (The Perceptron Pattern)

퍼셉트론은 입력의 가중 합에 편향을 더한 뒤 계단 함수를 적용해 이진 출력을 만듭니다. 신경망의 기본 단위입니다.

```
output = step(w1*x1 + w2*x2 + ... + wn*xn + bias)
```

## 단일 퍼셉트론으로 충분한 경우

- 문제가 선형 분리 가능: 직선(또는 초평면)으로 두 클래스를 나눌 수 있음
- 논리 게이트: AND, OR, NOT, NAND
- 단순 임계 결정: "점수가 X보다 큰가?"
- 겹치지 않는 두 영역으로 뭉치는 데이터의 이진 분류

## 여러 층이 필요한 경우

- 문제가 선형 분리 가능하지 않음: 단일 직선으로 클래스를 나눌 수 없음
- XOR와 패리티 문제
- "이건 되지만 저건 아님" 추론이 필요한 작업(조건 조합)
- 실제 분류: 이미지, 텍스트, 오디오 — 거의 항상 비선형

## 결정 체크리스트

1. 데이터를 그리거나 살펴보세요. 클래스 사이에 단일 직선 경계를 그을 수 있나요?
   - 예: 단일 퍼셉트론으로 충분
   - 아니오: 최소 두 층이 필요
2. 더 단순한 선형 결정의 AND/OR로 문제를 분해할 수 있나요?
   - 이 분해가 최소 네트워크 구조를 알려줍니다
   - XOR = (A OR B) AND (NOT (A AND B)) = 2층에 퍼셉트론 3개
3. 클래스가 두 개보다 많으면 클래스당 출력 노드가 하나씩 필요합니다

## 학습 규칙

```
error = expected - predicted
weight_new = weight_old + learning_rate * error * input
bias_new = bias_old + learning_rate * error
```

예측이 맞으면 아무 것도 바뀌지 않습니다. 틀리면 오차를 줄이도록 가중치가 이동합니다. 이것은 단일층 퍼셉트론에만 통합니다. 다층 네트워크에는 역전파가 필요합니다.

## 흔한 실수

- 단일 퍼셉트론으로 비선형 패턴을 학습하려 함 (절대 수렴하지 않음)
- 학습률을 너무 크게 (가중치가 진동) 또는 너무 작게 (학습이 끝없이 걸림)
- 편향 항을 잊음 (없으면 결정 경계가 원점을 지나야 함)
- 퍼셉트론 수렴(선형 분리 가능 데이터에서는 보장)과 일반 신경망 수렴(보장되지 않음)을 혼동
