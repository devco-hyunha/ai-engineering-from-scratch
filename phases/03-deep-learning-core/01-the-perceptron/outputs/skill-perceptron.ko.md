# 퍼셉트론 패턴

퍼셉트론은 입력의 가중 합에 편향을 더한 후, 스텝 함수를 적용하여 이진 출력을 생성합니다. 이는 신경망의 기본 단위입니다.

```
output = step(w1*x1 + w2*x2 + ... + wn*xn + bias)
```

## 단일 퍼셉트론으로 충분한 경우

- 문제가 선형 분리 가능할 때: 직선(또는 초평면)이 두 클래스를 나눌 수 있는 경우
- 논리 게이트: AND, OR, NOT, NAND
- 단순한 임계값 결정: "점수가 X 이상인가요?"
- 두 개의 겹치지 않는 영역으로 군집화되는 데이터에 대한 이진 분류기

## 다층이 필요한 경우

- 문제가 선형 분리 불가능할 때: 단일 직선으로 클래스를 분리할 수 없는 경우
- XOR 및 패리티 문제
- "이것이지만 저것은 아닌" 추론(조건들의 조합)이 필요한 모든 작업
- 실제 세계의 분류: 이미지, 텍스트, 오디오 - 거의 항상 비선형

## 의사 결정 체크리스트

1. 데이터를 플롯하거나 검사해 보세요. 클래스 사이에 단일 직선 경계를 그릴 수 있나요?
   - 예: 단일 퍼셉트론이 작동합니다
   - 아니요: 최소 두 층이 필요합니다
2. 문제를 더 단순한 선형 결정의 AND/OR로 분해할 수 있나요?
   - 이 분해는 최소 네트워크 구조를 알려줍니다
   - XOR = (A OR B) AND (NOT (A AND B)) = 2층에 3개의 퍼셉트론
3. 두 개 이상의 클래스가 있는 문제의 경우, 클래스당 하나의 출력 노드가 필요합니다

## 학습 규칙

```
error = expected - predicted
weight_new = weight_old + learning_rate * error * input
bias_new = bias_old + learning_rate * error
```

예측이 정확하면 아무것도 변하지 않습니다. 틀리면 가중치가 오차를 줄이도록 이동합니다. 이는 단일층 퍼셉트론에만 적용됩니다. 다층 네트워크는 역전파(Backpropagation)가 필요합니다.

## 공통 실수

- 단일 퍼셉트론으로 비선형 패턴을 학습하려고 시도하는 것(절대 수렴하지 않습니다)
- 학습률(Learning Rate)을 너무 높게 설정하는 것(가중치가 진동합니다) 또는 너무 낮게 설정하는 것(학습이 영원히 걸립니다)
- 편향(bias) 항을 잊는 것 (이 항이 없으면 결정 경계가 원점을 지나야 합니다)
- 퍼셉트론 수렴(선형 분리 가능한 데이터에 대해 보장됨)을 일반적인 신경망 수렴(보장되지 않음)과 혼동하는 것
