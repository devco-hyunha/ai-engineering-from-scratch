# Tree of Thoughts와 LATS: 의도적 탐색

> 단일 Chain of Thought (CoT) 궤적은 되돌아갈 여지가 없습니다. ToT (Yao et al., 2023)는 추론을 트리로 변환하여 각 노드에서 자기 평가를 수행합니다. LATS (Zhou et al., 2024)는 ToT, ReAct, Reflexion을 Monte Carlo Tree Search(MCTS) 아래에서 통합합니다. Game of 24는 CoT의 4%에서 ToT의 74%로 향상되며, LATS는 HumanEval에서 pass@1 92.7%를 달성합니다.

**유형:** Build
**언어:** Python (stdlib)
**선수 요건:** 14단계 · 01강 (에이전트 루프), 14단계 · 03강 (Reflexion)
**시간:** 약 75분

## 학습 목표

- 추론을 탐색으로 정의해 보세요: 노드는 "생각(thought)"이고, 간선은 "확장(expansion)"이며, 값은 "유망한 정도"입니다.
- 자기 평가 점수를 사용하는 stdlib 기반 ToT 스타일 BFS 트리 탐색을 구현해 보세요.
- 선택 / 확장 / 시뮬레이션 / 역전파를 포함하는 장난감 LATS MCTS 루프로 확장해 보세요.
- 토큰 배수 효과가 가치가 있는 경우(Game of 24, 코드 생성)와 단일 궤적으로 충분한 경우(단순 Q&A)를 결정해 보세요.

## 문제점

Chain of Thought는 선형적인 이동입니다. 첫 단계가 잘못되면 모든 후속 단계는 잘못된 전제 위에서 작동합니다. Game of 24 (네 자리 숫자를 + − × ÷ 연산으로 24를 만드는 문제)에서 GPT-4 CoT는 4%의 정확도를 기록합니다. 모델이 초기에 잘못된 하위 표현식을 선택하면 회복할 수 없습니다.

추론에 필요한 것은 여러 후보를 제안하고, 평가하고, 유망한 것을 선택하며, 막다른 골목이 나타나면 되돌아갈 수 있는 능력입니다. 이것이 바로 탐색입니다. Tree of Thoughts와 LATS는 이 두 가지 표준적인 공식화입니다.

## 개념

### Tree of Thoughts (Yao et al., NeurIPS 2023)

각 노드는 일관된 중간 단계("생각")입니다. 각 노드는 K개의 자식 생각으로 확장될 수 있습니다. LLM은 평가 프롬프트를 사용하여 각 노드를 자기 평가합니다. 탐색은 트리를 탐사합니다 — BFS, DFS, 또는 beam.

```
                     (root: "find 24 from 4 6 4 1")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- Score: HIGH
              /   \              |                  |
          ...    ...          ...                finish
```

자기 평가는 핵심적인 부분입니다. 논문은 세 가지 변형을 제시합니다: `sure / likely / impossible` 분류, `1..10` 수치 점수, 그리고 후보 간 투표. 세 가지 모두 Game of 24에서 CoT를 크게 능가합니다 (GPT-4 기준 4% -> 74%).

### LATS (Zhou et al., ICML 2024)

LATS는 ToT, ReAct, Reflexion을 MCTS 아래에서 통합합니다. LLM은 세 가지 역할을 수행합니다:

- **정책**: 후보 다음 행동(ReAct 스타일)을 제안합니다.
- **가치 함수**: 부분 궤적에 점수를 매깁니다(ToT 스타일 자기 평가).
- **자기 반성기**: 실패 시 자연어 반성(Reflexion 스타일)을 작성하고, 이를 사용하여 미래 롤아웃을 다시 시드합니다.

환경 피드백(관측)이 가치 함수에 혼합되어, 검색이 모델의 의견뿐만 아니라 실제 도구 결과에 의해 안내됩니다. 논문 시점의 결과: GPT-4로 HumanEval pass@1 92.7%(SOTA), GPT-3.5로 WebShop 평균 75.9(경사 기반 미세 조정에 근접).

### MCTS, 최소한

반복마다 네 단계:

1. **선택** — UCT(트리에 대한 상한 신뢰 구간)를 사용하여 루트에서 리프까지 이동합니다.
2. **확장** — 정책을 통해 K개의 자식을 생성합니다.
3. **시뮬레이션** — 정책을 사용하여 자식에서 롤아웃을 수행하고, 가치 함수(또는 환경 보상)로 리프에 점수를 매깁니다.
4. **역전파** — 경로에 따라 방문 횟수와 가치 추정치를 업데이트합니다.

UCT 공식: `Q(s, a) + c * sqrt(ln N(s) / N(s, a))`. 첫 번째 항은 활용, 두 번째 항은 탐색입니다. `c`를 작업별로 조정해 보세요.

### 비용 현실

검색은 토큰을 폭발시킵니다. Game of 24에 대한 ToT는 CoT의 100–1000배의 토큰을 사용합니다. LATS도 유사합니다. 이는 무료가 아니므로, 검색을 다음에 예약하세요:

- 단일 궤적이 명백히 불충분한 작업(Game of 24, 복잡한 코드).
- 월클록(wall-clock)이 정확성보다 덜 중요한 작업.
- 저렴하고 신뢰할 수 있는 가치 함수가 있는 작업(코드의 단위 테스트, 수학의 명시적 목표).

작업에 단일 정답이 있고 평가자가 잡음이 많다면, 검색은 종종 상황을 악화시킵니다 — "높은 점수를 받는" 오답을 찾아냅니다.

### 2026년 위치

대부분의 프로덕션 에이전트는 LATS를 실행하지 않습니다. 도구 기반 검증(CRITIC, 05강)과 함께 ReAct를 실행합니다. 검색은 전문화된 틈새에서 나타납니다:

- 가치 함수로 테스트를 실행하는 코딩 에이전트(HumanEval 스타일).
- 다중 쿼리 경로를 탐색하는 심층 연구 에이전트.
- LangGraph 하위 그래프 내의 계획 중심 워크플로.

AlphaEvolve (11강)는 2025년의 극단적인 사례입니다: 코드에 대한 진화적 탐색, 기계 검증 가능한 적합성, 최전선에서의 성과 (56년 만의 4x4 행렬 곱셈 개선).

## 구현하기

`code/main.py`는 다음을 구현합니다:

- 양식화된 "산술 연산 선택" 작업에 대한 작은 ToT BFS.
- UCT 선택을 사용하여 동일한 작업에 대한 장난감 LATS MCTS 루프 (선택 / 확장 / 시뮬레이션 / 역전파).
- 기호적 점수와 자기 평가 점수를 조합하는 가치 함수.

실행해 보세요:

```
python3 code/main.py
```

추적은 ToT가 BFS로 각 노드에서 세 후보를 확장하는 것을 보여 주며, LATS는 MCTS를 통해 최상의 롤아웃으로 수렴하는 것과 비교됩니다. 두 경우 모두 토큰 수가 출력됩니다.

## 사용하기

LangGraph는 ToT 스타일 탐색을 하위 그래프 패턴으로 제공합니다. LangChain 팀의 LATS 블로그 (2024년 5월)는 참고 튜토리얼입니다. LlamaIndex는 `TreeOfThoughts` 에이전트를 제공합니다. 대부분의 2026년 생산 에이전트에서는 이 패턴이 `if task_complexity > threshold: use_search()` 게이트 뒤에 있습니다 — 05강의 평가자-최적화자 패턴을 참조하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| Tree of Thoughts | "분지 CoT" | Yao 등 — 자기 평가가 있는 사고의 나무 |
| LATS | "LLM을 위한 MCTS" | Zhou 등 — MCTS 아래에서 ToT + ReAct + Reflexion을 통합 |
| UCT | "상한 신뢰 구간" | 활용(Q)과 탐색(ln N / n)의 균형을 맞추는 선택 공식 |
| 가치 함수 | "이 상태가 얼마나 좋은가" | 프롬프트된 LLM 점수 또는 환경 보상; 역전파에 피드백 |
| 정책 | "행동 제안자" | ReAct 스타일 생성기; 후보 다음 생각/행동을 방출 |
| 롤아웃 | "시뮬레이션된 궤적" | 정책을 사용하여 노드에서 리프까지 이동하고 가치로 점수 매김 |
| 역전파 | "조상 업데이트" | 리프의 보상을 경로 위로 푸시하여 방문 횟수와 Q를 업데이트 |
| 탐색 비용 | "토큰 폭발" | Game of 24에서 CoT의 100-1000배; 채택하기 전에 예산을 고려하세요 |
