# 신뢰성 정책

워크벤치는 업계에서 반복적으로 발생하는 5가지 실패 모드를 흡수합니다:

1. 환각(Hallucination)된 행동 — 규칙 세트 + 검증 게이트로 포착됩니다.
2. 범위 확대(Scope creep) — 범위 계약(Scope Contract) diff 체크로 포착됩니다.
3. 연쇄적 오류 — 피드백 기록 + null 종료 시 거부(refuse-on-null-exit)로 포착됩니다.
4. 컨텍스트 손실 — 저장소 메모리(repo memory)로 흡수됩니다; 채팅은 진실의 원천(source of truth)이 아닙니다.
5. 도구 오용 — 리뷰어 평가 기준의 검증 차원으로 포착됩니다.

이 정책은 검증 게이트로 강제됩니다. 오버라이드 경로는 서명되고 감사(audit)되며; 에이전트(Agent)는 스스로 오버라이드할 수 없습니다.
