# 에이전트 워크벤치 팩

신뢰할 수 있는 에이전트 작업을 원하는 모든 저장소에 바로 적용할 수 있는 워크벤치입니다.

## 제공 내용

- `AGENTS.md` 팩의 나머지 부분으로 연결하는 짧은 라우터입니다.
- `docs/` 규칙, 신뢰성 정책, 핸드오프 프로토콜, 리뷰어 평가 기준입니다.
- `schemas/` 상태, 보드, 범위 계약에 대한 JSON 스키마입니다.
- `scripts/` 초기화, 피드백 실행기, 검증 게이트, 핸드오프 생성기입니다.
- `bin/install.sh` 멱등성 있는 설치 프로그램입니다.

## 빠른 시작

```
bin/install.sh
$EDITOR task_board.json
python3 scripts/init_agent.py
```

## 버전 관리

`VERSION` 파일은 계약입니다. 주요 버전 상향은 상태 마이그레이션을 필요로 합니다.
