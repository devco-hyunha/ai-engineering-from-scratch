# 물리적 타당성 검사

생성된 비디오의 프로덕션 배포에는 자동화된 가드레일(Guardrails)이 필요합니다. 인간 리뷰는 확장성이 없으며, 물리 검사로 고전적인 실패 모드를 포착할 수 있습니다.

## 사용 시점

- 텍스트 또는 이미지 프롬프트에서 비디오를 생성하는 모든 제품.
- 비디오 생성 API 엔드포인트의 QA 자동화.
- 미세 조정(Fine-tuning)이나 기본 모델 업데이트 후 비디오 모델의 품질 드리프트 모니터링.

## 입력

- `video`: 텐서 `(T, H, W, 3)` 또는 mp4 파일 경로.
- 선택적 참조 정보: 예상 물체 수, 초기 장면 설명.

## 검사 항목

### 1. 물체 영속성
SAM 3.1 Object Multiplex를 사용하여 모든 감지된 물체를 프레임 간에 추적합니다. 안정적으로 추적된 물체가 3프레임 이하로 사라졌다가 다시 나타나는 경우를 플래그합니다 — 모델이 물체를 일시적으로 잃어버린 것입니다. 프레임 중심 근처에서 물체가 사라지면 하드 실패로 처리하고, 가장자리에서 사라지면 소프트 실패로 처리합니다.

### 2. 운동 부드러움
연속 프레임 간의 광학 흐름은 대부분 연속적이어야 합니다. 갑작스러운 픽셀 단위 흐름 스파이크는 텔레포테이션을 나타냅니다. RAFT로 흐름을 계산하고, 99퍼센타일 흐름 크기가 중위값의 10배 이상을 초과하는 프레임을 플래그합니다.

### 3. 중력 / 지지
고체로 감지된 물체(음식, 공, 도구)의 경우, 들어 올리는 동작이 없을 때 수직 위치가 증가하지 않는지 확인합니다. 물체 근처에 "잡는 손"이 감지되지 않는 한 상방 드리프트를 플래그합니다.

### 4. 신원 일관성
사람이나 캐릭터의 경우, 프레임 간에 얼굴 인식 임베딩(Embedding)을 사용합니다. 지속되는 신원에 대해 5프레임 윈도우에서 코사인 유사도(Cosine Similarity)가 0.8 이상을 유지해야 합니다. 임계값 미만이면 캐릭터가 변형된 것입니다.

### 5. 손과 팔다리
포즈 추정기(21강)를 실행합니다. 손에 보이는 손가락이 5개 이상이거나 4개 미만인 프레임, 팔 길이가 프레임 간에 두 배가 되는 프레임, 팔다리가 표면을 통해 몸과 교차하는 프레임을 플래그합니다.

### 6. 텍스트 렌더링 (프롬프트가 텍스트를 요청한 경우)
사용자 프롬프트에 따옴표로 묶인 문자열이 포함된 경우, 생성된 프레임을 OCR 처리하여 요청된 문자열에 대한 CER를 계산합니다. CER가 20%를 초과하면 플래그를 지정합니다.

## 보고서

```
[plausibility]
  video frames:           <T>
  permanence violations:  <N>
  smoothness violations:  <N>
  gravity violations:     <N>
  identity drift:         <N of 5-frame windows>
  limb anomalies:         <N>
  OCR CER vs requested:   <float>

[verdict]
  ship | hold | reject

[samples for review]
  frame ranges where each failure occurred
```

## 규칙

- 단일 검사에 대해 하드 블로킹을 하지 마세요. 점수를 집계하고 총 이상치가 임계값을 초과하면 검토를 위해 영상을 보류하세요.
- 신원 드리프트와 영속성 위반에 가장 높은 가중치를 부여하세요. 사용자가 가장 먼저 인지하는 부분입니다.
- 검사별 실패율을 시간에 따라 기록하세요. 상승하는 추세는 보통 기본 모델이 업데이트되었거나 프롬프트 분포가 이동했음을 의미합니다.
- 플래그가 지정된 영상을 절대 삭제하지 마세요. 모델 디버깅 및 사후 분석(Postmortem)을 위해 보관하세요.
- 민감한 콘텐츠(사람, 어린이, 공개 인물)의 경우 점수와 관계없이 모든 영상에 대해 인간 검토를 요구하세요.
