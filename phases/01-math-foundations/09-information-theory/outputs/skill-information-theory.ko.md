# ML을 위한 정보 이론

머신러닝 시스템에서 엔트로피, 교차 엔트로피, KL 발산 및 상호 정보량을 언제 사용해야 하는지 설명합니다.

## 의사 결정 체크리스트

1. 단일 분포의 불확실성을 측정하나요? **엔트로피**를 사용하세요.
2. 모델이 실제 레이블을 얼마나 잘 근사하는지 측정하나요? **교차 엔트로피**를 사용하세요 (이것이 분류 손실입니다).
3. 두 분포 간의 거리를 측정하나요? **KL 발산**을 사용하세요.
4. 두 변수가 관련되어 있는지 확인하나요? **상호 정보량**을 사용하세요.
5. 언어 모델의 품질을 보고하나요? **퍼플렉시티**를 사용하세요 (교차 엔트로피의 지수).
6. 한 모델을 다른 모델로 증류(distillation)하나요? 교사 모델에서 학생 모델로의 **KL 발산**을 최소화하세요.

## 각 측정값을 언제 사용해야 하는지

| 측정값 | 공식 | 사용 사례 | ML 적용 |
|---|---|---|---|
| 엔트로피 H(P) | -sum(p log p) | 이 분포는 얼마나 불확실한가요? | 데이터 복잡성, 최대 엔트로피 모델 |
| 교차 엔트로피 H(P,Q) | -sum(p log q) | 모델 Q가 실제 P를 예측하는 데 얼마나 좋은가요? | 분류 손실, 언어 모델 손실 |
| KL 발산 D(P\|\|Q) | sum(p log(p/q)) | P와 Q는 얼마나 다른가요? | VAE 손실 (ELBO), 지식 증류, RLHF |
| 상호 정보량 I(X;Y) | H(X) - H(X\|Y) | Y가 X에 대해 얼마나 많은 정보를 주나요? | 기능 선택, 표현 학습 |
| 퍼플렉시티 | exp(H(P,Q)) 또는 2^H | 모델은 얼마나 혼란스러워하나요? | 언어 모델 평가 |
| 조건부 엔트로피 H(X\|Y) | -sum(p(x,y) log p(x\|y)) | Y를 알았을 때 X에 남아 있는 불확실성 | 기능 정보량 |

## 핵심 관계

```
Cross-entropy  = Entropy + KL divergence
H(P, Q)        = H(P)   + D_KL(P || Q)

Since H(P) is constant during training:
  Minimizing cross-entropy = Minimizing KL divergence

Mutual information = Entropy - Conditional entropy
I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)

Perplexity = exp(cross-entropy in nats)
           = 2^(cross-entropy in bits)
```

| 정보량: -log(p) | -log2(p) | -ln(p) |

## 값 해석

| 엔트로피 값 | 의미 |
|---|---|
| 0 | 결정적. 하나의 결과가 확률 1을 가짐. |
| log(n) | 최대 불확실성. n개 결과에 대한 균등 분포. |
| 낮음 | 분포가 첨두. 모델이 확신함. |
| 높음 | 분포가 평평. 모델이 불확실함. |

| 퍼플렉시티 값 | 언어 모델 품질 |
|---|---|
| 1 | 완벽한 예측 (실제로는 발생하지 않음) |
| 10 | 평균적으로 ~10개의 동등한 확률 토큰 중 선택 |
| 50 | 표준 벤치마크에서의 GPT-2 수준 |
| < 10 | 잘 표현된 도메인에서의 최신 기술 |

## 공통 실수

- KL 발산을 계산하고 이를 대칭적인 것으로 취급하는 것. D_KL(P||Q) != D_KL(Q||P). 대칭적인 측정값을 사용하려면 Jensen-Shannon 발산을 사용하세요: JS = 0.5 * KL(P||M) + 0.5 * KL(Q||M) (여기서 M = 0.5*(P+Q)).
- 원-핫(one-hot) 레이블을 사용한 교차 엔트로피가 -log(p_true_class)로 단순화되는 것을 잊는 것. 참 분포가 원-핫일 때는 모든 클래스에 대해 합산할 필요가 없습니다.
- 코드에서는 log base 2를 사용하지만 nats로 보고하는 것 (또는 그 반대). PyTorch는 기본적으로 자연 로그를 사용합니다. nats를 bits로 변환하려면 log2(e) = 1.4427를 곱하세요.
- 빈 이벤트나 확률이 0인 이벤트의 엔트로피를 계산하는 것. 관례: 0 * log(0) = 0, 왜냐하면 lim(p->0) p*log(p) = 0이기 때문입니다.
- 다른 어휘(vocabulary) 간에 퍼플렉시티를 비교하는 것. 어휘 크기가 50k이고 퍼플렉시티가 30인 모델은 어휘 크기가 10k이고 퍼플렉시티가 30인 모델과 직접 비교할 수 없습니다.

## 프로덕션 ML에서 각 개념이 나타나는 위치

| 개념 | 볼 수 있는 위치 |
|---|---|
| 교차 엔트로피 손실 | 모든 분류 모델 (nn.CrossEntropyLoss) |
| KL 발산 | VAE ELBO, PPO 클리핑, 지식 증류 |
| 엔트로피 정규화 | RL에서의 탐색 보너스 (엔트로피가 높을수록 더 많은 탐색) |
| 상호 정보 | 특징 선택, InfoNCE 손실 (대조 학습) |
| 퍼플렉시티 | 언어 모델 벤치마크 (낮을수록 좋음) |
| 라벨 스무딩 | 원-hot을 부드러운 타깃으로 대체하여 교차 엔트로피 과신뢰를 줄임 |
| 온도 스케일링 | 소프트맥스 전에 로짓을 T로 나누어 출력의 엔트로피를 제어 |
