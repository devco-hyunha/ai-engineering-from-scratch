# 샘플링 전략 선택

텍스트 생성, 베이지안 추론, 몬테 카를로 추정, 학습에 적합한 샘플링 방법을 선택하는 방법입니다.

## 의사 결정 체크리스트

1. 출력(텍스트, 이미지)을 생성하고 있나요, 아니면 양(적분, 기댓값)을 추정하고 있나요?
2. 목표 분포에서 직접 샘플링할 수 있나요, 아니면 밀도만 평가할 수 있나요?
3. 목표 분포는 이산형인가요, 연속형인가요?
4. 샘플 공간의 차원은 몇 차원인가요? 낮음(< 5), 중간(5-100), 높음(> 100)?
5. 정확한 샘플이 필요한가요, 아니면 근사 샘플이 필요한가요?
6. 샘플링 연산을 통해 기울기가 필요한가요?

## 각 방법의 사용 시점

| 방법 | 사용 시점 | 복잡도 | 정확 여부 |
|---|---|---|---|
| 직접 샘플링 | CDF를 가지고 있거나 라이브러리 함수를 사용할 수 있음 | 샘플당 O(1) | 예 |
| 역 CDF | 알려진 폐형 CDF 역함수(지수, 코시) | 샘플당 O(1) | 예 |
| Box-Muller | 라이브러리 없이 정규 분포 샘플이 필요함 | 샘플당 O(1) | 예 |
| 기각 샘플링 | 목표 PDF를 평가할 수 있고, 차원이 낮음(1-3) | 샘플당 O(1/수락률) | 예 |
| 중요도 샘플링 | 개별 샘플이 아닌 기댓값이 필요함 | n개 샘플에 대해 O(n) | 근사 |
| 층화 샘플링 | 몬테 카를로 추정, 더 낮은 분산이 필요함 | n개 샘플에 대해 O(n) | 근사 |
| Metropolis-Hastings | 고차원, 비정규화 밀도를 평가할 수 있음 | 단계당 O(1) + 버인 | 점근적 |
| 깁스 샘플링 | 각 조건부 분포에서 샘플링할 수 있음 | 전체 스윕당 O(d) | 점근적 |
| HMC/NUTS | 고차원 연속형, 매끄러운 밀도 | 단계당 O(L * d) | 점근적 |
| 온도 샘플링 | LLM 텍스트 생성, 창의성 제어 | 어휘 크기 V에 대해 O(V) | N/A |
| Top-k 샘플링 | LLM 생성, 가능성이 낮은 토큰 제거 | O(V log k) | N/A |
| Top-p (핵 샘플링) | LLM 생성, 적응형 후보 집합 | O(V log V) | 해당 없음 |
| 재파라미터화 | 가우시안 샘플링을 통한 기울기 필요 (VAE) | O(d) | 예 |
| Gumbel-Softmax | 범주형 샘플링을 통한 기울기 필요 | k개 클래스에 대해 O(k) | 근사 |

## LLM 생성 설정

| 사용 사례 | 온도 | Top-p | Top-k | 비고 |
|---|---|---|---|---|
| 사실적 Q&A | 0.0 (탐욕) | -- | -- | 결정적, 무작위성 없음 |
| 코드 생성 | 0.2-0.5 | 0.9 | -- | 낮은 창의성, 높은 일관성 |
| 일반 채팅 | 0.7 | 0.9 | -- | 균형 잡힘 |
| 창의적 글쓰기 | 0.9-1.2 | 0.95 | -- | 높은 다양성 |
| 브레인스토밍 | 1.0-1.5 | 0.95 | -- | 최대 다양성, 일관성 손실 가능 |

온도와 top-p는 결합할 수 있습니다. 온도를 먼저 적용하여 로짓을 스케일링한 후, top-p 필터링을 적용해 보세요.

## MCMC 방법 선택

| 속성 | Metropolis-Hastings | Gibbs | HMC/NUTS |
|---|---|---|---|
| 차원 | 임의 | 임의 (100 미만일 때 최적) | 높음 (100+) |
| 조건부 필요 여부 | 아니요 | 예 | 아니요 |
| 기울기 필요 여부 | 아니요 | 아니요 | 예 |
| 수용률 | ~23%로 조정 | 항상 100% | ~65%로 조정 |
| 상관관계 | 높음 (랜덤 워크) | 중간 | 낮음 |
| 번인(Burn-in) | 길음 | 중간 | 짧음 |
| 최적 용도 | 탐색, 단순 모델 | 공액 모델, 베이지안 네트워크 | 연속 사후 분포, 심층 확률 모델 |

## 공통 실수

- 고차원에서 기각 샘플링을 사용하는 것. 차원이 증가하면 수용률이 지수적으로 감소합니다. 5차원 이상에서는 MCMC로 전환해 보세요.
- MCMC 제안 분산이 너무 높거나 낮게 설정하는 것. 너무 높으면 대부분의 제안이 기각되어 체인이 멈추고, 너무 낮으면 모든 제안이 수용되어 체인이 느리게 이동합니다. 랜덤 워크 MH의 경우 ~23% 수용률을 목표로 해 보세요.
- 번인(Burn-in)을 잊는 것. MCMC의 첫 N개 샘플은 시작점에 의해 편향됩니다. 적어도 1000 스텝을 버리세요 (복잡한 분포의 경우 더 많이 버리세요).
- 목표 분포와 매우 다른 제안 분포를 사용하여 중요도 샘플링을 수행하는 경우. 몇몇 샘플이 거대한 가중치를 가지게 되어 추정치가 신뢰할 수 없게 됩니다. 유효 샘플 크기(ESS)를 모니터링하세요: ESS = (sum w_i)^2 / sum(w_i^2).
- 결정적 출력(예: 분류, 구조화된 추출)이 필요한 작업에 온도(Temperature) > 0을 사용하는 경우. 대신 그리디(T=0) 또는 빔 검색을 사용하세요.
- Top-p와 온도를 결합하지 않는 경우. 온도만으로는 긴 꼬리의 잡음 토큰을 제거하지 못합니다. Top-p는 이를 제거합니다.
- 표준 샘플링 연산을 통해 역전파하는 경우. 연속 분포(가우시안)에는 재매개변수화 트릭을, 이산 분포(범주형)에는 Gumbel-Softmax를 사용하세요.

## 빠른 참조: 분산 감소 기법

| 기법 | 작동 방식 | 분산 감소 |
|---|---|---|
| 층화 샘플링 | 공간을 층으로 나누고 각 층에서 샘플링 | 항상 표준 MC 이하 |
| 대립 변수 | U와 1-U를 모두 사용 | 단조 함수에 효과적 |
| 통제 변수 | 알려진 평균을 가진 변수를 차감 | 상관관계에 비례 |
| 중요도 샘플링 | 더 나은 제안 분포에서 샘플의 가중치를 재조정 | 제안 분포의 품질에 의존 |
| 라틴 초입방체 | 각 차원을 독립적으로 층화 | 고차원에서 층화 샘플링보다 우수 |
