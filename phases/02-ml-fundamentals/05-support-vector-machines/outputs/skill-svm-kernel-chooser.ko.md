# SVM 커널 선택 가이드

SVM은 두 가지 선택으로 정의됩니다: 커널(결정 경계의 형태를 결정)과 정규화 파라미터(마진 폭과 분류 오차 사이의 트레이드오프를 제어). 이것을 제대로 고르는 것이 쓸모없는 모델과 강한 모델의 차이입니다.

## 결정 체크리스트

1. 데이터가 선형 분리 가능한가(또는 그에 가까운가)?
   - 예: 선형 커널을 쓰세요. 더 빠르고 해석하기 쉽습니다.
   - 아니오: 2단계로.

2. 특성 수 vs 샘플 수는?
   - 특성 >> 샘플 (예: TF-IDF 텍스트): 선형 커널. 고차원 데이터는 종종 선형 분리 가능합니다. RBF는 이득 없이 복잡도만 더합니다.
   - 샘플 >> 특성 (예: 특성 10-50개의 표 데이터): RBF 커널이 기본 선택입니다.

3. 결정 경계가 매끄러울 것으로 기대되는가?
   - 매끄럽고 연속인 경계: RBF 커널
   - 다항 형태의 경계: 다항 커널 (차수 2 또는 3부터)
   - 도메인 지식이 특정 상호작용 항을 시사: 맞는 차수의 다항 커널

4. 데이터셋이 얼마나 큰가?
   - 10,000 샘플 미만: 어떤 커널이든 동작, RBF가 안전한 기본값
   - 10,000~100,000: 선형 커널 또는 LinearSVC (원시 수식, 에포크당 O(n))
   - 100,000 초과: 커널 SVM을 쓰지 마세요. 선형 SVM, 그래디언트 부스팅, 또는 신경망으로 전환.

5. 특성을 스케일했는가?
   - SVM은 특성 스케일링이 필요합니다. 맞추기 전에 항상 표준화(평균 0, 분산 1)하세요. 스케일되지 않은 특성은 마진 기하를 왜곡합니다.

## 커널 선택 플로차트

```
Start
  |
  v
특성 > 1000 또는 특성 >> 샘플?
  Yes --> 선형 커널 (속도면 LinearSVC)
  No  --> 데이터셋 < 10k 샘플?
            Yes --> RBF 먼저 시도 (가장 범용적인 커널)
            No  --> 선형 커널 (커널 SVM은 O(n^2)~O(n^3))
```

RBF가 잘 안 되면 다항 차수 2-3을 시도하세요. 그것도 실패하면 문제가 SVM에 맞지 않을 수 있습니다.

## C 튜닝 (정규화)

C는 오분류에 대한 페널티를 제어합니다. 정규화 강도와는 역관계입니다.

| C value | Effect | When to use |
|---------|--------|-------------|
| 0.001 - 0.01 | 넓은 마진, 많은 위반 허용 | 노이즈 데이터, 일반화를 원할 때 |
| 0.1 - 1.0 | 균형 | 좋은 시작 범위 |
| 10 - 1000 | 좁은 마진, 적은 위반 | 깨끗한 데이터, 높은 정확도가 필요할 때 |

튜닝 전략:
- C=1.0으로 시작
- 로그 스케일로 탐색: [0.001, 0.01, 0.1, 1, 10, 100, 1000]
- 교차검증으로 최선 값을 고름
- 최선 C가 범위 끝에 있으면 그 방향으로 범위를 확장

## gamma 튜닝 (RBF 커널)

Gamma는 단일 학습 점의 영향이 얼마나 멀리 미치는지 제어합니다. 가우시안의 폭을 정의합니다.

| gamma value | Effect | When to use |
|-------------|--------|-------------|
| Small (0.001) | 각 점이 넓은 영역에 영향. 매끄럽고 단순한 경계 | 과소적합 또는 특성이 적을 때 |
| Medium (auto: 1/n_features) | sklearn 기본값. 합리적인 시작점 | 일반 사용 |
| Large (10+) | 각 점이 근처 점에만 영향. 복잡하고 요철인 경계 | 과적합 위험 |

튜닝 전략:
- gamma="scale"로 시작 (1 / (n_features * X.var()), sklearn 기본값)
- 로그 스케일로 탐색: [0.001, 0.01, 0.1, 1, 10]
- 낮은 gamma + 높은 C는 과적합 경향
- 높은 gamma + 낮은 C는 과소적합 경향

## C와 gamma 공동 튜닝

C와 gamma는 상호작용합니다. 독립이 아니라 항상 함께 튜닝하세요.

권장 접근:
1. 거친 그리드 탐색: C in [0.01, 0.1, 1, 10, 100], gamma in [0.001, 0.01, 0.1, 1, 10] (25조합)
2. 최선 영역을 찾음
3. 그 주변에서 세밀 그리드 탐색 (예: C in [5, 10, 20, 50], gamma in [0.05, 0.1, 0.2])
4. 전 과정에서 5-겹 교차검증 사용

## 흔한 실수

- 고차원 희소 데이터에 RBF 커널 사용 (선형이 더 낫고 100배 빠름)
- 특성 스케일 잊기 (가장 흔한 단일 SVM 실수)
- 노이즈 데이터에서 C를 너무 높게 (경계를 배우는 대신 노이즈를 암기)
- 5만 샘플 초과 데이터셋에 커널 SVM 사용 (학습 시간이 감당 불가)
- C와 gamma를 함께 튜닝하지 않음 (서로 보상함)
- 다항 차수 5+를 기본으로 (과적합이 심함, 먼저 2 또는 3을 시도)

## 빠른 참고

| Kernel | When to use | Key parameters | Training complexity |
|--------|------------|----------------|-------------------|
| Linear | Text/TF-IDF, 많은 특성, 큰 데이터 | C only | 에포크당 O(n) |
| RBF | 범용, 10k 샘플 미만 | C, gamma | O(n^2)~O(n^3) |
| Polynomial | 알려진 다항 관계 | C, degree, coef0 | O(n^2)~O(n^3) |
| Sigmoid | 거의 쓸모없음 (2층 신경망과 동등) | C, gamma, coef0 | O(n^2)~O(n^3) |
