# SVM 커널 선택 가이드

SVM은 두 가지 선택으로 정의됩니다: 커널(결정 경계의 형태를 결정)과 정규화 매개변수(마진 폭과 분류 오류 간의 균형을 조절)입니다. 이들을 올바르게 설정하는 것이 무용한 모델과 강력한 모델의 차이입니다.

## 결정 체크리스트

1. 데이터가 선형 분리 가능(또는 이에 가깝)합니까?
   - 예: 선형 커널을 사용하세요. 더 빠르고 해석이 쉽습니다.
   - 아니요: 2단계로 이동하세요.

2. 특징(feature)과 샘플(sample)의 비율은 어떻게 되나요?
   - 특징 >> 샘플 (예: TF-IDF를 사용한 텍스트): 선형 커널을 사용하세요. 고차원 데이터는 종종 선형 분리 가능합니다. RBF는 복잡도를 높이지만 이득이 없습니다.
   - 샘플 >> 특징 (예: 10-50개 특징을 가진 표 데이터): RBF 커널이 기본 선택입니다.

3. 결정 경계가 매끄럽기를 기대하나요?
   - 매끄럽고 연속적인 경계: RBF 커널
   - 다항식 형태의 경계: 다항식 커널 (2차 또는 3차부터 시작하세요)
   - 도메인 지식이 특정 상호작용 항을 제안함: 일치하는 차수의 다항식 커널

4. 데이터셋의 크기는 얼마나 되나요?
   - 10,000 샘플 미만: 모든 커널이 작동하며, RBF가 안전한 기본값입니다
   - 10,000 ~ 100,000: 선형 커널 또는 LinearSVC (원형 공식화, 에포크당 O(n))
   - 100,000 초과: 커널 SVM을 사용하지 마세요. 선형 SVM, 그래디언트 부스팅, 또는 신경망으로 전환하세요.

5. 특징을 스케일링(scale)했나요?
   - SVM은 특징 스케일링이 필요합니다. 항상 피팅(fitting) 전에 표준화(평균 0, 분산 1)하세요. 스케일링되지 않은 특징은 마진 기하학을 왜곡합니다.

## 커널 선택 흐름도

```
Start
  |
  v
Features > 1000 or features >> samples?
  Yes --> Linear kernel (LinearSVC for speed)
  No  --> Dataset < 10k samples?
            Yes --> Try RBF first (best general-purpose kernel)
            No  --> Linear kernel (kernel SVMs are O(n^2) to O(n^3))
```

RBF가 잘 작동하지 않으면 다항식 2-3차를 시도해 보세요. 실패하면 문제가 SVM에 적합하지 않을 수 있습니다.

## C (정규화) 튜닝

C는 오분류에 대한 페널티를 제어합니다. 정규화 강도와 반비례합니다.

| C 값 | 효과 | 사용 시점 |
|---------|--------|-------------|
| 0.001 - 0.01 | 넓은 마진, 많은 위반 허용 | 잡음 있는 데이터, 일반화 원할 때 |
| 0.1 - 1.0 | 균형 잡힘 | 좋은 시작 범위 |
| 10 - 1000 | 좁은 마진, 적은 위반 | 깨끗한 데이터, 높은 정확도 필요할 때 |

튜닝 전략:
- C=1.0으로 시작해 보세요
- 로그 스케일에서 탐색하세요: [0.001, 0.01, 0.1, 1, 10, 100, 1000]
- 교차 검증으로 최적 값을 선택하세요
- 최적 C가 범위의 경계에 있다면, 그 방향으로 범위를 확장하세요

## Gamma (RBF 커널) 튜닝

Gamma는 단일 학습 포인트의 영향이 얼마나 멀리까지 미치는지 제어합니다. 가우시안의 폭을 정의합니다.

| gamma 값 | 효과 | 사용 시점 |
|-------------|--------|-------------|
| 작음 (0.001) | 각 포인트가 넓은 영역에 영향을 미침. 매끄럽고 단순한 경계 | 과소 적합(Underfitting)이거나 특징이 적을 때 |
| 중간 (auto: 1/n_features) | sklearn 기본값. 합리적인 시작점 | 일반적인 사용 |
| 큼 (10+) | 각 포인트가 가까운 포인트에만 영향을 미침. 복잡하고 구불구불한 경계 | 과적합(Overfitting) 위험 |

튜닝 전략:
- gamma="scale" (1 / (n_features * X.var()), sklearn 기본값)으로 시작해 보세요
- 로그 스케일에서 탐색하세요: [0.001, 0.01, 0.1, 1, 10]
- 낮은 gamma + 높은 C는 과적합(Overfitting) 경향이 있습니다
- 높은 gamma + 낮은 C는 과소 적합(Underfitting) 경향이 있습니다

## C와 gamma의 결합 튜닝

C와 gamma는 상호작용합니다. 항상 독립적으로가 아니라 함께 튜닝하세요.

권장 접근법:
1. 거친 그리드 탐색: C는 [0.01, 0.1, 1, 10, 100], gamma는 [0.001, 0.01, 0.1, 1, 10] (25개 조합)
2. 최적 영역을 찾으세요
3. 최적 영역 주변에서 미세 그리드 탐색 (예: C는 [5, 10, 20, 50], gamma는 [0.05, 0.1, 0.2])
4. 전체 과정에서 5-폴드 교차 검증(5-fold cross-validation)을 사용하세요

## 공통 실수

- 고차원 희소 데이터에 RBF 커널 사용 (선형이 더 좋고 100배 빠름)
- 특징 스케일링을 잊는 것 (가장 흔한 SVM 실수)
- 잡음이 많은 데이터에서 C를 너무 높게 설정하면 (경계를 학습하는 대신 잡음을 암기하게 됩니다)
- 5만 샘플 이상의 데이터셋에 커널 SVM을 사용하는 것 (학습 시간이 감당할 수 없을 정도로 길어집니다)
- C와 gamma를 함께 튜닝하지 않는 것 (두 매개변수가 서로를 보충합니다)
- 다항식 차수를 기본값인 5 이상으로 설정하는 것 (과적합이 심하게 발생하므로, 먼저 2 또는 3을 시도해 보세요)

## 빠른 참조

| 커널 | 사용 시점 | 주요 매개변수 | 학습 복잡도 |
|--------|------------|----------------|-------------------|
| 선형 | 텍스트/TF-IDF, 많은 특징, 대규모 데이터 | C만 | 에포크당 O(n) |
| RBF | 범용, 1만 샘플 미만 | C, gamma | O(n^2) ~ O(n^3) |
| 다항식 | 알려진 다항식 관계 | C, degree, coef0 | O(n^2) ~ O(n^3) |
| 시그모이드 | 거의 유용하지 않음 (2층 신경망과 동일) | C, gamma, coef0 | O(n^2) ~ O(n^3) |
