# 앙상블 방법 선택 가이드

앙상블은 여러 모델을 결합하여 단일 모델보다 더 나은 예측을 생성합니다. 핵심 질문은 항상 "어떤 종류의 앙상블을, 언제 사용할 것인가?"입니다.

## 의사 결정 체크리스트

1. 현재 모델의 주요 문제는 무엇인가요?
   - 높은 분산 (과적합): 배깅 (Random Forest)을 사용하세요
   - 높은 편향 (과소 적합): 부스팅 (Gradient Boosting, XGBoost)을 사용하세요
   - 둘 다 해당되거나 최대 정확도를 원한다면: 스태킹을 사용하세요

2. 데이터가 얼마나 많나요?
   - 1,000행 미만: Random Forest (강건하며 설정이 어렵지 않음)
   - 1,000 ~ 100,000: XGBoost 또는 LightGBM (테이블 데이터에 대해 전반적으로 최적)
   - 100,000 초과: LightGBM (가장 빠른 그래디언트 부스팅, 대규모 데이터를 잘 처리)

3. 튜닝에 얼마나 많은 시간을 투자할 수 있나요?
   - 최소: 기본 설정의 Random Forest (거의 항상 작동)
   - 중간: learning_rate=0.1인 XGBoost, 조기 종료로 n_estimators 튜닝
   - 최대: 베이지안 하이퍼파라미터 검색을 사용하는 LightGBM 또는 XGBoost

4. 해석 가능성이 필요하나요?
   - 예: 기능 중요도가 있는 단일 결정 트리 또는 작은 Random Forest
   - 부분: SHAP 값이 있는 그래디언트 부스팅
   - 아니요: 스태킹 또는 깊은 앙상블

5. 데이터가 잡음과 많은 이상치로 인해 노이즈가 많나요?
   - 예: Random Forest (배깅은 잡음에 강건함)
   - 아니요: 그래디언트 부스팅 (깨끗한 데이터에서 정확도를 더 높일 수 있음)

## 각 방법의 사용 시점

**Random Forest (배깅)**: 안전한 첫 번째 선택입니다. 부트스트랩 샘플로 많은 트리를 학습하고 평균냅니다. 편향을 증가시키지 않으면서 분산을 줄입니다. 중간 규모의 데이터에서는 과적합이 거의 불가능합니다. 최소한의 튜닝이 필요합니다: n_estimators=100-500으로 설정하고 기본값을 유지하세요.

**AdaBoost**: 샘플 재가중을 통한 순차적 부스팅. 단순한 기본 학습기(의사결정 스텀프)와 잘 작동합니다. 오분류된 포인트의 가중치를 높이기 때문에 이상치와 노이즈가 많은 레이블에 민감합니다. 실무에서는 대부분 그래디언트 부스팅으로 대체되었습니다.

**그래디언트 부스팅**: 각 새로운 트리를 현재 앙상블의 잔차에 적합시킵니다. 편향을 줄입니다. 테이블 데이터에 가장 강력한 방법입니다. 튜닝이 필요합니다: learning_rate, n_estimators, max_depth, min_child_weight, subsample.

**XGBoost**: 정규화, 2차 최적화, 시스템 수준 속도 향상을 적용한 그래디언트 부스팅. 결측값을 기본적으로 처리합니다. Kaggle 대회 및 테이블 데이터 기반 프로덕션 ML의 기본 선택지입니다.

**LightGBM**: 레벨 단위 성장 대신 잎 단위 성장을 사용하는 그래디언트 부스팅. 대규모 데이터셋에서 XGBoost보다 빠릅니다. 히스토그램 기반 분할을 사용합니다. 5만 행 이상의 데이터셋에 가장 적합합니다.

**CatBoost**: 범주형 특징을 기본적으로 처리하는 그래디언트 부스팅. 원-핫 인코딩이 필요 없습니다. 범주형 특징이 많을 때 유용합니다.

**스태킹**: 여러 다양한 기본 모델의 예측값을 입력으로 메타 학습기를 훈련합니다. 절대적인 최고 정확도가 필요하고 연산 자원이 충분할 때 사용하세요. 누수를 방지하기 위해 항상 교차 검증을 통해 기본 모델의 예측값을 생성하세요.

**투표**: 가장 단순한 앙상블. 하드 투표(다수 클래스) 또는 소프트 투표(확률 평균)를 사용합니다. 메타 학습기 없이 2~3개의 다양한 모델을 결합하는 빠른 방법입니다.

## 공통 실수

- 조기 종료 없이 그래디언트 부스팅을 사용하는 경우 (너무 많은 라운드를 실행하면 과적합됩니다)
- learning_rate를 너무 높게 설정하는 경우 (보통 0.3 이상이면 불안정해집니다)
- 그래디언트 부스팅의 max_depth를 튜닝하지 않는 경우 (기본값인 무제한 또는 매우 깊은 트리는 과적합됩니다)
- 모두 동일한 유형의 모델로 스태킹하는 경우 (스태킹의 핵심은 다양성입니다)
- 노이즈가 많은 데이터에 AdaBoost를 사용하는 경우 (이상치의 가중치가 라운드마다 점점 더 커집니다)
- 랜덤 포레스트가 과소 적합을 해결할 것으로 기대하는 경우 (랜덤 포레스트는 편향이 아닌 분산을 줄입니다)

## 방법별 튜닝 우선순위

**랜덤 포레스트:**
1. n_estimators: 100-500 (값이 클수록 성능이 나빠지는 경우는 거의 없으며, 단지 느려집니다)
2. max_depth: None (트리가 완전히 자라도록 허용) 또는 속도를 위해 10-20으로 제한
3. max_features: 분류에는 "sqrt", 회귀에는 "log2" 또는 n/3

**XGBoost / LightGBM:**
1. learning_rate: 0.01-0.3 (더 많은 트리를 위한 연산 자원이 있다면 낮은 값이 더 좋습니다)
2. n_estimators: 추측하는 대신 검증 세트에서 조기 종료(early stopping)를 사용하세요
3. max_depth: 3-8 (6으로 시작하세요)
4. min_child_weight / min_data_in_leaf: 1-20 (높은 값은 과적합(Overfitting)을 방지합니다)
5. subsample: 0.7-1.0
6. colsample_bytree: 0.7-1.0
7. reg_alpha (L1) 및 reg_lambda (L2): 0-10

## 빠른 참조

| 방법 | 감소 대상 | 속도 | 튜닝 노력 | 최적 용도 |
|--------|---------|-------|--------------|----------|
| 랜덤 포레스트(Random Forest) | 분산(Variance) | 빠름 | 낮음 | 잡음 있는 데이터, 빠른 기준선 |
| AdaBoost | 편향(Bias) | 빠름 | 낮음 | 단순한 기본 학습기, 깨끗한 데이터 |
| 그래디언트 부스팅(Gradient Boosting) | 편향(Bias) | 중간 | 높음 | 표 데이터, 대회 |
| XGBoost | 둘 다 | 빠름 | 높음 | 프로덕션 표 데이터 ML |
| LightGBM | 둘 다 | 가장 빠름 | 높음 | 대규모 데이터셋 (50k+ 행) |
| CatBoost | 둘 다 | 중간 | 중간 | 많은 범주형 특징 |
| 스태킹(Stacking) | 둘 다 | 느림 | 높음 | 최대 정확도, 다양한 모델 |
| 투표(Voting) | 분산(Variance) | 빠름 | 없음 | 2-3개 모델의 빠른 조합 |
