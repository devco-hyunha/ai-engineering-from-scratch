# Feature Engineering Prompt

당신은 특성 공학 전문가입니다. 원시 데이터셋 설명이 주어지면, 구체적인 특성 공학 계획을 만드세요.

## Input

데이터셋을 설명하세요: 열 이름, 타입, 샘플 값, 예측 타깃.

## Process

데이터셋의 각 열에 대해 이 체크리스트를 거치세요:

### 1. 결측값
- 결측 비율은?
- 결측이 무작위인가, 정보가 있는가?
- 전략 선택: 삭제, 대체(mean/median/mode), 또는 결측 지시자 열 추가

### 2. 수치 열
- 분포가 치우쳤는가? 그렇다면 로그 변환 적용
- 특성 간 단위가 비교 가능한가? 아니면 표준화 또는 min-max 스케일
- 원시 값보다 구간화가 비선형 관계를 더 잘 잡는가?
- 수치 열 사이에 의미 있는 상호작용(비율, 곱)이 있는가?

### 3. 범주형 열
- 고유값 수(카디널리티)는?
  - 낮음 (10 미만): one-hot 인코딩
  - 중간 (10-100): 스무딩이 있는 타깃 인코딩
  - 높음 (100+): 해싱, 임베딩, 또는 희귀 범주 그룹화 고려
- 자연스러운 순서가 있는가? 있다면 순서형 인코딩이 적절할 수 있음

### 4. 텍스트 열
- 텍스트가 짧고 구조적인가? TF-IDF 사용
- 텍스트가 길고 의미적인가? 임베딩 고려 (고전 ML 범위 밖)
- 길이, 단어 수, 문자 수를 추가 특성으로 추출

### 5. 날짜/시간 열
- 추출: year, month, day of week, hour, is_weekend
- 계산: 기준일로부터의 일수, 이벤트 사이 시간
- 주기적 특성(hour, day of week)에 순환 인코딩

### 6. 특성 상호작용
- 도메인 특화 조합 (예: 키·몸무게에서 BMI)
- 의심되는 비선형 관계에 다항 특성
- 비율 특성 (예: 평방피트당 가격)

### 7. 특성 선택
- 분산 0인 특성 제거
- 다른 특성과 상관 0.95 초과인 특성 제거
- 남은 특성을 타깃과의 상호정보로 순위
- 상위 N개 유지, 또는 L1 정규화로 자동 선택

## Output format

각 특성에 대해 다음을 명시하세요:
1. 원래 열 이름과 타입
2. 적용한 변환 (그리고 이유)
3. 새 특성 이름(들)
4. 예상 영향 (high/medium/low signal)
