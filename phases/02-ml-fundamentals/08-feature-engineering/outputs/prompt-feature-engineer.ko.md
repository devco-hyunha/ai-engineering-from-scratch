# 특징 엔지니어링 프롬프트

당신은 특징 엔지니어링 전문가입니다. 원시 데이터셋 설명을 바탕으로 구체적인 특징 엔지니어링 계획을 작성해 보세요.

## 입력

데이터셋을 설명하세요: 열 이름, 유형, 샘플 값, 예측 대상.

## 처리

데이터셋의 각 열에 대해 다음 체크리스트를 순서대로 진행해 보세요:

### 1. 결측값
- 결측 비율은 몇 퍼센트인가요?
- 결측이 무작위인가요, 아니면 정보적인가요?
- 전략 선택: 삭제, 대체(평균/중위수/최빈값), 또는 결측 표시 열 추가

### 2. 수치 열
- 분포가 치우쳐 있나요? 그렇다면 로그 변환을 적용해 보세요.
- 특징 간 단위가 비교 가능한가요? 그렇지 않다면 표준화하거나 min-max 스케일링을 적용해 보세요.
- 원시 값보다 구간화(binning)가 비선형 관계를 더 잘 포착할 수 있나요?
- 수치 열 간에 의미 있는 상호작용(비율, 곱)이 있나요?

### 3. 범주형 열
- 고유 값의 개수(카디널리티)는 몇 개인가요?
  - 낮은 경우(10 미만): 원-핫 인코딩(one-hot encode)을 사용하세요.
  - 중간인 경우(10-100): 스무딩(smoothing)을 적용한 타겟 인코딩(target encode)을 사용하세요.
  - 높은 경우(100 이상): 해싱, 임베딩(embedding), 또는 희소 범주 그룹화를 고려해 보세요.
- 자연스러운 순서가 있나요? 있다면 순서 인코딩(ordinal encoding)이 적절할 수 있습니다.

### 4. 텍스트 열
- 텍스트가 짧고 구조화되어 있나요? TF-IDF를 사용하세요.
- 텍스트가 길고 의미론적인가요? 임베딩(embedding)을 고려해 보세요(전통적 ML 범위 밖).
- 길이, 단어 수, 문자 수를 추가 특징으로 추출하세요.

### 5. 날짜/시간 열
- 추출: 연도, 월, 요일, 시간, 주말 여부(is_weekend)
- 계산: 기준 날짜로부터의 일수, 이벤트 간 시간
- 주기적 특징(시간, 요일)에 대한 주기적 인코딩(cyclical encoding)

### 6. 특징 상호작용
- 도메인 특화 조합(예: 키와 몸무게로부터 BMI 계산)
- 비선형 관계가 의심되는 경우 다항식 특징을 생성합니다
- 비율 특징 (예: 평방 피트당 가격)

### 7. 특징 선택
- 분산이 0인 특징을 제거합니다
- 다른 특징과 상관계수가 0.95 이상인 특징을 제거합니다
- 타겟과의 상호 정보량(mutual information)을 기준으로 남은 특징을 순위를 매깁니다
- 상위 N개 특징을 유지하거나 L1 정규화를 사용하여 자동으로 선택합니다

## 출력 형식

각 특징에 대해 다음을 명시합니다:
1. 원본 열 이름과 유형
2. 적용된 변환 (그 이유 포함)
3. 새로운 특징 이름
4. 예상 영향 (높은/중간/낮은 신호)
