# 회귀 전략 가이드

회귀는 연속적인 값을 예측합니다. 올바른 접근법은 특징(features)과 타겟(target) 간의 관계, 특징의 수, 과적합(Overfitting) 위험에 따라 달라집니다.

## 의사 결정 체크리스트

1. 특징(features)과 타겟(target) 간의 관계가 대략 선형인가요?
   - 예: 일반적인 선형 회귀로 시작하세요
   - 아니요: 다항 특징(polynomial features)이나 비선형 모델을 시도해 보세요

2. 샘플(sample)에 비해 특징(features)이 몇 개 있나요?
   - 특징이 적고 샘플이 많은 경우: 일반적인 선형 회귀가 잘 작동합니다
   - 특징이 많고 샘플이 적은 경우: 정규화(regularization)를 사용하세요 (Ridge 또는 Lasso)
   - 샘플보다 특징이 많은 경우: 특징(features)을 선택하려면 Lasso (L1)를 사용하거나, 모든 가중치(weight)를 축소하려면 Ridge (L2)를 사용하세요

3. 해석 가능성(interpretability)이 필요하나요?
   - 예: 특징(features)이 적은 선형 회귀를 사용하거나, 자동 특징(features) 선택을 위해 Lasso를 사용하세요
   - 아니요: 다항 특징(polynomial features)을 사용하거나, 트리 기반 모델이나 신경망으로 이동하세요

4. 데이터셋이 작은가요 (10,000행 미만)?
   - 속도를 위해 정규 방정식(normal equation, closed-form solution)을 사용하세요
   - 신뢰할 수 있는 평가를 위해 교차 검증(cross-validation)이 필수입니다

5. 데이터셋이 큰가요 (수백만 행)?
   - 확률적 경사 하강법 (SGD)(Stochastic Gradient Descent (SGD)) 또는 미니배치(mini-batch) 경사 하강법을 사용하세요
   - O(n^3) 행렬 역전(matrix inversion) 때문에 정규 방정식(normal equation)이 너무 느립니다

## 각 접근법을 사용할 때

**일반 선형 회귀**: 모든 회귀 작업의 기준선입니다. 여기서 시작하세요. R-squared가 허용 범위 내이고 모델이 단순하다면 여기서 멈추세요.

**다항 회귀**: 산점도(scatter plot)가 선이 아닌 곡선을 보여줍니다. 차수(degree) 2로 시작하세요. 검증(validation) 성능으로 정당화되는 경우에만 차수를 높이세요. 차수 > 5는 거의 항상 과적합(Overfitting)됩니다.

**Ridge 회귀 (L2)**: 많은 상관된 특징(features)이 있는 경우. 모든 가중치(weight)는 0으로 축소되지만 정확히 0이 되지는 않습니다. 모든 특징(features)이 기여한다고 믿을 때 적합합니다.

**Lasso 회귀 (L1)**: 많은 특성이 있고 그중 몇 개만 중요하다고 의심되는 경우. Lasso는 관련 없는 특성의 가중치를 정확히 0으로 만들어 자동 특성 선택을 수행합니다.

**Elastic Net**: L1 및 L2 페널티를 결합합니다. 많은 상관된 특성이 있고 일부 특성 선택을 원할 때 사용하세요.

## 공통 실수

- 경사 하강법 전에 특성 스케일링을 건너뛰는 것 (수렴이 극도로 느려집니다)
- 하이퍼파라미터 튜닝에 테스트 세트 성능을 사용하는 것 (검증 세트 또는 교차 검증 사용)
- 검증 오차를 확인하지 않고 고차 다항식을 피팅하는 것 (학습 R^2는 차수가 증가하면 항상 증가합니다)
- 잔차 플롯을 무시하는 것 (잔차에 패턴이 있으면 R^2는 오해를 불러일으킬 수 있습니다)
- R^2를 유일한 지표로 취급하는 것 (잔차 분포, MAE 및 도메인별 임계값을 확인하세요)

## 빠른 참조

| 방법 | 사용 시점 | 정규화 | 특성 선택 |
|--------|------------|---------------|-------------------|
| OLS | 기준선, 적은 특성 | 없음 | 수동 |
| Ridge | 많은 특성, 모두 관련 있음 | L2 (축소) | 없음 |
| Lasso | 많은 특성, 몇 개만 관련 있음 | L1 (0으로 만듦) | 자동 |
| Elastic Net | 많은 상관된 특성 | L1 + L2 | 부분적 |
| 다항식 | 비선형 관계 | Ridge/Lasso를 추가 적용 | 차수 수동 선택 |
