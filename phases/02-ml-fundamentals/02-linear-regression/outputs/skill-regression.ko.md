# 회귀 전략 가이드 (Regression Strategy Guide)

회귀는 연속 값을 예측합니다. 올바른 접근은 특성과 타깃 사이의 관계, 특성 수, 과적합 위험에 달려 있습니다.

## 결정 체크리스트

1. 특성과 타깃 사이의 관계가 대략 선형인가?
   - 예: 일반 선형 회귀로 시작
   - 아니오: 다항 특성 또는 비선형 모델을 시도

2. 샘플 대비 특성이 얼마나 많은가?
   - 특성 적음, 샘플 많음: 일반 선형 회귀로 충분
   - 특성 많음, 샘플 적음: 정규화 사용 (Ridge 또는 Lasso)
   - 특성이 샘플보다 많음: 특성 선택을 위해 Lasso(L1), 또는 모든 가중치를 줄이기 위해 Ridge(L2)

3. 해석 가능성이 필요한가?
   - 예: 특성이 적은 선형 회귀, 또는 자동 특성 선택을 위한 Lasso
   - 아니오: 다항 특성, 또는 트리 기반 모델이나 신경망으로 이동

4. 데이터셋이 작은가 (10,000행 미만)?
   - 속도를 위해 정규방정식(닫힌 형태 해) 사용
   - 신뢰할 수 있는 평가를 위해 교차검증이 필수

5. 데이터셋이 큰가 (수백만 행)?
   - 확률적 경사하강법(SGD) 또는 미니배치 경사하강법 사용
   - 정규방정식은 O(n^3) 행렬 역산 때문에 너무 느림

## 각 접근을 언제 쓸까

**일반 선형 회귀 (Ordinary Linear Regression)**: 모든 회귀 과제의 베이스라인. 여기서 시작하세요. R-squared가 충분하고 모델이 단순하면 여기서 멈추세요.

**다항 회귀 (Polynomial Regression)**: 산점도가 직선이 아니라 곡선을 보일 때. 2차부터 시작하세요. 검증 성능으로 정당화될 때만 올리세요. 차수 > 5는 거의 항상 과적합합니다.

**Ridge 회귀 (L2)**: 상관된 특성이 많을 때. 모든 가중치가 0 쪽으로 줄어들지만 정확히 0이 되지는 않습니다. 모든 특성이 기여한다고 믿을 때 좋습니다.

**Lasso 회귀 (L1)**: 특성이 많고 일부만 중요하다고 의심할 때. Lasso는 무관한 특성 가중치를 정확히 0으로 만들어 자동 특성 선택을 수행합니다.

**Elastic Net**: L1과 L2 페널티를 결합합니다. 상관된 특성이 많고 어느 정도의 특성 선택을 원할 때 쓰세요.

## 흔한 실수

- 경사하강법 전에 특성 스케일링을 건너뛰기 (수렴이 극도로 느려짐)
- 하이퍼파라미터 조정에 테스트 세트 성능을 사용 (검증 세트 또는 교차검증을 사용)
- 검증 오차를 확인하지 않고 고차 다항식을 맞춤 (학습 R^2는 차수와 함께 항상 증가)
- 잔차 플롯을 무시 (잔차에 패턴이 있으면 R^2가 오해를 줄 수 있음)
- R^2를 유일한 지표로 취급 (잔차 분포, MAE, 도메인별 임계값도 확인)

## 빠른 참고

| Method | When to use | Regularization | Feature selection |
|--------|------------|---------------|-------------------|
| OLS | 베이스라인, 특성 적음 | None | Manual |
| Ridge | 특성 많음, 모두 관련 | L2 (shrink) | No |
| Lasso | 특성 많음, 소수만 관련 | L1 (zero out) | Automatic |
| Elastic Net | 상관된 특성 많음 | L1 + L2 | Partial |
| Polynomial | 비선형 관계 | Ridge/Lasso를 위에 추가 | Manual degree choice |
