# 분류 베이스라인 가이드 (Classification Baseline Guide)

복잡한 모델을 시도하기 전에, 로지스틱 회귀로 베이스라인을 잡으세요. 수 초 만에 학습하고, 확률을 내며, 완전히 해석 가능합니다. 의외로 많은 실무 문제는 더 화려한 것이 필요 없습니다.

## 결정 체크리스트

1. 결정 경계가 선형일 가능성이 높은가?
   - 예: 로지스틱 회귀로 충분할 가능성이 큼
   - 아니오: 그래도 개선을 측정할 베이스라인으로 원함

2. 특성이 몇 개인가?
   - 50 미만: 표준 로지스틱 회귀로 충분
   - 50에서 10,000: L2 정규화(Ridge) 추가
   - 10,000 초과(예: TF-IDF 텍스트 특성): L1 정규화(Lasso) 또는 LinearSVC 사용

3. 데이터셋이 불균형한가?
   - 5:1 미만: 조정 없이 괜찮음
   - 5:1에서 50:1: sklearn에서 `class_weight="balanced"` 사용
   - 50:1 초과: 클래스 가중치와 적절한 지표(precision, recall, 또는 F1)를 함께 사용

4. 특성이 서로 다른 스케일인가?
   - 로지스틱 회귀 전에 항상 표준화하세요. 경사 기반 최적화를 쓰므로, 스케일되지 않은 특성은 수렴을 느리게 하거나 결정 경계를 왜곡합니다.

5. 결측값이 있는가?
   - 학습 전에 대체(impute)하세요. 로지스틱 회귀는 NaN을 다룰 수 없습니다.
   - 수치 열은 중앙값, 범주형은 최빈값 대체를 쓰세요.

## 로지스틱 회귀로 충분할 때

- 특성 관계가 대체로 선형인 이진 분류
- 클래스 라벨뿐 아니라 확률 출력이 필요할 때
- 해석 가능성이 요구될 때(표준화 후 계수가 특성 중요도의 방향과 상대 크기를 나타냄)
- 학습 데이터가 작을 때(수백~수천 샘플)
- 실시간 서빙용 빠른 모델이 필요할 때(추론 시 단일 내적)
- 규제·컴플라이언스가 설명 가능성을 요구할 때

## 업그레이드할 때

- 특성 공학을 시도했는데도 정확도가 목표보다 한참 아래에 정체
- 특성과 타깃의 관계가 분명히 비선형(잔차 플롯 확인)
- 큰 표 데이터(1만+ 행): 그래디언트 부스팅(XGBoost 또는 LightGBM) 시도
- 다항 특성으로도 잡지 못하는 복잡한 특성 상호작용
- 이미지·텍스트·시퀀스 데이터: 원시 입력에 로지스틱 회귀는 동작하지 않음

## 분류 베이스라인 전처리 단계

1. **학습/테스트 분할**을 전처리보다 먼저. 데이터 누수를 막습니다.
2. **결측값 처리**: 수치는 중앙값, 범주형은 최빈값 대체.
3. **범주형 인코딩**: 카디널리티가 낮으면(10값 미만) 원-핫, 높으면 타깃 인코딩. 타깃 인코딩은 학습 폴드에서만 fit(누수 방지를 위해 out-of-fold 인코딩 사용).
4. **수치 스케일**: StandardScaler(평균 0, 분산 1). 학습에 fit, 양쪽에 transform.
5. **로지스틱 회귀 fit**: `C=1.0`(기본 정규화).
6. **평가**: 혼동 행렬, precision, recall, F1. 정확도만 보지 말 것.
7. **임계값 조정**: 기본 0.5가 최적인 경우는 드묾. 0.1에서 0.9를 훑고 precision/recall 우선순위에 맞는 임계값을 고르세요.

## 흔한 실수

- 불균형 데이터에서 정확도만 평가(다수 클래스를 예측하는 모델이 점수는 높지만 쓸모없음)
- 특성 스케일 잊기(스케일되지 않은 로지스틱 회귀는 느리게 학습하고 더 나쁜 해로 수렴)
- 결정 임계값을 테스트 세트로 조정(검증 또는 교차검증 사용)
- 베이스라인을 건너뛰고 XGBoost로 직행(해석 가능성을 잃고 기준점이 없음)
- 다중공선성 미점검(고상관 특성이 계수 분산을 부풀림)

## 빠른 참고

| Scenario | Model | Regularization | Key setting |
|----------|-------|---------------|-------------|
| 특성 적음, 해석 가능 | LogisticRegression | L2 (default) | C=1.0 |
| 특성 많음, 일부 무관 | LogisticRegression | L1 | penalty="l1", solver="saga" |
| 고차원 희소(텍스트) | SGDClassifier | L1 or ElasticNet | loss="log_loss" |
| 불균형 클래스 | LogisticRegression | L2 | class_weight="balanced" |
| 확률 필요 | LogisticRegression | L2 | predict_proba() |
| 클래스 라벨만 필요 | LinearSVC | L2 | 큰 데이터에서 LR보다 빠름 |
