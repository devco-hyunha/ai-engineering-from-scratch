# 클러스터링 알고리즘 선택 가이드

클러스터링에는 단 하나의 최적 알고리즘이 없습니다. 올바른 선택은 클러스터의 형태, 클러스터 수를 알고 있는지, 데이터에 잡음이 얼마나 많은지, 그리고 데이터셋의 크기에 따라 달라집니다.

## 의사결정 체크리스트

1. 클러스터 수를 알고 있나요?
   - 예: K-Means 또는 GMM
   - 아니요: DBSCAN (클러스터를 자동으로 찾음) 또는 계층적 클러스터링 (덴드로그램을 다양한 수준에서 절단)

2. 클러스터의 형태는 어떤가요?
   - 대략적으로 구형 (블롭 형태): K-Means
   - 크기가 다른 타원형: GMM
   - 임의의 형태 (초승달, 링, 체인): DBSCAN
   - 중첩되거나 계층적: 계층적 클러스터링

3. 데이터에 잡음이나 이상치가 있나요?
   - 예: DBSCAN (잡음 포인트를 명시적으로 라벨링) 또는 GMM (확률이 낮은 포인트는 이상치)
   - 아니요: K-Means가 적합합니다

4. 소프트 할당(확률)이 필요 있나요?
   - 예: GMM는 각 클러스터에 대해 P(cluster | 데이터 포인트)를 제공합니다
   - 아니요: K-Means 또는 DBSCAN은 하드 할당을 제공합니다

5. 데이터셋의 크기는 얼마나 되나요?
   - 10,000 미만: 모든 알고리즘이 작동합니다
   - 10,000 ~ 1,000,000: K-Means (빠름), Mini-Batch K-Means (더 빠름)
   - 1,000,000 초과: Mini-Batch K-Means 또는 BIRCH. 계층적 클러스터링은 너무 느립니다.

## 각 접근법을 사용할 때

**K-Means**: 기본 시작점. 빠름(O(n * k * iterations)), 단순하며 많은 문제에 충분히 적합합니다. K를 선택하기 위해 팔꿈치 방법(elbow method)이나 실루엣 점수(silhouette score)를 사용하세요. 한계: 구형 클러스터를 가정하며, 초기화에 민감합니다(K-Means++를 사용하거나 여러 번 실행하세요), 다양한 크기의 클러스터를 잘 처리하지 못합니다.

**DBSCAN**: 임의의 형태의 클러스터를 발견하고 이상치를 자동으로 감지하는 데 가장 적합합니다. 두 개의 매개변수: eps (이웃 반경)과 min_samples (최소 밀도)를 사용합니다. K를 지정할 필요가 없습니다. 한계점: 클러스터의 밀도가 매우 다르면 성능이 떨어지며, eps 튜닝이 어려울 수 있습니다. eps를 추정하기 위해 k-거리 플롯을 사용해 보세요: 각 점의 k번째 최근접 이웃까지의 거리를 계산하고, 정렬한 후, 팔꿈치(elbow)를 찾아보세요.

**계층적(Agglomerative)**: 병합 트리를 구축합니다. 여러 세분화 수준에서 클러스터 구조를 탐색할 때 유용합니다 (덴드로그램을 다양한 높이에서 잘라보세요). Ward 연결 방식은 컴팩트한 클러스터에 가장 잘 작동합니다. 단일 연결 방식은 길쭉한 클러스터를 찾지만 잡음에 민감합니다. 한계점: O(n^2) 메모리와 O(n^3) 시간이 필요하므로 대규모 데이터셋에는 실용적이지 않습니다.

**GMM (가우시안 혼합 모델)(Gaussian Mixture Models)**: 확률적 할당을 사용하는 소프트 클러스터링입니다. 각 클러스터를 자체 평균과 공분산을 가진 가우시안 분포로 모델링합니다. 클러스터가 타원형이거나 겹칠 때 K-Means보다 더 좋습니다. 구성 요소의 수를 선택하기 위해 BIC (베이지안 정보 기준)(Bayesian Information Criterion)을 사용해 보세요. 한계점: 가우시안 분포를 가정하며, 비볼록 형태에서는 실패할 수 있고, 초기화에 민감합니다.

## 클러스터 품질 평가 (레이블 없음)

| 지표 | 측정 내용 | 범위 | 사용 시점 |
|--------|-----------------|-------|----------|
| 실루엣 점수 | 응집력 대 분리도 | -1 ~ 1 (높을수록 좋음) | K 값이나 알고리즘 비교 |
| 관성 (클러스터 내 SS) | 클러스터의 밀집도 | 0 ~ 무한대 (낮을수록 좋음) | K-Means의 팔꿈치 방법 |
| BIC / AIC | 복잡도 페널티가 포함된 모델 적합도 | 낮을수록 좋음 | GMM 구성 요소 수 선택 |
| Calinski-Harabasz 지수 | 군간 분산 대 군내 분산의 비율 | 높을수록 좋음 | 빠른 비교 |
| Davies-Bouldin 지수 | 클러스터 간 평균 유사성 | 낮을수록 좋음 | 겹치는 클러스터에 페널티 부여 |

## 공통 실수

- 특징을 스케일링하지 않고 K-Means를 실행하는 것 (더 큰 스케일의 특징이 거리 계산에 지배적으로 영향을 미침)
- 실제 데이터가 고차원일 때 2D로 데이터를 눈으로 보고 K를 선택하는 것 (실루엣 점수를 사용해 보세요)
- 비구형 클러스터에 K-Means를 사용하는 것 (초승달이나 링 형태의 데이터는 DBSCAN이 필요합니다)
- DBSCAN의 eps를 너무 크게 설정하면(모든 데이터가 하나의 클러스터로 묶임) 또는 너무 작게 설정하면(모든 데이터가 잡음으로 처리됨) 문제가 발생합니다.
- 클러스터 레이블을 정답(ground truth)으로 취급하지 마세요. 클러스터링은 탐색적이며, 도메인 지식을 통해 검증해야 합니다.
- 20,000개 이상의 포인트가 있는 데이터셋에 계층적 클러스터링을 실행하지 마세요. 메모리와 시간이 급격히 증가합니다.
