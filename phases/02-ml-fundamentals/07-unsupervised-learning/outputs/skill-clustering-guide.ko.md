# 클러스터링 알고리즘 선택 가이드

클러스터링에 단일 최선 알고리즘은 없습니다. 올바른 선택은 클러스터 형태, 클러스터 수를 아는지, 데이터에 노이즈가 얼마나 있는지, 데이터셋이 얼마나 큰지에 달립니다.

## 결정 체크리스트

1. 클러스터 수를 아는가?
   - 예: K-Means 또는 GMM
   - 아니오: DBSCAN(클러스터를 자동으로 찾음), 또는 계층적(덴드로그램을 다른 수준에서 자름)

2. 클러스터 형태는?
   - 대략 구형(덩어리형): K-Means
   - 크기가 다른 타원형: GMM
   - 임의 형태(초승달, 고리, 사슬): DBSCAN
   - 중첩 또는 계층적: 계층적 클러스터링

3. 데이터에 노이즈나 이상치가 있는가?
   - 예: DBSCAN(노이즈 점을 명시적으로 라벨) 또는 GMM(저확률 점이 이상치)
   - 아니오: K-Means로 충분

4. 소프트 할당(확률)이 필요한가?
   - 예: GMM이 각 클러스터에 대해 P(cluster | data point)를 줌
   - 아니오: K-Means 또는 DBSCAN이 하드 할당을 줌

5. 데이터셋이 얼마나 큰가?
   - 10,000 미만: 어떤 알고리즘이든 동작
   - 10,000 ~ 1,000,000: K-Means(빠름), Mini-Batch K-Means(더 빠름)
   - 1,000,000 초과: Mini-Batch K-Means 또는 BIRCH. 계층적은 너무 느림.

## 각 접근을 언제 쓸까

**K-Means**: 기본 출발점. 빠르고(O(n * k * iterations)), 단순하며, 많은 문제에 충분합니다. K를 고르려면 엘보우 방법이나 실루엣 점수를 쓰세요. 한계: 구형 클러스터를 가정하고, 초기화에 민감하며(K-Means++를 쓰거나 여러 번 실행), 크기가 다른 클러스터를 잘 다루지 못합니다.

**DBSCAN**: 임의 형태의 클러스터를 발견하고 이상치를 자동으로 탐지하는 데 최선입니다. 파라미터 두 개: eps(이웃 반경)와 min_samples(최소 밀도). K를 지정할 필요가 없습니다. 한계: 밀도가 매우 다른 클러스터에서는 고전하고, eps 튜닝이 까다로울 수 있습니다. eps 추정에는 k-거리 플롯을 쓰세요: 각 점의 k번째 최근접 이웃까지의 거리를 계산하고, 정렬한 뒤 엘보우를 찾습니다.

**계층적 (응집형)**: 병합 트리를 만듭니다. 여러 세분성에서 클러스터 구조를 탐색하고 싶을 때 유용합니다(덴드로그램을 다른 높이에서 자름). Ward 연결은 조밀한 클러스터에 가장 잘 맞습니다. 단일 연결은 길쭉한 클러스터를 찾지만 노이즈에 민감합니다. 한계: O(n^2) 메모리와 O(n^3) 시간이라 큰 데이터셋에는 비현실적입니다.

**GMM (가우시안 혼합 모델)**: 확률적 할당이 있는 소프트 클러스터링. 각 클러스터를 자체 평균·공분산을 가진 가우시안 분포로 모델링합니다. 클러스터가 타원형이거나 겹칠 때 K-Means보다 낫습니다. 성분 수는 BIC(Bayesian Information Criterion)로 고르세요. 한계: 가우시안 분포를 가정하고, 비볼록 형태에서 실패할 수 있으며, 초기화에 민감합니다.

## 클러스터 품질 평가 (라벨 없음)

| Metric | What it measures | Range | Use when |
|--------|-----------------|-------|----------|
| Silhouette score | 응집 vs 분리 | -1 ~ 1 (높을수록 좋음) | K 값이나 알고리즘 비교 |
| Inertia (within-cluster SS) | 클러스터 조밀도 | 0 ~ inf (낮을수록 좋음) | K-Means용 엘보우 방법 |
| BIC / AIC | 복잡도 페널티가 있는 모델 적합 | 낮을수록 좋음 | GMM 성분 수 선택 |
| Calinski-Harabasz index | 그룹 간 대 그룹 내 분산 비율 | 높을수록 좋음 | 빠른 비교 |
| Davies-Bouldin index | 클러스터 간 평균 유사도 | 낮을수록 좋음 | 겹치는 클러스터에 페널티 |

## 흔한 실수

- 특성을 스케일하지 않고 K-Means 실행 (스케일이 큰 특성이 거리 계산을 지배)
- 실제 데이터가 고차원인데 2D로 눈으로 보고 K를 고름 (실루엣 점수를 사용)
- 비구형 클러스터에 K-Means 사용 (초승달·고리형 데이터는 DBSCAN 필요)
- DBSCAN eps를 너무 크게(전부 한 클러스터) 또는 너무 작게(전부 노이즈) 설정
- 클러스터 라벨을 정답처럼 취급 (클러스터링은 탐색적임; 도메인 지식으로 검증)
- 20,000점 넘는 데이터셋에 계층적 클러스터링 실행 (메모리와 시간이 폭발)
