# 기능 선택 전략

올바른 기능 선택 방법을 선택하고 적용하기 위한 빠른 참조입니다.

## 1단계: 정리부터 시작하기

어떤 방법을 적용하기 전에, 명백히 쓸모없는 기능을 제거하세요:

- **상수 기능**: 분산 = 0. 제거하세요.
- **준상수 기능**: 분산 < 0.01 (또는 설정한 임계값). 제거하세요.
- **중복 기능**: 동일한 열. 하나만 남기고 나머지는 제거하세요.
- **ID 열**: 행마다 고유하며, 일반화 가능한 정보를 담고 있지 않습니다. 제거하세요.

이 작업은 몇 초가 소요되며, 지저분한 실제 데이터셋에서 기능의 10-30%를 제거할 수 있습니다.

## 2단계: 상황에 따라 방법 선택하기

### 빠른 의사결정 트리

1. **50개 미만의 기능?** 상호 정보(Mutual Information) 순위 매기기부터 시작하세요. 상위 K개를 유지하세요.
2. **50 - 500개의 기능?** 먼저 분산 임계값을 사용하세요. 선형 모델을 사용한다면 L1 (Lasso)을, 트리 기반 모델을 사용한다면 트리 중요도를 사용하세요.
3. **500개 이상의 기능?** 방법들을 연결하세요: 분산 임계값 -> 상호 정보 필터 (상위 50%) -> 남은 기능에 대한 RFE.
4. **해석 가능성이 필요합니까?** L1 정규화는 정확한 0/0이 아닌 값을 제공합니다. 트리 중요도는 순위 매겨진 점수를 제공합니다.
5. **비선형 관계를 포착해야 합니까?** 상호 정보나 트리 기반 중요도를 사용하세요. L1은 피하세요 (선형 전용).
6. **기능 간 상호작용이 필요합니까?** RFE나 트리 기반 중요도를 사용하세요. 필터 방법은 상호작용을 놓칩니다.

### 방법 참조

| 방법 | 사용 시점 | 피해야 할 시점 |
|--------|------------|---------------|
| 분산 임계값 | 항상, 첫 단계로 | 절대 건너뛰지 마세요 |
| 상호 정보 | 빠른 순위 매기기, 비선형 관계 | 기능 간 상호작용 탐지가 필요할 때 |
| RFE | 철저한 선택, 중간 규모의 기능 수 | 매우 비싼 모델, 1000개 이상의 기능 |
| L1 / Lasso | 선형 모델, 빠른 내장형 선택 | 비선형 문제, 높은 상관관계를 가진 기능 |
| 트리 중요도 | 비선형 관계, 특징 상호작용 | 고카디널리티 특징에 편향됨 |
| 순열 중요도 | 모델에 독립적인 검증, 최종 확인 | 초기 선별에는 너무 느림 |

## 3단계: 선택된 특징 검증하기

- 선택된 특징과 모든 특징을 사용했을 때의 모델 성능을 비교해 보세요
- 단일 훈련/테스트 분할이 아닌 교차 검증(Cross-Validation)을 사용하세요
- 성능이 1-2% 이상 떨어지면 유용한 특징을 제거했을 수 있습니다
- 성능이 개선되면 잡음 특징을 성공적으로 제거한 것입니다

## 4단계: 흔한 함정 처리하기

### 상관된 특징
- L1은 상관된 그룹에서 임의로 하나를 선택하고 나머지는 0으로 만듭니다
- 먼저 상관 행렬을 계산하고 상관된 특징 중 어떤 것을 유지할지 결정하세요
- 트리 중요도는 상관된 특징들 사이에 중요도를 분산시킵니다

### 데이터 누수(Data Leakage)
- 훈련 데이터에만 특징 선택을 적용하세요
- 테스트 데이터에도 동일한 선택을 적용하세요
- 교차 검증에서는 각 폴드 내부에서 특징 선택이 이루어져야 합니다

### 특징 선택에 대한 과적합(Overfitting)
- RFE를 너무 많은 반복으로 수행하면 훈련 세트에 과적합될 수 있습니다
- 선택에 사용된 데이터가 아닌 홀드아웃 데이터로 검증하세요
- 더 견고한 결과를 위해 안정성 선택(서브샘플 반복)을 사용하세요

## 5단계: 프로덕션 체크리스트

- [ ] 분산 임계값(Variance Threshold)을 첫 번째 필터로 적용
- [ ] 특징 선택이 훈련 데이터에만 적용됨
- [ ] 선택된 특징이 문서화됨 (이름, 사용된 방법, 점수)
- [ ] 성능 비교 완료: 선택된 특징 vs 모든 특징
- [ ] 단일 분할 평가가 아닌 교차 검증(Cross-Validation) 수행
- [ ] 특징 선택이 훈련 파이프라인에 통합됨 (수동으로 수행하지 않음)
- [ ] 특징 드리프트에 대한 모니터링이 설정됨 (선택된 특징이 낡아질 수 있음)
