# 불균형 데이터 전략

불균형 분류를 처리하기 위한 결정 체크리스트입니다. 이 순서를 따라가며 문제에 맞는 올바른 접근법을 선택해 보세요.

## 1단계: 불균형 정도 측정

- 클래스별 샘플 수 계산
- 불균형 비율 계산 (다수 클래스 / 소수 클래스)
- 경미: 비율 < 3:1 (예: 70/30)
- 중간: 비율 3:1 ~ 20:1 (예: 95/5)
- 심각: 비율 > 20:1 (예: 99/1)

## 2단계: 올바른 지표 선택

불균형 데이터셋에서는 정확도보다 정밀도/재현율/F1을 선호합니다. 문제에 따라 선택하세요:

| 상황 | 주요 지표 | 보조 지표 |
|-----------|---------------|-----------------|
| 양성 누락이 매우 비용이 큼 (사기, 질병) | 재현율 | F2 점수 |
| 오탐이 비용이 큼 (스팸 필터, 추천) | 정밀도 | F0.5 점수 |
| 둘 다 대략적으로 중요함 | F1 점수 | MCC |
| 단일 랭킹 지표가 필요함 | AUPRC | AUC-ROC |
| 데이터셋 간 비교가 필요함 | MCC | AUPRC |

## 3단계: 재균형 전략 선택

### 불균형 심각도에 따라

| 불균형 | 먼저 시도 | 두 번째 시도 | 피해야 할 것 |
|-----------|-----------|------------|-------|
| 경미 (< 3:1) | 클래스 가중치 | 임계값 튜닝 | 오버샘플링 (불필요) |
| 중간 (3:1 ~ 20:1) | SMOTE + 클래스 가중치 | 임계값 튜닝 추가 | 언더샘플링 (데이터 손실 과다) |
| 심각 (> 20:1) | SMOTE + 클래스 가중치 + 임계값 | 균형 잡힌 배깅(bagging) 앙상블 | 언더샘플링 단독 |

### 데이터셋 크기에 따라

| 데이터셋 크기 | 선호 전략 | 이유 |
|-------------|-------------------|--------|
| < 1,000 샘플 | 오버샘플링 또는 SMOTE | 다수 클래스 데이터를 잃을 여유가 없음 |
| 1,000 - 10,000 | SMOTE + 임계값 튜닝 | k-NN을 위한 소수 클래스 샘플이 충분함 |
| > 10,000 | 클래스 가중치 또는 언더샘플링 | 빠르고 소수 클래스 데이터가 충분함 |

## 4단계: 기법 적용하기

### 클래스 가중치 (항상 먼저 시도해 보세요)
- sklearn에서는: `class_weight='balanced'`
- 데이터 수정이 필요하지 않습니다
- 손실 기반 모델이라면 어떤 모델이든 작동합니다
- 기대값 측면에서 오버샘플링과 동일합니다

### SMOTE
- 학습 데이터에만 적용하세요 (테스트/검증 데이터에는 절대 적용하지 마세요)
- k=5 이웃을 사용하세요 (기본값)
- 최고의 결과를 위해 클래스 가중치와 결합하세요
- 경계 포인트 근처의 잡음 합성 포인트에 주의하세요

### 임계값 튜닝
- 모델을 학습하고 검증 세트에서 예측 확률을 얻으세요
- 0.05부터 0.95까지 임계값을 스윕하세요
- 선택한 지표가 최대화되는 임계값을 선택하세요
- 항상 검증 데이터로 튜닝하세요, 테스트 데이터로는 절대 튜닝하지 마세요

## 5단계: 적절하게 검증하기

- 층화 교차 검증(각 폴드에서 클래스 비율을 보존)을 사용하세요
- 원래의 (리샘플링되지 않은) 테스트 세트에서 지표를 보고하세요
- 분할 전에 SMOTE를 적용하지 마세요 -- 학습 폴드에만 적용하세요
- "항상 다수 클래스를 예측"하는 기준선과 비교하세요

## 6단계: 피해야 할 일반적인 실수

- 학습/테스트 분할 전에 전체 데이터셋에 SMOTE를 적용하는 것 (데이터 누수)
- 평가지표로 정확도를 사용하는 것
- 클래스 가중치를 먼저 시도하지 않는 것 (가장 단순한 접근법이며, 종종 충분합니다)
- 오버샘플링한 후 교차 검증하는 것 (합성 포인트가 폴드 간에 누수됩니다)
- 임계값 튜닝을 무시하는 것 (무료 성능 향상, 재학습이 필요하지 않습니다)
- 소규모 데이터셋에 무작위 언더샘플링을 사용하는 것 (너무 많은 데이터를 버립니다)

## 빠른 의사결정 트리

1. 불균형 비율이 < 3:1인가요? -> 클래스 가중치만 시도해 보세요
2. 데이터셋이 > 10,000 샘플인가요? -> 클래스 가중치 + 임계값 튜닝
3. 데이터셋이 < 1,000 샘플인가요? -> SMOTE + 클래스 가중치
4. 그렇지 않은 경우 -> SMOTE + 클래스 가중치 + 임계값 튜닝
5. 여전히 충분하지 않은가요? -> 균형 배깅 앙상블
