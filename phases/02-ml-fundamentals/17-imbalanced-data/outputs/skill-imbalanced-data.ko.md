# 불균형 데이터 전략 (Imbalanced Data Strategy)

불균형 분류를 다루기 위한 결정 체크리스트입니다. 이 순서를 따라 문제에 맞는 접근을 고르세요.

## 1단계: 불균형 측정

- 클래스별 샘플 수를 셉니다
- 불균형 비율을 계산합니다 (다수 / 소수)
- 경미: 비율 < 3:1 (예: 70/30)
- 중간: 비율 3:1 ~ 20:1 (예: 95/5)
- 심각: 비율 > 20:1 (예: 99/1)

## 2단계: 올바른 지표 선택

불균형 데이터셋에서는 정확도보다 precision/recall/F1을 선호하세요. 문제에 따라 고르세요:

| Situation | Primary Metric | Secondary Metric |
|-----------|---------------|-----------------|
| 양성을 놓치는 비용이 매우 큼 (사기, 질병) | Recall | F2 score |
| 오경보 비용이 큼 (스팸 필터, 추천) | Precision | F0.5 score |
| 둘 다 대략 동일하게 중요 | F1 score | MCC |
| 단일 순위 지표가 필요 | AUPRC | AUC-ROC |
| 데이터셋 간 비교가 필요 | MCC | AUPRC |

## 3단계: 재균형 전략 선택

### 불균형 심각도별

| Imbalance | First Try | Second Try | Avoid |
|-----------|-----------|------------|-------|
| 경미 (< 3:1) | 클래스 가중치 | 임계값 튜닝 | 오버샘플링 (불필요) |
| 중간 (3:1 ~ 20:1) | SMOTE + 클래스 가중치 | 그 위에 임계값 튜닝 | 언더샘플링 (데이터 손실 과다) |
| 심각 (> 20:1) | SMOTE + 클래스 가중치 + 임계값 | 균형 배깅 앙상블 | 언더샘플링만 |

### 데이터셋 크기별

| Dataset Size | Preferred Strategy | Reason |
|-------------|-------------------|--------|
| < 1,000 samples | 오버샘플링 또는 SMOTE | 다수 데이터를 잃을 여유가 없음 |
| 1,000 - 10,000 | SMOTE + 임계값 튜닝 | k-NN에 충분한 소수 샘플 |
| > 10,000 | 클래스 가중치 또는 언더샘플링 | 빠르고, 소수 데이터 충분 |

## 4단계: 기법 적용

### 클래스 가중치 (항상 먼저 시도)
- sklearn: `class_weight='balanced'`
- 데이터 수정 불필요
- 손실 기반 모델이면 동작
- 기댓값 측면에서 오버샘플링과 동등

### SMOTE
- 학습 데이터에만 적용 (테스트/검증에는 절대 금지)
- k=5 이웃 사용 (기본값)
- 클래스 가중치와 결합하면 최선
- 경계 근처의 노이즈 합성 점에 주의

### 임계값 튜닝
- 모델 학습 후 검증 세트에서 예측 확률을 얻음
- 임계값을 0.05부터 0.95까지 스윕
- 선택한 지표를 최대화하는 임계값 선택
- 항상 검증 데이터에서 튜닝, 테스트 데이터에서는 금지

## 5단계: 올바르게 검증

- 계층화 교차검증 사용 (각 폴드에서 클래스 비율 유지)
- 원래(리샘플링하지 않은) 테스트 세트에서 지표 보고
- 분할 전에 SMOTE를 적용하지 말 것 — 학습 폴드에만
- "항상 다수 예측" 베이스라인과 비교

## 6단계: 피해야 할 흔한 실수

- train/test 분할 전 전체 데이터셋에 SMOTE 적용 (데이터 누수)
- 평가 지표로 정확도 사용
- 클래스 가중치를 먼저 시도하지 않음 (가장 단순하고 종종 충분)
- 오버샘플링 후 교차검증 (합성 점이 폴드 간 누수)
- 임계값 튜닝 무시 (재학습 없이 얻는 성능)
- 작은 데이터셋에 랜덤 언더샘플링 (너무 많은 데이터 버림)

## 빠른 결정 트리

1. 불균형 비율 < 3:1인가? -> 클래스 가중치만 시도
2. 데이터셋 > 10,000 샘플인가? -> 클래스 가중치 + 임계값 튜닝
3. 데이터셋 < 1,000 샘플인가? -> SMOTE + 클래스 가중치
4. 그 외 -> SMOTE + 클래스 가중치 + 임계값 튜닝
5. 여전히 부족한가? -> 균형 배깅 앙상블
